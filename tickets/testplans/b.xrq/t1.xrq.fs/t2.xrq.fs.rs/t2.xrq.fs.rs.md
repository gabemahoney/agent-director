## Setup

Use the harness's db-reset isolation and a private temporary HOME. The existing
ts-helper seeds a waiting parent and waiting child. Set the existing settle_ms to
1000. The helper's write-family-transition invokes the actual gated store writer;
it does not backdate or patch either family's history.

## Steps

1. Confirm the waiting parent's initial status, then run a separate writer process
   changing its child from waiting to working; let that process exit.
2. Read only persisted SQL history to establish the real transition clock and old
   family value; do not call any reporting surface while the interval elapses.
3. Wait one interval, then run fresh CLI status/get/list processes.

## Pass criteria

The writer stored working with a waiting family base and a positive timestamp.
Each fresh reader reports working for the parent's family while the parent's own
state remains waiting. No status/get/list polls occur between the writer and the
first read after the interval. The driver emits its ordinary case and summary JSON.

```bash
set -euo pipefail
case_dir=$(mktemp -d)
trap 'rm -rf "$case_dir"' EXIT
export HOME="$case_dir/home"
mkdir -p "$HOME/.config/agent-director"
db="$HOME/.config/agent-director/state.db"
helper="${FAMILY_TS_HELPER:-/work/source/bin/ts-helper}"
"$helper" seed-spawn --store "$db" --id restart-parent --state waiting --create-store >/dev/null
"$helper" seed-spawn --store "$db" --id restart-child --state waiting >/dev/null
"$helper" seed-parent-child --store "$db" --parent-id restart-parent --child-id restart-child >/dev/null
printf '[state]\nsettle_ms = 1000\n' > "$HOME/.config/agent-director/config.toml"
agent-director status --instance-id restart-parent > "$case_dir/before.json"
jq -e '.state == "waiting" and .family_state == "waiting"' "$case_dir/before.json" >/dev/null
"$helper" write-family-transition --store "$db" --id restart-child --state working --settle-ms 1000 >/dev/null
history=$(/opt/driver/sql.sh -readonly "$db" "SELECT family_state || '|' || family_settled_state || '|' || (family_changed_ms > 0) FROM spawns WHERE instance_id='restart-parent'")
test "$history" = 'working|waiting|1'
sleep 1.1
agent-director status --instance-id restart-parent > "$case_dir/status.json"
agent-director get --instance-id restart-parent > "$case_dir/get.json"
agent-director list --parent '' > "$case_dir/list.json"
jq -e '.state == "waiting" and .family_state == "working"' "$case_dir/status.json" >/dev/null
jq -e '.state == "waiting" and .family_state == "working"' "$case_dir/get.json" >/dev/null
jq -e '[.spawns[] | select(.instance_id == "restart-parent" and .state == "waiting" and .family_state == "working")] | length == 1' "$case_dir/list.json" >/dev/null
printf '%s\n' 'fresh processes observed durable family transition without intervening polls'
```
