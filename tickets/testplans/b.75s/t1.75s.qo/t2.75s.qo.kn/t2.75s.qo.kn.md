# spawn-20: `kill` refuses a leftover of the id beside a `pending` row

Maps to Epic `t1.h98.aq` (Plan `b.h98`, honest kill), Task
`t2.h98.aq.dm`, Subtask `t3.h98.aq.dm.1d`, and Docker case spawn-20 (SRD
SR-20.9; SR-6.1's Leftover row; SR-1.4's `ErrTmuxSessionConflict` "not
this launch's session"). A `pending` row whose launching process stopped
before its create has a launch start and its own launch token, but no
session carries its label. A session in the container carries the label
of an earlier launch of the same id, from this store. `kill` of the id
finds that session as a Leftover. It is refused with
`ErrTmuxSessionConflict` and sends no kill. The session keeps running and
the row stays `pending`.

## Setup

Per-case DB-reset has wiped `~/.agent-director/state.db` and ended every
tmux server. The container has `agent-director`, `tmux`,
`sqlite3` and `jq` on PATH; plain `tmux` reaches the same default socket
agent-director resolves from `TMUX` / `TMUX_TMPDIR`. The script records
the live session ids first and, on exit, kills any session that was not
there before (by its `$N` id), so a regression cannot leak a session into
later cases (the next reset, which ends every tmux server, would end the
leftover too).
The instance id X is `sp20-<uuid>`, so no earlier case's leftover can
carry it. No `claude` runs and no hook is sent: the row is seeded with
`sqlite3` and the leftover runs `sleep`.

## Steps

1. Read this store's id with `sqlite3` from `store_meta` (`key =
   'store_id'`).
2. In the container, create a session named `cd-sp20-leftover` running
   `sleep 3600` and read its tmux id `$N` and the server's socket path.
   Label it as an earlier launch of X with `tmux set-option -t <$N>
   @ad_owner "ad1 <old token> <$N> X <store id>"` (five fields, the last
   this store's id), where the old token is 16 lowercase hex characters.
3. Seed X's `pending` row with `sqlite3`, as a launch whose process
   stopped after its row was written and before its create: recorded
   name `cd-sp20-leftover`, `launch_started_at` now in milliseconds,
   `launch_token` another 16-hex token (not the leftover's),
   `tmux_socket` the server's socket path, and no server or pane
   identity.
4. `agent-director kill --claude-instance-id X`, and read the last JSON
   line on stderr.
5. Check the session still runs (by `$N`) and read X's row with
   `sqlite3`.

## Pass criteria

- Step 1: the store id is 16 lowercase hex characters.
- Step 4: `kill` exits non-zero; `err_name == "ErrTmuxSessionConflict"`;
  the decoded `err_description` contains `not this launch's session`, the
  leftover's quoted name and tmux id (`"cd-sp20-leftover" ($N)`), `no
  kill was sent`, `Operator actions` and `README`. It names no command
  that ends a session: none of `kill-session`, `kill-pane`,
  `kill-server`, `agent-director kill`, `--include-finished`,
  `agent-director-admin`, `kill-finished`, `attach`;
  every `tmux ` in it is the prose "tmux session(s)", never tmux followed
  by a subcommand or flag. It carries neither label token nor the store
  id.
- Step 5: `tmux has-session -t <$N>` succeeds and the session's
  `@ad_owner` is unchanged; X's row has `state == 'pending'`, its
  `launch_token`, `row_version` 0 and no `pane_id`.

## Script

```bash
set -euo pipefail

db="$HOME/.agent-director/state.db"
x="sp20-$(cat /proc/sys/kernel/random/uuid)"
name=cd-sp20-leftover
# The leftover's token (an earlier launch) and the row's own token: two
# different 16-lowercase-hex tokens, never minted by this run.
old_token=0123456789abcdef
row_token=fedcba9876543210

session_ids() {
    tmux ls -F '#{session_id}' 2>/dev/null || true
}
before="$(session_ids)"
cleanup() {
    local sid
    for sid in $(session_ids); do
        case " $(printf '%s ' $before)" in
            *" $sid "*) ;;
            *) tmux kill-session -t "$sid" 2>/dev/null || true ;;
        esac
    done
}
trap cleanup EXIT

last_json() {
    printf '%s
' "$1" | awk '/^\{/{ln=$0} END{print ln}'
}

# Step 1: this store's id.
store_id="$(/opt/driver/sql.sh "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
if ! [[ "$store_id" =~ ^[0-9a-f]{16}$ ]]; then
    echo "FAIL: store_meta store_id is not 16 lowercase hex: [$store_id]" >&2
    exit 1
fi

# Step 2: a session labelled as an earlier launch of X, from this store.
sid="$(tmux new-session -d -s "$name" -P -F '#{session_id}' sleep 3600)"
socket="$(tmux display-message -p -t "$sid" '#{socket_path}')"
label="ad1 $old_token $sid $x $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
if [ -z "$socket" ]; then
    echo "FAIL: could not read the tmux socket path" >&2
    exit 1
fi

# Step 3: X's pending row, stopped before its create.
started_ms="$(date +%s%3N)"
/opt/driver/sql.sh "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name,
       relay_mode, launch_started_at, launch_token, tmux_socket)
   VALUES ('$x', 'pending', '/tmp', '$name', 'off', $started_ms,
       '$row_token', '$socket');"

# Step 4: kill of X is refused; no kill is sent.
set +e
err="$(agent-director kill --claude-instance-id "$x" 2>&1 >/dev/null)"
code=$?
set -e
if [ "$code" -eq 0 ]; then
    echo "FAIL: kill of $x exited 0 beside leftover $sid; stderr: $err" >&2
    exit 1
fi
envelope="$(last_json "$err")"
got="$(printf '%s' "$envelope" | jq -r '.err_name')"
if [ "$got" != "ErrTmuxSessionConflict" ]; then
    echo "FAIL: err_name=$got; want ErrTmuxSessionConflict; stderr: $err" >&2
    exit 1
fi
desc="$(printf '%s' "$envelope" | jq -r '.err_description')"
for want in "not this launch's session" "\"$name\" ($sid)" \
    "no kill was sent" "Operator actions" "README"; do
    case "$desc" in
        *"$want"*) ;;
        *)
            echo "FAIL: description lacks [$want]: $desc" >&2
            exit 1
            ;;
    esac
done
for forbidden in kill-session kill-pane kill-server "agent-director kill" \
    --include-finished agent-director-admin kill-finished attach \
    "$old_token" "$row_token" "$store_id"; do
    case "$desc" in
        *"$forbidden"*)
            echo "FAIL: description contains [$forbidden]: $desc" >&2
            exit 1
            ;;
    esac
done
# Every "tmux " is the prose "tmux session(s)", never a tmux command.
tmux_uses="$(printf '%s' "$desc" | grep -oE 'tmux +[^ ]+' || true)"
if printf '%s
' "$tmux_uses" | grep -vE '^(tmux sessions?)?$' >/dev/null; then
    echo "FAIL: description names a tmux command [$tmux_uses]: $desc" >&2
    exit 1
fi

# Step 5: the leftover still runs, its label untouched; X is still pending.
if ! tmux has-session -t "$sid" 2>/dev/null; then
    echo "FAIL: leftover session $sid no longer runs after the refused kill" >&2
    exit 1
fi
got_label="$(tmux show-options -t "$sid" -v @ad_owner)"
if [ "$got_label" != "$label" ]; then
    echo "FAIL: leftover label changed: [$got_label]; want [$label]" >&2
    exit 1
fi
row="$(/opt/driver/sql.sh -separator '|' "$db" \
  "SELECT state, launch_token, row_version, COALESCE(pane_id, '')
   FROM spawns WHERE claude_instance_id = '$x';")"
if [ "$row" != "pending|$row_token|0|" ]; then
    echo "FAIL: X's row is [$row]; want [pending|$row_token|0|]" >&2
    exit 1
fi

echo "spawn-20 ok: kill of pending $x refused beside leftover $sid; no kill sent; session runs; row pending"
```
