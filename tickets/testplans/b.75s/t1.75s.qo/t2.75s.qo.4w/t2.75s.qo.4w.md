# spawn-15: a finished row spawned again without the reuse opt-in collides and nothing changes

Maps to SRD SR-20.9 spawn-15 and SR-10.1/SR-10.2 (Epic 17 `t1.h98.i4`,
Task `t2.h98.i4.tm`, Subtask `t3.h98.i4.tm.pm`; spec `t3.h98.i4.y9.qu`):
without the opt-in (`--reuse-finished`) a `spawn` with the id of a
finished row is refused with `ErrInstanceIdCollision`, and the row, its
history and the tmux sessions are left exactly as they were. A caller that
wants the id back spawns again with the same id, opting in to reuse
(`--reuse-finished`); that is spawn-16.

Agent and hooks (SR-20.9, SR-22.9; collector "Driver mode"): X's spawn
runs with `PATH=/opt/driver/stand-in-claude:$PATH` prefixed, so its pane
process is the stand-in's interactive bash; every hook is typed into X's
recorded pane with `/opt/driver/pane-hook.sh <id> '<payload>'`. No hook is
piped from the case's own shell. The refused spawn carries the same prefix,
so a regression that launched would start the stand-in, not Claude Code.

Credential isolation (Epic 10's kill-10 pattern), before any tmux or
agent-director call: `ANTHROPIC_API_KEY` and `CLAUDE_CODE_OAUTH_TOKEN` are
unset and removed from the tmux server's global environment (tolerating no
server); after the launch, neither appears in
`/proc/<recorded pane_pid>/environ` ("credentials reached the agent").

## Setup

Per-case DB-reset. X's id is `sp15-<uuid>` (the trail is not reset
between cases, so records are selected by this id) and its session is
named `cd-sp15`, so the reset sweeps it; an EXIT trap also ends it by its
session id and removes the transcripts the case seeds.

1. Credential isolation as above.
2. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd /tmp
   --tmux-session-name cd-sp15 --claude-instance-id X` → exit 0, echoes
   X. Read X's `tmux_socket`, `pane_id` and `pane_pid` with `sqlite3`, the
   pane's session id `$N`, and check the pane environment.
3. Seed two transcripts under `$HOME/.claude/projects/-tmp/` and type a
   SessionStart for each into X's pane (`sp15-s0-<tag>`, then
   `sp15-s1-<tag>` = S1): the second rotates the first into X's
   `session_history`, so the history check below compares a non-empty
   history. A `sqlite3` read shows `waiting`, S1 and `pid` = `pane_pid`.
4. Type a SessionEnd into X's pane → X is `ended`.
5. End X's session by its `$N`, then wait (bounded, 5 s) until the
   processes X records have exited: `pid`, `pane_pid` and, when this was
   its server's last session, `tmux_server_pid` (resume-1's wait).

## Steps

1. Capture X's full `spawns` row (`SELECT *`, with a header, so every
   column, `row_version` and `life_number` included), X's
   `session_history` entries (`SELECT *`, ordered) and the set of tmux
   session ids on X's socket.
2. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd /tmp
   --tmux-session-name cd-sp15 --claude-instance-id X` (no opt-in) → exit
   1; the last JSON line on stderr has `err_name` `ErrInstanceIdCollision`.
3. Read the row, the history and the session set again; read the trail
   (`~/.agent-director/ad-trail.jsonl`).

## Pass criteria

- Setup: the spawn exits 0; no credential variable in the pane environ;
  after the second SessionStart X is `waiting|S1|<pane_pid>`; after
  SessionEnd it is `ended`; the history holds at least one entry; X's
  recorded processes exit within 5 s of its session ending.
- Step 2: exit 1 and `ErrInstanceIdCollision`.
- Step 3: the row read and the history read are byte-identical to the
  captured ones; the session set is unchanged (no session was created);
  the trail holds no `ad.spawn.reused` record for X.

Each failed check prints a `FAIL:` line naming what was expected and what
was seen; the final line summarises what was checked.

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN
tmux set-environment -g -u ANTHROPIC_API_KEY 2>/dev/null || true
tmux set-environment -g -u CLAUDE_CODE_OAUTH_TOKEN 2>/dev/null || true

db="$HOME/.agent-director/state.db"
trail="$HOME/.agent-director/ad-trail.jsonl"
standin_path="/opt/driver/stand-in-claude:$PATH"
jsonl_dir="$HOME/.claude/projects/-tmp"
uuid="$(cat /proc/sys/kernel/random/uuid)"
tag="${uuid:0:8}"
x="sp15-$uuid"
name=cd-sp15
s0="sp15-s0-$tag"
s1="sp15-s1-$tag"
err_file="$(mktemp)"
sock=""
x_sid=""
fail() { echo "FAIL: $*"; exit 1; }
cleanup() {
    [ -z "$x_sid" ] || tmux ${sock:+-S "$sock"} kill-session -t "$x_sid" 2>/dev/null || true
    rm -f "$err_file" "$jsonl_dir/$s0.jsonl" "$jsonl_dir/$s1.jsonl"
}
trap cleanup EXIT

# end_and_wait <id> <tmux target>: ends the row's tmux session, then waits
# (bounded, 5 s) until the processes the row records have exited (no /proc
# entry): its pid and pane_pid, and its tmux_server_pid when the session was
# the server's last. A server that holds other sessions must still run after.
end_and_wait() {
    local id="$1" target="$2" rec rpid rpane rserver rsock n left p end
    rec="$(sqlite3 -readonly "$db" "SELECT IFNULL(pid,'') || '|' || IFNULL(pane_pid,'') || '|' || IFNULL(tmux_server_pid,'') || '|' || IFNULL(tmux_socket,'') FROM spawns WHERE claude_instance_id = '$id';")"
    IFS='|' read -r rpid rpane rserver rsock <<<"$rec"
    [[ "$rpid|$rpane|$rserver" =~ ^[0-9]+\|[0-9]+\|[0-9]+$ ]] || fail "$id records pid|pane_pid|tmux_server_pid [$rpid|$rpane|$rserver]; want all set"
    n="$(tmux ${rsock:+-S "$rsock"} list-sessions 2>/dev/null | wc -l)"
    tmux ${rsock:+-S "$rsock"} kill-session -t "$target" || fail "kill-session -t $target of $id failed"
    set -- "$rpid" "$rpane"
    [ "$n" -gt 1 ] || set -- "$@" "$rserver"
    end=$(( $(date +%s%N) + 5000000000 ))
    while :; do
        left=""
        for p in "$@"; do [ ! -e "/proc/$p" ] || left+=" $p"; done
        [ -n "$left" ] || break
        [ "$(date +%s%N)" -lt "$end" ] || fail "$id's recorded process(es)$left still running 5 s after its session $target ended"
        sleep 0.1
    done
    [ "$n" -le 1 ] || [ -e "/proc/$rserver" ] || fail "tmux server $rserver of $id ended although it held $((n - 1)) other session(s)"
}
row_field() { sqlite3 -readonly "$db" "SELECT IFNULL($2,'') FROM spawns WHERE claude_instance_id = '$1';"; }
no_creds() {
    local v
    for v in ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN; do
        if grep -qz "^$v=" "/proc/$1/environ"; then
            fail "credentials reached the agent: $v is in /proc/$1/environ ($2)"
        fi
    done
}
hook() { /opt/driver/pane-hook.sh "$1" "$2" >/dev/null || fail "hook $2 for $1 exited non-zero"; }
session_start() { printf '{"hook_event_name":"SessionStart","source":"startup","transcript_path":"%s"}' "$1"; }
session_end='{"hook_event_name":"SessionEnd","reason":"logout"}'
last_json() { printf '%s' "$1" | awk '/^\{/{ln=$0} END{print ln}'; }
full_row() { sqlite3 -readonly -header -nullvalue '<null>' -separator '|' "$db" "SELECT * FROM spawns WHERE claude_instance_id = '$x';"; }
full_hist() { sqlite3 -readonly -header -nullvalue '<null>' -separator '|' "$db" "SELECT * FROM session_history WHERE claude_instance_id = '$x' ORDER BY history_id;"; }
session_set() { { tmux ${sock:+-S "$sock"} list-sessions -F '#{session_id}' 2>/dev/null || true; } | sort; }
trail_count() {
    [ -f "$trail" ] || { echo 0; return; }
    jq -c --arg e "$1" --arg x "$2" 'select(.event == $e and .claude_instance_id == $x)' "$trail" | grep -c . || true
}
# spawn_x <args...>: a stand-in spawn of X; stdout in $out, stderr in $err_file, exit status in $rc.
spawn_x() {
    set +e
    out="$(PATH="$standin_path" agent-director spawn --claude-instance-id "$x" "$@" 2>"$err_file")"
    rc=$?
    set -e
}

mkdir -p "$jsonl_dir"

# Setup 2: spawn X with the stand-in.
spawn_x --cwd /tmp --tmux-session-name "$name"
[ "$rc" -eq 0 ] || fail "spawn of X exited $rc; want 0: $(cat "$err_file")"
[ "$(jq -r '.claude_instance_id' <<<"$out")" = "$x" ] || fail "spawn of X echoed [$out]; want id $x"
sock="$(row_field "$x" tmux_socket)"
pane="$(row_field "$x" pane_id)"
pane_pid="$(row_field "$x" pane_pid)"
[ -n "$pane" ] && [[ "$pane_pid" =~ ^[0-9]+$ ]] || fail "X records pane_id|pane_pid [$pane|$pane_pid]; want both set"
x_sid="$(tmux ${sock:+-S "$sock"} display-message -p -t "$pane" '#{session_id}')"
[[ "$x_sid" =~ ^\$[0-9]+$ ]] || fail "X's pane $pane gave session id [$x_sid]"
no_creds "$pane_pid" "X after spawn"

# Setup 3-4: two SessionStarts (the first is rotated into the history), then SessionEnd.
for s in "$s0" "$s1"; do
    echo '{}' > "$jsonl_dir/$s.jsonl"
    hook "$x" "$(session_start "$jsonl_dir/$s.jsonl")"
done
got="$(sqlite3 -readonly "$db" "SELECT state || '|' || IFNULL(claude_session_id,'') || '|' || IFNULL(pid,'') FROM spawns WHERE claude_instance_id = '$x';")"
[ "$got" = "waiting|$s1|$pane_pid" ] || fail "X after SessionStart state|session|pid [$got]; want waiting|$s1|$pane_pid"
hook "$x" "$session_end"
st="$(row_field "$x" state)"
[ "$st" = "ended" ] || fail "X after SessionEnd state=$st; want ended"
n_hist="$(sqlite3 -readonly "$db" "SELECT COUNT(*) FROM session_history WHERE claude_instance_id = '$x';")"
[ "$n_hist" -ge 1 ] || fail "X's session_history has $n_hist entries; want at least 1 (else the history check proves nothing)"

# Setup 5: end X's session by its $N and wait for its recorded processes.
end_and_wait "$x" "$x_sid"
x_sid=""

# Step 1: capture.
row_before="$(full_row)"
hist_before="$(full_hist)"
set_before="$(session_set)"
[ -n "$row_before" ] || fail "X's row is missing before the spawn"
ver_life="$(sqlite3 -readonly "$db" "SELECT row_version || '|' || life_number FROM spawns WHERE claude_instance_id = '$x';")"

# Step 2: the same spawn without the opt-in collides.
spawn_x --cwd /tmp --tmux-session-name "$name"
[ "$rc" -eq 1 ] || fail "spawn of finished X without --reuse-finished exited $rc; want 1: $(cat "$err_file")"
err_name="$(last_json "$(cat "$err_file")" | jq -r '.err_name')"
[ "$err_name" = "ErrInstanceIdCollision" ] || fail "spawn without opt-in err_name=[$err_name]; want ErrInstanceIdCollision: $(cat "$err_file")"

# Step 3: nothing changed.
row_after="$(full_row)"
[ "$row_after" = "$row_before" ] || fail "X's row changed: [$row_after]; was [$row_before]"
hist_after="$(full_hist)"
[ "$hist_after" = "$hist_before" ] || fail "X's session_history changed: [$hist_after]; was [$hist_before]"
set_after="$(session_set)"
[ "$set_after" = "$set_before" ] || fail "tmux session set changed: [$set_after]; was [$set_before]"
n_reused="$(trail_count ad.spawn.reused "$x")"
[ "$n_reused" -eq 0 ] || fail "$n_reused ad.spawn.reused record(s) for X; want none"

echo "spawn-15 ok: finished X ($x, row_version|life $ver_life, $n_hist history entr(y/ies)) spawned again without --reuse-finished -> ErrInstanceIdCollision; row, history and session set unchanged; no ad.spawn.reused"
```
