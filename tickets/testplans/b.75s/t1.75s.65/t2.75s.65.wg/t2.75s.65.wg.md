# relay-4: second decide returns ErrAlreadyDecided

Per SRD §6.2: the decide UPDATE is guarded by `decision IS NULL`.
First call wins; second call sees a populated decision column and
the UPDATE no-ops; the verb surfaces ErrAlreadyDecided.

## Setup

Per-case DB-reset.

## Steps

1. Seed row, background hook.
2. First decide --decision allow → exits 0.
3. Second decide --decision deny → non-zero with
   err_name=ErrAlreadyDecided.

## Pass criteria

- Second decide exits non-zero with the typed error.

## Script

```bash
set -euo pipefail
trap 'if [ -n "${hook_pid:-}" ]; then kill "$hook_pid" 2>/dev/null || true; fi' EXIT
sqlite3 "$HOME/.agent-director/state.db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode)
   VALUES ('id-r4', 'waiting', '/tmp', 'cd-r4', 'on');"

hook_out=$(mktemp)
( printf '%s' '{"hook_event_name":"PermissionRequest","tool_name":"Bash"}' \
  | AGENT_DIRECTOR_RELAY_MODE=on \
    AGENT_DIRECTOR_INSTANCE_ID=id-r4 \
    agent-director hook >"$hook_out" 2>/dev/null ) &
hook_pid=$!

# decide now REQUIRES --request-token: read the token the backgrounded
# hook minted for the open permission_requests row. The SAME token must
# be reused on the second decide so it targets the already-decided row.
token=""
for _ in $(seq 1 50); do
    token=$(sqlite3 "$HOME/.agent-director/state.db" \
      "SELECT request_token FROM permission_requests
       WHERE claude_instance_id='id-r4' AND decision IS NULL
       ORDER BY request_id DESC LIMIT 1;")
    [ -n "$token" ] && break
    sleep 0.1
done
if [ -z "$token" ]; then
    echo "FAIL: no open permission_requests row for id-r4 (hook never upserted)"; exit 1
fi

agent-director decide --claude-instance-id id-r4 --request-token "$token" --decision allow >/dev/null
wait "$hook_pid"

# Second decide AFTER the hook has exited — reuse the SAME request_token
# so it targets the row the first decide already wrote, tripping the
# IS-NULL guard.
stderr_file=$(mktemp)
if agent-director decide --claude-instance-id id-r4 --request-token "$token" --decision deny 2>"$stderr_file" >/dev/null; then
    echo "FAIL: second decide exited 0; want ErrAlreadyDecided"; exit 1
fi
err=$(jq -r '.err_name' "$stderr_file")
if [ "$err" != "ErrAlreadyDecided" ]; then
    echo "FAIL: err_name=$err; want ErrAlreadyDecided"; exit 1
fi
echo "relay-4 ok: second decide → ErrAlreadyDecided"
```
