# state-changed-at

Shell testplan for get's and list's raw `state_changed_at` (b.k6i), run as
`make test-docker EPIC=state-changed-at DRIVER_MODE=shell`. The driver resets
the store before the one self-contained case. No credentials, agent, tmux
session, background process or wall-clock wait is used: the case seeds fixed
`state_changed_ms` values through `/opt/driver/sql.sh` and reads them back
through the shipped binary.

It covers only the wire contract: a stored millisecond stamp keeps its
fraction, a zero stamp reads as the Unix epoch, every agent's row and a
pending row carry it, get and list agree, status has none, and no read writes
the stamp. Which writes move the stamp, settling and stuck stay unit tests.
The case prints one compact JSON evidence line of the observed values.

The orchestrator runs it. A job-scheduler context for it creates and chowns
every path the job writes in one `RUN`, as
`tickets/testplans/b.vis/full-unit-job/Dockerfile` does.
