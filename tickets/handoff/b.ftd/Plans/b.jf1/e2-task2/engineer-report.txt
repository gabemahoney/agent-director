AUTHENTICATED STORE ENTRY
InsertCursorRequest is a narrow gateway entry, not a fake HookGate. Inside BEGIN IMMEDIATE it re-reads Spawn and complete persisted CursorRuntime, verifies agent/token/life/pane pid/start/session/current nonterminal state, exact runtime/connection/pipe/fd identity and nonretirement, and calls independent VerifyRuntime + VerifyPane evidence after lock acquisition. It checks time after the potentially slow evidence checks. Atomic check_permission state/settle/version/liveness changes plus permission insert/cap eviction reuse existing SQL conventions. Existing immediate-parent hook gate untouched.
Hook process fields are NULL, never gateway PID; finite millisecond-rounded SettledAt persists. On relay on: decision deadline = admission + configured relay window; settlement = deadline + 4-second reserve. Relay off: settlement immediately in past for truthful immediate fallen_back/pane availability. Native lifetime is bounded: 30 minutes when relay off, or fixed settlement + 30 minutes with relay on. Prompt-generation timer pauses while actual open requests have their own bounded lifetimes; it does not prematurely kill a long permission wait.
AckCursorDecision reuses existing ack/timeout SQL under the same authenticated transaction check and exact immutable persisted settlement. At/timeout/deadline are evaluated after acquiring the lock. A recorded allow cannot be acknowledged after its approval deadline; it is preserved unacknowledged rather than rewritten or emitted late. Timeout denial gets its own durable ack; timeout decision mutation emits established trail event. Failed insert/ack emits ZERO relay ACP reply bytes, including deny. Admission/storage/identity failures are fatal bounded failures with no generic deny-envelope forwarding. Policy rejections occur before admission and are a separately labeled non-relay response path.

ARBITRATION / WRITER
One event-loop request arbiter mediates API decision, actual native key, timeout, cancellation and execution proof. First-writer store predicates preserve API/native races. API decision is not ack; native claim is not relay delivered_at.
Every relay response is enqueued only after own committed delivered_at. Each outgoingFrame carries a final request/authority guard, fixed deadline and completion callback. Serialized writer checks current binding, exact request acknowledgement/native claim, retirement/cancellation and deadline before Write. It rechecks transport expiry after slow evidence checks, so a guard which resumes after transport expiry cannot write late. Queued allows expire at decision deadline; denials expire by settlement. All queued responses retire at hard settlement/cancellation, including deny. No uncertain write is replayed. Existing general protocol frames retain bounded FIFO/single writer behavior.
A still-open unacknowledged native request can remain available after relay settlement. A fresh deliberate pane selection can resolve that native request, including superseding an unacknowledged recorded API decision after settlement. Keys selected during the expired relay decision window are refused instead of carried into fallback. Once an answer was queued/uncertain, keys are retired and no replay becomes a pane answer. Native hard timeout, user interruption, policy-required session cancellation, intentional exit and shutdown retire controllers; terminal requests cannot revive.
