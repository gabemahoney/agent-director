# kill-10: kill aborts a pending launch; the row stays pending

Maps to SRD SR-20.9 kill-10 (AC-KILL-17; Epic `t1.h98.aq`, the honest
kill; SR-6.1, SR-22.5). A caller that bounds `pending` by its launch
start aborts a launch whose agent never reports in with `kill`. X is
spawned and its agent never reports in (no hook is synthesised), so X is
`pending` with its session up. `kill` of X finds X's labelled session,
kills its pane and session, waits until the recorded pane process is
gone and returns 0 with `kill_sent` true. The session is gone and X is
still `pending`: `kill` never changes a row's state (`find-missing`'s
later mark is covered by unit tests, SR-20.6).

## Setup

Per-case DB-reset. The spawn runs with
`PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the
`agent-director` command (tmux finds `claude` on the launching process's
PATH), so X's pane process is the stand-in claude's interactive bash,
which sends no hook by itself and exits on the pane kill's SIGHUP. No
hook is synthesised at all. As a second guard, before any tmux or
agent-director call the script:

1. unsets `ANTHROPIC_API_KEY` and `CLAUDE_CODE_OAUTH_TOKEN`;
2. removes both from the global environment of a tmux server already
   answering on the default socket the spawn uses (`tmux
   set-environment -g -u`), tolerating "no server";
3. right after the spawn, before any state assertion, checks neither
   name appears in `/proc/<recorded pane_pid>/environ`, failing with
   "credentials reached the agent".

X's session is named `cd-k10` (the harness's reserved prefix; the
DB-reset ends it with every tmux server); an EXIT trap also removes it
by its session id on the
recorded socket.

## Steps

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd
   /tmp --tmux-session-name cd-k10` → X's id.
2. Read X's `tmux_socket`, `pane_id` and `pane_pid` with `sqlite3`; get
   X's session id `$N` from tmux (the recorded pane's `#{session_id}` on
   that socket). Run the credential check above.
3. `status` X → `pending`.
4. `agent-director kill --claude-instance-id X`.
5. Check X's session by `$N`, the recorded pane pid and `status` X.

## Pass criteria

- Neither credential variable is in the pane process's environment.
- `status` X is `pending` before the kill.
- kill exits 0 and its stdout JSON has `kill_sent == true`.
- `tmux -S <socket> has-session -t '<$N>'` returns non-zero after the
  kill, and the recorded pane pid is gone (absent or a zombie).
- `status` X is still `pending` after the kill.

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN
tmux set-environment -g -u ANTHROPIC_API_KEY 2>/dev/null || true
tmux set-environment -g -u CLAUDE_CODE_OAUTH_TOKEN 2>/dev/null || true

db="$HOME/.agent-director/state.db"
standin_path="/opt/driver/stand-in-claude:$PATH"
fail() { echo "FAIL: $*"; exit 1; }
sock=""
sid=""
trap '[ -z "$sid" ] || tmux -S "$sock" kill-session -t "$sid" 2>/dev/null || true' EXIT

# The spawn's stderr (a "pre-trust failed" note: no ~/.claude.json here) is
# shown only if the spawn fails, so the case's last line stays the summary.
spawn_err="$(mktemp)"
spawn_out="$(PATH="$standin_path" agent-director spawn --cwd /tmp --tmux-session-name cd-k10 2>"$spawn_err")" \
    || fail "spawn exited non-zero: $(cat "$spawn_err")"
id="$(jq -r '.claude_instance_id' <<<"$spawn_out")"
[ -n "$id" ] && [ "$id" != "null" ] || fail "spawn returned no claude_instance_id: $spawn_out"

IFS='|' read -r sock pane pane_pid < <(/opt/driver/sql.sh -readonly "$db" \
    "SELECT IFNULL(tmux_socket,'') || '|' || IFNULL(pane_id,'') || '|' || IFNULL(pane_pid,'') FROM spawns WHERE claude_instance_id = '$id';")
[ -n "$sock" ] && [ -n "$pane" ] && [[ "$pane_pid" =~ ^[0-9]+$ ]] \
    || fail "recorded tmux_socket|pane_id|pane_pid=[$sock|$pane|$pane_pid]; want all set"
sid="$(tmux -S "$sock" display-message -p -t "$pane" '#{session_id}')"
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "pane $pane gave session id [$sid]"

for v in ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN; do
    if grep -qz "^$v=" "/proc/$pane_pid/environ"; then
        fail "credentials reached the agent: $v is in /proc/$pane_pid/environ"
    fi
done

state="$(agent-director status --claude-instance-id "$id" | jq -r '.state')"
[ "$state" = "pending" ] || fail "before kill state=$state; want pending (the agent reported in on its own?)"

out="$(agent-director kill --claude-instance-id "$id")" || fail "kill exited non-zero; want 0"
sent="$(jq -r '.kill_sent' <<<"$out")"
[ "$sent" = "true" ] || fail "kill_sent=$sent; want true (stdout: $out)"

if tmux -S "$sock" has-session -t "$sid" 2>/dev/null; then
    fail "X's session $sid still exists after kill"
fi
if [ -e "/proc/$pane_pid" ]; then
    st="$(sed -E 's/^.*\) //' "/proc/$pane_pid/stat" 2>/dev/null | cut -d' ' -f1 || true)"
    [ -z "$st" ] || [ "$st" = "Z" ] || fail "recorded pane process $pane_pid still running (state $st) after kill"
fi
state="$(agent-director status --claude-instance-id "$id" | jq -r '.state')"
[ "$state" = "pending" ] || fail "after kill state=$state; want pending (kill never changes a row's state)"

echo "kill-10 ok: pending X ($id) → kill exit 0 with kill_sent true; session $sid and pane process $pane_pid gone; X still pending"
```
