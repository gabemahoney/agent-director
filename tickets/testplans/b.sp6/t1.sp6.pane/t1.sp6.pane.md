# idle-screen

Shell testplan for the `idle_screen` Displayed State and
`idle_screen_availability` (PRD t1.ob8.s4, SRD t1.ob8.gw, Epics t1.sp6.rk and
t1.sp6.6s). The driver resets a binary-derived store before each independent
case. No credentials or real agent are needed: a case spawns the stand-in
Claude or Codex (an interactive bash in a real tmux pane) and types its
`SessionStart` and `UserPromptSubmit` into the pane with
`/opt/driver/pane-hook.sh`, so the shipped binary samples a real owned pane on
every `status`, `get` and `list`. No case waits out a timeout: the committed
pane baseline has no public writer but a read, so a case moves its start
(`spawns.pane_since_ms`) back with `/opt/driver/sql.sh`, a reviewed exception
to the raw-SQL rule like the needs-intelligence group's ownership columns. The
Cursor case seeds its rows and request with `sql.sh` too.

The cases cover, through public reads, refusals and the trail only, the
configured `[state] idle_screen_timeout_seconds` read, the display shown
alike to independent processes, the per-spawn `--idle-screen-timeout-seconds`
override recorded and winning over the configuration, and Cursor's
unavailability with its `needs_intelligence` detection retained. Each
displayed entry writes exactly one `ad.spawn.displayed_state_transition`
record (`instance_id`, `prior_state`, `new_state`, `event`, `ts`, with `ts`
the shown `since`); a read that displays no change writes none. The trail
(`~/.config/agent-director/ad-trail.jsonl`) is not reset between cases, so
records are selected by the case's own instance ids. Expected wire values come
from the shared `cmd/agent-director/testdata/display/idle_screen.json` and
`needs_intelligence.json`. Exact timeout and settle boundaries, capture
failures, races and direct moves between the two states stay unit tests
(`pkg/api/idle_screen_test.go`, `idle_screen_settle_test.go`). Each case
prints one compact JSON evidence line of observed values; on a binary without
the v14 columns (`observation_version`, `display_observation`, `display_exit`,
`idle_screen_timeout_seconds` and the pane baseline) it prints
`availability: unavailable` and exits 77, never a pass. The runnable driver is
`test/driver/idle-screen.sh`.
