# Long launch — `long-launch` testplan

Regression for b.xhh: launch payloads over tmux's command-message limit
reach a real pane process on spawn, reuse and resume. Run with
`make test-docker EPIC=long-launch DRIVER_MODE=shell`.

The existing recording driver stand-in is selected for both Claude and
Codex. It ignores agent settings while recording the argv/env produced by
each agent's actual composer. Cursor's synthetic ACP process and the raw
Linux argument boundaries are covered by `test/realtmux/long_launch*_test.go`.
The dedicated scheduler kit repeats both suites on tmux 3.2a and 3.3a;
the standard integration image supplies 3.3a only.
