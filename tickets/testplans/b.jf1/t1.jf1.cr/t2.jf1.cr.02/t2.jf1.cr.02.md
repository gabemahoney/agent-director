# Test case: Blocking plan, independent hold and cancellation

Maps to E2 AC2; SR-4.1, SR-5.1/5.2, SR-9.2. Mode early_end's turn-end retirement maps to Bug b.gwj.

## Setup

The harness reset supplies its clean baseline. Source the shared driver, which creates an additional private synthetic Cursor namespace with an override store and control sentinel. All SQL, including raw-byte observer queries and faults, goes through /opt/driver/sql.sh. Source mount and shipped binary must match the scheduler's full commit. No authenticated runtime is used.

## Steps

Execute the ordered block below. Each check tests the stated caller-visible state, preserved fields, request correlation, committed evidence, actual wire bytes or process lifetime. Any injected fault is a test fixture action; it does not establish a production configuration feature.

Mode early_end: the peer sends the permission and plan requests, then ends its turn (end_turn) without waiting for answers. Once the gateway's turn_outcome record shows end_turn, both requests are proven gone with proven_gone_how turn_end, still undecided, and the row reads waiting and get lists no open permission request. A later decide of each request succeeds with delivery not_confirmed and stores its verdict, which never reaches the agent. After the gateway and runtime exit, the peer has received no reply frame for either request, so nothing was delivered late or fabricated, and no session/cancel.

Mode cancel_busy: the peer waits for answers. The row holds check_permission, send-keys and pause are refused, a deny of the plan reaches the peer as rejected while the permission stays open, and a real terminal cancellation (Ctrl-C) sends one session/cancel and retires the permission with no reply frame.

## Pass criteria

Every assertion passes and one final JSON object contains this case ID, stable check names, status pass, authenticated_cursor false and separate variable facts. Do not treat an exit code alone as evidence. The collector must be executed externally before claiming a case pass.

```bash
set -euo pipefail
receipts=$(mktemp /tmp/cr-plan-receipts-XXXXXX)
for mode in early_end cancel_busy; do
(
source /work/source/test/driver/cursor-owned-launch.sh
relay_scenario plan
if [[ $mode == early_end ]]; then jq '.completeBeforeAnswers=true' "$case_dir/scenario" > "$case_dir/next"; mv "$case_dir/next" "$case_dir/scenario"; fi
relay_start
wait_until request_count_is 2
plan_tool=$(jq -r '.requests[]|select(.id=="plan")|.params.toolCallId' "$case_dir/scenario")
permission_tool=$(jq -r '.requests[]|select(.id=="permission")|.params.toolCall.toolCallId' "$case_dir/scenario")
plan_token=$(request_token "$plan_tool"); permission_token=$(request_token "$permission_tool")
if [[ $mode == early_end ]]; then
 # b.gwj: a turn that ends with requests undecided retires them; the row reports the agent's waiting.
 transcript=$(sql "SELECT jsonl_path FROM spawns WHERE instance_id='$id';")
 turn_ended() { jq -se 'any(.[]; .kind=="turn_outcome" and .data.stop_reason=="end_turn")' "$transcript" >/dev/null; }
 wait_until turn_ended
 retired() { [[ $(sql "SELECT count(*) FROM permission_requests WHERE instance_id='$id' AND proven_gone_at IS NOT NULL AND proven_gone_how='turn_end' AND decision IS NULL AND delivered_at IS NULL;") == 2 ]]; }
 wait_until retired
 wait_state waiting
 ad get --instance-id "$id" | jq -e '.state=="waiting" and (.permission_requests // [])==[]' >/dev/null
 # A late decide stores its verdict and reports it not_confirmed; it never reaches the agent.
 late_decide() {
  relay_decide "$1" "$2" >"$case_dir/late-out"
  jq -e '.delivery=="not_confirmed"' "$case_dir/late-out" >/dev/null
  [[ $(sql "SELECT decision FROM permission_requests WHERE request_token='$1';") == "$2" ]]
 }
 late_decide "$plan_token" deny; late_decide "$permission_token" allow
 [[ $(sql "SELECT count(*) FROM permission_requests WHERE instance_id='$id' AND proven_gone_how='turn_end';") == 2 ]]
 tmux -S "$socket" send-keys -t "$pane" -l -- /exit; tmux -S "$socket" send-keys -t "$pane" Enter
else
 wait_state check_permission
 [[ $(sql "SELECT count(*) FROM permission_requests WHERE instance_id='$id' AND proven_gone_at IS NULL;") == 2 ]]
 relay_guard
 relay_decide "$plan_token" deny >/dev/null
 wait_until reply_count_is 1
 frames | jq -se '[.[]|select(.id=="plan")]|length==1 and .[0].result.outcome.outcome=="rejected"' >/dev/null
 [[ $(sql "SELECT decision IS NULL AND delivered_at IS NULL AND proven_gone_at IS NULL FROM permission_requests WHERE request_token='$permission_token';") == 1 ]]
 # Real terminal cancellation retires the still-open permission; no fabricated answer.
 tmux -S "$socket" send-keys -t "$pane" C-c
fi
wait_gone "$gateway"; wait_gone "$runtime"
cancels=$(frames | jq -sc '[.[]|select(.method=="session/cancel")]|length')
if [[ $mode == cancel_busy ]]; then [[ $cancels == 1 ]]; else [[ $cancels == 0 ]]; fi
if [[ $mode == early_end ]]; then answered='["plan","permission"]'; else answered='["permission"]'; fi
[[ $(frames | jq -sc --argjson ids "$answered" '[.[]|select((.id|IN($ids[])) and (has("method")|not))]|length') == 0 ]]
kill -0 "$control_sentinel"
if [[ $mode == early_end ]]; then
 relay_receipt t2.jf1.cr.02 '["AC2.end-turn-retires","AC2.end-turn-no-late-answer"]' >> "$receipts"
else
 relay_receipt t2.jf1.cr.02 '["AC2.blocking-plan","AC2.independent-permission","AC2.reject","AC2.cancel-no-late-answer"]' >> "$receipts"
fi
)
done
jq -s '{case:"t2.jf1.cr.02",status:"pass",checks:["AC2.end-turn-retires","AC2.end-turn-no-late-answer","AC2.blocking-plan","AC2.independent-permission","AC2.reject","AC2.cancel-no-late-answer"],authenticated_cursor:false,facts:{runs:map(.facts)}}' "$receipts"

```
