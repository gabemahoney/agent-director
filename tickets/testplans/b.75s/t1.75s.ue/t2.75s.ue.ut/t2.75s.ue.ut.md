# resume-7: parent_id is re-derived on every resume

Per SRD §7.5: `parent_id` records who currently owns the Spawn, not
who originally created it. spawn B inside A → B's parent is A.
Resume B from a bare shell → B's parent goes NULL. Epic 8
(`t1.h98.xw`, SR-20.9, SR-22.9): a hook moves the row only when it
comes from the row's own pane process, so B's hooks are typed into B's
pane.

## Setup

Per-case DB-reset. The spawns and the resume run with
`PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the
`agent-director` command, so each pane process is the stand-in claude's
interactive bash. Hooks are typed into B's pane with
`/opt/driver/pane-hook.sh <id> '<payload>'` (see the collector's
"Driver mode").

## Steps

1. Spawn A (no parent env).
2. Spawn B with `AGENT_DIRECTOR_INSTANCE_ID=<A>` in env → B's
   parent_id is A.
3. Type a SessionStart into B's pane → claude_session_id populated.
4. Seed JSONL on disk.
5. Type a SessionEnd into B's pane → state=ended.
6. Free B's tmux session via tmux kill-session, then wait (bounded,
   5 s) until B's recorded `pid` and `pane_pid` (read with `sqlite3`)
   have exited, so the resume's lookup does not meet B's pane process
   still exiting. A's session keeps the tmux server running (like
   kill-4's bystander), so the server is checked to still run instead.
7. `resume B` from a bare shell (env unset) → B's parent_id is now
   NULL.

## Pass criteria

- B's parent_id before resume is A.
- B's parent_id after resume is empty (NULL in DB).

## Script

```bash
set -euo pipefail
standin_path="/opt/driver/stand-in-claude:$PATH"
db="$HOME/.agent-director/state.db"
fail() { echo "FAIL: $*"; exit 1; }
# end_and_wait <id> <tmux target>: ends the row's tmux session, then waits
# (bounded, 5 s) until the processes the row records have exited (no /proc
# entry), so resume's lookup meets neither a pane process nor a tmux server
# that is still exiting: its pid and pane_pid, and its tmux_server_pid when
# the session was the server's last. A server that holds other sessions
# keeps running (as kill-4's bystander does), and must still run after.
end_and_wait() {
    local id="$1" target="$2" rec rpid rpane rserver rsock n left p end
    rec="$(sqlite3 -readonly "$db" "SELECT IFNULL(pid,'') || '|' || IFNULL(pane_pid,'') || '|' || IFNULL(tmux_server_pid,'') || '|' || IFNULL(tmux_socket,'') FROM spawns WHERE claude_instance_id = '$id';")"
    IFS='|' read -r rpid rpane rserver rsock <<<"$rec"
    [[ "$rpid|$rpane|$rserver" =~ ^[0-9]+\|[0-9]+\|[0-9]+$ ]] || fail "$id records pid|pane_pid|tmux_server_pid [$rpid|$rpane|$rserver]; want all set"
    n="$(tmux ${rsock:+-S "$rsock"} list-sessions 2>/dev/null | wc -l)"
    tmux ${rsock:+-S "$rsock"} kill-session -t "$target" || fail "kill-session -t $target of $id failed"
    set -- "$rpid" "$rpane"
    [ "$n" -gt 1 ] || set -- "$@" "$rserver"
    end=$(( $(date +%s%N) + 5000000000 ))
    while :; do
        left=""
        for p in "$@"; do [ ! -e "/proc/$p" ] || left+=" $p"; done
        [ -n "$left" ] || break
        [ "$(date +%s%N)" -lt "$end" ] || fail "$id's recorded process(es)$left still running 5 s after its session $target ended"
        sleep 0.1
    done
    [ "$n" -le 1 ] || [ -e "/proc/$rserver" ] || fail "tmux server $rserver of $id ended although it held $((n - 1)) other session(s)"
}
a=$(PATH="$standin_path" agent-director spawn --cwd /tmp | jq -r '.claude_instance_id')
test -n "$a"

b=$(AGENT_DIRECTOR_INSTANCE_ID="$a" PATH="$standin_path" agent-director spawn --cwd /tmp | jq -r '.claude_instance_id')
test -n "$b"

# Sanity check: B's parent is A.
parent=$(agent-director get --claude-instance-id "$b" | jq -r '.parent_id')
if [ "$parent" != "$a" ]; then
    echo "FAIL: precondition parent_id=$parent; want $a"; exit 1
fi

sess_b=$(agent-director get --claude-instance-id "$b" | jq -r '.tmux_session_name')
session_id="r7-session-uuid"
# transcript_path is the real on-disk path; the hook persists it as the
# row's jsonl_path, which resume Stats pre-flight (b.93m). Typed into B's
# pane: SR-22.9 applies a hook only from the recorded pane process.
jsonl_path="$HOME/.claude/projects/-tmp/${session_id}.jsonl"
/opt/driver/pane-hook.sh "$b" \
    "{\"hook_event_name\":\"SessionStart\",\"transcript_path\":\"${jsonl_path}\"}" >/dev/null

mkdir -p "$HOME/.claude/projects/-tmp"
echo '{}' > "$jsonl_path"

/opt/driver/pane-hook.sh "$b" '{"hook_event_name":"SessionEnd","reason":"logout"}' >/dev/null

state=$(agent-director get --claude-instance-id "$b" | jq -r '.state')
if [ "$state" != "ended" ]; then
    echo "FAIL: precondition B state=$state; want ended"; exit 1
fi

# A's session keeps the tmux server running, so the wait covers B's pid
# and pane_pid, and checks the server still runs.
end_and_wait "$b" "$sess_b"

# Bare-shell resume — explicitly unset the env var.
unset AGENT_DIRECTOR_INSTANCE_ID
PATH="$standin_path" agent-director resume --claude-instance-id "$b" >/dev/null

# B's parent is now NULL (empty string in the JSON envelope).
parent=$(agent-director get --claude-instance-id "$b" | jq -r '.parent_id // empty')
if [ -n "$parent" ]; then
    echo "FAIL: parent_id=$parent after bare-shell resume; want empty"; exit 1
fi
echo "resume-7 ok: bare-shell resume nulled parent_id (was $a)"
```
