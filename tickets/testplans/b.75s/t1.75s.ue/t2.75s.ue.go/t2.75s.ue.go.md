# resume-1: happy path — resume from ended

Maps to Epic 9 AC #1 (state cycle: spawn → end → resume → new tmux
session up). Stitches together spawn, synthesized SessionStart/End
hooks, JSONL seeding, and the resume verb. Epic 8 (`t1.h98.xw`,
SR-20.9, SR-22.9): a hook moves the row only when it comes from the
row's own pane process, so the hooks are typed into the pane.

## Setup

Per-case DB-reset. The spawn and the resume run with
`PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the
`agent-director` command, so the pane process is the stand-in claude's
interactive bash. Hooks are typed into the row's pane with
`/opt/driver/pane-hook.sh <id> '<payload>'` (see the collector's
"Driver mode"); none is piped from the case's own shell.

## Steps

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd /tmp`
   → capture id and tmux_session_name.
2. Type a SessionStart hook into the row's pane with a transcript_path
   whose basename-minus-extension is a known session uuid; this
   populates `claude_session_id` and transitions state pending→waiting.
3. Compute the JSONL path: `$HOME/.claude/projects/-tmp/<session>.jsonl`
   and pass it as the SessionStart `transcript_path` so the hook persists
   it as the row's `jsonl_path`. Create the directory and touch the file
   (resume Stats the persisted `jsonl_path` pre-flight — b.93m).
4. Type a SessionEnd hook into the row's pane → state=ended, ended_at
   stamped.
5. `tmux kill-session -t <original session name>` so the canonical
   name is free.
6. `PATH=/opt/driver/stand-in-claude:$PATH agent-director resume
   --claude-instance-id <id>` → exits 0; result envelope contains the
   same id.
7. `tmux has-session -t <name>` exits 0 (new session up).

## Pass criteria

- spawn + each hook firing + resume all exit 0.
- After resume, a tmux session exists under the canonical name.
- Resume's result envelope echoes the same claude_instance_id.

## Script

```bash
set -euo pipefail
standin_path="/opt/driver/stand-in-claude:$PATH"
id=$(PATH="$standin_path" agent-director spawn --cwd /tmp | jq -r '.claude_instance_id')
test -n "$id"
sess=$(agent-director get --claude-instance-id "$id" | jq -r '.tmux_session_name')
test -n "$sess"

# SessionStart synth: claude_session_id will be `r1-session-uuid`. The
# transcript_path is the real on-disk path; the hook persists it as the
# row's jsonl_path, which resume Stats pre-flight (b.93m). Typed into the
# row's pane: SR-22.9 applies a hook only from the recorded pane process.
session_id="r1-session-uuid"
jsonl_dir="$HOME/.claude/projects/-tmp"
jsonl_path="$jsonl_dir/${session_id}.jsonl"
/opt/driver/pane-hook.sh "$id" \
    "{\"hook_event_name\":\"SessionStart\",\"transcript_path\":\"${jsonl_path}\"}" >/dev/null

# Seed the JSONL on disk where resume will Stat it.
mkdir -p "$jsonl_dir"
echo '{}' > "$jsonl_path"

# SessionEnd synth (typed into the pane) → row goes terminal.
/opt/driver/pane-hook.sh "$id" '{"hook_event_name":"SessionEnd","reason":"logout"}' >/dev/null

state=$(agent-director get --claude-instance-id "$id" | jq -r '.state')
if [ "$state" != "ended" ]; then
    echo "FAIL: precondition state=$state; want ended"; exit 1
fi

# Free the canonical tmux session name.
tmux kill-session -t "$sess" 2>/dev/null || true

# Resume (relaunches the stand-in).
out=$(PATH="$standin_path" agent-director resume --claude-instance-id "$id")
got_id=$(printf '%s' "$out" | jq -r '.claude_instance_id')
if [ "$got_id" != "$id" ]; then
    echo "FAIL: resume returned id=$got_id; want $id"; exit 1
fi

# New tmux session up under the same name.
if ! tmux has-session -t "$sess" 2>/dev/null; then
    echo "FAIL: tmux session $sess not up after resume"; exit 1
fi
echo "resume-1 ok: ended → resume → new tmux session up"
```
