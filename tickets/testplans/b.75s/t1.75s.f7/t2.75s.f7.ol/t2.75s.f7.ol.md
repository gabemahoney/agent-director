# install-11: upgrade from the old layout

b.ssz moved AD's directory from `~/.agent-director` to
`~/.config/agent-director` (SR-11.7) and renamed config.toml's
`disable_askuserquestion` and a template's `claude_args` (SR-11.2). This case
runs the real upgrade: an install of the PREVIOUS release, made by that
release's own `install.sh` (baked into the image under `/opt/previous-release`,
sha256-pinned, see test/Dockerfile), is upgraded by this release's `install.sh`
with the same flags and from the same directory.

## Setup

Per-case DB-reset. The case makes its own absolute mktemp `HOME` and builds the
old-layout install in it with `/opt/driver/old-layout.sh` (the previous release
installed with `--binary`, `--admin-binary`, `--register-mcp`, hooks on and the
default PATH link; one `ended` Claude row; templates `worker` (with
`claude_args`) and `reviewer` (tables with quoted keys); `config.toml` with
`disable_askuserquestion = true` under `[defaults]`). Every store read or write
goes through `/opt/driver/sql.sh`. No schema version is written down: the
expected `user_version` and table structure of the old and the new store
come from reference stores each binary made itself.

## Steps

1. Build the old-layout install and snapshot its directory
   (`/opt/driver/tree-snapshot.sh`: path, kind, mode, sha256; a store is not
   listed, it is compared by `user_version`, table structure and rows).
2. Run this release's `install.sh` from the same directory with the same
   flags.
3. Check the new directory, the kept directory, the store, config.toml, the
   templates and their backups, settings.json, the MCP registration and the
   PATH link.
4. Run `install.sh` a second time and check that it changed nothing but the
   timestamped `.bak` copies every install makes.

## Pass criteria

- Exit 0; the printed output names the kept directory.
- `~/.config/agent-director` holds every file the old directory held except
  `bin/` and `admin/`, with the same modes and bytes, except config.toml and
  the two templates (below); the files it gained are named explicitly: a
  `.pre-agent-rename.<ts>` backup of each of those three, and the
  `config.toml.bak.<ts>` of the hooks' config.toml merge; the trail may only
  have grown.
- The newest `~/.agent-director.pre-move-*` equals the snapshot, store
  included (at the previous release's `user_version` and schema).
- The new store is at this binary's `user_version` and schema, has the
  old store's file mode (the kept store too), and `list` shows the row with
  agent `claude`.
- config.toml reads `disable_ask_user = true`, with `disable_askuserquestion`
  gone and nothing else changed; each template carries `agent = "claude"`
  (`worker` with `agent_args` for `claude_args`; `reviewer` with its tables
  byte for byte) and has a `.pre-agent-rename.<ts>` backup equal to the
  original.
- settings.json holds this binary's help hooks and none that name the old
  path; `claude mcp get agent-director` names the new binary in the original
  scope; the PATH link points to the new binary.
- A second run changes nothing in either directory, settings.json or the MCP
  registration, except the new `.bak.<ts>` copies.

## Script

```bash
set -euo pipefail
export LC_ALL=C

PREV=/opt/previous-release
INSTALL=/opt/skills/install-agent-director/install.sh
NEWBIN=/usr/local/bin/agent-director
NEWADMIN=/opt/bin/agent-director-admin
SQL=/opt/driver/sql.sh
SNAP=/opt/driver/tree-snapshot.sh

T=$(mktemp -d /tmp/install-11-XXXXXX)
home="$T/home"
mkdir "$home" "$T/scratch"

fail() {
    echo "FAIL: $*" >&2
    exit 1
}

# Reference stores, one per binary, made in a scratch HOME so this case's
# HOME gets no directory from them: the expected versions and schemas.
HOME="$T/scratch" "$PREV/agent-director" list --store-path "$T/ref-old.db" >/dev/null
HOME="$T/scratch" "$NEWBIN" list --store-path "$T/ref-new.db" >/dev/null
old_ver=$($SQL -readonly "$T/ref-old.db" 'PRAGMA user_version')
new_ver=$($SQL -readonly "$T/ref-new.db" 'PRAGMA user_version')
# The store's structure: each table's columns (name, type, not-null, default,
# primary key, in order) and each index's columns. Not `.sha3sum --schema` (it
# also hashes every table's rows, and store_meta holds a random store_id per
# store) and not `.schema` (a column added or renamed by a migration changes
# the CREATE text, not the structure).
schema_dump() {
    $SQL -readonly "$1" "SELECT 'T', m.name, p.cid, p.name, p.type, p.\"notnull\", p.dflt_value, p.pk FROM sqlite_master m, pragma_table_info(m.name) p WHERE m.type = 'table' ORDER BY m.name, p.cid;"
    $SQL -readonly "$1" "SELECT 'I', m.name, m.tbl_name, i.seqno, i.name FROM sqlite_master m, pragma_index_info(m.name) i WHERE m.type = 'index' ORDER BY m.name, i.seqno;"
}
schema_hash() { schema_dump "$1" | sha256sum | cut -d' ' -f1; }
old_sch=$(schema_hash "$T/ref-old.db")
new_sch=$(schema_hash "$T/ref-new.db")
[ "$old_ver" -gt 0 ] || fail "previous release's user_version=[$old_ver]"
[ "$new_ver" -gt "$old_ver" ] || fail "this release's user_version [$new_ver] is not above the previous [$old_ver]"
[ "$old_sch" != "$new_sch" ] || fail "the two releases' schemas hash alike"
store_state() { # <db>: "user_version schema-hash"
    echo "$($SQL -readonly "$1" 'PRAGMA user_version') $(schema_hash "$1")"
}

# The old-layout install, in this case's own HOME, from a fixed directory.
export HOME="$home"
export PATH="$home/.local/bin:/usr/local/bin:/usr/bin:/bin"
cd "$home"
/opt/driver/old-layout.sh "$home" >"$T/helper.out" 2>"$T/helper.err" || { tail -c 300 "$T/helper.err" >&2; fail "old-layout.sh"; }
kv() { sed -n "s/^$1=//p" "$T/helper.out"; }
old="$home/.agent-director"
[ "$(kv dir)" = "$old" ] || fail "helper dir=[$(kv dir)]"
oldbin=$(kv bin)
olddb=$(kv db)
[ "$(kv instance_id)" = old-layout-1 ] || fail "helper instance_id"
mcp_by=$(kv mcp)
[ "$mcp_by" != none ] || fail "no MCP registration could be made (mcp=none)"

# Facts of the old install itself.
[ "$(store_state "$olddb")" = "$old_ver $old_sch" ] || fail "old store is not at the previous release's version and schema"
[ "$($SQL -readonly "$olddb" "SELECT state FROM spawns WHERE claude_instance_id = 'old-layout-1'")" = ended ] || fail "old row is not ended"
[ -f "$old/templates/worker.toml" ] && [ -f "$old/templates/reviewer.toml" ] || fail "old templates missing"
grep -q '^claude_args = ' "$old/templates/worker.toml" || fail "old worker has no claude_args"
grep -qE '^ *"[^"]*\.[^"]*" = ' "$old/templates/reviewer.toml" || fail "old reviewer holds no quoted key"
grep -qx 'disable_askuserquestion = true' "$old/config.toml" || fail "old config lacks disable_askuserquestion"
[ "$(readlink "$home/.local/bin/agent-director")" = "$oldbin" ] || fail "old PATH link"
mcp_before=$(claude mcp get agent-director 2>&1 || true)
grep -qF "$oldbin" <<<"$mcp_before" || fail "old MCP registration does not name $oldbin"
scope_before=$(sed -n 's/^ *Scope: *//p' <<<"$mcp_before")
[ -n "$scope_before" ] || fail "no Scope line in claude mcp get"

old_db_mode=$(stat -c %a "$olddb")
$SNAP "$old" >"$T/old.full"
$SNAP "$old" --skip bin --skip admin --skip ad-trail.jsonl >"$T/old.part"
cp -p "$home/.claude/settings.json" "$T/settings.before"
cp -p "$old/config.toml" "$T/config.old"
cp -p "$old/templates/worker.toml" "$T/worker.old"
cp -p "$old/templates/reviewer.toml" "$T/reviewer.old"

# The upgrade: the same flags, the same directory.
upgrade() { # <n>
    set +e
    "$INSTALL" --binary "$NEWBIN" --admin-binary "$NEWADMIN" --register-mcp >"$T/install$1.out" 2>"$T/install$1.err"
    rc=$?
    set -e
    [ "$rc" = 0 ] || { tail -c 250 "$T/install$1.err" >&2; fail "install.sh run $1 exit=$rc"; }
}
upgrade 1

new="$home/.config/agent-director"
newbin="$new/bin/agent-director"
newdb="$new/state.db"
[ -d "$new" ] || fail "no $new"
[ ! -e "$old" ] || fail "$old is still there"
kept_n=$(ls -d "$home"/.agent-director.pre-move-* | wc -l)
[ "$kept_n" = 1 ] || fail "$kept_n kept directories; want 1"
kept=$(ls -d "$home"/.agent-director.pre-move-*)
grep -qF "$kept" "$T/install1.out" || fail "the output does not name $kept"

# The kept directory is the snapshot, store included at the previous version.
$SNAP "$kept" >"$T/kept.snap"
diff "$T/old.full" "$T/kept.snap" >"$T/d" || fail "the kept directory differs from the old one: $(head -c 200 "$T/d" | tr '\n' ' ')"
[ "$(store_state "$kept/state.db")" = "$old_ver $old_sch" ] || fail "the kept store changed"
[ "$(stat -c %a "$kept/state.db")" = "$old_db_mode" ] || fail "the kept store's mode changed"
[ "$($SQL -readonly "$kept/state.db" 'SELECT COUNT(*) FROM spawns')" = 1 ] || fail "the kept store's rows changed"

# The new directory: every file but bin/ and admin/, same modes and bytes,
# except what is named here.
$SNAP "$new" --skip bin --skip admin --skip ad-trail.jsonl >"$T/new.part"
cut -f1 "$T/old.part" | sort >"$T/p-old"
cut -f1 "$T/new.part" | sort >"$T/p-new"
comm -23 "$T/p-old" "$T/p-new" >"$T/removed"
comm -13 "$T/p-old" "$T/p-new" >"$T/added"
awk -F'\t' 'NR==FNR{o[$1]=$0; next} ($1 in o) && o[$1]!=$0 {print $1}' "$T/old.part" "$T/new.part" >"$T/changed"
[ ! -s "$T/removed" ] || fail "files lost in the move: $(tr '\n' ' ' <"$T/removed")"
printf '%s\n' config.toml templates/reviewer.toml templates/worker.toml >"$T/changed.want"
diff "$T/changed.want" "$T/changed" >/dev/null || fail "changed files: $(tr '\n' ' ' <"$T/changed"); want config.toml and the two templates"
fld() { awk -F'\t' -v p="$2" '$1==p{print $2 "\t" $3 "\t" $4}' "$1"; }
mode_of() { awk -F'\t' -v p="$2" '$1==p{print $3}' "$1"; }
for p in config.toml templates/reviewer.toml templates/worker.toml; do
    [ "$(mode_of "$T/old.part" "$p")" = "$(mode_of "$T/new.part" "$p")" ] || fail "mode of $p changed"
done
sed -E 's/\.(bak|pre-agent-rename)\.[0-9][0-9-]*$/.\1.<ts>/' "$T/added" >"$T/added.norm"
printf '%s\n' \
    'config.toml.bak.<ts>' \
    'config.toml.pre-agent-rename.<ts>' \
    'templates/reviewer.toml.pre-agent-rename.<ts>' \
    'templates/worker.toml.pre-agent-rename.<ts>' >"$T/added.want"
diff "$T/added.want" "$T/added.norm" >/dev/null || fail "files added to the new directory: $(tr '\n' ' ' <"$T/added.norm")"
# Each .pre-agent-rename backup is the original: same mode, same bytes. The
# .bak of the hooks' config.toml merge is config.toml as that merge found it
# (already migrated; the merge adds nothing to it), mode kept.
while IFS= read -r b; do
    case "$b" in
        *.pre-agent-rename.*)
            orig="${b%.pre-agent-rename.*}"
            [ "$(fld "$T/new.part" "$b")" = "$(fld "$T/old.part" "$orig")" ] || fail "backup $b is not the original $orig"
            ;;
        config.toml.bak.*)
            [ "$(fld "$T/new.part" "$b")" = "$(fld "$T/new.part" config.toml)" ] || fail "$b is not the migrated config.toml"
            ;;
        *) fail "unexpected new file $b" ;;
    esac
done <"$T/added"

# The trail only grew (when the old directory had one).
if [ -f "$kept/ad-trail.jsonl" ]; then
    cmp -n "$(stat -c %s "$kept/ad-trail.jsonl")" "$kept/ad-trail.jsonl" "$new/ad-trail.jsonl" || fail "the new trail does not start with the old one"
fi

# The new store: this binary's version and schema, the row, agent claude.
[ "$(store_state "$newdb")" = "$new_ver $new_sch" ] || fail "new store is not at this release's version and schema: $(store_state "$newdb")"
[ "$(stat -c %a "$newdb")" = "$old_db_mode" ] || fail "the new store's mode [$(stat -c %a "$newdb")] differs from the old store's [$old_db_mode]"
row=$($SQL -readonly "$newdb" "SELECT instance_id || '|' || state || '|' || agent FROM spawns")
[ "$row" = "old-layout-1|ended|claude" ] || fail "new store row=[$row]"
listed=$("$newbin" list | jq -r '.spawns[] | select(.instance_id == "old-layout-1") | .agent')
[ "$listed" = claude ] || fail "list shows agent=[$listed]; want claude"

# config.toml: the key renamed, nothing else changed.
sed 's/^disable_askuserquestion = true$/disable_ask_user = true/' "$T/config.old" | cmp - "$new/config.toml" || fail "config.toml is not the old one with the key renamed"
grep -qx 'disable_ask_user = true' "$new/config.toml" || fail "no disable_ask_user = true"
! grep -q 'disable_askuserquestion' "$new/config.toml" || fail "disable_askuserquestion is still in config.toml"

# Templates: agent = "claude" before the first table header; the first has
# agent_args for claude_args; the second's tables are byte for byte.
w="$new/templates/worker.toml"
r="$new/templates/reviewer.toml"
[ "$(grep -c '^agent = "claude"$' "$w")" = 1 ] || fail "worker: agent line"
sed -e '/^agent = "claude"$/d' -e 's/^agent_args = /claude_args = /' "$w" | cmp - "$T/worker.old" || fail "worker is not the old one with agent_args and agent"
grep -q '^agent_args = ' "$w" || fail "worker has no agent_args"
! grep -q '^claude_args' "$w" || fail "worker still has claude_args"
[ "$(grep -c '^agent = "claude"$' "$r")" = 1 ] || fail "reviewer: agent line"
sed '/^agent = "claude"$/d' "$r" | cmp - "$T/reviewer.old" || fail "reviewer is not the old one plus agent"
awk '/^\[/{exit} /^agent = "claude"$/{f=1} END{exit !f}' "$r" || fail "reviewer: agent is not before the first table"

# settings.json: this binary's help hooks, none naming the old path.
settings="$home/.claude/settings.json"
[ "$(grep -cF "$newbin help" "$settings")" -ge 1 ] || fail "settings.json holds no help hook for $newbin"
! grep -qF "$old" "$settings" || fail "settings.json still names $old"
[ "$(jq -S 'del(.hooks)' "$settings")" = "$(jq -S 'del(.hooks)' "$T/settings.before")" ] || fail "settings.json changed outside hooks"

# MCP: the new binary, the original scope. PATH link: the new binary.
mcp_after=$(claude mcp get agent-director 2>&1 || true)
grep -qF "$newbin" <<<"$mcp_after" || fail "claude mcp get does not name $newbin"
! grep -qF "$oldbin" <<<"$mcp_after" || fail "claude mcp get still names $oldbin"
[ "$(sed -n 's/^ *Scope: *//p' <<<"$mcp_after")" = "$scope_before" ] || fail "MCP scope changed from [$scope_before]"
[ "$(readlink "$home/.local/bin/agent-director")" = "$newbin" ] || fail "PATH link does not point to $newbin"
cmp "$NEWBIN" "$newbin" || fail "installed agent-director is not this build"
cmp "$NEWADMIN" "$new/admin/agent-director-admin" || fail "installed admin is not this build"

# A second run changes nothing but the timestamped .bak copies. (Claude Code's
# own telemetry/ files under ~/.claude, which every `claude` run may add, are
# not the install's and are left out of the snapshot.)
$SNAP "$new" >"$T/new.full1"
$SNAP "$kept" >"$T/kept.full1"
$SNAP "$home/.claude" --skip telemetry >"$T/claude.full1"
store1=$(store_state "$newdb")
upgrade 2
$SNAP "$new" >"$T/new.full2"
$SNAP "$kept" >"$T/kept.full2"
$SNAP "$home/.claude" --skip telemetry >"$T/claude.full2"
diff "$T/kept.full1" "$T/kept.full2" >/dev/null || fail "the second run changed the kept directory"
[ "$(ls -d "$home"/.agent-director.pre-move-* | wc -l)" = 1 ] || fail "the second run made another kept directory"
[ ! -e "$old" ] || fail "the second run recreated $old"
[ "$(store_state "$newdb")" = "$store1" ] || fail "the second run changed the store"
for pair in "new:$T/new.full1:$T/new.full2" "claude:$T/claude.full1:$T/claude.full2"; do
    IFS=: read -r label s1 s2 <<<"$pair"
    awk -F'\t' 'NR==FNR{o[$1]=$0; next} ($1 in o) && o[$1]!=$0 {print "changed " $1}' "$s1" "$s2" >"$T/d2"
    cut -f1 "$s1" | sort >"$T/q1"
    cut -f1 "$s2" | sort >"$T/q2"
    comm -23 "$T/q1" "$T/q2" | sed 's/^/removed /' >>"$T/d2"
    comm -13 "$T/q1" "$T/q2" | sed 's/^/added /' >>"$T/d2"
    ! grep -vE '^added (config\.toml|settings\.json)\.bak\.[0-9-]+$' "$T/d2" >"$T/d3" || fail "second run, $label: $(tr '\n' ' ' <"$T/d3")"
done
mcp_again=$(claude mcp get agent-director 2>&1 || true)
[ "$mcp_again" = "$mcp_after" ] || fail "the second run changed the MCP registration"
grep -qF 'nothing to add' "$T/install2.out" || fail "the second run did not say it adds no MCP registration"
[ "$(readlink "$home/.local/bin/agent-director")" = "$newbin" ] || fail "the second run moved the PATH link"

rm -rf "$T"
echo "install-11 ok: upgrade from the old layout moved, migrated and re-ran cleanly (mcp set up by: $mcp_by)"
```
