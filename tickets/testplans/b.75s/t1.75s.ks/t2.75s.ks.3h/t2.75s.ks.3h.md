# kill-1: kill on a live row ends its labelled session (kill_sent true)

Per Epic 5 AC #3 (`Spawn → kill → tmux session gone`), revised by SRD
SR-20.9, SR-6.1 and SR-1.4 (Epic `t1.h98.aq`, the honest kill). `kill`
finds the row's session by its `@ad_owner` label, not by name: one
lookup on the row's socket (the default socket here, since the seeded
row records none) finds the one session labelled
`ad1 <row's launch token> <$N> <row id> <this store's id>`. It kills
the agent's pane by pane id, then the labelled session by session id,
and waits until the agent's pane process is gone before it returns 0
with `kill_sent` true. The row's state never changes.

The session is made by hand, so its pane also gets the per-pane label
`@ad_pane` `<token> <%N>`, as agent-director's own create sets it: that
lets `kill` adopt the pane as the agent's (SR-3.6), kill it and wait on
its process rather than falling back to a follow-up lookup.

## Setup

Per-case DB-reset (fresh store, no `cd-*` sessions). The store exists
after the reset, so its id can be read from `store_meta`. The script
records nothing outside the `cd-` prefix; an EXIT trap removes the
session by its session id if the case fails part-way.

## Steps

1. Read this store's id with `sqlite3` (`SELECT value FROM store_meta
   WHERE key = 'store_id'`).
2. `tmux new-session -d -s cd-k1 -e AGENT_DIRECTOR_INSTANCE_ID=id-k1 --
   cat`, capturing the session id `$N`, the pane id `%N` and the pane
   pid (the `cat` process).
3. Seed a `spawns` row `id-k1` at state `waiting`, session name `cd-k1`,
   with a `launch_token` of 16 lowercase hex characters and no recorded
   socket, pid or pane; read the token back with `sqlite3`.
4. Label the session: `tmux set-option -t '<$N>' @ad_owner 'ad1 <token>
   <$N> id-k1 <store id>'`, and its pane: `tmux set-option -p -t '<%N>'
   @ad_pane '<token> <%N>'`. Read the label back with `tmux show-options
   -t '<$N>' -v @ad_owner`.
5. `agent-director kill --claude-instance-id id-k1`.
6. Check the session by its `$N`, the `cat` pid, the row's state, and the
   last `ad.kill.called` trail line for `id-k1`.

## Pass criteria

- The store id and the token are 16 lowercase hex; the label read back
  has five fields and equals the one set.
- kill exits 0 and its stdout JSON has `kill_sent == true`.
- `tmux has-session -t '<$N>'` and `tmux has-session -t cd-k1` both
  return non-zero after the kill.
- The `cat` pid is gone (absent or a zombie).
- The row is still `waiting` (`kill` never changes a row's state).
- The last `ad.kill.called` line in `~/.agent-director/ad-trail.jsonl`
  for `id-k1` has `outcome == "ok"`, `kill_sent == true` and
  `pane_killed == true` (the pane kill was sent).

## Script

```bash
set -euo pipefail
db="$HOME/.agent-director/state.db"
trail="$HOME/.agent-director/ad-trail.jsonl"
fail() { echo "FAIL: $*"; exit 1; }
sid=""
trap '[ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true' EXIT

store_id="$(sqlite3 "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

read -r sid pane cat_pid < <(tmux new-session -d -s cd-k1 -e AGENT_DIRECTOR_INSTANCE_ID=id-k1 \
    -P -F '#{session_id} #{pane_id} #{pane_pid}' -- cat)
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"

seed_token="$(od -An -N8 -tx1 /dev/urandom | tr -d ' 
')"
sqlite3 "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, launch_token)
   VALUES ('id-k1', 'waiting', '/tmp', 'cd-k1', 'off', '$seed_token');"
token="$(sqlite3 "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-k1';")"
[[ "$token" =~ ^[0-9a-f]{16}$ ]] || fail "launch_token is not 16 lowercase hex: [$token]"

label="ad1 $token $sid id-k1 $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
tmux set-option -p -t "$pane" @ad_pane "$token $pane"
got_label="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$got_label" = "$label" ] || fail "label read back [$got_label]; want [$label]"
read -r -a fields <<<"$got_label"
[ "${#fields[@]}" -eq 5 ] || fail "label has ${#fields[@]} fields; want 5: [$got_label]"

out="$(agent-director kill --claude-instance-id id-k1)" || fail "kill exited non-zero; want 0"
sent="$(jq -r '.kill_sent' <<<"$out")"
[ "$sent" = "true" ] || fail "kill_sent=$sent; want true (stdout: $out)"

if tmux has-session -t "$sid" 2>/dev/null; then
    fail "tmux session $sid (cd-k1) still exists after kill"
fi
if tmux has-session -t cd-k1 2>/dev/null; then
    echo "FAIL: tmux session cd-k1 still exists after kill"; exit 1
fi
if [ -e "/proc/$cat_pid" ]; then
    st="$(sed -E 's/^.*\) //' "/proc/$cat_pid/stat" 2>/dev/null | cut -d' ' -f1 || true)"
    [ -z "$st" ] || [ "$st" = "Z" ] || fail "pane process $cat_pid still running (state $st) after kill"
fi
state="$(sqlite3 "$db" "SELECT state FROM spawns WHERE claude_instance_id = 'id-k1';")"
[ "$state" = "waiting" ] || fail "row state=$state after kill; want waiting (kill never changes state)"

line="$(jq -cR 'fromjson? | select(.event == "ad.kill.called" and .claude_instance_id == "id-k1")' "$trail" | tail -n 1)"
[ -n "$line" ] || fail "no ad.kill.called line for id-k1 in $trail"
tr="$(jq -r '[.outcome, .kill_sent, .pane_killed] | map(tostring) | join(" ")' <<<"$line")"
[ "$tr" = "ok true true" ] || fail "ad.kill.called outcome/kill_sent/pane_killed=[$tr]; want [ok true true]: $line"

echo "kill-1 ok: labelled live row → kill → kill_sent true, pane killed, session $sid gone, cat $cat_pid gone, row still waiting"
```
