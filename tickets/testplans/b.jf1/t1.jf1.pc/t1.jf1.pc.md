# cursor-pane-controls

Authoring only; five ordered representative compositions. Scheduler runs the
exact committed revision through `make test-docker EPIC=cursor-pane-controls
DRIVER_MODE=shell`. No case has been executed by this author. The registry has
17 groups after this addition, not 17 passing groups.

Use the existing Docker driver, reset and whole-case private ERR/xtrace diagnostics.
Each case creates its own HOME/configured/default decoys, explicit override store,
short private tmux socket, runtime, gateway and unrelated process sentinel through
cursor-owned-launch.sh. Every SQL observation or fault uses /opt/driver/sql.sh;
its default 5000ms busy timeout is unchanged. Event observation uses the existing
20s finite harness wait (15s process/state waits), not sleeps to choose races.
Public callers retain their product timeouts; a 35s outer process deadline bounds
their cleanup. No product 3s cancellation or 1.5s caller guard is widened.

The image supplies /usr/local/bin/agent-director, Bun, Node, tmux, build tools and
the helper at /opt/driver. It does not supply a preinstalled Bun client or tsc.
Case .01 copies package build inputs to its private directory, installs pinned
lockfile dependencies, runs the canonical build.ts (including declarations),
packs the resulting package and installs that tarball into an isolated consumer.
Network/package dependency failure is a prerequisite failure, never an installed
package pass. The library ships no CLI: its explicit _cliPath selects the image's
actual binary. Cases .02–.05 use shipped CLI/MCP and synthetic ACP, not installed
Cursor. See COVERAGE.md and operator-acceptance.md for pending genuine human work.

For raw success/failure evidence, the scheduler must retain the case-owned
`/tmp/cursor-pane-controls-artifacts/<instance-id>/` directory before container
removal (for example its scheduler-owned bind mount at that fixed test-only
destination). The helper exports protected/trace/sent/raw bytes and independent
authority JSONL there before cleanup. The canonical driver's details field is
truncated and is not a raw archive. The final Integration Writer supplies the
exact committed-image scheduler invocation and mount ownership, not this author.
