# spawn-1: spawn returns pending with a launch start; SessionStart hook flips to waiting

Maps to Epic 3 AC #1 (`spawn --cwd /tmp` returns id; `status` shows
pending immediately; SessionStart hook bumps to waiting) and Epic 7
(`t1.h98.hy`, AC-CAT-04 launch-start half, SR-22.2): `status` of a
`pending` row carries `launch_started_at` (RFC3339 UTC, millisecond
precision); on any other row the key is omitted.

## Setup

Per-case DB-reset has already wiped `~/.agent-director/state.db`. The
container has `agent-director`, `tmux`, `sqlite3`, `jq` on PATH.

## Steps

1. Record the wall clock (whole seconds), run
   `agent-director spawn --cwd /tmp` → capture `claude_instance_id`,
   record the wall clock again.
2. `agent-director status --claude-instance-id <id>` → assert state =
   `pending` and `launch_started_at` is present: an RFC3339 UTC
   timestamp ending in `Z`, with at most three fraction digits, that
   falls within the spawn's wall-clock window (one second of slack
   either side).
3. Synthesize a SessionStart hook payload and pipe it into
   `AGENT_DIRECTOR_INSTANCE_ID=<id> agent-director hook`. Exit 0 with
   empty stdout.
4. `agent-director status --claude-instance-id <id>` → assert state =
   `waiting` and the `launch_started_at` key is absent (not `null`).
   `get` shows the session id taken from the transcript path.

## Pass criteria

- Step 1 exit 0; result JSON has non-empty `claude_instance_id`.
- Step 2 returns `state` = `pending` and a `launch_started_at` matching
  `^YYYY-MM-DDTHH:MM:SS(.f{1,3})?Z$` inside the spawn's window, e.g.
  `{"state":"pending","launch_started_at":"2026-09-29T12:00:00.123Z"}`.
- Step 3 exits 0 with empty stdout (state-tracking fail-open).
- Step 4 returns `state` = `waiting` with no `launch_started_at` key,
  e.g. `{"state":"waiting"}`; `get` shows
  `claude_session_id` = `abc-uuid`.

## Script

```bash
set -euo pipefail
before="$(date -u +%s)"
spawn_out="$(agent-director spawn --cwd /tmp)"
after="$(date -u +%s)"
id="$(printf '%s' "$spawn_out" | jq -r '.claude_instance_id')"
test -n "$id"
status_out="$(agent-director status --claude-instance-id "$id")"
state="$(printf '%s' "$status_out" | jq -r '.state')"
test "$state" = "pending"
test "$(printf '%s' "$status_out" | jq -r 'has("launch_started_at")')" = "true"
started="$(printf '%s' "$status_out" | jq -r '.launch_started_at')"
[[ "$started" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}(\.[0-9]{1,3})?Z$ ]]
started_s="$(date -u -d "$started" +%s)"
test "$started_s" -ge "$((before - 1))"
test "$started_s" -le "$((after + 1))"
hook_out="$(printf '{"hook_event_name":"SessionStart","transcript_path":"/x/abc-uuid.jsonl"}' \
  | AGENT_DIRECTOR_INSTANCE_ID="$id" agent-director hook)"
test -z "$hook_out"
status_out="$(agent-director status --claude-instance-id "$id")"
state="$(printf '%s' "$status_out" | jq -r '.state')"
test "$state" = "waiting"
test "$(printf '%s' "$status_out" | jq -r 'has("launch_started_at")')" = "false"
session_id="$(agent-director get --claude-instance-id "$id" | jq -r '.claude_session_id')"
test "$session_id" = "abc-uuid"
echo "spawn-1 ok: id=$id launch_started_at=$started state=waiting (launch start omitted) session_id=$session_id"
```
