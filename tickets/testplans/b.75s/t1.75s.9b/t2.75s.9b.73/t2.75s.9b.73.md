# recov-2: NULL-identity live rows with empty probe reconcile to missing

Maps to Epic 8 AC #4, updated for b.93m. The pre-b.93m "degraded-mode
guard refuses to write when the probe is empty" behavior was **removed**
in b.93m (commit 915830e — find-missing went per-row and evidence-based;
guard removed). find-missing now partitions live rows:

- Rows with BOTH a recorded pid AND proc_starttime get an evidence-based
  liveness-checker verdict.
- Rows with a NULL pid OR NULL proc_starttime (partial identity) fall back
  to the environ probe-set diff (SR-7.5): a live id absent from the probe
  set is marked `missing`.

This case seeds two live-state rows directly via `sqlite3` with NO
pid/proc_starttime (partial identity) and ensures no process carries their
`AGENT_DIRECTOR_INSTANCE_ID`. Both rows take the SR-7.5 fallback, are absent
from the (empty) probe set, and are therefore reconciled to `missing`.

## Setup

Per-case DB-reset.

## Steps

1. SIGTERM any process whose environ carries
   `AGENT_DIRECTOR_INSTANCE_ID` (cleanup from prior cases).
2. Poll `/proc` until no such process remains.
3. INSERT 2 live-state rows directly via `sqlite3` (no pid/proc_starttime →
   partial identity → SR-7.5 environ-probe fallback).
4. `find-missing` → expect `count=2`, `.ids` = both seeded ids, exit 0.
5. Both rows are now in state `missing`.

## Pass criteria

- find-missing exits 0.
- `count=2`; `.ids` = `["id-dg-1","id-dg-2"]` (sorted).
- Both seeded rows are now in state `missing`.

## Script

```bash
set -euo pipefail

# Find every claude-tagged pid (its environ carries the marker env
# var) and ask it to exit. The harness runs as a single user inside
# the container so signal delivery should be unrestricted.
for pid in $(ls /proc 2>/dev/null | grep -E '^[0-9]+$'); do
    if [ -r "/proc/$pid/environ" ] && \
        grep -aqz "^AGENT_DIRECTOR_INSTANCE_ID=" "/proc/$pid/environ" 2>/dev/null; then
        kill "$pid" 2>/dev/null || true
    fi
done

# Wait up to 30s for /proc to be free of any straggler. The previous
# case's survivor may take a moment to actually die.
deadline=$(( $(date +%s) + 30 ))
remaining=1
while [ "$(date +%s)" -lt "$deadline" ]; do
    remaining=0
    for pid in $(ls /proc 2>/dev/null | grep -E '^[0-9]+$'); do
        if [ -r "/proc/$pid/environ" ] && \
            grep -aqz "^AGENT_DIRECTOR_INSTANCE_ID=" "/proc/$pid/environ" 2>/dev/null; then
            remaining=1
            kill -9 "$pid" 2>/dev/null || true
        fi
    done
    if [ "$remaining" -eq 0 ]; then
        break
    fi
    sleep 0.5
done
if [ "$remaining" -eq 1 ]; then
    echo "FAIL: leftover AGENT_DIRECTOR_INSTANCE_ID env in /proc even after SIGKILL+30s"; exit 1
fi

# Seed two live-state rows with NO pid/proc_starttime → partial identity →
# SR-7.5 environ-probe fallback.
sqlite3 "$HOME/.agent-director/state.db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode)
   VALUES ('id-dg-1', 'waiting', '/tmp', 'cd-dg-1', 'off'),
          ('id-dg-2', 'working', '/tmp', 'cd-dg-2', 'off');"

res=$(agent-director find-missing)
count=$(printf '%s' "$res" | jq -r '.count')
ids=$(printf '%s' "$res" | jq -c '.ids')
if [ "$count" != "2" ]; then
    echo "FAIL: count=$count; want 2 (empty probe → NULL-identity rows reconcile missing; res=$res)"; exit 1
fi
if [ "$ids" != '["id-dg-1","id-dg-2"]' ]; then
    echo "FAIL: ids=$ids; want [\"id-dg-1\",\"id-dg-2\"]"; exit 1
fi

s1=$(sqlite3 "$HOME/.agent-director/state.db" "SELECT state FROM spawns WHERE claude_instance_id='id-dg-1';")
s2=$(sqlite3 "$HOME/.agent-director/state.db" "SELECT state FROM spawns WHERE claude_instance_id='id-dg-2';")
if [ "$s1" != "missing" ] || [ "$s2" != "missing" ]; then
    echo "FAIL: rows not reconciled to missing ($s1, $s2)"; exit 1
fi
echo "recov-2 ok: empty probe → NULL-identity live rows reconciled to missing"
```
