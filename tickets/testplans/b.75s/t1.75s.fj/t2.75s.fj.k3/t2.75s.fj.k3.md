# discover-9: list-subagents shows a launched subagent running, then stopped, then with its launch details

Maps to Epic `t1.f5h.f9` AC 2 (a) (SRD `t1.xjn.du` SR-15.7 (a), SR-4.5,
SR-6.3, SR-7.1 to SR-7.3, SR-7.8, N11). X is spawned for real and reports
in (a SessionStart `startup` typed into its pane), then its own pane
process delivers the subagent hooks one by one, and `list-subagents`
reads the records after each step. A hook applies only from the row's own
pane process (SR-22.9), so each is typed with `/opt/driver/pane-hook.sh`.

- A SubagentStart for id A, with no launch request, is an unconfirmed
  entry: `list-subagents` shows no record and `sql.sh` shows A's entry
  with `confirmed` 0.
- A launch request (PreToolUse of the `Agent` tool) opens a claimable
  launch; the SubagentStart of its type for id B claims it. B is the
  one record, `running`, with its `subagent_type` from the start's
  `agent_type` and `description`, `model`, `parent_type`, `parent_id`,
  `tool_use_id` and `run_mode` null: a claim confirms and fills nothing
  (N11).
- B's SubagentStop makes it `stopped` with `close_reason` `stop_event`.
- B's `completed` launch result (PostToolUse of `Agent`) sets
  `description`, `model`, `parent_type` `agent` with X's instance id as
  `parent_id`, `tool_use_id` and `run_mode` `foreground`, and changes
  neither the state nor B's times.
- A is never shown.

## Setup

Per-case DB-reset. The trail `~/.config/agent-director/ad-trail.jsonl` is
not wiped, so any trail check would filter on X's instance id (this case
reads none). The spawn runs with
`PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the `agent-director`
command, so X's pane process is the stand-in claude's interactive bash,
which sends no hook by itself. The payloads are minimal: `hook_event_name`
and the SR-5.1 fields of each step (`tool_name` for the tool hooks), and
no content. The store is read only through `list-subagents` and
`/opt/driver/sql.sh`. The case starts a real tmux session; the DB-reset
fixture ends it.

## Steps

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --agent claude --cwd /tmp`
   → X. Type a SessionStart (`source` `startup`) into X's pane. X is
   `waiting`.
2. Type a SubagentStart for `d9-sub-a` (`agent_type` `general-purpose`).
   `list-subagents` reads `{"tracked":true,"subagents":[]}`; `sql.sh`
   shows A's entry, `confirmed` 0.
3. Type a PreToolUse (`tool_name` `Agent`, `tool_use_id` `d9-toolu-b`,
   `tool_input.subagent_type` `general-purpose`). `list-subagents` still
   shows no record; one claimable launch is open.
4. Type a SubagentStart for `d9-sub-b` (`agent_type` `general-purpose`).
   `list-subagents` shows exactly one record, B, `running`, with the
   fields above; the claimable launch is gone; A is still unconfirmed.
5. Type a SubagentStop for `d9-sub-b`. B is `stopped`, `close_reason`
   `stop_event`, `stopped_at` set, `lost_at` null; the six launch fields
   are still null.
6. Type a PostToolUse (`tool_name` `Agent`, `tool_use_id` `d9-toolu-b`,
   `tool_input.subagent_type` and `description`, `tool_response.status`
   `completed`, `agentId` `d9-sub-b`, `resolvedModel` `d9-model`). B has
   its description, model, parent, tool call and `run_mode` `foreground`;
   its state, `close_reason` and times are as after step 5; A is still
   not shown.

## Pass criteria

- Every hook exits 0 with empty stdout.
- After step 2: no record; A's entry exists with `confirmed` 0.
- After step 3: no record.
- After step 4: `tracked` true and one record: `subagent_id`
  `d9-sub-b`, `instance_id` X, `state` `running`, `subagent_type`
  `general-purpose`, `session_id` `d9-sess-b`, `first_started_at` and
  `started_at` set, `description`, `model`, `parent_type`, `parent_id`,
  `tool_use_id`, `run_mode`, `close_reason`, `stopped_at` and `lost_at`
  null.
- After step 5: `state` `stopped`, `close_reason` `stop_event`,
  `stopped_at` set, `lost_at` null, the six launch fields null.
- After step 6: `description` `d9 short description`, `model`
  `d9-model`, `parent_type` `agent`, `parent_id` X, `tool_use_id`
  `d9-toolu-b`, `run_mode` `foreground`; `state`, `close_reason`,
  `first_started_at`, `started_at` and `stopped_at` equal those after
  step 5; still one record; A's entry still `confirmed` 0.

## Script

```bash
set -euo pipefail
db="$HOME/.config/agent-director/state.db"
fail() { echo "FAIL: $*"; exit 1; }
id="$(PATH="/opt/driver/stand-in-claude:$PATH" agent-director spawn --agent claude --cwd /tmp | jq -r '.instance_id')"
test -n "$id" || fail "spawn returned no instance_id"

# hook <label> <payload>: type it into X's own pane; exit 0 and empty stdout.
hook() {
    local out
    out="$(/opt/driver/pane-hook.sh "$id" "$2")" || fail "[$1] hook exited non-zero"
    test -z "$out" || fail "[$1] hook stdout = $out; want empty"
}
subs() { agent-director list-subagents --instance-id "$id"; }
# check <label> <jq filter>: the filter must be true of list-subagents' output.
check() {
    local got
    got="$(subs)"
    jq -e "$2" <<<"$got" >/dev/null || fail "[$1] list-subagents = $got; want $2"
}
# sqlv <sql>: one read-only value from the store.
sqlv() { /opt/driver/sql.sh -readonly "$db" "$1"; }
entry_a() { sqlv "SELECT confirmed || '|' || state || '|' || IFNULL(subagent_type, '') FROM subagents WHERE instance_id = '$id' AND subagent_id = 'd9-sub-a';"; }
launches() { sqlv "SELECT count(*) FROM subagent_launches WHERE instance_id = '$id';"; }
null_launch_fields='[.description, .model, .parent_type, .parent_id, .tool_use_id, .run_mode] | all(. == null)'

# 1. X reports in.
hook session-start '{"hook_event_name":"SessionStart","source":"startup","transcript_path":"/x/d9-session.jsonl"}'
state="$(agent-director status --instance-id "$id" | jq -r '.state')"
test "$state" = "waiting" || fail "after SessionStart state=$state; want waiting"

# 2. A starts with no launch request: an unconfirmed entry, never shown.
hook start-a '{"hook_event_name":"SubagentStart","agent_id":"d9-sub-a","agent_type":"general-purpose","session_id":"d9-sess-a"}'
check after-start-a '.tracked == true and .subagents == []'
got="$(entry_a)"
test "$got" = "0|running|general-purpose" || fail "[start-a] A's entry = [$got]; want 0|running|general-purpose"

# 3. A launch request opens a claimable launch and shows nothing.
hook request-b '{"hook_event_name":"PreToolUse","tool_name":"Agent","tool_use_id":"d9-toolu-b","tool_input":{"subagent_type":"general-purpose"}}'
check after-request-b '.subagents == []'
got="$(launches)"
test "$got" = "1" || fail "[request-b] open launches = $got; want 1"

# 4. B's start claims it: one running record, no launch field filled.
hook start-b '{"hook_event_name":"SubagentStart","agent_id":"d9-sub-b","agent_type":"general-purpose","session_id":"d9-sess-b"}'
check after-start-b ".tracked == true and (.subagents | length) == 1 and (.subagents[0]
    | .subagent_id == \"d9-sub-b\" and .instance_id == \"$id\" and .state == \"running\"
      and .subagent_type == \"general-purpose\" and .session_id == \"d9-sess-b\"
      and (.first_started_at | type) == \"string\" and (.started_at | type) == \"string\"
      and (.close_reason == null and .stopped_at == null and .lost_at == null)
      and ($null_launch_fields))"
got="$(launches)"
test "$got" = "0" || fail "[start-b] open launches = $got; want 0 (the start claimed it)"
got="$(entry_a)"
test "$got" = "0|running|general-purpose" || fail "[start-b] A's entry = [$got]; want 0|running|general-purpose"

# 5. B stops.
hook stop-b '{"hook_event_name":"SubagentStop","agent_id":"d9-sub-b"}'
check after-stop-b '(.subagents | length) == 1 and (.subagents[0]
    | .state == "stopped" and .close_reason == "stop_event" and (.stopped_at | type) == "string"
      and .lost_at == null and ('"$null_launch_fields"'))'
times_before="$(subs | jq -c '.subagents[0] | [.first_started_at, .started_at, .stopped_at]')"

# 6. B's completed launch result fills its launch details and changes no state or time.
hook result-b '{"hook_event_name":"PostToolUse","tool_name":"Agent","tool_use_id":"d9-toolu-b","tool_input":{"subagent_type":"general-purpose","description":"d9 short description"},"tool_response":{"status":"completed","agentId":"d9-sub-b","resolvedModel":"d9-model"}}'
check after-result-b ".tracked == true and (.subagents | length) == 1 and (.subagents[0]
    | .subagent_id == \"d9-sub-b\" and .state == \"stopped\" and .close_reason == \"stop_event\"
      and .lost_at == null and .description == \"d9 short description\" and .model == \"d9-model\"
      and .parent_type == \"agent\" and .parent_id == \"$id\" and .tool_use_id == \"d9-toolu-b\"
      and .run_mode == \"foreground\")"
times_after="$(subs | jq -c '.subagents[0] | [.first_started_at, .started_at, .stopped_at]')"
test "$times_after" = "$times_before" || fail "[result-b] times changed: $times_before -> $times_after"
got="$(entry_a)"
test "$got" = "0|running|general-purpose" || fail "[result-b] A's entry = [$got]; want 0|running|general-purpose"
got="$(launches)"
test "$got" = "0" || fail "[result-b] open launches = $got; want 0"

echo "discover-9 ok: id=$id; A (d9-sub-a) stayed unconfirmed and unlisted; B (d9-sub-b) claimed its launch: running with no launch fields, stopped (stop_event) at its SubagentStop, then description/model/parent agent=$id/tool_use_id/run_mode foreground from its completed result, times unchanged"
```
