# resume-11: a resumed row is pending until its agent reports in

Maps to SRD SR-20.9 resume-11 (AC-RES-18, AC-RES-11): `resume` moves a
finished row to `pending` — a launch in progress whose agent has not
reported in yet — keeping its session id and history, and the row
becomes `waiting` only when the agent reports in (SessionStart). The
`resume` result carries `pre_trust` (SR-22.6): X is spawned without
`--no-pre-trust`, so its row allows pre-trust and the resume, with a
`.claude.json` in place, reports `ok` and writes the folder-trust entry.

Hook-driven steps (Epic 8 `t1.h98.xw`, SR-20.9, SR-22.9: a hook moves
the row only when it comes from the row's own pane process): the
SessionStart/SessionEnd payloads in Setup are typed into X's pane, and
the SessionStart in the last step into the pane the resume created,
all through one `hook()` helper that calls
`/opt/driver/pane-hook.sh <id> '<payload>'` (see the collector's
"Driver mode"). No hook is piped from the case's own shell, and no hook
is sent between the resume and the pending-phase checks.

## Setup

Per-case DB-reset. The spawn and both resumes run with
`PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the
`agent-director` command, so the pane process is the stand-in claude's
interactive bash, which sends no hook by itself: the resumed row cannot
report in until the case types a SessionStart. As a second guard the
script also unsets `ANTHROPIC_API_KEY` and `CLAUDE_CODE_OAUTH_TOKEN`
before its first spawn, so even a real Claude would have no credentials.
The script seeds `$HOME/.claude.json` (the file pre-trust targets: X's
row sets no `CLAUDE_CONFIG_DIR`) with `{}` before the spawn, so neither
launch prints a "pre-trust failed" line, and removes it when the case
exits so nothing leaks to later cases.

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd /tmp`
   → capture X's id and tmux session name.
2. Type two SessionStarts into X's pane with different session ids, each with a
   `transcript_path` that is the real on-disk path under
   `$HOME/.claude/projects/-tmp/` (seeded first). The second rotates the
   first into the row's history, so `prior_sessions` is non-empty.
3. Type a SessionEnd into X's pane → X is `ended` with `ended_at` set (and the
   `pid` its SessionStart recorded still set).
4. End X's tmux session so the name is free, then wait (bounded, 5 s)
   until the processes X records have exited: `pid`, `pane_pid` and,
   when this was its server's last session, `tmux_server_pid` (read
   with `sqlite3`).
5. Record X's `started_at`, `claude_session_id` and `prior_sessions`
   from `get` before the resume.

## Steps

1. Wait until the clock's whole second is past X's `started_at`
   (`started_at` carries whole seconds), so the launch start is strictly
   later whatever the timing.
2. Immediately before it, re-seed `$HOME/.claude.json` with `{}` (no
   entry for X's cwd); then `resume` X → exits 0, echoes X's id and
   reports `pre_trust` `ok`; `$HOME/.claude.json` now has
   `projects[<X's canonical cwd>].hasTrustDialogAccepted` true (the cwd
   looked up canonical, `pwd -P` of `/tmp`, as spawn-9 does).
3. Right away, `status` X → `pending`, with a `launch_started_at` later
   than `started_at`, both compared as instants at whole-second
   precision.
4. `get` X → the same `claude_session_id` and the same `prior_sessions`
   as before the resume.
5. `sqlite3` read of X's row → `pid` NULL and `ended_at` NULL.
6. A second `resume` X → non-zero exit; stderr `err_name` is
   `ErrSpawnNotResumable` and `err_description` contains "a launch of
   this row began at" and "its agent has not reported in"; `status` X is
   still `pending`, and `$HOME/.claude.json` is byte-identical to after
   the first resume (the refused resume does not pre-trust).
7. Type a SessionStart for X with its current session id into the pane
   the resume created → `status` X is `waiting` and has no
   `launch_started_at` key; a read-only `sqlite3` read shows X's `pid`
   equal to its `pane_pid`, both set (the applied SessionStart records
   the hook's parent, the resumed pane process).

## Pass criteria

- Setup preconditions hold: after SessionEnd X is `ended` with
  `ended_at` and `pid` set, its session id is the second one, and
  `prior_sessions` is non-empty.
- The first `resume` result's `pre_trust` is `ok` and the trust entry for
  X's canonical cwd is `true` in `$HOME/.claude.json`; the refused second
  `resume` leaves that file byte-identical.
- Every check in Steps 2-7 holds. Each failed check prints a `FAIL:` line
  naming what was expected and what was seen; the final line summarises
  what was checked.

If X turns `waiting` before step 3 without the typed SessionStart,
something in the resumed pane reported in on its own (for example the
stand-in was not selected): report that rather than loosening the case.

## Script

```bash
set -euo pipefail
# The stand-in sends no hook by itself; as a second guard, no credentials
# either, so nothing in the resumed pane can report in on its own.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN
standin_path="/opt/driver/stand-in-claude:$PATH"
db="$HOME/.agent-director/state.db"
jsonl_dir="$HOME/.claude/projects/-tmp"
claude_json="$HOME/.claude.json"
fail() { echo "FAIL: $*"; exit 1; }
# end_and_wait <id> <tmux target>: ends the row's tmux session, then waits
# (bounded, 5 s) until the processes the row records have exited (no /proc
# entry), so resume's lookup meets neither a pane process nor a tmux server
# that is still exiting: its pid and pane_pid, and its tmux_server_pid when
# the session was the server's last. A server that holds other sessions
# keeps running (as kill-4's bystander does), and must still run after.
end_and_wait() {
    local id="$1" target="$2" rec rpid rpane rserver rsock n left p end
    rec="$(/opt/driver/sql.sh -readonly "$db" "SELECT IFNULL(pid,'') || '|' || IFNULL(pane_pid,'') || '|' || IFNULL(tmux_server_pid,'') || '|' || IFNULL(tmux_socket,'') FROM spawns WHERE claude_instance_id = '$id';")"
    IFS='|' read -r rpid rpane rserver rsock <<<"$rec"
    [[ "$rpid|$rpane|$rserver" =~ ^[0-9]+\|[0-9]+\|[0-9]+$ ]] || fail "$id records pid|pane_pid|tmux_server_pid [$rpid|$rpane|$rserver]; want all set"
    n="$(tmux ${rsock:+-S "$rsock"} list-sessions 2>/dev/null | wc -l)"
    tmux ${rsock:+-S "$rsock"} kill-session -t "$target" || fail "kill-session -t $target of $id failed"
    set -- "$rpid" "$rpane"
    [ "$n" -gt 1 ] || set -- "$@" "$rserver"
    end=$(( $(date +%s%N) + 5000000000 ))
    while :; do
        left=""
        for p in "$@"; do [ ! -e "/proc/$p" ] || left+=" $p"; done
        [ -n "$left" ] || break
        [ "$(date +%s%N)" -lt "$end" ] || fail "$id's recorded process(es)$left still running 5 s after its session $target ended"
        sleep 0.1
    done
    [ "$n" -le 1 ] || [ -e "/proc/$rserver" ] || fail "tmux server $rserver of $id ended although it held $((n - 1)) other session(s)"
}
# Pre-trust targets $HOME/.claude.json (X sets no CLAUDE_CONFIG_DIR). Seed it
# so no launch prints "pre-trust failed"; remove it on exit so it does not
# leak into later cases.
trap 'rm -f "$claude_json"' EXIT
echo '{}' > "$claude_json"

id=$(PATH="$standin_path" agent-director spawn --cwd /tmp | jq -r '.claude_instance_id')
[ -n "$id" ] || fail "spawn returned no claude_instance_id"
sess=$(agent-director get --claude-instance-id "$id" | jq -r '.tmux_session_name')

# Synthesised hooks (setup and the last step only), typed into X's recorded
# pane: SR-22.9 applies a hook only when its parent is the row's pane
# process. pane-hook.sh exits with the hook's own exit status.
hook() { /opt/driver/pane-hook.sh "$id" "$1" >/dev/null || fail "hook $1 exited non-zero"; }
session_start() {
    printf '{"hook_event_name":"SessionStart","transcript_path":"%s"}' "$jsonl_dir/$1.jsonl"
}

# Setup: two sessions (so prior_sessions is non-empty), then SessionEnd.
mkdir -p "$jsonl_dir"
for s in r11-session-a r11-session-b; do
    echo '{}' > "$jsonl_dir/$s.jsonl"
    hook "$(session_start "$s")"
done
hook '{"hook_event_name":"SessionEnd","reason":"logout"}'

before=$(agent-director get --claude-instance-id "$id")
state=$(jq -r '.state' <<<"$before")
[ "$state" = "ended" ] || fail "precondition state=$state; want ended"
sid_before=$(jq -r '.claude_session_id' <<<"$before")
[ "$sid_before" = "r11-session-b" ] || fail "precondition claude_session_id=$sid_before; want r11-session-b"
prior_before=$(jq -c '.prior_sessions' <<<"$before")
n_prior=$(jq 'length' <<<"$prior_before")
[ "$n_prior" -ge 1 ] || fail "precondition prior_sessions=$prior_before; want non-empty"
ended_before=$(/opt/driver/sql.sh "$db" "SELECT IFNULL(ended_at,'') FROM spawns WHERE claude_instance_id='$id';")
[ -n "$ended_before" ] || fail "precondition ended_at empty after SessionEnd; want set"
pid_before=$(/opt/driver/sql.sh "$db" "SELECT IFNULL(pid,'') FROM spawns WHERE claude_instance_id='$id';")
[ -n "$pid_before" ] || fail "precondition pid NULL after SessionStart; want set (else the NULL check proves nothing)"
started_at=$(jq -r '.started_at' <<<"$before")
started_s=$(date -u -d "$started_at" +%s)

# Free the name and wait for the recorded processes to exit.
end_and_wait "$id" "$sess"

# started_at carries whole seconds: let the clock pass it so the launch
# start is strictly later deterministically.
while [ "$(date -u +%s)" -le "$started_s" ]; do sleep 0.1; done

# Re-seeded with no entry for X's cwd right before the resume, so the entry
# checked below can only come from the resume's own pre-trust (SR-22.6).
cwd=$(cd /tmp && pwd -P)
echo '{}' > "$claude_json"
out=$(PATH="$standin_path" agent-director resume --claude-instance-id "$id") || fail "resume exited non-zero; want 0"
got_id=$(jq -r '.claude_instance_id' <<<"$out")
[ "$got_id" = "$id" ] || fail "resume echoed id=$got_id; want $id"
pre_trust=$(jq -r '.pre_trust' <<<"$out")
[ "$pre_trust" = "ok" ] || fail "resume pre_trust=$pre_trust; want ok"
trusted=$(jq -r --arg cwd "$cwd" '.projects[$cwd].hasTrustDialogAccepted // "absent"' "$claude_json")
[ "$trusted" = "true" ] || fail "after resume $claude_json projects[$cwd].hasTrustDialogAccepted=$trusted; want true"
claude_json_after=$(mktemp)
cp "$claude_json" "$claude_json_after"

# Pending-phase checks, right after the resume.
st=$(agent-director status --claude-instance-id "$id")
state=$(jq -r '.state' <<<"$st")
[ "$state" = "pending" ] || fail "after resume state=$state; want pending (waiting means the agent reported in on its own)"
launch=$(jq -r '.launch_started_at // empty' <<<"$st")
[ -n "$launch" ] || fail "after resume status has no launch_started_at; want one"
launch_s=$(date -u -d "$launch" +%s)
[ "$launch_s" -gt "$started_s" ] || fail "launch_started_at=$launch not later than started_at=$started_at"

after=$(agent-director get --claude-instance-id "$id")
sid_after=$(jq -r '.claude_session_id' <<<"$after")
[ "$sid_after" = "$sid_before" ] || fail "after resume claude_session_id=$sid_after; want $sid_before"
prior_after=$(jq -c '.prior_sessions' <<<"$after")
[ "$prior_after" = "$prior_before" ] || fail "after resume prior_sessions=$prior_after; want $prior_before"

row=$(/opt/driver/sql.sh "$db" "SELECT IFNULL(pid,'NULL') || '|' || IFNULL(ended_at,'NULL') FROM spawns WHERE claude_instance_id='$id';")
[ "$row" = "NULL|NULL" ] || fail "after resume pid|ended_at=$row; want NULL|NULL"

# A second resume of the pending row is refused as a launch in progress.
stderr_file=$(mktemp)
if PATH="$standin_path" agent-director resume --claude-instance-id "$id" >/dev/null 2>"$stderr_file"; then
    fail "second resume exited 0; want non-zero"
fi
err_name=$(jq -r '.err_name' "$stderr_file")
[ "$err_name" = "ErrSpawnNotResumable" ] || fail "second resume err_name=$err_name; want ErrSpawnNotResumable"
desc=$(jq -r '.err_description' "$stderr_file")
for want in "a launch of this row began at" "its agent has not reported in"; do
    case "$desc" in
        *"$want"*) ;;
        *) fail "second resume err_description lacks \"$want\": $desc" ;;
    esac
done
state=$(agent-director status --claude-instance-id "$id" | jq -r '.state')
[ "$state" = "pending" ] || fail "after refused resume state=$state; want pending"
cmp -s "$claude_json" "$claude_json_after" || fail "refused resume changed $claude_json; want byte-identical"

# The agent reports in: SessionStart (current session id) typed into the
# pane the resume created (pane-hook.sh reads the row's pane now).
hook "$(session_start "$sid_before")"
st=$(agent-director status --claude-instance-id "$id")
state=$(jq -r '.state' <<<"$st")
[ "$state" = "waiting" ] || fail "after SessionStart state=$state; want waiting"
has_launch=$(jq 'has("launch_started_at")' <<<"$st")
[ "$has_launch" = "false" ] || fail "after SessionStart status has launch_started_at; want absent"
# SR-22.9: the applied SessionStart records the hook's parent, the resumed pane process.
pids=$(/opt/driver/sql.sh -readonly "$db" "SELECT IFNULL(pid,'NULL') || '|' || IFNULL(pane_pid,'NULL') FROM spawns WHERE claude_instance_id='$id';")
[[ "$pids" =~ ^([0-9]+)\|([0-9]+)$ ]] || fail "after SessionStart pid|pane_pid=$pids; want both set"
[ "${BASH_REMATCH[1]}" = "${BASH_REMATCH[2]}" ] || fail "after SessionStart pid|pane_pid=$pids; want pid = pane_pid"

echo "resume-11 ok: resume->pending, pre_trust ok + trust entry written, launch>started, session+${n_prior} prior kept, pid/ended_at NULL; 2nd resume ErrSpawnNotResumable, .claude.json unchanged; SessionStart->waiting, no launch_started_at, pid=pane_pid"
```
