# Test case: Installed Bun multiline input and mixed caller continuity

Maps E3 AC1/2/5; SR-0.2, SR-0.3, SR-3.1–3.3, SR-4.1–4.2.

## Setup

Linux Docker image and source mount at the exact scheduler SHA. Image build must
install locked build dependencies, run the canonical build including declarations,
pack and install the public Bun tarball into its baked consumer. Runtime networking
stays disabled; source-input hashes must match the image. Shared isolated Cursor helper;
scripted synthetic ACP and actual tmux, CLI, MCP and installed Bun consumer.

## Steps

1. Verify baked package provenance and copy its installed consumer into a private
   directory without invoking a package manager. Send two
   successive complete Unicode multiline prompts through separate installed clients.
2. Hold a third turn by explicit runtime event. Admit a terminal-shaped input,
   then a multiline installed-client input. Replace the MCP inspection caller
   while the turn and queue remain active; release the held turn exactly once.
3. Correlate exact FIFO texts, submission/request/session IDs and raw bytes;
   inspect the pane through the installed client, pause and verify owned death.

## Pass criteria

Five exact accepted/start/outcome/wire correlations, unchanged launch identity
across caller replacement, no cancellation from follow-ups, both decoys unchanged,
unrelated sentinel alive. One final stable-check JSON verdict. No human/auth claim.

```bash
set -euo pipefail
source /work/source/test/driver/cursor-pane-controls.sh
check_id=installed.setup
pc_install_bun
pc_start
texts=($'第一 🐝\nline café' $'second 🦋\n別の行' HOLD 'terminal queued café' $'public queued 🐝\nlast line')
printf '%s\0' "${texts[@]}" | jq -Rs 'split("\u0000")[:-1]' > "$case_dir/want.json"
for i in 0 1; do
 check_id=prompt.successive-multiline
 pc_send Bun "${texts[$i]}" >/dev/null
 check prompt.ready wait_until pc_ready "$((i+1))"
done
pc_send Bun HOLD >/dev/null
check prompt.held wait_until pc_prompts_is 3
pc_terminal "${texts[3]}"
check prompt.terminal-admitted wait_until pc_count_is submission_accepted 4
pc_send Bun "${texts[4]}" >/dev/null
check prompt.public-admitted wait_until pc_count_is submission_accepted 5
for caller in 1 2; do
 pc_public MCP get "$(jq -cn --arg id "$id" '{instance_id:$id}')" > "$case_dir/recreated-$caller.json"
 check caller.identity pc_identity
 check caller.active test "$(row_state)" = working
 check caller.queue-held pc_prompts_is 3
done
touch "$case_dir/release"
check prompt.completed wait_until pc_ready 5
pc_correlate
pc_public Bun read-pane "$(jq -cn --arg id "$id" '{instance_id:$id,n_lines:200}')" | jq -e '.pane|contains("Synthetic reply:") and contains("last line")' >/dev/null
check_id=owned.pause
pc_public Bun pause "$(jq -cn --arg id "$id" '{instance_id:$id}')" >/dev/null
check owned.runtime-gone wait_gone "$runtime"
check owned.gateway-gone wait_gone "$gateway"
pc_finish t2.jf1.pc.01 '["prompt.exact-FIFO-IDs-raw","caller.replaced-active-queue","installed.tarball-public-client","owned.pause-death","store.decoys"]'
```
