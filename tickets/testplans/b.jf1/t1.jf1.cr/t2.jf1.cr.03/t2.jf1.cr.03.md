# Test case: Durable first-byte acknowledgements and absent ack faults

Maps to E2 AC3; SR-4.2, SR-5.2, SR-9.1/9.2.

## Setup

The harness reset supplies its clean baseline. Source the shared driver, which creates an additional private synthetic Cursor namespace with an override store and control sentinel. All SQL, including raw-byte observer queries and faults, goes through /opt/driver/sql.sh. Source mount and shipped binary must match the scheduler's full commit. No authenticated runtime is used.

## Steps

Execute the ordered block below. Each check tests the stated caller-visible state, preserved fields, request correlation, committed evidence, actual wire bytes or process lifetime. Any injected fault is a test fixture action; it does not establish a production configuration feature.

## Pass criteria

Every assertion passes and one final JSON object contains this case ID, stable check names, status pass, authenticated_cursor false and separate variable facts. Do not treat an exit code alone as evidence. The collector must be executed externally before claiming a case pass.

```bash
set -euo pipefail
receipts=$(mktemp /tmp/cr-ack-receipts-XXXXXX)
for verdict in allow deny timeout; do
 for fault in none failed missing; do
  (
   CURSOR_RELAY_TIMEOUT=2
   source /work/source/test/driver/cursor-owned-launch.sh
   relay_scenario permission
   relay_observe
   relay_start
   wait_until request_count_is 1
   token=$(sql "SELECT request_token FROM permission_requests WHERE instance_id='$id';")
   if [[ $fault == failed ]]; then relay_fault_ack; fi
   if [[ $fault == missing ]]; then sql "CREATE TRIGGER refuse_ack BEFORE UPDATE OF delivered_at ON permission_requests WHEN NEW.delivered_at IS NOT NULL BEGIN SELECT RAISE(IGNORE); END;"; fi
   before=$(raw_size)
   if [[ $verdict != timeout ]]; then relay_decide "$token" "$verdict" >/dev/null; fi
   if [[ $fault == none ]]; then
    wait_until reply_count_is 1
    jq -se 'length>=1 and all(.[]; length==1 and .[0].decision!=null and .[0].delivered_at!=null)' "$case_dir/commits.jsonl" >/dev/null
    [[ $(sql "SELECT delivered_at IS NOT NULL FROM permission_requests WHERE request_token='$token';") == 1 ]]
   else
    wait_until delivery_is "$token" fallen_back
    [[ $(raw_size) == "$before" ]]
    [[ $(sql "SELECT delivered_at IS NULL FROM permission_requests WHERE request_token='$token';") == 1 ]]
   fi
   relay_receipt t2.jf1.cr.03 '["AC3.committed-before-raw-byte","AC3.failed-ack-zero-bytes","AC3.missing-ack-zero-bytes","AC3.timeout-deny-zero-without-ack"]' >> "$receipts"
  )
 done
done
jq -s '{case:"t2.jf1.cr.03",status:"pass",checks:["AC3.committed-before-raw-byte","AC3.failed-ack-zero-bytes","AC3.missing-ack-zero-bytes","AC3.timeout-deny-zero-without-ack"],authenticated_cursor:false,facts:{runs:map(.facts)}}' "$receipts"
```
