# interact-10: a row whose name is held by another row's session

Maps to SRD SR-20.9 (new interact-10), SR-3.4, SR-7.2 and SR-18.1
(Epic 11 `t1.h98.m6`, Task `t2.h98.m6.cp`): the pane verbs find a row's
session only by the row's own `@ad_owner` label, never by its name. Row
A records the name `cd-i10` but has no session of its own; a session
named `cd-i10` is up, and it is row B's: made with
`-e AGENT_DIRECTOR_INSTANCE_ID=id-i10b` and labelled for B. A's lookup
finds no session carrying A's label, and the session holding A's name
carries only another row's label, so A's session is Gone (never Ours,
never A's to adopt): `send-keys` of A returns `ErrTmuxSendKeys` and
`read-pane` of A returns `ErrTmuxCaptureFailed`, and B's pane receives
nothing.

Seeding (kill-1 pattern, `t2.75s.ks.3h`): B's session is made by hand
with `cat` as its only pane, so that pane is window 0 pane 0, exactly
what a send or capture by the name `cd-i10` would hit. Its `$N` and pane
id `%N` are captured at creation. B's row carries its own 16-hex
`launch_token` and records no socket, server, pid or pane; the token and
the store id (`store_meta` `store_id`) are read back with `sqlite3`,
never hard-coded; the session gets the five-field label
`ad1 <B's token> <$N> id-i10b <store id>` (`set-option -t '<$N>'`) and
the pane gets `@ad_pane` `<B's token> <%N>` (`set-option -p`), as
agent-director's own create sets them. Row A carries a different
`launch_token` and also records no socket, server, pid or pane. Nothing
is adopted for A (its lookup is Gone), so A's whole row is unchanged.
A positive control, `read-pane` of B, shows B's label is well-formed
(B's lookup is Ours), so A's results come from the label not being A's,
not from a malformed label.

## Setup

Per-case DB-reset has wiped `~/.agent-director/state.db` and ended
every tmux server; the store exists after the reset, so its id can be
read from `store_meta`. The container has `agent-director`, `tmux`,
`sqlite3`, and `jq` on PATH. An EXIT trap removes B's session by its
session id if the case fails part-way.

## Steps

1. Read this store's id with `sqlite3` (`SELECT value FROM store_meta
   WHERE key = 'store_id'`).
2. Seed rows `id-i10a` and `id-i10b`, both `waiting`, both with
   `tmux_session_name=cd-i10`, each with its own `launch_token` of 16
   lowercase hex characters; read both tokens back with `sqlite3` and
   check they differ.
3. `tmux new-session -d -s cd-i10 -e AGENT_DIRECTOR_INSTANCE_ID=id-i10b
   -- cat`, capturing `$N` and `%N`; label the session for B by `$N`
   and B's pane with `@ad_pane`; read both back.
4. Type a marker `B-MARK-i10` into B's pane by pane id and wait until a
   capture of `%N` shows it (the capture sees live pane content).
5. Snapshot both rows (every column) and B's label.
6. `agent-director send-keys --claude-instance-id id-i10a --text
   'i10-sent-to-a'`.
7. `agent-director read-pane --claude-instance-id id-i10a`.
8. Wait 0.5 s, then capture B's pane by `%N` and list every pane of B's
   session by `$N`.
9. Positive control: `agent-director read-pane --claude-instance-id
   id-i10b`.

## Pass criteria

- The store id and both tokens are 16 lowercase hex; the tokens differ;
  the label read back has five fields and equals the one set.
- Step 6 exits non-zero; stderr JSON `err_name` is `ErrTmuxSendKeys`.
- Step 7 exits non-zero; stderr JSON `err_name` is
  `ErrTmuxCaptureFailed`.
- Step 8: B's pane shows `B-MARK-i10` and no `i10-sent-to-a`; B's
  session `$N` still has exactly its one pane `%N`, still running
  (`has-session -t '<$N>'`); its `@ad_owner` is unchanged.
- Both rows (every column) are the same as in step 5.
- Step 9 exits 0 and its `.pane` shows `B-MARK-i10` and no
  `i10-sent-to-a`.

## Script

```bash
set -euo pipefail
db="$HOME/.agent-director/state.db"
fail() { echo "FAIL: $*"; exit 1; }
sid=""
stderr_file="$(mktemp)"
trap 'rm -f "$stderr_file"; [ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true' EXIT

store_id="$(/opt/driver/sql.sh "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

for r in id-i10a id-i10b; do
    seed_token="$(od -An -N8 -tx1 /dev/urandom | tr -dc '0-9a-f')"
    /opt/driver/sql.sh "$db" \
      "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, launch_token)
       VALUES ('$r', 'waiting', '/tmp', 'cd-i10', 'off', '$seed_token');"
done
token_a="$(/opt/driver/sql.sh "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-i10a';")"
token_b="$(/opt/driver/sql.sh "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-i10b';")"
[[ "$token_a" =~ ^[0-9a-f]{16}$ ]] || fail "A's launch_token is not 16 lowercase hex: [$token_a]"
[[ "$token_b" =~ ^[0-9a-f]{16}$ ]] || fail "B's launch_token is not 16 lowercase hex: [$token_b]"
[ "$token_a" != "$token_b" ] || fail "A and B have the same token [$token_a]"

read -r sid pane < <(tmux new-session -d -s cd-i10 -e AGENT_DIRECTOR_INSTANCE_ID=id-i10b \
    -P -F '#{session_id} #{pane_id}' -- cat)
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"
[[ "$pane" =~ ^%[0-9]+$ ]] || fail "new-session gave pane id [$pane]"

label="ad1 $token_b $sid id-i10b $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
tmux set-option -p -t "$pane" @ad_pane "$token_b $pane"
got_label="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$got_label" = "$label" ] || fail "label read back [$got_label]; want [$label]"
read -r -a fields <<<"$got_label"
[ "${#fields[@]}" -eq 5 ] || fail "label has ${#fields[@]} fields; want 5: [$got_label]"
got_ad_pane="$(tmux show-options -p -t "$pane" -v @ad_pane)"
[ "$got_ad_pane" = "$token_b $pane" ] || fail "@ad_pane read back [$got_ad_pane]; want [$token_b $pane]"

tmux send-keys -t "$pane" -l 'B-MARK-i10'
tmux send-keys -t "$pane" Enter
for _ in $(seq 1 50); do
    tmux capture-pane -p -t "$pane" | grep -q 'B-MARK-i10' && break
    sleep 0.1
done
tmux capture-pane -p -t "$pane" | grep -q 'B-MARK-i10' || fail "marker never showed in B's pane $pane"

rows_q="SELECT * FROM spawns WHERE claude_instance_id IN ('id-i10a', 'id-i10b') ORDER BY claude_instance_id;"
rows_before="$(/opt/driver/sql.sh "$db" "$rows_q")"

# A's send-keys: Gone (the name's holder carries only B's label), nothing sent.
if agent-director send-keys --claude-instance-id id-i10a --text 'i10-sent-to-a' 2>"$stderr_file"; then
    fail "send-keys of A exited 0; want ErrTmuxSendKeys"
fi
err_name="$(jq -r '.err_name' <"$stderr_file")"
[ "$err_name" = "ErrTmuxSendKeys" ] || fail "send-keys of A err_name [$err_name]; want ErrTmuxSendKeys ($(cat "$stderr_file"))"

# A's read-pane: Gone too.
if agent-director read-pane --claude-instance-id id-i10a >/dev/null 2>"$stderr_file"; then
    fail "read-pane of A exited 0; want ErrTmuxCaptureFailed"
fi
err_name="$(jq -r '.err_name' <"$stderr_file")"
[ "$err_name" = "ErrTmuxCaptureFailed" ] || fail "read-pane of A err_name [$err_name]; want ErrTmuxCaptureFailed ($(cat "$stderr_file"))"

# B's pane received nothing; B's session, pane and label are untouched.
sleep 0.5
b_text="$(tmux capture-pane -p -t "$pane")"
grep -q 'B-MARK-i10' <<<"$b_text" || fail "B's pane $pane lost its marker: [$b_text]"
if grep -q 'i10-sent-to-a' <<<"$b_text"; then
    fail "A's text reached B's pane $pane: [$b_text]"
fi
tmux has-session -t "$sid" 2>/dev/null || fail "B's session $sid is gone"
panes="$(tmux list-panes -s -t "$sid" -F '#{pane_id}')"
[ "$panes" = "$pane" ] || fail "B's session $sid panes [$panes]; want only $pane"
got_label="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$got_label" = "$label" ] || fail "B's label changed: [$got_label]; want [$label]"

rows_after="$(/opt/driver/sql.sh "$db" "$rows_q")"
[ "$rows_before" = "$rows_after" ] || fail "rows changed: before [$rows_before] after [$rows_after]"

# Positive control: B's own lookup is Ours, so its label is well-formed.
rp="$(agent-director read-pane --claude-instance-id id-i10b)" || fail "read-pane of B exited non-zero"
b_read="$(jq -r '.pane' <<<"$rp")"
grep -q 'B-MARK-i10' <<<"$b_read" || fail "read-pane of B did not return its marker: [$b_read]"
if grep -q 'i10-sent-to-a' <<<"$b_read"; then
    fail "read-pane of B shows A's text: [$b_read]"
fi

echo "interact-10 ok: A (name cd-i10, no session) -> send-keys ErrTmuxSendKeys, read-pane ErrTmuxCaptureFailed; B's session $sid pane $pane got nothing, label and both rows unchanged; read-pane of B reads its own pane"
```
