# Exempt --keep-prior and file-only reuse

Maps to the existing installer flag contract and b.kii E7. Before layout
establishment, --keep-prior preserves the mutable old binary. Once a layout
exists, the same flag is explicitly unused and immutable versions are retained.
Install-16 exercises publication rollback without restoring a database.

## Setup

Scratch HOME with a pre-layout canonical pair. The runtime has one appended
byte solely to distinguish the preserved prior file from the shipped candidate;
it is not a separately stamped version eligible for versioned publication.

## Steps

1. Establish the exempt layout with --keep-prior. Check the prior file's exact
   bytes/mode and the shipped binary through the permanent entry.
2. Rerun the identical install with --keep-prior. Require its unused summary,
   unchanged prior snapshot and retained ready version.

## Pass criteria

Both installs exit 0. Exempt snapshot bytes survive; later reuse creates no
additional versions and does not overwrite that snapshot.

```bash
set -euo pipefail
TESTHOME=$(mktemp -d)
trap 'rm -rf "$TESTHOME"' EXIT
root="$TESTHOME/.config/agent-director"
mkdir -p "$root/bin" "$root/admin"
cp /usr/local/bin/agent-director "$root/bin/agent-director"
printf '\0' >>"$root/bin/agent-director"
cp /opt/bin/agent-director-admin "$root/admin/agent-director-admin"
cp "$root/bin/agent-director" "$TESTHOME/old"
for iteration in 1 2; do
    HOME="$TESTHOME" /opt/skills/install-agent-director/install.sh --binary /usr/local/bin/agent-director --no-hooks --no-symlink --keep-prior >"$TESTHOME/out" 2>"$TESTHOME/err" \
        || { cat "$TESTHOME/out" "$TESTHOME/err"; exit 1; }
    cmp "$TESTHOME/old" "$root/bin/agent-director.prior"
    [ "$(stat -c %a "$root/bin/agent-director.prior")" = 755 ]
    [ "$(readlink "$root/bin/agent-director")" = ../current/agent-director ]
    cmp /usr/local/bin/agent-director "$root/bin/agent-director"
    [ -f "$root/current/ready" ]
    [ "$(find "$root/versions" -name ready | wc -l)" = 1 ]
done
grep -q -- '--keep-prior unused' "$TESTHOME/out"
echo 'install-8 ok: exempt prior retained, later flag unused, immutable version reused'
```
