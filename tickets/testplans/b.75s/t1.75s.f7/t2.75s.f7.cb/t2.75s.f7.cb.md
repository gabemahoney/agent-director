# InstallCrashRerunRollback

Maps to b.kii E7 criteria 2–3, M3 T2/T5/T6/T8, Subtask t3.xis.jo.m5.kx.

## Setup

Reuse install-15's cached pair, caller adapters and shared fixtures, with an
independent scratch HOME and TMUX namespace. The later admin is **instrumented**
only at its Engine construction; the real filesystem operations and admin
dispatch/results are unchanged. The shrinking-coverage candidate is compiled
with an empty covered set in both binaries, with no fault overlay or edited
manifest. The initial installed pair and rollback admin are shipped unmodified.

## Steps

1. Complete exempt setup and matched control calls as in install-15. Run actual
   install.sh; hold its admin at `after:current.rename`, before directory fsync.
2. Complete four-interface covered/uncovered sends and representative CLI calls
   while held. SIGKILL that exact admin PID. Require installer exit 5 with
   unknown publication outcome; repeat runtime calls after its death.
3. Remove the case's barrier file and rerun the identical installer request.
   Immutable pair bytes must match, so forward completion uses that same
   instrumented admin, now with no hold. Require the exact summary selecting
   the candidate with reused=true, recovered_version equal to the candidate,
   publication_state=published, durable=true and initialization_complete=true.
   Before rollback, verify the previously absent completion record binds the
   interrupted intent's sequence and original SHA-256. Check stable entries.
4. Use the unmodified shipped admin's `rollback-version --version <initial>`.
   Install the genuinely compiled shrinking candidate; require exit 5 and
   coverage_regression with no rejected ready version. Repeat runtime calls
   through the restored shipped pair and the existing clients.
5. Deliver all held Claude Messages using the shared owned-hook protocol.

## Pass criteria

The rename/crash exposes a complete executable pair. Every bounded send and
representative CLI call succeeds in control, held, dead, published and
rolled-back phases; the zero-wait relay decision receives a real acknowledgement.
Acceptance order/pairs survive recovery, rollback and refusal. Every accepted
body is handed over once, with the exact qualified Result from install-15.
Admin-only windows change no runtime data, input, wake or lifecycle identity.
Retained executables remain usable. Process death is not power-loss durability
evidence or the T7 host-stalled SQLite exception; 5g owns the other crash points.

```bash
set -euo pipefail
bash /opt/driver/busy-send-install/install.sh crash
```
