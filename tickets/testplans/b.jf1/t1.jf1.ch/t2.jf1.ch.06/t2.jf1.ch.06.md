# Test case: composed independent child

Maps E7 AC5/6, PRD13–15 and SR8/9/11. Reuse the configured MCP child,
public operations, protected records and isolated real tmux collector.

Create an actual child through the parent's configured MCP. Observe legitimate
child session start and completed work, including one shipped hook invoked by
that child's actual runtime but addressed to the parent. Require distinct
gateway/connection authority and unchanged parent session/token/life/runtime,
all-life history and transcript. Hook exit success is never rejection proof.

Admit the child's captured execute permission. Complete useful parent work and
switch the finished parent from Cursor to an inert Codex stand-in. Assert the
parent's legitimate life/session change separately. The child's identity,
association and discovery remain stable; ordinary Cursor/Codex list-subagents
both return tracked=false and an empty array. Parent events cannot decide,
deliver, prove or renew the child's request; its unknown-origin hold remains.

Resolve the exact child token through decide/get-permission, observe its actual
correlated ACP answer, retain the hold after delivered acknowledgement, then
emit the matching session/tool execution update with rawOutput. Require useful
child work after that proof and a legitimate child end without parent mutation.
Retire owned runtime/gateway/MCP processes before tmux teardown. Preserve first
failures, raw child protocol, protected records and authority snapshots.

tmux transport are real. No native Cursor/Codex consumption, shell sandbox,
compaction, runtime/platform/client timing or account acceptance follows.
