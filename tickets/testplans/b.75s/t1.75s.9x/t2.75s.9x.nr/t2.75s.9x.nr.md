# interact-11: a resumed row is pending with its new session up; send-keys --allow-pending reaches it

Maps to SRD SR-20.9 (new interact-11, launch pending; PRD AC-PANE-08,
AC-PANE-09, AC-DOC-14), SR-7.1, SR-22.8 and SR-18.14 (Epic 11
`t1.h98.m6`, Task `t2.h98.m6.cp`). This is the Epic's user demo: X is
spawned, reports in, finishes and is resumed; the resume's new session
comes up while X's row is `pending` (its agent has not reported in
yet). An agent can then already drive and read that session:
`send-keys --allow-pending` with empty text exits 0 (it presses Enter
in the agent's pane), a non-empty text is delivered and runs, and
`read-pane` returns the pane. Without `--allow-pending`, `send-keys`
refuses the `pending` row with `ErrSpawnNotInteractive` and types
nothing. A second row Y, finished and never resumed, is refused with
`ErrSpawnNotInteractive` even with `--allow-pending` (finished rows are
refused with no tmux call) and stays `ended`. X stays `pending` through
all the pane-verb calls and turns `waiting` only when SessionStart is
sent from the resumed pane.

Agent and hooks (SR-20.9, SR-22.9; collector "Driver mode"): no real
`claude` starts. Both spawns and the resume run with
`PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the
`agent-director` command, so each pane's process is the stand-in's
interactive bash (`bash --noprofile --norc -i`, checked through
`/proc/<pane_pid>/cmdline` after the resume, since a resume does not
re-select the stand-in through the row's extra environment). Every hook
is typed into the row's recorded pane with `/opt/driver/pane-hook.sh
<id> '<payload>'`, so the hook's parent is the pane process; no hook is
piped from the case's own shell, and none is sent between the resume
and the pending-phase checks. Text typed with `send-keys` lands in that
bash.

Pane identity: the spawn and the resume record the pane id and pid from
their own create reply, so nothing is adopted here; the pane verbs
reach X's resumed pane by the recorded pane id under the row's current
launch token.

Credential isolation (Epic 10 Task 4 T6 pattern), before any tmux or
agent-director call: `ANTHROPIC_API_KEY` and `CLAUDE_CODE_OAUTH_TOKEN`
are unset and removed from the tmux server's global environment
(tolerating no server); after each spawn and after the resume, neither
appears in `/proc/<recorded pane_pid>/environ`.

## Setup

Per-case DB-reset. The container has `agent-director`, `tmux`,
`sqlite3`, `jq`, the stand-in claude under `/opt/driver/stand-in-claude/`
and `/opt/driver/pane-hook.sh`. X's session is named `cd-i11x` and Y's
`cd-i11y`, so the reset sweeps them; an EXIT trap also kills both by
session id, and removes the transcripts the case seeds.

1. Credential isolation as above.
2. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd
   /tmp --tmux-session-name cd-i11x` → X. Read X's `tmux_socket`,
   `pane_id` and `pane_pid` with `sqlite3`; check the pane environ.
3. Seed X's transcript `$HOME/.claude/projects/-tmp/i11-x.jsonl`, then
   type a SessionStart with that `transcript_path` into X's pane → a
   `sqlite3` read shows `state` `waiting`, `claude_session_id` `i11-x`
   and `pid` = `pane_pid`.
4. Type a SessionEnd into X's pane → X is `ended`.
5. End X's session by its session id (`$N`, read from the pane), then
   wait (bounded, 5 s) until the processes X records have exited:
   `pid`, `pane_pid` and, when this was its server's last session,
   `tmux_server_pid` (read with `sqlite3`), so the resume's lookup
   meets neither a pane process nor a tmux server still exiting.
6. `PATH=/opt/driver/stand-in-claude:$PATH agent-director resume
   --claude-instance-id X` → exit 0, echoes X.

## Steps

1. Right after the resume: `status` X is `pending` with a
   `launch_started_at`; a `sqlite3` read gives the resumed pane's
   `pane_id` and `pane_pid` (both set, the pid differs from the first
   pane's); the pane's process is the stand-in bash; the pane environ
   holds no credentials.
2. `agent-director send-keys --claude-instance-id X --allow-pending
   --text ''` → exit 0, `{}`.
3. `agent-director send-keys --claude-instance-id X --allow-pending
   --text 'echo i11-$((40+2))'` → exit 0, `{}`; the resumed pane (by
   pane id) shows `i11-42`.
4. `agent-director read-pane --claude-instance-id X` → exit 0 with a
   string `pane` field showing `i11-42`.
5. `agent-director send-keys --claude-instance-id X --text 'echo
   i11-noflag-$((1+1))'` (no `--allow-pending`) → non-zero,
   `ErrSpawnNotInteractive`; after 0.5 s the pane shows no
   `i11-noflag-2`.
6. `status` X is still `pending`.
7. Y: `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd
   /tmp --tmux-session-name cd-i11y`; check its pane environ; type a
   SessionStart (`transcript_path` `.../i11-y.jsonl`) then a SessionEnd
   into Y's pane → Y is `ended` (its session still runs: the stand-in
   bash outlives the SessionEnd).
8. `agent-director send-keys --claude-instance-id Y --allow-pending
   --text 'echo i11-to-y-$((2+2))'` → non-zero, `ErrSpawnNotInteractive`;
   Y is still `ended`; after 0.5 s Y's pane (by pane id) shows no
   `i11-to-y-4`.
9. Type a SessionStart (`source` `resume`, `transcript_path` X's
   `i11-x.jsonl`) into X's resumed pane → `status` X is `waiting`
   with no `launch_started_at`; a `sqlite3` read shows `pid` = the
   resumed `pane_pid`.

## Pass criteria

- Setup: both spawns and the resume exit 0; X records a session id
  `i11-x` and `pid` = `pane_pid` after its first SessionStart, and is
  `ended` after SessionEnd; no credential variable in any recorded
  pane's environ.
- Steps 1-6: X is `pending` right after the resume and after every
  pane-verb call; the resumed pane process is the stand-in bash;
  `send-keys --allow-pending` with empty and non-empty text exits 0 with
  `{}` and the text runs in the resumed pane; `read-pane` exits 0 and
  returns that pane; `send-keys` without the flag gives
  `ErrSpawnNotInteractive` and types nothing.
- Steps 7-8: Y is `ended`, `send-keys --allow-pending` of Y gives
  `ErrSpawnNotInteractive`, types nothing, and Y stays `ended`.
- Step 9: X is `waiting` only after the SessionStart typed into the
  resumed pane, with `pid` = the resumed `pane_pid`.

Each failed check prints a `FAIL:` line naming what was expected and
what was seen. If X turns `waiting` before step 9, something in the
resumed pane reported in on its own (for example the stand-in was not
selected): report that rather than loosening the case.

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN
tmux set-environment -g -u ANTHROPIC_API_KEY 2>/dev/null || true
tmux set-environment -g -u CLAUDE_CODE_OAUTH_TOKEN 2>/dev/null || true

db="$HOME/.agent-director/state.db"
standin_path="/opt/driver/stand-in-claude:$PATH"
jsonl_dir="$HOME/.claude/projects/-tmp"
fail() { echo "FAIL: $*"; exit 1; }
# end_and_wait <id> <tmux target>: ends the row's tmux session, then waits
# (bounded, 5 s) until the processes the row records have exited (no /proc
# entry), so resume's lookup meets neither a pane process nor a tmux server
# that is still exiting: its pid and pane_pid, and its tmux_server_pid when
# the session was the server's last. A server that holds other sessions
# keeps running (as kill-4's bystander does), and must still run after.
end_and_wait() {
    local id="$1" target="$2" rec rpid rpane rserver rsock n left p end
    rec="$(sqlite3 -readonly "$db" "SELECT IFNULL(pid,'') || '|' || IFNULL(pane_pid,'') || '|' || IFNULL(tmux_server_pid,'') || '|' || IFNULL(tmux_socket,'') FROM spawns WHERE claude_instance_id = '$id';")"
    IFS='|' read -r rpid rpane rserver rsock <<<"$rec"
    [[ "$rpid|$rpane|$rserver" =~ ^[0-9]+\|[0-9]+\|[0-9]+$ ]] || fail "$id records pid|pane_pid|tmux_server_pid [$rpid|$rpane|$rserver]; want all set"
    n="$(tmux ${rsock:+-S "$rsock"} list-sessions 2>/dev/null | wc -l)"
    tmux ${rsock:+-S "$rsock"} kill-session -t "$target" || fail "kill-session -t $target of $id failed"
    set -- "$rpid" "$rpane"
    [ "$n" -gt 1 ] || set -- "$@" "$rserver"
    end=$(( $(date +%s%N) + 5000000000 ))
    while :; do
        left=""
        for p in "$@"; do [ ! -e "/proc/$p" ] || left+=" $p"; done
        [ -n "$left" ] || break
        [ "$(date +%s%N)" -lt "$end" ] || fail "$id's recorded process(es)$left still running 5 s after its session $target ended"
        sleep 0.1
    done
    [ "$n" -le 1 ] || [ -e "/proc/$rserver" ] || fail "tmux server $rserver of $id ended although it held $((n - 1)) other session(s)"
}
sock=""
x_sid=""
y_sid=""
err_file="$(mktemp)"
cleanup() {
    [ -z "$x_sid" ] || tmux ${sock:+-S "$sock"} kill-session -t "$x_sid" 2>/dev/null || true
    [ -z "$y_sid" ] || tmux ${sock:+-S "$sock"} kill-session -t "$y_sid" 2>/dev/null || true
    rm -f "$err_file" "$jsonl_dir/i11-x.jsonl" "$jsonl_dir/i11-y.jsonl"
}
trap cleanup EXIT

# row_field <id> <column>: one read-only sqlite3 read of a column, '' for NULL.
row_field() { sqlite3 -readonly "$db" "SELECT IFNULL($2,'') FROM spawns WHERE claude_instance_id = '$1';"; }
state_of() { agent-director status --claude-instance-id "$1" | jq -r '.state'; }
no_creds() {
    for v in ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN; do
        if grep -qz "^$v=" "/proc/$1/environ"; then
            fail "credentials reached the agent: $v is in /proc/$1/environ ($2)"
        fi
    done
}
# Every hook is typed into the row's recorded pane (its parent is the pane process).
hook() { /opt/driver/pane-hook.sh "$1" "$2" >/dev/null || fail "hook $2 for $1 exited non-zero"; }
session_start() {
    printf '{"hook_event_name":"SessionStart","source":"%s","transcript_path":"%s"}' "$1" "$jsonl_dir/$2.jsonl"
}
session_end='{"hook_event_name":"SessionEnd","reason":"logout"}'
# spawn_standin <session name>: spawn with the stand-in claude; prints the id.
spawn_standin() {
    local out
    out="$(PATH="$standin_path" agent-director spawn --cwd /tmp --tmux-session-name "$1" 2>"$err_file")" \
        || fail "spawn $1 exited non-zero: $(cat "$err_file")"
    jq -r '.claude_instance_id' <<<"$out"
}
pane_lacks() {
    sleep 0.5
    if tmux ${sock:+-S "$sock"} capture-pane -p -t "$1" | grep -q -- "$2"; then
        fail "$2 reached pane $1 ($3)"
    fi
}

mkdir -p "$jsonl_dir"

# Setup 2: spawn X with the stand-in.
x="$(spawn_standin cd-i11x)"
[ -n "$x" ] && [ "$x" != "null" ] || fail "spawn of X returned no claude_instance_id"
sock="$(row_field "$x" tmux_socket)"
pane1="$(row_field "$x" pane_id)"
pane1_pid="$(row_field "$x" pane_pid)"
[ -n "$pane1" ] && [[ "$pane1_pid" =~ ^[0-9]+$ ]] || fail "X records pane_id|pane_pid [$pane1|$pane1_pid]; want both set"
x_sid="$(tmux ${sock:+-S "$sock"} display-message -p -t "$pane1" '#{session_id}')"
[[ "$x_sid" =~ ^\$[0-9]+$ ]] || fail "X's pane $pane1 gave session id [$x_sid]"
no_creds "$pane1_pid" "X after spawn"

# Setup 3-4: SessionStart then SessionEnd, typed into X's pane.
echo '{}' > "$jsonl_dir/i11-x.jsonl"
hook "$x" "$(session_start startup i11-x)"
got="$(sqlite3 -readonly "$db" "SELECT state || '|' || IFNULL(claude_session_id,'') || '|' || IFNULL(pid,'') FROM spawns WHERE claude_instance_id = '$x';")"
[ "$got" = "waiting|i11-x|$pane1_pid" ] || fail "X after SessionStart state|session|pid [$got]; want waiting|i11-x|$pane1_pid"
hook "$x" "$session_end"
st="$(state_of "$x")"
[ "$st" = "ended" ] || fail "X after SessionEnd state=$st; want ended"

# Setup 5-6: end X's session by id, then resume X with the stand-in.
end_and_wait "$x" "$x_sid"
x_sid=""
out="$(PATH="$standin_path" agent-director resume --claude-instance-id "$x" 2>"$err_file")" \
    || fail "resume of X exited non-zero: $(cat "$err_file")"
[ "$(jq -r '.claude_instance_id' <<<"$out")" = "$x" ] || fail "resume echoed [$out]; want id $x"

# Step 1: pending with its new session up, the stand-in as its pane process.
st_json="$(agent-director status --claude-instance-id "$x")"
st="$(jq -r '.state' <<<"$st_json")"
[ "$st" = "pending" ] || fail "X right after resume state=$st; want pending (waiting means it reported in on its own)"
[ -n "$(jq -r '.launch_started_at // empty' <<<"$st_json")" ] || fail "X after resume has no launch_started_at: $st_json"
sock="$(row_field "$x" tmux_socket)"
pane="$(row_field "$x" pane_id)"
pane_pid="$(row_field "$x" pane_pid)"
[ -n "$pane" ] && [[ "$pane_pid" =~ ^[0-9]+$ ]] || fail "resumed X records pane_id|pane_pid [$pane|$pane_pid]; want both set"
[ "$pane_pid" != "$pane1_pid" ] || fail "resumed pane_pid $pane_pid equals the first pane's"
x_sid="$(tmux ${sock:+-S "$sock"} display-message -p -t "$pane" '#{session_id}')"
[[ "$x_sid" =~ ^\$[0-9]+$ ]] || fail "resumed pane $pane gave session id [$x_sid]"
cmdline="$(tr '\0' ' ' < "/proc/$pane_pid/cmdline")"
[ "$cmdline" = "bash --noprofile --norc -i " ] || fail "resumed pane process $pane_pid runs [$cmdline]; want the stand-in's bash"
no_creds "$pane_pid" "X after resume"

# Step 2: empty text with --allow-pending presses Enter only, exit 0.
out="$(agent-director send-keys --claude-instance-id "$x" --allow-pending --text '' 2>"$err_file")" \
    || fail "send-keys --allow-pending (empty) of pending X exited non-zero: $(cat "$err_file")"
[ "$(jq -c '.' <<<"$out")" = "{}" ] || fail "send-keys --allow-pending (empty) stdout [$out]; want {}"

# Step 3: a text with --allow-pending is delivered to the resumed pane and runs.
out="$(agent-director send-keys --claude-instance-id "$x" --allow-pending --text 'echo i11-$((40+2))' 2>"$err_file")" \
    || fail "send-keys --allow-pending of pending X exited non-zero: $(cat "$err_file")"
[ "$(jq -c '.' <<<"$out")" = "{}" ] || fail "send-keys --allow-pending stdout [$out]; want {}"
for _ in $(seq 1 50); do
    tmux ${sock:+-S "$sock"} capture-pane -p -t "$pane" | grep -q 'i11-42' && break
    sleep 0.1
done
tmux ${sock:+-S "$sock"} capture-pane -p -t "$pane" | grep -q 'i11-42' || fail "i11-42 never showed in X's resumed pane $pane"

# Step 4: read-pane returns the resumed pane.
rp="$(agent-director read-pane --claude-instance-id "$x" 2>"$err_file")" \
    || fail "read-pane of pending X exited non-zero: $(cat "$err_file")"
[ "$(jq -r '.pane | type' <<<"$rp")" = "string" ] || fail "read-pane of X has no string pane field: $rp"
jq -r '.pane' <<<"$rp" | grep -q 'i11-42' || fail "read-pane of X does not show i11-42: $rp"

# Step 5: without --allow-pending the pending row is refused; nothing typed.
if agent-director send-keys --claude-instance-id "$x" --text 'echo i11-noflag-$((1+1))' >/dev/null 2>"$err_file"; then
    fail "send-keys of pending X without --allow-pending exited 0; want ErrSpawnNotInteractive"
fi
err_name="$(jq -r '.err_name' <"$err_file")"
[ "$err_name" = "ErrSpawnNotInteractive" ] || fail "send-keys without flag err_name [$err_name]; want ErrSpawnNotInteractive ($(cat "$err_file"))"
pane_lacks "$pane" 'i11-noflag-2' "send-keys without --allow-pending"

# Step 6: X is still pending.
st="$(state_of "$x")"
[ "$st" = "pending" ] || fail "X after the pane-verb calls state=$st; want pending"

# Step 7: Y, finished and never resumed.
y="$(spawn_standin cd-i11y)"
[ -n "$y" ] && [ "$y" != "null" ] || fail "spawn of Y returned no claude_instance_id"
y_pane="$(row_field "$y" pane_id)"
y_pane_pid="$(row_field "$y" pane_pid)"
[ -n "$y_pane" ] && [[ "$y_pane_pid" =~ ^[0-9]+$ ]] || fail "Y records pane_id|pane_pid [$y_pane|$y_pane_pid]; want both set"
y_sid="$(tmux ${sock:+-S "$sock"} display-message -p -t "$y_pane" '#{session_id}')"
[[ "$y_sid" =~ ^\$[0-9]+$ ]] || fail "Y's pane $y_pane gave session id [$y_sid]"
no_creds "$y_pane_pid" "Y after spawn"
echo '{}' > "$jsonl_dir/i11-y.jsonl"
hook "$y" "$(session_start startup i11-y)"
hook "$y" "$session_end"
st="$(state_of "$y")"
[ "$st" = "ended" ] || fail "Y after SessionEnd state=$st; want ended"
tmux ${sock:+-S "$sock"} has-session -t "$y_sid" 2>/dev/null || fail "Y's session $y_sid is not running after SessionEnd"

# Step 8: Y is refused even with --allow-pending, stays ended, gets nothing.
if agent-director send-keys --claude-instance-id "$y" --allow-pending --text 'echo i11-to-y-$((2+2))' >/dev/null 2>"$err_file"; then
    fail "send-keys --allow-pending of ended Y exited 0; want ErrSpawnNotInteractive"
fi
err_name="$(jq -r '.err_name' <"$err_file")"
[ "$err_name" = "ErrSpawnNotInteractive" ] || fail "send-keys --allow-pending of Y err_name [$err_name]; want ErrSpawnNotInteractive ($(cat "$err_file"))"
st="$(state_of "$y")"
[ "$st" = "ended" ] || fail "Y after the refused send state=$st; want ended"
pane_lacks "$y_pane" 'i11-to-y-4' "send-keys --allow-pending of ended Y"

# Step 9: SessionStart (source resume) from X's resumed pane turns X waiting.
st="$(state_of "$x")"
[ "$st" = "pending" ] || fail "X before its SessionStart state=$st; want pending"
hook "$x" "$(session_start resume i11-x)"
st_json="$(agent-director status --claude-instance-id "$x")"
st="$(jq -r '.state' <<<"$st_json")"
[ "$st" = "waiting" ] || fail "X after the resumed pane's SessionStart state=$st; want waiting"
[ "$(jq 'has("launch_started_at")' <<<"$st_json")" = "false" ] || fail "X waiting still has launch_started_at: $st_json"
pid="$(row_field "$x" pid)"
[ "$pid" = "$pane_pid" ] || fail "X pid=$pid after SessionStart; want the resumed pane_pid $pane_pid"

echo "interact-11 ok: X ($x) resumed -> pending, stand-in pane $pane; send-keys --allow-pending empty and text exit 0 (i11-42 ran), read-pane returns the pane; no flag -> ErrSpawnNotInteractive, nothing typed; ended Y ($y) -> ErrSpawnNotInteractive, still ended; SessionStart from resumed pane -> waiting, pid=$pid"
```
