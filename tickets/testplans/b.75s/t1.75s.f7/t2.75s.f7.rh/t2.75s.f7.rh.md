# install-8: --keep-prior snapshots the previous binary for rollback

Per SRD §16.2 (post b.43y): the install uses the temp+atomic-mv
pattern (gh/kubectl/terraform style) instead of the version-manager
symlink pattern. The optional `--keep-prior` flag snapshots the
existing binary to `agent-director.prior` before the swap so the
operator can roll back with `mv .prior canonical`. A re-install of the
same pair (agent-director already byte-identical to the one being
installed, and agent-director-admin byte-identical too or not
installed) is not snapshotted (b.2wk). Both installs here take the
image's agent-director-admin, so the first install is of an older
agent-director build: the image's binary with one byte appended.

## Setup

Per-case DB-reset.

## Steps

1. First install the older build with no `--keep-prior`. Confirm the
   canonical path is a regular file and no `.prior` snapshot exists.
2. Capture the sha256 of the first-install canonical.
3. Second install, of the image's binary, with `--keep-prior`. Confirm:
   - the canonical path is still a regular file (not a symlink),
     byte-for-byte the image's binary,
   - `agent-director.prior` exists at mode 0755,
   - `.prior`'s sha256 matches the first-install canonical's sha256
     (byte-for-byte the previous binary, preserved for rollback).
4. Roll back via `mv .prior canonical`. Confirm the rolled-back
   canonical's sha256 matches the first-install sha256 and that
   `.prior` no longer exists (the rollback consumed it).

## Pass criteria

- After the first install: no `.prior` snapshot.
- After the second install: the canonical is the image's binary;
  `.prior` exists, mode 0755, sha256 matches the first install's binary.
- After rollback: canonical's sha256 matches the first install; no
  `.prior` left behind.

## Script

```bash
set -euo pipefail
TESTHOME=$(mktemp -d)

# The older build: the image's binary with one byte appended. Both
# installs take the image's agent-director-admin, so this is what makes
# the pair differ from its source and the upgrade below snapshot (b.2wk).
OLDDIR=$(mktemp -d)
cp /usr/local/bin/agent-director "$OLDDIR/agent-director"
printf '\0' >>"$OLDDIR/agent-director"
chmod 0755 "$OLDDIR/agent-director"

# First install, of the older build. No --keep-prior, so no .prior snapshot.
HOME="$TESTHOME" /opt/skills/install-agent-director/install.sh \
    --binary "$OLDDIR/agent-director" --no-symlink >/dev/null

canonical="$TESTHOME/.agent-director/bin/agent-director"
prior="$TESTHOME/.agent-director/bin/agent-director.prior"

if [ ! -f "$canonical" ] || [ -L "$canonical" ]; then
    echo "FAIL: first-install canonical is not a regular file"; exit 1
fi
if [ -e "$prior" ]; then
    echo "FAIL: .prior snapshot exists after first install without --keep-prior"; exit 1
fi
sha1=$(sha256sum "$canonical" | awk '{print $1}')

# Second install, of the image's binary, WITH --keep-prior. .prior
# should snapshot the first-install binary; the canonical path should be
# a fresh regular file (the new install).
HOME="$TESTHOME" /opt/skills/install-agent-director/install.sh \
    --binary /usr/local/bin/agent-director --no-symlink --keep-prior >/dev/null

if [ ! -f "$canonical" ] || [ -L "$canonical" ]; then
    echo "FAIL: second-install canonical is not a regular file"; exit 1
fi
if ! cmp -s "$canonical" /usr/local/bin/agent-director; then
    echo "FAIL: second-install canonical is not /usr/local/bin/agent-director"; exit 1
fi
if [ ! -f "$prior" ]; then
    echo "FAIL: --keep-prior did not create $prior"; exit 1
fi
prior_mode=$(stat -c '%a' "$prior")
if [ "$prior_mode" != "755" ]; then
    echo "FAIL: .prior mode=$prior_mode; want 755"; exit 1
fi
prior_sha=$(sha256sum "$prior" | awk '{print $1}')
if [ "$prior_sha" != "$sha1" ]; then
    echo "FAIL: .prior sha=$prior_sha; want first-install sha=$sha1"; exit 1
fi

# Rollback: mv .prior canonical. The restored binary must match the
# first-install content by sha256, and .prior should be gone.
mv -f "$prior" "$canonical"
restored_sha=$(sha256sum "$canonical" | awk '{print $1}')
if [ "$restored_sha" != "$sha1" ]; then
    echo "FAIL: rolled-back sha=$restored_sha; want first-install sha=$sha1"; exit 1
fi
if [ -e "$prior" ]; then
    echo "FAIL: .prior still present after mv-rollback"; exit 1
fi

echo "install-8 ok: --keep-prior snapshots prior binary; mv-rollback restores it"
```
