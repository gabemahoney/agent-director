# mcp-2: tools/list count matches manifest minus filtered

Per SRD §4.1: tools/list is generated from pkg/api/manifest.Verbs,
filtering out `hook` (internal), `serve` (self-referential), and
`trail-emit` (CLI-only write verb with no MCP dispatch handler), and
`cursor-host` (internal Cursor gateway entrypoint — see
internal/mcp/server.go ExposedVerb). This case pins the
drift-by-construction invariant: a new manifest verb that isn't
filtered must appear in tools/list, and the count must stay
synchronized.

## Setup

Per-case DB-reset.

## Steps

1. Pipe initialize + tools/list into the server.
2. Parse stdout's second line; collect the whole tool-name inventory and count.
3. Compare against all manifest names via `agent-director help`, excluding
   exactly `hook`, `serve`, `trail-emit` and `cursor-host` and translating
   hyphens to underscores.

## Pass criteria

- The complete sorted tool-name inventory equals the manifest inventory minus
  the four explicit exclusions, with hyphens translated to underscores.
- `len(result.tools)` equals `(help.verbs count) - 4`; none of the four
  internal verbs appears in tools/list. Counts are derived from the manifest,
  so future exposed additions must appear without repinning a constant.

## Script

```bash
set -euo pipefail
out=$(printf '%s
%s
' \
    '{"jsonrpc":"2.0","id":1,"method":"initialize"}' \
    '{"jsonrpc":"2.0","id":2,"method":"tools/list"}' \
    | agent-director serve --stdio 2>/dev/null)
tools=$(printf '%s' "$out" | sed -n '2p' | jq -ce '.result.tools')
verbs=$(agent-director help | jq -ce '.verbs')
# Independent contract inventory: do not reuse the server's exposure predicate.
deny='["hook", "serve", "trail-emit", "cursor-host"]'
n_tools=$(jq -r 'length' <<<"$tools")
n_verbs=$(jq -r 'length' <<<"$verbs")
expected=$(( n_verbs - 4 ))
want=$(jq -c --argjson deny "$deny" '[.[] | .name as $name | select($deny | index($name) | not) | .name | gsub("-"; "_")] | sort' <<<"$verbs")
got=$(jq -c '[.[].name] | sort' <<<"$tools")
if [ "$got" != "$want" ] || [ "$n_tools" != "$expected" ]; then
    echo "FAIL: tools=$n_tools verbs=$n_verbs expected=$expected (verbs - hook - serve - trail-emit - cursor-host); got=$got want=$want"
    exit 1
fi
jq -e --argjson deny "$deny" '[.[].name] as $names | all($deny[]; gsub("-"; "_") as $name | $names | index($name) | not)' <<<"$tools" >/dev/null
echo "mcp-2 ok: complete tools/list inventory matches manifest; $n_tools = manifest($n_verbs) - 4 filtered (hook, serve, trail-emit, cursor-host)"
```
