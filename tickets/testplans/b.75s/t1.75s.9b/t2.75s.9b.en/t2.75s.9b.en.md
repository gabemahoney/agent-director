# recov-6: agent-director-admin delete returns per-row results; batch does not abort on a bad id

Maps to Epic 8 AC #3. A mix of valid and bogus ids returns a map
recording each outcome; the valid rows are deleted while the bogus
one surfaces `ErrSpawnNotFound`. `delete` is the operator tool's verb
(b.vqr): the main CLI has none (`agent-director delete` is
`ErrUnknownVerb` and removes nothing). The harness image keeps
agent-director-admin off PATH at `/opt/bin/agent-director-admin`
(install.sh installs it at `~/.agent-director/admin/agent-director-admin`),
so the case runs it by that full path.

## Setup

Per-case DB-reset.

## Steps

1. INSERT two rows (`id-d-1`, `id-d-2`).
2. `agent-director delete --claude-instance-id id-d-1`: refused as an
   unknown verb; `id-d-1` is still there.
3. `/opt/bin/agent-director-admin delete --claude-instance-id id-d-1
   --claude-instance-id bogus --claude-instance-id id-d-2`.
4. Expect result map `{id-d-1:ok, bogus:ErrSpawnNotFound, id-d-2:ok}`.
5. Both valid rows are gone; bogus was never inserted.

## Pass criteria

- `agent-director delete` exits 1 with `err_name` `ErrUnknownVerb` and
  removes nothing.
- agent-director-admin delete exits 0.
- result.results map matches expectations.
- Valid rows removed from DB.

## Script

```bash
set -euo pipefail
/opt/driver/sql.sh "$HOME/.agent-director/state.db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode)
   VALUES ('id-d-1', 'ended', '/tmp', 'cd-d-1', 'off'),
          ('id-d-2', 'ended', '/tmp', 'cd-d-2', 'off');"

# The main CLI has no delete verb.
set +e
err=$(agent-director delete --claude-instance-id id-d-1 2>&1 >/dev/null)
code=$?
set -e
name=$(printf '%s' "$err" | jq -r '.err_name' 2>/dev/null || true)
if [ "$code" -ne 1 ] || [ "$name" != "ErrUnknownVerb" ]; then
    echo "FAIL: agent-director delete exited $code with [$err]; want 1 and ErrUnknownVerb"; exit 1
fi
n=$(/opt/driver/sql.sh "$HOME/.agent-director/state.db" \
    "SELECT COUNT(*) FROM spawns WHERE claude_instance_id = 'id-d-1';")
if [ "$n" != "1" ]; then
    echo "FAIL: agent-director delete removed id-d-1"; exit 1
fi

res=$(/opt/bin/agent-director-admin delete --claude-instance-id id-d-1 \
        --claude-instance-id bogus --claude-instance-id id-d-2)
ok1=$(printf '%s' "$res" | jq -r '.results["id-d-1"]')
ok2=$(printf '%s' "$res" | jq -r '.results["id-d-2"]')
b=$(printf '%s' "$res" | jq -r '.results.bogus')
if [ "$ok1" != "ok" ] || [ "$ok2" != "ok" ] || [ "$b" != "ErrSpawnNotFound" ]; then
    echo "FAIL: results=$res; want id-d-1:ok id-d-2:ok bogus:ErrSpawnNotFound"; exit 1
fi

n=$(/opt/driver/sql.sh "$HOME/.agent-director/state.db" \
    "SELECT COUNT(*) FROM spawns WHERE claude_instance_id IN ('id-d-1','id-d-2','bogus');")
if [ "$n" != "0" ]; then
    echo "FAIL: $n row(s) remain; want 0 (both valids deleted)"; exit 1
fi
echo "recov-6 ok: per-row result map; partial failure didn't abort the batch"
```
