# interact-2: multiline composed as one buffer

Maps to Epic 4 AC #2 (`send-keys --text $'line1
line2'` produces a
single composed message visible as two lines). Pins the SRD §4.3
contract that LF (0x0A) bytes in the text payload compose newlines in
the input box rather than triggering submission.

Revised by Epic 11 (`t1.h98.m6`, Task `t2.h98.m6.ki`; SR-3.4, SR-3.6,
SR-7.2, SR-20.9): the pane is read back with `read-pane`, which finds
the row's session only by its `@ad_owner` label and captures the
agent's pane by pane id. The session is seeded like kill-1
(`t2.75s.ks.3h`): the row has a launch token and records no socket,
server, pid or pane; the session carries the five-field label
`ad1 <token> <$N> id-i2 <store id>` and its pane `@ad_pane`
`<token> <%N>`, so `read-pane` finds the agent's pane through that
`@ad_pane` and writes nothing (`row_version` and `pane_id` unchanged).

## Setup

Per-case DB-reset. A `cat` pane provides a deterministic echo target.
An EXIT trap removes the session by its session id if the case fails
part-way.

## Steps

1. Read this store's id from `store_meta` with `sqlite3`.
2. `tmux new-session -d -s cd-i2 -e AGENT_DIRECTOR_INSTANCE_ID=id-i2 --
   cat`, capturing `$N`, `%N` and the pane pid.
3. Seed a `spawns` row `id-i2` at state `waiting` with a 16-hex
   `launch_token`; read the token back with `sqlite3`.
4. Set the five-field `@ad_owner` label on `$N` and `@ad_pane`
   `<token> <%N>` on the pane; read the label back.
5. `agent-director send-keys --claude-instance-id id-i2 --text $'line1
line2'`.
6. Read the pane with `read-pane` (row `row_version` and `pane_id` read
   before and after); assert both `line1` and `line2` appear.
7. Inspect that exactly one trailing Enter was emitted (cat echoes two
   lines if the buffer was one composed message; cat would echo each
   line separately on its own pre-Enter chunk regardless, so the LF
   preservation is asserted at the byte level by reading the pane).

## Pass criteria

- The store id and token are 16 lowercase hex; the label read back has
  five fields and equals the one set.
- send-keys exit 0.
- read-pane exit 0; both `line1` and `line2` are in the pane.
- The bytes between them include LF (not stripped).
- read-pane leaves `row_version` and `pane_id` unchanged.

## Script

```bash
set -euo pipefail
db="$HOME/.agent-director/state.db"
fail() { echo "FAIL: $*"; exit 1; }
sid=""
trap '[ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true' EXIT

store_id="$(/opt/driver/sql.sh "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

read -r sid pane pane_pid < <(tmux new-session -d -s cd-i2 -e AGENT_DIRECTOR_INSTANCE_ID=id-i2 \
    -P -F '#{session_id} #{pane_id} #{pane_pid}' -- cat)
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"
[[ "$pane" =~ ^%[0-9]+$ ]] || fail "new-session gave pane id [$pane]"

seed_token="$(od -An -N8 -tx1 /dev/urandom | tr -dc '0-9a-f')"
/opt/driver/sql.sh "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, launch_token)
   VALUES ('id-i2', 'waiting', '/tmp', 'cd-i2', 'off', '$seed_token');"
token="$(/opt/driver/sql.sh "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-i2';")"
[[ "$token" =~ ^[0-9a-f]{16}$ ]] || fail "launch_token is not 16 lowercase hex: [$token]"

label="ad1 $token $sid id-i2 $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
tmux set-option -p -t "$pane" @ad_pane "$token $pane"
got_label="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$got_label" = "$label" ] || fail "label read back [$got_label]; want [$label]"
read -r -a fields <<<"$got_label"
[ "${#fields[@]}" -eq 5 ] || fail "label has ${#fields[@]} fields; want 5: [$got_label]"

agent-director send-keys --claude-instance-id id-i2 --text $'line1
line2' >/dev/null || fail "send-keys exited non-zero"
sleep 0.2

row_q="SELECT row_version || '|' || COALESCE(pane_id, '') FROM spawns WHERE claude_instance_id = 'id-i2';"
before="$(/opt/driver/sql.sh "$db" "$row_q")"
rp="$(agent-director read-pane --claude-instance-id id-i2 --n-lines 100)" || fail "read-pane exited non-zero"
after="$(/opt/driver/sql.sh "$db" "$row_q")"
[ "$before" = "$after" ] || fail "read-pane changed the row: row_version|pane_id [$before] -> [$after]"

pane_text="$(jq -r '.pane' <<<"$rp")"
echo "$pane_text" | grep -q "line1" || fail "line1 missing from pane $pane: [$pane_text]"
echo "$pane_text" | grep -q "line2" || fail "line2 missing from pane $pane: [$pane_text]"
# Multiline preservation: line1 and line2 must occupy separate display
# lines in the captured pane buffer.
lines="$(echo "$pane_text" | grep -c -E '^line[12]$' || true)"
test "$lines" -ge 2 || fail "want line1 and line2 on separate lines; got $lines: [$pane_text]"
echo "interact-2 ok: both lines composed; pane $pane read by id; row unchanged ($after)"
```
