# agent-7: [launch] claude_path launches the program it names

Maps to SRD SR-14.5 and the launch rule of Epic 13 (`b.ssz`): a
`[launch] claude_path` in `config.toml` is the program every Claude launch
runs, in place of `claude` looked up on the PATH. With `claude` off the
PATH, a `spawn --agent claude` still launches, and the program it runs is
the one named. `get` shows the row's agent, `claude`.

Unlike the other cases, this one does NOT put the stand-in directory on
the PATH: the only way the stand-in can start is `claude_path`.

## Setup

Per-case DB-reset. `claude` (the image installs it under `/usr/bin`) is kept off the PATH by
running `agent-director` with a PATH of one temporary directory that
symlinks every tool in `/usr/bin` and `/bin` except `claude`, so `tmux`
and the shell still resolve. The case writes `~/.agent-director/config.toml`
and removes it and the directory on exit.

## Steps

1. Write `config.toml` with `[launch]` `claude_path =
   "/opt/driver/stand-in-claude/claude"`.
2. Check `claude` is not found on that temporary PATH and `tmux` is.
3. With that PATH, `agent-director spawn --agent claude --cwd /tmp
   --instance-id <id> --tmux-session-name cd-ag-lp` (agent-director by its
   full path) → exit 0.
4. `agent-director get --instance-id <id>`.
5. Read the row's `pane_pid` and `tmux_socket` from the store and the
   pane process's command line from `/proc/<pane_pid>/cmdline`.

## Pass criteria

- Step 2: `claude` is not found on the temporary PATH; `tmux` is.
- Step 3: exit 0 and the result's `instance_id` is the id sent.
- Step 4: `agent` is `claude` and `state` is `pending` (the stand-in
  sends no hook).
- Step 5: the store's `agent` column is `claude`; the pane process
  `pane_pid` is alive and, within 5 s, its command line is the stand-in's
  interactive shell (`bash --noprofile --norc -i`): the stand-in started
  although `claude` is not on the PATH.

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN

db="$HOME/.agent-director/state.db"
config="$HOME/.agent-director/config.toml"
standin="/opt/driver/stand-in-claude/claude"
bare_dir=""
bare_path=""
ad="$(command -v agent-director)"
uuid="$(cat /proc/sys/kernel/random/uuid)"
id="ag-lp-$uuid"
name="cd-ag-lp"
sock=""
sid=""
fail() { echo "FAIL: $*"; exit 1; }
spawn_err="$(mktemp)"
cleanup() {
    [ -z "$sid" ] || tmux ${sock:+-S "$sock"} kill-session -t "$sid" 2>/dev/null || true
    rm -f "$config" "$spawn_err"
    [ -z "$bare_dir" ] || rm -rf "$bare_dir"
}
trap cleanup EXIT

# Step 1: the config.
[ -x "$standin" ] || fail "$standin is not an executable file"
mkdir -p "$HOME/.agent-director"
printf '[launch]\nclaude_path = "%s"\n' "$standin" > "$config"

# The harness image carries /usr/bin/claude, so /usr/bin:/bin cannot serve as a
# claude-free PATH. Build one directory that links every tool of /usr/bin and
# /bin except claude: the launch resolves tmux and the shell there, never claude.
bare_dir="$(mktemp -d)"
for src in /usr/bin/* /bin/*; do
    [ "${src##*/}" = claude ] || ln -s "$src" "$bare_dir/${src##*/}" 2>/dev/null || true
done
bare_path="$bare_dir"

# Step 2: claude is off the PATH the launch will see; tmux is on it.
if PATH="$bare_path" command -v claude >/dev/null 2>&1; then
    fail "claude is found on PATH=$bare_path: $(PATH="$bare_path" command -v claude)"
fi
PATH="$bare_path" command -v tmux >/dev/null 2>&1 || fail "tmux is not found on PATH=$bare_path"

# Step 3: spawn with the bare PATH and no stand-in directory on it.
set +e
out="$(PATH="$bare_path" "$ad" spawn --agent claude --cwd /tmp --instance-id "$id" --tmux-session-name "$name" 2>"$spawn_err")"
rc=$?
set -e
[ "$rc" -eq 0 ] || fail "spawn exited $rc; want 0: $(cat "$spawn_err")"
[ "$(jq -r '.instance_id' <<<"$out")" = "$id" ] || fail "spawn echoed [$out]; want id $id"

# Step 4: get shows the agent.
row="$(agent-director get --instance-id "$id")"
got="$(jq -r '[.agent, .state] | join("|")' <<<"$row")"
[ "$got" = "claude|pending" ] || fail "get agent|state=[$got]; want claude|pending: $row"

# Step 5: the store agrees, and the pane runs the stand-in.
rec="$(/opt/driver/sql.sh -readonly "$db" "SELECT agent || '|' || IFNULL(pane_pid,'') || '|' || IFNULL(tmux_socket,'') || '|' || IFNULL(pane_id,'') FROM spawns WHERE instance_id = '$id';")"
IFS='|' read -r col_agent pane_pid sock pane <<<"$rec"
[ "$col_agent" = "claude" ] || fail "spawns.agent=[$col_agent]; want claude"
[[ "$pane_pid" =~ ^[0-9]+$ ]] && [ -n "$pane" ] || fail "row records pane_pid|pane_id [$pane_pid|$pane]; want both set"
sid="$(tmux ${sock:+-S "$sock"} display-message -p -t "$pane" '#{session_id}' 2>/dev/null)" || fail "the row's pane $pane is not in any tmux session: the launch did not stay up"
want_cmd="bash --noprofile --norc -i"
end=$(( $(date +%s%N) + 5000000000 ))
cmd=""
while :; do
    [ -e "/proc/$pane_pid" ] || fail "pane process $pane_pid is gone: the launch did not stay up"
    cmd="$(tr '\0' ' ' < "/proc/$pane_pid/cmdline" 2>/dev/null | sed 's/ $//')"
    [ "$cmd" = "$want_cmd" ] && break
    [ "$(date +%s%N)" -lt "$end" ] || fail "pane process $pane_pid command line [$cmd]; want [$want_cmd] (the stand-in) within 5 s"
    sleep 0.1
done

echo "agent-7 ok: claude_path=$standin with claude off PATH ($bare_path) launched the stand-in (pane $pane_pid runs [$cmd]); get agent=claude state=pending"
```
