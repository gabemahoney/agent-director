# spawn-14: a tab in an explicit instance id gives ErrInvalidFlags

Maps to Epic `t1.h98.cu` (Plan `b.h98`), scope "Ids" and Docker case
spawn-14 (SRD SR-9.1; AC-SPN-02, AC-CAT-03). An id with an ASCII
control character can never carry a valid tmux owner label, so `spawn`
must refuse it with `ErrInvalidFlags` before it loads a template, reads
or writes the store, or calls tmux. The error description must not
contain the id.

## Setup

Per-case DB-reset has wiped `~/.agent-director/state.db` and killed any
`cd-*` tmux sessions. The container has `agent-director`, `tmux`,
`sqlite3` and `jq` on PATH. The script records the live session ids
first and, on exit, kills any session that was not there before, so a
regression cannot leak a session into later cases.

## Steps

1. Record the live tmux session ids.
2. `agent-director spawn --cwd /tmp --claude-instance-id "$id"`, where
   `id` is `sp14left<TAB>sp14right` (built with `$'...	...'`, so the
   id holds a real tab byte).
3. Read the last JSON line on stderr.
4. `agent-director list`, and count rows in the `spawns` table.
5. Read the live tmux session ids again.

## Pass criteria

- Step 2 exits non-zero.
- Step 3: `err_name == "ErrInvalidFlags"`; the decoded
  `err_description` does not contain the id, and the raw stderr
  contains neither `sp14left` nor `sp14right`.
- Step 4: `list` gives `.spawns | length == 0`, and
  `SELECT COUNT(*) FROM spawns` is `0`.
- Step 5: the session ids equal the step 1 ids (no new session).

## Script

```bash
set -euo pipefail

id=$'sp14left	sp14right'

session_ids() {
    tmux ls -F '#{session_id}' 2>/dev/null || true
}
before="$(session_ids)"
cleanup() {
    local sid
    for sid in $(session_ids); do
        case " $(printf '%s ' $before)" in
            *" $sid "*) ;;
            *) tmux kill-session -t "$sid" 2>/dev/null || true ;;
        esac
    done
}
trap cleanup EXIT

set +e
err="$(agent-director spawn --cwd /tmp --claude-instance-id "$id" 2>&1 >/dev/null)"
code=$?
set -e
if [ "$code" -eq 0 ]; then
    echo "FAIL: spawn accepted an instance id containing a tab" >&2
    exit 1
fi

envelope="$(printf '%s
' "$err" | awk '/^\{/{ln=$0} END{print ln}')"
got="$(printf '%s' "$envelope" | jq -r '.err_name')"
if [ "$got" != "ErrInvalidFlags" ]; then
    echo "FAIL: err_name=$got; stderr: $err" >&2
    exit 1
fi

desc="$(printf '%s' "$envelope" | jq -r '.err_description')"
case "$desc" in
    *"$id"*)
        echo "FAIL: err_description contains the id: $desc" >&2
        exit 1
        ;;
esac
case "$err" in
    *sp14left* | *sp14right*)
        echo "FAIL: stderr echoes part of the id: $err" >&2
        exit 1
        ;;
esac

n_list="$(agent-director list | jq '.spawns | length')"
test "$n_list" = "0"
n_db="$(sqlite3 "$HOME/.agent-director/state.db" 'SELECT COUNT(*) FROM spawns;')"
test "$n_db" = "0"

after="$(session_ids)"
if [ "$after" != "$before" ]; then
    echo "FAIL: tmux sessions changed; before=[$before] after=[$after]" >&2
    exit 1
fi

echo "spawn-14 ok: tab in id -> ErrInvalidFlags ($desc); no row; no session"
```
