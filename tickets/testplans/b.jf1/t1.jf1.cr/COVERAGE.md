Every row maps SR-4 state/authority, SR-5 permission/delivery/question policy and SR-9 persistence/bounds as named in each case. Existing Claude/Codex regression owners are preserved; the final full sandbox writer owns the complete Go/Bun suite after documentation settles. No production, schema, public API or later-Epic feature is introduced here.

The raw observer samples SQLite at the first receiving data callback before readline parses a frame. Unit assertions use absolute raw-byte offsets, so a partial or coalesced chunk is not counted as a whole response. SQL observer results are independent connections, not the gateway's uncommitted handle. Kernel pipe backpressure tests separately fill the paused peer’s kernel pipe with a labelled 4096-byte fixture control and retain those unread bytes after transport retirement to avoid treating an empty parsed-frame trace as zero physical output. The collector's post-ack tmux wrapper blocks actual evidence queries; it forwards to real tmux and does not fake pane/kernel authority.

Explicit pending predicates: actual current-revision authenticated request kinds/options/child route and native choices; any live question-denial observation; supported runtime/protocol/platform receipts. Cursor load/resume is currently refused: fresh/load policy signatures in unit fixtures do not enable E4. Loaded-session/manual predicates are deferred until that feature is authorized and implemented. R2 captures establish prior route feasibility, not current AD relay acceptance; R3 is a closed product decision, not live prevention proof. See operator-acceptance.md.

The shared peer also records SentFrames independently from received Frames: public field comparisons use the exact scripted params emitted on the peer side, with actual gateway admission establishing reception. SentFrames is not authenticated traffic. PauseAfterRequests publishes an explicit paused barrier before the test injects kernel backpressure; no polling delay is used as proof that reads stopped.
