# busy-send-uncovered-1: raw keys unchanged and a busy-send option refused on an uncovered agent

Maps to Task `t2.xis.pu.ar` and SRD `t1.kii.kn` SR-9.2 (with SR-9.4's
details). A `send-keys` naming no busy-send option keeps today's raw keys
for an agent busy send does not cover: `--no-enter` types its text with no
Enter, `--key` sends one key. Naming one, even `--confirmed-delivery=false`,
is `ErrCantSend` with reason `agent_not_covered`, and nothing is stored,
sent or typed.

The refused call lands in the middle of a line the case is typing at the
stand-in's shell, so a stray byte or Enter would change that line. The
case's own final Enter is the fence: the line it submits writes the file
`o` and then creates `f`. Pane input is ordered, so once `f` exists every
earlier key has been read. `o` then holds exactly what the line typed.

## Setup

Per-case DB-reset. The case writes `~/.config/agent-director/config.toml`
with `[launch]` `codex_path = "/opt/driver/stand-in-codex/codex"`, makes a
cwd and a temporary Codex folder holding the rollout the `SessionStart`
names, and removes them, the config and the stand-in's record directory on
exit.

## Steps

1. Write the config; make the cwd and the Codex folder with its rollout.
2. `agent-director spawn --agent codex --cwd <cwd> --instance-id <id>
   --tmux-session-name cd-bs-un --extra-env CODEX_HOME=<folder>`; type a
   `SessionStart`; `get`.
3. `send-keys --text "echo ka-<tag>" --no-enter`, then `send-keys --key Z`.
4. Dump the store with `sql.sh`; `send-keys --text " busy-<tag>"
   --confirmed-delivery=false`; dump the store again.
5. `send-keys --text " > <cwd>/o; : > <cwd>/f" --no-enter`, then
   `send-keys --key Enter`; wait up to 10 s for `<cwd>/f`.
6. Read `<cwd>/o`; `read-pane --n-lines 40`; `get`.

## Pass criteria

- Step 2: the row is `waiting` with `busy_send` `not_covered`.
- Steps 3 and 5: each `send-keys` exits 0 and prints `{}`.
- Step 4: exit 1, nothing on stdout, `err_name` `ErrCantSend` and
  `err_details` exactly `{"class":"cant_send","reason":"agent_not_covered",
  "resend_safe":true,"retry_with":"new_send"}`; the two dumps are
  byte-identical (no Message, force attempt, permission request, input
  record or row change).
- Step 5: `<cwd>/f` exists within 10 s.
- Step 6: `<cwd>/o` is exactly `ka-<tag>Z` and a newline, so step 3 typed
  its text and key with no Enter and step 4 typed nothing. The pane shows
  `echo ka-<tag>Z > <cwd>/o` and never `busy-<tag>`. The row is still
  `waiting` and `not_covered`.

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN CODEX_HOME

db="$HOME/.config/agent-director/state.db"
config="$HOME/.config/agent-director/config.toml"
standin="/opt/driver/stand-in-codex/codex"
rec_root="/tmp/stand-in-codex"
uuid="$(cat /proc/sys/kernel/random/uuid)"
tag="${uuid:0:8}"
id="bs-un-$uuid"
sid="$(cat /proc/sys/kernel/random/uuid)"
codex_home=""
cwd=""
rollout=""
errfile="$(mktemp)"
fail() { echo "FAIL: $*"; exit 1; }

col() { /opt/driver/sql.sh -readonly "$db" "SELECT $1 FROM spawns WHERE instance_id = '$id';"; }

cleanup() {
    local row sock pane s
    row="$(col "IFNULL(tmux_socket,'') || '|' || IFNULL(pane_id,'')" 2>/dev/null || true)"
    sock="${row%%|*}"
    pane="${row#*|}"
    if [ -n "$pane" ]; then
        s="$(tmux ${sock:+-S "$sock"} display-message -p -t "$pane" '#{session_id}' 2>/dev/null || true)"
        [ -z "$s" ] || tmux ${sock:+-S "$sock"} kill-session -t "$s" 2>/dev/null || true
    fi
    rm -f "$config" "$errfile"
    rm -rf "$rec_root/$id" ${codex_home:+"$codex_home"} ${cwd:+"$cwd"}
    rmdir "$rec_root" 2>/dev/null || true
}
trap cleanup EXIT

# wait_state WANT: the row's state (get) is WANT within 10 s.
wait_state() {
    local want="$1" end got=""
    end=$(( $(date +%s) + 10 ))
    while :; do
        got="$(agent-director get --instance-id "$id" | jq -r '.state')"
        [ "$got" != "$want" ] || return 0
        [ "$(date +%s)" -lt "$end" ] || fail "row $id state is [$got]; want [$want] within 10 s"
        sleep 0.2
    done
}

# fire EVENT [EXTRA_JSON]: type the Codex hook EVENT into the row's pane; the
# hook must exit 0 and print nothing.
fire() {
    local extra='{}' body out
    [ $# -lt 2 ] || extra="$2"
    body="$(jq -cn --arg e "$1" --arg sid "$sid" --arg tp "$rollout" --arg cwd "$cwd" --argjson x "$extra" \
        '{hook_event_name: $e, session_id: $sid, transcript_path: $tp, cwd: $cwd, model: "codex-stand-in", permission_mode: "default"} + $x')"
    out="$(/opt/driver/pane-hook.sh --agent codex "$id" "$body")" || fail "the $1 hook exited non-zero"
    [ -z "$out" ] || fail "the $1 hook printed [$out]; want nothing"
}

# send ARGS...: a send-keys with no busy-send option exits 0 and prints {}.
send() {
    local out
    out="$(agent-director send-keys --instance-id "$id" "$@")" || fail "send-keys $* exited non-zero"
    [ "$(jq -c . <<<"$out")" = "{}" ] || fail "send-keys $* printed [$out]; want {}"
}

# coverage: the row's state and busy_send (get).
coverage() { agent-director get --instance-id "$id" | jq -r '[.state, .busy_send] | join("|")'; }

# Step 1: the config, the cwd, and a Codex folder with the rollout the payload names.
[ -x "$standin" ] || fail "$standin is not an executable file"
mkdir -p "$HOME/.config/agent-director"
printf '[launch]\ncodex_path = "%s"\n' "$standin" > "$config"
cwd="$(mktemp -d /tmp/bsu-XXXXXX)"
cwd="$(cd -P "$cwd" && pwd)"
codex_home="$(mktemp -d)"
rollout="$codex_home/sessions/2026/11/13/rollout-2026-11-13T10-00-00-$sid.jsonl"
mkdir -p "$(dirname "$rollout")"
printf '{"type":"session_meta"}\n' > "$rollout"

# Step 2: a waiting codex row, which busy send does not cover.
out="$(agent-director spawn --agent codex --cwd "$cwd" --instance-id "$id" --tmux-session-name cd-bs-un \
    --extra-env "CODEX_HOME=$codex_home")" || fail "spawn exited non-zero"
[ "$(jq -r '.instance_id' <<<"$out")" = "$id" ] || fail "spawn echoed [$out]; want id $id"
end=$(( $(date +%s%N) + 10000000000 ))
until [ -s "$rec_root/$id/pid" ]; do
    [ "$(date +%s%N)" -lt "$end" ] || fail "no stand-in record at $rec_root/$id within 10 s"
    sleep 0.1
done
fire SessionStart '{"source":"startup"}'
wait_state waiting
[ "$(coverage)" = "waiting|not_covered" ] || fail "row reads [$(coverage)]; want waiting|not_covered"

# Step 3: raw keys with no busy-send option: text with no Enter, then one literal character.
send --text "echo ka-$tag" --no-enter
send --key Z

# Step 4: a busy-send option on the uncovered row, mid-line.
before="$(/opt/driver/sql.sh -readonly "$db" .dump)"
set +e
refused="$(agent-director send-keys --instance-id "$id" --text " busy-$tag" --confirmed-delivery=false 2>"$errfile")"
rc=$?
set -e
after="$(/opt/driver/sql.sh -readonly "$db" .dump)"
[ "$rc" -eq 1 ] || fail "the refused send-keys exited $rc; want 1: $(cat "$errfile")"
[ -z "$refused" ] || fail "the refused send-keys printed [$refused] on stdout"
envelope="$(awk '/^\{/{ln=$0} END{print ln}' "$errfile")"
[ "$(jq -r '.err_name' <<<"$envelope")" = "ErrCantSend" ] || fail "err_name is [$(jq -r '.err_name' <<<"$envelope")]; want ErrCantSend: $(cat "$errfile")"
details="$(jq -cS '.err_details' <<<"$envelope")"
[ "$details" = '{"class":"cant_send","reason":"agent_not_covered","resend_safe":true,"retry_with":"new_send"}' ] \
    || fail "err_details is [$details]: $(cat "$errfile")"
[ "$before" = "$after" ] || fail "the refused send-keys changed the store: $(diff <(printf '%s\n' "$before") <(printf '%s\n' "$after") || true)"

# Step 5: finish the line with raw keys; the file it creates last is the fence.
send --text " > $cwd/o; : > $cwd/f" --no-enter
send --key Enter
end=$(( $(date +%s) + 10 ))
until [ -e "$cwd/f" ]; do
    [ "$(date +%s)" -lt "$end" ] || fail "the line was not run within 10 s of its Enter (no $cwd/f)"
    sleep 0.1
done

# Step 6: the line the shell ran held exactly the raw keys.
printf 'ka-%sZ\n' "$tag" | cmp -s - "$cwd/o" || fail "$cwd/o is [$(cat -A "$cwd/o" 2>/dev/null)]; want [ka-${tag}Z\$]"
pane="$(agent-director read-pane --instance-id "$id" --n-lines 40 | jq -r '.pane')"
[[ "$pane" == *"echo ka-${tag}Z > $cwd/o"* ]] || fail "the pane does not show the typed line: $pane"
[[ "$pane" != *"busy-$tag"* ]] || fail "the refused text reached the pane: $pane"
[ "$(coverage)" = "waiting|not_covered" ] || fail "row reads [$(coverage)] after the sends; want waiting|not_covered"

echo "busy-send-uncovered-1 ok: raw --no-enter text and --key typed as before; --confirmed-delivery=false refused ErrCantSend agent_not_covered with nothing typed or stored"
```
