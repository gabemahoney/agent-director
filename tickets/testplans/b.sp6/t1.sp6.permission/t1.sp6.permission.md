# permission-stuck

Run `make test-docker EPIC=permission-stuck DRIVER_MODE=shell` only in the
scheduler. The driver resets a binary-derived isolated schema before each
independent case. No credentials, interactive agent, background AD worker or
real timeout waits are needed. All SQL uses `/opt/driver/sql.sh`.

The shared collector verifies all-agent public state and process-to-process
continuation, representative continuity and report-only command guards. Exact
clock boundaries, stale races and settlement matrices remain unit tests.
Each case prints deterministic JSON evidence; a missing feature prints
`availability: unavailable` and exits 77, never reports a pass.

Scheduler execution must pair immutable main then branch in the SAME job,
preserve both outcomes even if main fails, use `--memory 8g --network off
--channel C0B3X876XSB`, and report its job ID. The scheduler template creates
and chowns every write path in one RUN. Prepare immutable source directories
and binaries before submitting; `scheduler/runner.py` executes the ordered
collector against main and branch without early termination. Main lacking
this capability is unavailable, not passed. The integration writer owns
execution and interpretation; this lane only authors the registered plan.
