# interact-12: only the row's own pane process moves it (pid_mismatch from the driver's shell and from a second pane)

Maps to Epic 8 (`t1.h98.xw`, SR-20.9, SR-22.9, SR-14 `ad.hook.ignored`,
PRD AC-HOOK-04): a hook applies only when its parent process is the
row's recorded pane process (`getppid()` and that pid's start time equal
the row's `pane_pid` and `pane_starttime`). A SessionStart that carries
X's `AGENT_DIRECTOR_INSTANCE_ID` but comes from anywhere else (the
driver's shell, or another pane in X's own tmux session) changes
nothing: X stays `pending`, the hook exits 0 with empty stdout, and the
trail gains exactly one `ad.hook.ignored` with `reason` =
`pid_mismatch`. The same SessionStart typed into X's own pane applies
and X turns `waiting`.

## Setup

Per-case DB-reset has already wiped `~/.agent-director/state.db` (the
trail `~/.agent-director/ad-trail.jsonl` is not wiped, so every trail
check filters on this case's instance id). The container has
`agent-director`, `tmux`, `sqlite3`, `jq` on PATH, the stand-in claude
under `/opt/driver/stand-in-claude/` and the helper
`/opt/driver/pane-hook.sh`.

The spawn runs with `PATH=/opt/driver/stand-in-claude:$PATH` prefixed to
the `agent-director` command (tmux finds `claude` on the launching
process's PATH), so the session's command is the stand-in `claude`,
which `exec`s an interactive bash: that shell is the pane process
agent-director records. `pane-hook.sh` types
`agent-director hook < <payload file> > <out>; echo $? > <rc>` into a
pane with `tmux send-keys` (the row's pane by default, another pane with
`--pane <target>`) and prints the hook's stdout, exiting with the hook's
exit status. The typed hook inherits `AGENT_DIRECTOR_INSTANCE_ID` from
the session, as a real agent's hook would.

## Steps

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd /tmp`
   → capture `claude_instance_id` X. `status` shows `pending`. A
   read-only `sqlite3` read gives the row's `pane_pid`,
   `tmux_session_name` and `tmux_socket`.
2. From the driver's shell, pipe a SessionStart
   (`transcript_path` `/x/i12-pipe.jsonl`) into
   `AGENT_DIRECTOR_INSTANCE_ID=X agent-director hook`. The hook's parent
   is the case's own shell (`$$`), not X's pane process.
3. Assert: exit 0, empty stdout; `status` still `pending`; `get` shows
   no session id; the trail has exactly one `ad.hook.ignored` for X, with
   `hook_event` = `SessionStart`, `reason` = `pid_mismatch`,
   `parent_pid` = `$$`, `hook_session_id` = `i12-pipe`,
   `row_pane_pid` = X's `pane_pid`, `source` = `ad_hook`.
4. `tmux split-window -d -t "=<session>:" -P -F '#{pane_id}'
   /opt/driver/stand-in-claude/claude` in X's session (on X's socket);
   read the new pane's `pane_pid` with `display-message`; it differs from
   X's `pane_pid`.
5. Type a SessionStart (`transcript_path` `/x/i12-split.jsonl`) into
   the new pane with `pane-hook.sh --pane <new pane> X '<payload>'`.
6. Assert: exit 0, empty stdout; `status` still `pending`; `get` shows
   no session id; the trail now has exactly two `ad.hook.ignored` for X,
   the second with `reason` = `pid_mismatch`, `parent_pid` = the new
   pane's `pane_pid`, `hook_session_id` = `i12-split`, `row_pane_pid` =
   X's `pane_pid`.
7. Type a SessionStart (`transcript_path` `/x/i12-own.jsonl`) into X's
   own pane with `pane-hook.sh X '<payload>'`.
8. Assert: exit 0, empty stdout; `status` = `waiting`; `get` shows
   session id `i12-own`; a read-only `sqlite3` read shows `pid` =
   `pane_pid` (the applied SessionStart records the hook's parent, the
   pane process); the trail still has exactly two `ad.hook.ignored` for
   X (the applied hook writes none).

## Pass criteria

- Step 1: spawn exit 0, non-empty `claude_instance_id`, state `pending`,
  `pane_pid` set.
- Steps 2-3: the piped hook exits 0 with empty stdout; X stays `pending`
  with no session id; one `ad.hook.ignored` for X, e.g.
  `{"event":"ad.hook.ignored","claude_instance_id":"<X>","hook_event":"SessionStart","reason":"pid_mismatch","parent_pid":<$$>,"hook_session_id":"i12-pipe","row_pane_pid":<pane_pid>,"source":"ad_hook",…}`.
- Steps 4-6: the second pane's process differs from X's; the hook typed
  there exits 0 with empty stdout; X stays `pending` with no session id;
  a second `ad.hook.ignored` for X with `reason` = `pid_mismatch` and
  `parent_pid` = the second pane's process.
- Steps 7-8: the hook typed into X's own pane exits 0 with empty stdout;
  X is `waiting` with session id `i12-own` and `pid` = `pane_pid`; no
  third `ad.hook.ignored` for X.

## Script

```bash
set -euo pipefail
db="$HOME/.agent-director/state.db"
trail="$HOME/.agent-director/ad-trail.jsonl"
id="$(PATH="/opt/driver/stand-in-claude:$PATH" agent-director spawn --cwd /tmp | jq -r '.claude_instance_id')"
test -n "$id"
test "$(agent-director status --claude-instance-id "$id" | jq -r '.state')" = "pending"
row="$(sqlite3 -readonly -separator '|' "$db" "SELECT COALESCE(pane_pid, ''), COALESCE(tmux_session_name, ''), COALESCE(tmux_socket, '') FROM spawns WHERE claude_instance_id = '$id';")"
IFS='|' read -r pane_pid sess sock <<<"$row"
[[ "$pane_pid" =~ ^[0-9]+$ ]] || { echo "FAIL: pane_pid = '$pane_pid'; want a pid"; exit 1; }
test -n "$sess" || { echo "FAIL: row records no tmux session"; exit 1; }
ignored() {
    if [[ -r "$trail" ]]; then
        jq -cR --arg id "$id" 'fromjson? | select(.event == "ad.hook.ignored" and .claude_instance_id == $id)' "$trail"
    fi
}
still_pending() {
    local st sid
    st="$(agent-director status --claude-instance-id "$id" | jq -r '.state')"
    test "$st" = "pending" || { echo "FAIL [$1]: state = $st; want pending (hook ignored)"; exit 1; }
    sid="$(agent-director get --claude-instance-id "$id" | jq -r '.claude_session_id // ""')"
    test -z "$sid" || { echo "FAIL [$1]: claude_session_id = $sid; want none (hook ignored)"; exit 1; }
}
check_ignored() {
    local label="$1" want_n="$2" want_parent="$3" want_sid="$4" n rec
    n="$(ignored | wc -l)"
    test "$n" -eq "$want_n" || { echo "FAIL [$label]: $n ad.hook.ignored for $id; want $want_n"; ignored; exit 1; }
    rec="$(ignored | tail -n 1)"
    printf '%s' "$rec" | jq -e --argjson pp "$want_parent" --argjson rp "$pane_pid" --arg sid "$want_sid" \
        '.hook_event == "SessionStart" and .reason == "pid_mismatch" and .parent_pid == $pp and .row_pane_pid == $rp and .hook_session_id == $sid and .source == "ad_hook"' >/dev/null \
        || { echo "FAIL [$label]: ad.hook.ignored = $rec"; exit 1; }
}

# 1. From the driver's shell: the hook's parent is this script's shell, not X's pane process.
# (stdout goes to a file, not $(...), so the hook's parent is this shell itself, $$.)
pipe_out_file="$(mktemp)"
printf '%s' '{"hook_event_name":"SessionStart","transcript_path":"/x/i12-pipe.jsonl"}' | AGENT_DIRECTOR_INSTANCE_ID="$id" agent-director hook >"$pipe_out_file"
test ! -s "$pipe_out_file" || { echo "FAIL [pipe]: hook stdout = $(cat "$pipe_out_file"); want empty"; exit 1; }
rm -f "$pipe_out_file"
still_pending pipe
check_ignored pipe 1 "$$" i12-pipe

# 2. From a second pane in X's own session: same session environment, different process.
split="$(tmux ${sock:+-S "$sock"} split-window -d -t "=$sess:" -P -F '#{pane_id}' /opt/driver/stand-in-claude/claude)"
test -n "$split"
split_pid="$(tmux ${sock:+-S "$sock"} display-message -p -t "$split" '#{pane_pid}')"
[[ "$split_pid" =~ ^[0-9]+$ ]] || { echo "FAIL: split pane_pid = '$split_pid'"; exit 1; }
test "$split_pid" != "$pane_pid" || { echo "FAIL: split pane shares X's pane_pid $pane_pid"; exit 1; }
split_out="$(/opt/driver/pane-hook.sh --pane "$split" "$id" '{"hook_event_name":"SessionStart","transcript_path":"/x/i12-split.jsonl"}')"
test -z "$split_out" || { echo "FAIL [split]: hook stdout = $split_out; want empty"; exit 1; }
still_pending split
check_ignored split 2 "$split_pid" i12-split

# 3. From X's own pane process: applies.
own_out="$(/opt/driver/pane-hook.sh "$id" '{"hook_event_name":"SessionStart","transcript_path":"/x/i12-own.jsonl"}')"
test -z "$own_out" || { echo "FAIL [own]: hook stdout = $own_out; want empty"; exit 1; }
state="$(agent-director status --claude-instance-id "$id" | jq -r '.state')"
test "$state" = "waiting" || { echo "FAIL [own]: state = $state; want waiting"; exit 1; }
sid="$(agent-director get --claude-instance-id "$id" | jq -r '.claude_session_id')"
test "$sid" = "i12-own" || { echo "FAIL [own]: claude_session_id = $sid; want i12-own"; exit 1; }
pids="$(sqlite3 -readonly "$db" "SELECT COALESCE(pid, 'NULL') || '|' || COALESCE(pane_pid, 'NULL') FROM spawns WHERE claude_instance_id = '$id';")"
test "$pids" = "$pane_pid|$pane_pid" || { echo "FAIL [own]: pid|pane_pid = $pids; want $pane_pid|$pane_pid"; exit 1; }
n="$(ignored | wc -l)"
test "$n" -eq 2 || { echo "FAIL [own]: $n ad.hook.ignored for $id; want 2 (the applied hook writes none)"; exit 1; }
echo "interact-12 ok: id=$id pane_pid=$pane_pid; driver-shell and split-pane ($split_pid) SessionStarts ignored (pid_mismatch); own pane's applied, state=waiting"
```
