# Test case: Uncertain rotation caller replacement and refused provisional input

Maps E3 AC3/4/5; SR-0.3, SR-3.3, SR-4.1–4.2, SR-6.2.

## Setup

Shared isolated shipped CLI/MCP with synthetic session/new rejection held behind
an explicit release file. No deadline extension or sleep selects the interleaving.

## Steps

Hold the second session/new reply, admit terminal and public provisional inputs,
replace MCP and inspect the old current identity. Release rejection. Verify each
held submission is refused once, never accepted/dispatched, and owned processes die.

## Pass criteria

Unconfirmed identity never becomes current/history; exact held submission IDs and
texts get refusal dispositions, absent from all raw model requests. No fabricated end.

```bash
set -euo pipefail
source /work/source/test/driver/cursor-pane-controls.sh
pc_start
jq -cn --arg session "$session" '{sessionId:$session,waitForNew:true,newReplies:[{error:{code:-32000,message:"synthetic collector rejection"}}]}' > "$case_dir/scenario"
ad send-keys --instance-id "$id" --text /new >/dev/null
new_pending() { [[ $(frames | jq -s '[.[]|select(.method=="session/new")]|length') == 2 ]]; }
check rotation.unconfirmed wait_until new_pending
pc_send MCP 'held public never replay 🐝' >/dev/null
pc_terminal 'held terminal never replay'
check input.two-provisional wait_until pc_count_is input_held 2
pc_public MCP get "$(jq -cn --arg id "$id" '{instance_id:$id}')" > "$case_dir/inspection.json"
check caller.old-identity pc_identity
touch "$case_dir/new-release"
check owned.runtime-gone wait_gone "$runtime"
check owned.gateway-gone wait_gone "$gateway"
check input.zero-wire pc_raw_complete
check input.refused-count pc_count_is held_input_refused 2
check rotation.no-history test "$(sql "SELECT count(*) FROM session_history WHERE instance_id='$id';")" = 0
check rotation.old-session test "$(sql "SELECT session_id FROM spawns WHERE instance_id='$id';")" = "$session"
check input.no-admission pc_count_is submission_accepted 0
check input.no-dispatch pc_prompts_is 0
check failure.no-end pc_count_is session_end 0
jq -se '[.[]|select(.kind=="input_held")]|map(.data.submission_id)|sort' "$path" > "$case_dir/held-ids"
jq -se '[.[]|select(.kind=="held_input_refused")]|map(.data.submission_id)|sort' "$path" > "$case_dir/refused-ids"
check input.exact-refusals cmp "$case_dir/held-ids" "$case_dir/refused-ids"
jq -se '[.[]|select(.kind=="input_held")]|map(.data.text)|sort == (["held public never replay 🐝","held terminal never replay"]|sort)' "$path" >/dev/null
pc_finish t2.jf1.pc.04 '["rotation.unconfirmed-old-identity","caller.replaced-during-rotation","input.exact-refused-IDs","input.zero-wire","failure.no-fabricated-history-end"]'
```
