# kill-6: a prefix neighbour carrying another id is left alone

Maps to SRD SR-20.9 kill-6 (Epic `t1.h98.aq`, the honest kill; SR-6.1,
SR-1.4). A name target in tmux prefix-matches, so a kill by the name
`cd-k6` could once end `cd-k6x`. `kill` now targets only the session
labelled for the row, by session id. Here row `id-k6` (`cd-k6`) has no
session at all, while `cd-k6x` runs labelled for another row, `id-k6x`,
with a five-field label ending with this store's id: the lookup finds
no session with `id-k6`'s label (Gone), so `kill` of `id-k6` returns 0
with `kill_sent` false and `cd-k6x` keeps running with its label
unchanged.

Both rows carry a `launch_token`, so `id-k6` could be Ours if a session
carried its label: the case does not pass merely because a row with no
token is never Ours.

## Setup

Per-case DB-reset. An EXIT trap removes `cd-k6x` by its session id.

## Steps

1. Read this store's id with `sqlite3` from `store_meta` (`key =
   'store_id'`).
2. Seed `spawns` rows at state `waiting`: `id-k6` (session name
   `cd-k6`) and `id-k6x` (session name `cd-k6x`), each with its own
   16-lowercase-hex `launch_token`; read both tokens back with
   `sqlite3`.
3. `tmux new-session -d -s cd-k6x -e AGENT_DIRECTOR_INSTANCE_ID=id-k6x --
   cat`, capturing its session id `$N`; set `@ad_owner`
   `ad1 <id-k6x's token> <$N> id-k6x <store id>` on `'<$N>'` and read it
   back. No `cd-k6` session exists.
4. `agent-director kill --claude-instance-id id-k6`.
5. Check `cd-k6x` by its `$N` and its label.

## Pass criteria

- The label read back has five fields and ends with this store's id.
- kill exits 0 and its stdout JSON has `kill_sent == false`.
- `tmux has-session -t '<$N>'` succeeds after the kill, and
  `show-options -t '<$N>' -v @ad_owner` is byte-identical to before.
- Both rows are still `waiting`.

## Script

```bash
set -euo pipefail
db="$HOME/.agent-director/state.db"
fail() { echo "FAIL: $*"; exit 1; }
sid=""
trap '[ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true' EXIT

store_id="$(/opt/driver/sql.sh "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

for row in k6 k6x; do
    t="$(od -An -N8 -tx1 /dev/urandom | tr -d ' 
')"
    /opt/driver/sql.sh "$db" \
      "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, launch_token)
       VALUES ('id-$row', 'waiting', '/tmp', 'cd-$row', 'off', '$t');"
done
token="$(/opt/driver/sql.sh "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-k6';")"
[[ "$token" =~ ^[0-9a-f]{16}$ ]] || fail "id-k6 launch_token is not 16 lowercase hex: [$token]"
x_token="$(/opt/driver/sql.sh "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-k6x';")"
[[ "$x_token" =~ ^[0-9a-f]{16}$ ]] || fail "id-k6x launch_token is not 16 lowercase hex: [$x_token]"

sid="$(tmux new-session -d -s cd-k6x -e AGENT_DIRECTOR_INSTANCE_ID=id-k6x -P -F '#{session_id}' -- cat)"
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"
label="ad1 $x_token $sid id-k6x $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
before="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$before" = "$label" ] || fail "label read back [$before]; want [$label]"
read -r -a fields <<<"$before"
[ "${#fields[@]}" -eq 5 ] && [ "${fields[4]}" = "$store_id" ] || fail "label [$before]; want five fields ending with $store_id"
if tmux has-session -t '=cd-k6' 2>/dev/null; then
    fail "a session named exactly cd-k6 exists; the row must have none"
fi

out="$(agent-director kill --claude-instance-id id-k6)" || fail "kill exited non-zero; want 0"
sent="$(jq -r '.kill_sent' <<<"$out")"
[ "$sent" = "false" ] || fail "kill_sent=$sent; want false (stdout: $out)"

tmux has-session -t "$sid" 2>/dev/null || fail "neighbour $sid (cd-k6x) no longer runs after kill of id-k6"
after="$(tmux show-options -t "$sid" -v @ad_owner 2>/dev/null || true)"
[ "$after" = "$before" ] || fail "neighbour label changed: [$after]; want [$before]"
states="$(/opt/driver/sql.sh "$db" "SELECT group_concat(state, ',') FROM (SELECT state FROM spawns WHERE claude_instance_id IN ('id-k6','id-k6x') ORDER BY claude_instance_id);")"
[ "$states" = "waiting,waiting" ] || fail "row states=$states after kill; want waiting,waiting"

echo "kill-6 ok: row cd-k6 with no session → kill exit 0 with kill_sent false; prefix neighbour cd-k6x ($sid) still runs, label unchanged"
```
