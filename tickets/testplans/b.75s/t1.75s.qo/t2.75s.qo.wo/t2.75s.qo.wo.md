# spawn-9: fresh-cwd pre-trust flips hasTrustDialogAccepted before spawn

Maps to bug b.f75 AC #1 + #6 (`spawn --cwd <fresh-dir>` results in
state=`waiting` within ~5s without human-in-the-loop, and
`~/.claude.json` projects.<cwd>.hasTrustDialogAccepted is true after
the spawn). Epic 8 (`t1.h98.xw`, SR-20.9, SR-22.9): a hook moves the row
only when it comes from the row's own pane process, so the SessionStart
is typed into the pane.

## Setup

Per-case DB-reset has already wiped `~/.agent-director/state.db`. The
container has `agent-director`, `tmux`, `jq` on PATH.

The case uses a synthetic `~/.claude.json` seeded with an empty
projects map. The harness writes to `$HOME/.claude.json` directly —
no real Claude Code install is required, since pre-trust only cares
about the file's shape. The spawn runs with
`PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the `agent-director`
command (tmux finds `claude` on the launching process's PATH), so the pane
process is the stand-in claude's interactive bash, and
`/opt/driver/pane-hook.sh <id> '<payload>'` types the hook into that
pane with `tmux send-keys` (exiting with the hook's exit status). No hook
is piped from the case's own shell.

No real Claude Code may run while this case reads and writes
`~/.claude.json`. A running Claude Code rewrites that file (under its own
lock, which pre-trust does not take), so its write can drop the trust
entry between the spawn and step 6. The per-case DB-reset ends every tmux
server, whatever its sessions are named, and waits for (or after 5 s
kills) what their panes run, so an earlier case's real Claude does not
outlive it (b.8yq). Before b.8yq the reset ended only `cd-` sessions while
default session names are `<cwd base>-<id8>`, so an earlier case's real
Claude kept running; that is why every spawn before this case in the
collector uses the stand-in. If step 6 fails, the failure lists any Claude
Code process that is still running.

## Steps

1. Seed `$HOME/.claude.json` with `{"projects":{}}` and pick a fresh
   cwd that has never been Claude-Code-trusted (a `mktemp -d`).
2. Assert that `projects.<cwd>.hasTrustDialogAccepted` is unset
   beforehand.
3. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd <fresh-dir>`
   → capture `claude_instance_id`.
4. Type a SessionStart hook payload into the row's pane with
   `/opt/driver/pane-hook.sh <id> '<payload>'` (mirrors what the
   spawned Claude would emit — keeps the case API-free).
5. `agent-director status --claude-instance-id <id>` → assert
   state = `waiting`.
6. Re-read `$HOME/.claude.json` and assert
   `projects.<canonical cwd>.hasTrustDialogAccepted == true`.

## Pass criteria

- Step 3 exits 0; result JSON has non-empty `claude_instance_id`.
- Step 4 exits 0 with empty stdout (state-tracking fail-open).
- Step 5 returns `{"state":"waiting"}`.
- Step 6 confirms the trust key was flipped to `true` by the spawn.

## Script

```bash
set -euo pipefail
fail() { echo "FAIL spawn-9: $*"; exit 1; }
echo '{"projects":{}}' > "$HOME/.claude.json"
cwd="$(cd "$(mktemp -d)" && pwd -P)"  # canonical (symlink-resolved) path
# Precondition: trust key absent.
pre="$(jq -r --arg cwd "$cwd" '.projects[$cwd].hasTrustDialogAccepted // "absent"' "$HOME/.claude.json")"
test "$pre" = "absent" || fail "precondition hasTrustDialogAccepted=$pre for fresh $cwd; want absent"
spawn_out="$(PATH="/opt/driver/stand-in-claude:$PATH" agent-director spawn --cwd "$cwd")"
id="$(printf '%s' "$spawn_out" | jq -r '.claude_instance_id')"
[ -n "$id" ] && [ "$id" != "null" ] || fail "spawn returned no claude_instance_id: $spawn_out"
hook_out="$(/opt/driver/pane-hook.sh "$id" '{"hook_event_name":"SessionStart","transcript_path":"/x/abc-uuid.jsonl"}')"
test -z "$hook_out" || fail "SessionStart hook printed [$hook_out]; want nothing"
state="$(agent-director status --claude-instance-id "$id" | jq -r '.state')"
test "$state" = "waiting" || fail "state=$state after SessionStart for $id; want waiting"
post="$(jq -r --arg cwd "$cwd" '.projects[$cwd].hasTrustDialogAccepted' "$HOME/.claude.json")"
if [ "$post" != "true" ]; then
  # A running Claude Code rewrites ~/.claude.json and can drop the entry.
  others="$(pgrep -a -f '^claude( |$)' | cut -c1-60 | tr '\n' '|' || true)"
  fail "hasTrustDialogAccepted=$post for $cwd; want true; projects=$(jq -c '.projects // {} | keys' "$HOME/.claude.json" 2>&1); running Claude Code: [${others}]"
fi
echo "spawn-9 ok: id=$id state=waiting hasTrustDialogAccepted=true"
```
