# mcp-9: MCP spawn's extra_env, label and claude_args reach the launch

Maps to b.pti and b.zkp. MCP `spawn` decodes `extra_env` as a JSON
object with string values, and `label` and `claude_args` as arrays of
strings (the shapes mcp-8 pins in tools/list). This case sends all
three through `agent-director serve --stdio` and checks that they
reach the launch: the variables and `AGENT_DIRECTOR_LABEL_*` on the
tmux session env, `claude_args` on the agent's argv after
agent-director's own `--settings <json>`, and the labels and
`claude_args` on the row `get` shows.

Agent: the server runs with a recording stand-in `claude` first on its
PATH. tmux looks `claude` up on the PATH of agent-director's own
process, so the server's PATH selects it (see
`/opt/driver/stand-in-claude/claude`). The recorder writes its argv,
NUL-separated, to a file, then execs `/opt/driver/stand-in-claude/claude`,
whose interactive bash keeps the session alive. No real Claude Code
runs and no hook is sent, so the row stays `pending`.

`CLAUDE_CONFIG_DIR` is a fresh directory under `/tmp`. Pre-trust finds
no `.claude.json` there and the spawn proceeds (as in resume-10). The
case does not assert `pre_trust`.

## Setup

Per-case DB-reset. The id is `mcp9-<uuid>` and the session name
`cd-mcp9-<tag>`, which the reset sweeps. An EXIT trap ends the session
on the row's socket and removes the case's temp directories.

## Steps

1. Write the recording `claude` into a temp directory.
2. Pipe `initialize` and a `tools/call` of `spawn` into
   `PATH=<recorder dir>:$PATH agent-director serve --stdio`, with
   arguments `cwd` `/tmp`, `claude_instance_id`, `tmux_session_name`,
   `extra_env` `{"MCP9_FOO":"bar","CLAUDE_CONFIG_DIR":"<fresh dir>"}`,
   `label` `["team=mcp9","my-key=v1"]` and
   `claude_args` `["--model","mcp9-model"]`.
3. Read the second response.
4. `agent-director get --claude-instance-id <id>`.
5. `tmux -S <tmux_socket> show-environment -t =<session> <name>` for
   `MCP9_FOO`, `CLAUDE_CONFIG_DIR`, `AGENT_DIRECTOR_LABEL_TEAM` and
   `AGENT_DIRECTOR_LABEL_MY_KEY`.
6. Wait (bounded, 5 s) for the recorder's argv file, then read it.

## Pass criteria

- Step 3: no JSON-RPC `error`; `result.content[0].text` is JSON whose
  `claude_instance_id` is the id sent.
- Step 4: `state` `pending`, `tmux_session_name` the name sent,
  `labels` `{"team":"mcp9","my-key":"v1"}`, `claude_args`
  `["--model","mcp9-model"]`.
- Step 5: `MCP9_FOO=bar`, `CLAUDE_CONFIG_DIR=<fresh dir>`,
  `AGENT_DIRECTOR_LABEL_TEAM=mcp9`, `AGENT_DIRECTOR_LABEL_MY_KEY=v1`.
- Step 6: the argv is exactly `--settings`, a JSON object, `--model`,
  `mcp9-model`.

Each failed check prints a `FAIL:` line naming what was expected and
what was seen.

## Script

```bash
set -euo pipefail
uuid="$(cat /proc/sys/kernel/random/uuid)"
id="mcp9-$uuid"
name="cd-mcp9-${uuid:0:8}"
work="$(mktemp -d /tmp/mcp9.XXXXXX)"
cfg="$(mktemp -d /tmp/mcp9-cfg.XXXXXX)"
argv_file="$work/argv"
sock=""
fail() { echo "FAIL: $*"; exit 1; }
cleanup() {
    tmux ${sock:+-S "$sock"} kill-session -t "=$name" 2>/dev/null || true
    rm -rf "$work" "$cfg"
}
trap cleanup EXIT

# Step 1: the recording stand-in claude.
mkdir "$work/bin"
cat >"$work/bin/claude" <<EOF
#!/bin/bash
printf '%s\0' "\$@" >"$argv_file.tmp"
mv "$argv_file.tmp" "$argv_file"
exec /opt/driver/stand-in-claude/claude "\$@"
EOF
chmod 0755 "$work/bin/claude"

# Step 2: MCP spawn with an object extra_env and array label and claude_args.
args="$(jq -cn --arg id "$id" --arg name "$name" --arg cfg "$cfg" '{
    cwd: "/tmp", claude_instance_id: $id, tmux_session_name: $name,
    extra_env: {MCP9_FOO: "bar", CLAUDE_CONFIG_DIR: $cfg},
    label: ["team=mcp9", "my-key=v1"],
    claude_args: ["--model", "mcp9-model"]}')"
call="$(jq -cn --argjson a "$args" '{jsonrpc: "2.0", id: 2, method: "tools/call", params: {name: "spawn", arguments: $a}}')"
out="$(printf '%s
%s
' \
    '{"jsonrpc":"2.0","id":1,"method":"initialize"}' "$call" \
    | PATH="$work/bin:$PATH" agent-director serve --stdio 2>/dev/null)"

# Step 3: the spawn succeeded.
second="$(sed -n '2p' <<<"$out")"
[ -n "$second" ] || fail "no response to the spawn call; server output: [$out]"
[ -z "$(jq -c '.error // empty' <<<"$second")" ] || fail "spawn returned an error: $second"
got="$(jq -r '.result.content[0].text | fromjson | .claude_instance_id' <<<"$second" 2>/dev/null)" || got="(no JSON result)"
[ "$got" = "$id" ] || fail "spawn result claude_instance_id=[$got]; want [$id]: $second"

# Step 4: the row.
row="$(agent-director get --claude-instance-id "$id")"
sock="$(jq -r '.tmux_socket // ""' <<<"$row")"
want="$(jq -cn --arg name "$name" '["pending", $name, {team: "mcp9", "my-key": "v1"}, ["--model", "mcp9-model"]]')"
if ! jq -e --argjson want "$want" '[.state, .tmux_session_name, .labels, .claude_args] == $want' <<<"$row" >/dev/null; then
    fail "get [state, tmux_session_name, labels, claude_args]=$(jq -c '[.state, .tmux_session_name, .labels, .claude_args]' <<<"$row"); want $want"
fi

# Step 5: the session env.
for kv in "MCP9_FOO=bar" "CLAUDE_CONFIG_DIR=$cfg" "AGENT_DIRECTOR_LABEL_TEAM=mcp9" "AGENT_DIRECTOR_LABEL_MY_KEY=v1"; do
    got="$(tmux ${sock:+-S "$sock"} show-environment -t "=$name" "${kv%%=*}" 2>&1)" || true
    [ "$got" = "$kv" ] || fail "session $name env ${kv%%=*}: [$got]; want [$kv]"
done

# Step 6: claude's argv.
end=$(( $(date +%s%N) + 5000000000 ))
while [ ! -e "$argv_file" ]; do
    [ "$(date +%s%N)" -lt "$end" ] || fail "the recording claude wrote no argv within 5 s"
    sleep 0.1
done
mapfile -t -d '' argv <"$argv_file"
seen="$(tr '\0' ' ' <"$argv_file")"
[ "${#argv[@]}" -eq 4 ] && [ "${argv[0]}" = "--settings" ] || fail "claude argv [$seen]; want --settings <json> --model mcp9-model"
jq -e 'type == "object"' <<<"${argv[1]}" >/dev/null || fail "claude --settings value is not a JSON object: [${argv[1]:0:200}]"
[ "${argv[2]} ${argv[3]}" = "--model mcp9-model" ] || fail "claude argv after --settings <json>: [${argv[2]} ${argv[3]}]; want [--model mcp9-model]"
echo "mcp-9 ok: session $name env has MCP9_FOO, CLAUDE_CONFIG_DIR, AGENT_DIRECTOR_LABEL_TEAM/MY_KEY; claude argv --settings <json> --model mcp9-model; get labels and claude_args match"
```
