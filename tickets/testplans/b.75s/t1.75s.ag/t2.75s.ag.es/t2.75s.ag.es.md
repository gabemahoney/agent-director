# agent-21: the Escape pane answer on a fallen-back codex request

Maps to SRD SR-8.1, SR-8.3, SR-8.4 and SR-14.5 of Epic 13 (`b.ssz`), and to
b.146 rule 8: when a relayed request's hook is gone before it acked a
verdict, the request has fallen back and only an answer at the pane (or
`record-pane-answer`) closes it. On a Codex row the pane answer's key is
Escape (Codex's own deny). The case makes the relay hook fall back by killing
the process the request recorded (`hook_pid`), reads the pane for its hash,
and calls `send-keys --request-token <t> --as deny --key Escape
--expect-pane-sha256 <hash>`: exit 0, the request reads `pane_answer` `sent`,
`pane_as` `deny`, decision `deny` with `decision_reason` `pane`. Nothing in
agent-director's records proves the dialog gone, so a plain `send-keys` is
still refused (`ErrDialogMaybeOpen`). A Codex `Interrupt` (no `agent_id`),
typed as Codex sends it when Escape stops the turn, makes the row `waiting`
and proves the request gone (`turn_end`); then a plain `send-keys` types.

Agent and hooks (collector "Driver mode"): the pane process is the Codex
stand-in `/opt/driver/stand-in-codex/codex`, named by `[launch] codex_path`,
an interactive bash; every hook is typed into its pane with
`/opt/driver/pane-hook.sh --agent codex`. The Escape key reaches that bash,
which drops a lone Escape (the stand-in binds it to an empty macro), so the
Interrupt line typed next is not read as a meta key and keeps its first
letter.

## Setup

Per-case DB-reset. The case writes `~/.config/agent-director/config.toml`
with `[launch]` `codex_path = "/opt/driver/stand-in-codex/codex"`, makes a
cwd and a temporary Codex folder holding the one rollout file the payloads
name, and removes them, the config and the stand-in's record directory on
exit.

## Steps

1. Write the config; make the cwd and the Codex folder with its rollout.
2. `agent-director spawn --agent codex --cwd <cwd> --instance-id <id>
   --tmux-session-name cd-ag-es --relay-mode on --extra-env
   CODEX_HOME=<folder>`; type a `SessionStart`; the row is `waiting`.
3. Type a `PermissionRequest` (tool `Bash`) with `pane-hook.sh --agent codex
   --no-wait`; wait for the open request; the row is `check_permission`.
4. `kill -KILL` the request's recorded `hook_pid`; wait for the hook's
   status line to be written; `get-permission` reads `fallen_back`.
5. `read-pane` for `pane_sha256`; `send-keys --request-token <t> --as deny
   --key Escape --expect-pane-sha256 <hash>`; `get-permission`.
6. Plain `send-keys --text <marker>`.
7. Type a Codex `Interrupt`; `get` and `get-permission`.
8. Plain `send-keys --text <marker>` again; `read-pane`.

## Pass criteria

- Step 3: the hook is still running; one open request whose `hook_pid` is a
  running process; the row is `check_permission`.
- Step 4: the hook's status is not 0 (it was killed); `get-permission` shows
  `delivery` `fallen_back`, `hook_alive` false and `decision` null.
- Step 5: send-keys exits 0 with `{}`; `get-permission` shows `pane_answer`
  `sent`, `pane_as` `deny`, `decision` `deny`, `decision_reason` `pane` and
  `proven_gone_at` null.
- Step 6: exit 1 with `err_name` `ErrDialogMaybeOpen`; the marker never
  reaches the pane.
- Step 7: the Interrupt hook exits 0 and prints nothing (the line was not
  mangled); the row is `waiting`; `get-permission` shows `proven_gone_how`
  `turn_end` and a `proven_gone_at`.
- Step 8: send-keys exits 0 with `{}`; the marker is on the pane within
  10 s.

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN CODEX_HOME

db="$HOME/.config/agent-director/state.db"
config="$HOME/.config/agent-director/config.toml"
standin="/opt/driver/stand-in-codex/codex"
rec_root="/tmp/stand-in-codex"
uuid="$(cat /proc/sys/kernel/random/uuid)"
id="ag-es-$uuid"
sid="$(cat /proc/sys/kernel/random/uuid)"
marker="ag-es-marker-$RANDOM$RANDOM"
codex_home=""
cwd=""
rollout=""
errfile="$(mktemp)"
fail() { echo "FAIL: $*"; exit 1; }

col() { /opt/driver/sql.sh -readonly "$db" "SELECT $1 FROM spawns WHERE instance_id = '$id';"; }

cleanup() {
    local row sock pane s
    row="$(col "IFNULL(tmux_socket,'') || '|' || IFNULL(pane_id,'')" 2>/dev/null || true)"
    sock="${row%%|*}"
    pane="${row#*|}"
    if [ -n "$pane" ]; then
        s="$(tmux ${sock:+-S "$sock"} display-message -p -t "$pane" '#{session_id}' 2>/dev/null || true)"
        [ -z "$s" ] || tmux ${sock:+-S "$sock"} kill-session -t "$s" 2>/dev/null || true
    fi
    rm -f "$config" "$errfile"
    rm -rf "$rec_root/$id" ${codex_home:+"$codex_home"} ${cwd:+"$cwd"}
    rmdir "$rec_root" 2>/dev/null || true
}
trap cleanup EXIT

# wait_state WANT: the row's state (get) is WANT within 10 s.
wait_state() {
    local want="$1" end got=""
    end=$(( $(date +%s) + 10 ))
    while :; do
        got="$(agent-director get --instance-id "$id" | jq -r '.state')"
        [ "$got" != "$want" ] || return 0
        [ "$(date +%s)" -lt "$end" ] || fail "row $id state is [$got]; want [$want] within 10 s"
        sleep 0.2
    done
}

# fire EVENT [EXTRA_JSON]: type the Codex hook EVENT into the row's pane; the
# hook must exit 0 and print nothing.
fire() {
    local extra='{}' body out
    [ $# -lt 2 ] || extra="$2"
    body="$(jq -cn --arg e "$1" --arg sid "$sid" --arg tp "$rollout" --arg cwd "$cwd" --argjson x "$extra" \
        '{hook_event_name: $e, session_id: $sid, transcript_path: $tp, cwd: $cwd, model: "codex-stand-in", permission_mode: "default"} + $x')"
    out="$(/opt/driver/pane-hook.sh --agent codex "$id" "$body")" || fail "the $1 hook exited non-zero"
    [ -z "$out" ] || fail "the $1 hook printed [$out]; want nothing"
}

# pane_has TEXT: the row's pane shows TEXT now.
pane_has() {
    local pane_text
    pane_text="$(agent-director read-pane --instance-id "$id" --n-lines 40 | jq -r '.pane')"
    [[ "$pane_text" == *"$1"* ]]
}

# Step 1: the config, the cwd, and a Codex folder with the rollout the payloads name.
[ -x "$standin" ] || fail "$standin is not an executable file"
mkdir -p "$HOME/.config/agent-director"
printf '[launch]\ncodex_path = "%s"\n' "$standin" > "$config"
cwd="$(mktemp -d /tmp/ag-es-XXXXXX)"
cwd="$(cd -P "$cwd" && pwd)"
codex_home="$(mktemp -d)"
rollout="$codex_home/sessions/2026/10/12/rollout-2026-10-12T10-00-00-$sid.jsonl"
mkdir -p "$(dirname "$rollout")"
printf '{"type":"session_meta"}\n' > "$rollout"

# Step 2: a waiting codex row with the relay on.
out="$(agent-director spawn --agent codex --cwd "$cwd" --instance-id "$id" --tmux-session-name cd-ag-es \
    --relay-mode on --extra-env "CODEX_HOME=$codex_home")" || fail "spawn exited non-zero"
[ "$(jq -r '.instance_id' <<<"$out")" = "$id" ] || fail "spawn echoed [$out]; want id $id"
end=$(( $(date +%s%N) + 10000000000 ))
until [ -s "$rec_root/$id/pid" ]; do
    [ "$(date +%s%N)" -lt "$end" ] || fail "no stand-in record at $rec_root/$id within 10 s"
    sleep 0.1
done
fire SessionStart '{"source":"startup"}'
wait_state waiting

# Step 3: the PermissionRequest, typed as a hook that blocks on the relay.
req="$(jq -cn --arg sid "$sid" --arg tp "$rollout" --arg cwd "$cwd" \
    '{hook_event_name: "PermissionRequest", session_id: $sid, transcript_path: $tp, cwd: $cwd, model: "codex-stand-in", permission_mode: "default", turn_id: "turn-1", tool_name: "Bash", tool_input: {command: "touch shell.txt", description: "write a file"}}')"
job="$(/opt/driver/pane-hook.sh --agent codex --no-wait "$id" "$req")"
token=""
for _ in $(seq 1 100); do
    token="$(/opt/driver/sql.sh -readonly "$db" "SELECT request_token FROM permission_requests WHERE instance_id = '$id' AND decision IS NULL ORDER BY request_id DESC LIMIT 1;")"
    [ -z "$token" ] || break
    sleep 0.1
done
[ -n "$token" ] || fail "no open permission request for $id: the relay hook never recorded one"
[ ! -s "$job/rc" ] || fail "the relay hook has already exited ($(cat "$job/rc")) with no decision"
wait_state check_permission
hook_pid="$(/opt/driver/sql.sh -readonly "$db" "SELECT IFNULL(hook_pid, '') FROM permission_requests WHERE request_token = '$token';")"
[[ "$hook_pid" =~ ^[1-9][0-9]*$ ]] || fail "the request records hook_pid [$hook_pid]; want a pid"
kill -0 "$hook_pid" 2>/dev/null || fail "the recorded hook pid $hook_pid is not running"

# Step 4: the hook falls back: it is killed before any verdict.
kill -KILL "$hook_pid"
end=$(( $(date +%s) + 10 ))
until [ -s "$job/rc" ]; do
    [ "$(date +%s)" -lt "$end" ] || fail "the pane's shell wrote no status for the killed hook within 10 s"
    sleep 0.1
done
[ "$(cat "$job/rc")" != "0" ] || fail "the killed hook exited 0"
perm="$(agent-director get-permission --request-token "$token")"
[ "$(jq -r '[.delivery, .hook_alive, .decision] | map(tostring) | join("|")' <<<"$perm")" = "fallen_back|false|null" ] \
    || fail "request reads [$(jq -r '[.delivery, .hook_alive, .decision] | map(tostring) | join("|")' <<<"$perm")]; want fallen_back|false|null: $perm"

# Step 5: read the pane, answer with Escape. The pane is quiet once the shell
# has written the status line, so the hash is the one the answer is checked against.
sleep 1
pane_json="$(agent-director read-pane --instance-id "$id")"
hash="$(jq -r '.pane_sha256' <<<"$pane_json")"
[[ "$hash" =~ ^[0-9a-f]{64}$ ]] || fail "read-pane gave pane_sha256 [$hash]"
out="$(agent-director send-keys --instance-id "$id" --request-token "$token" --as deny --key Escape --expect-pane-sha256 "$hash")" \
    || fail "the Escape pane answer exited non-zero"
[ "$(jq -c . <<<"$out")" = "{}" ] || fail "the pane answer printed [$out]; want {}"
perm="$(agent-director get-permission --request-token "$token")"
got="$(jq -r '[.pane_answer, .pane_as, .decision, .decision_reason] | join("|")' <<<"$perm")"
[ "$got" = "sent|deny|deny|pane" ] || fail "request reads [$got]; want sent|deny|deny|pane: $perm"
[ "$(jq -r '.proven_gone_at' <<<"$perm")" = "null" ] || fail "request proven gone by the pane answer alone: $perm"

# Step 6: the pane answer proves nothing, so a plain send-keys is held.
set +e
agent-director send-keys --instance-id "$id" --text "echo $marker" >/dev/null 2>"$errfile"
rc=$?
set -e
[ "$rc" -eq 1 ] || fail "plain send-keys exited $rc; want 1: $(cat "$errfile")"
envelope="$(awk '/^\{/{ln=$0} END{print ln}' "$errfile")"
[ "$(jq -r '.err_name' <<<"$envelope")" = "ErrDialogMaybeOpen" ] || fail "err_name is [$(jq -r '.err_name' <<<"$envelope")]; want ErrDialogMaybeOpen: $(cat "$errfile")"
sleep 1
if pane_has "$marker"; then fail "the held send-keys typed its marker into the pane"; fi

# Step 7: Codex's Interrupt (Escape stopped the turn) proves it gone and the row waits.
fire Interrupt '{"turn_id":"turn-1"}'
wait_state waiting
perm="$(agent-director get-permission --request-token "$token")"
[ "$(jq -r '.proven_gone_how' <<<"$perm")" = "turn_end" ] || fail "proven_gone_how is [$(jq -r '.proven_gone_how' <<<"$perm")]; want turn_end: $perm"
[ "$(jq -r '.proven_gone_at' <<<"$perm")" != "null" ] || fail "proven_gone_at is null after the Interrupt: $perm"

# Step 8: now a plain send-keys types.
out="$(agent-director send-keys --instance-id "$id" --text "echo $marker")" || fail "plain send-keys exited non-zero after the Interrupt"
[ "$(jq -c . <<<"$out")" = "{}" ] || fail "send-keys printed [$out]; want {}"
end=$(( $(date +%s) + 10 ))
until pane_has "$marker"; do
    [ "$(date +%s)" -lt "$end" ] || fail "the marker never reached the pane within 10 s"
    sleep 0.2
done

echo "agent-21 ok: hook killed -> fallen_back; send-keys --key Escape pane answer (sent, deny, pane); held until the Codex Interrupt (turn_end), row waiting, then plain send-keys types"
```
