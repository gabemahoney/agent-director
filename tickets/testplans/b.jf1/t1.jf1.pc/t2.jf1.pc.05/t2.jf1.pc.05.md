# Test case: Owned crash and protected transcript fault inspection

Maps E3 AC5; SR-0.3, SR-3.3, SR-4.1–4.2.

## Setup

Two independent helper namespaces. Synthetic runtime, actual Linux process death
and shipped CLI/MCP; permission fault uses the same protected-file mode boundary
as the focused public test. No source changes or fault helpers outside the case.

## Steps

For a protected-file mode fault, attempt an ordinary prompt and inspect through
replacement MCP. For an owned runtime SIGKILL, inspect and reconcile with public
find-missing. In both cases independently prove owned death and sentinel survival.

## Pass criteria

No accepted/model input after the persistence fault and no claimed durable end.
A crash end record is allowed only with runtime_gone and real runtime death;
process reconciliation must yield missing or a genuine ended record. No replay.

```bash
set -euo pipefail
receipts=$(mktemp /tmp/pc-failure-receipts-XXXXXX)
for fault in protected-mode runtime-crash; do
 (
  source /work/source/test/driver/cursor-pane-controls.sh
  pc_start
  if [[ $fault == protected-mode ]]; then
   chmod 0644 "$path"
   ad send-keys --instance-id "$id" --text 'faulted input must not execute' >/dev/null
  else
   kill -KILL "$runtime"
  fi
  check owned.runtime-gone wait_gone "$runtime"
  check owned.gateway-gone wait_gone "$gateway"
  pc_public MCP get "$(jq -cn --arg id "$id" '{instance_id:$id}')" > "$case_dir/public.json"
  check input.zero-admission pc_count_is submission_accepted 0
  check input.zero-prompt-frames pc_prompts_is 0
  check input.zero-wire pc_raw_complete
  if [[ $fault == protected-mode ]]; then
   check failure.no-fabricated-end pc_count_is session_end 0
   jq -e '.state!="ended"' "$case_dir/public.json" >/dev/null
  else
   jq -se 'all(.[]; .kind!="session_end" or .data.runtime_gone==true)' "$path" >/dev/null
   ad find-missing >/dev/null
   state=$(row_state)
   if [[ $state == ended ]]; then check crash.durable-end pc_count_is session_end 1; else check crash.reconciled test "$state" = missing; fi
  fi
  pc_finish t2.jf1.pc.05 '["failure.protected-no-admission","crash.process-reconciliation","failure.no-fabricated-end","owned.exact-death-sentinel"]' | jq --arg fault "$fault" '.facts.fault=$fault' >> "$receipts"
 )
done
jq -sc '{case:"t2.jf1.pc.05",status:"pass",checks:["failure.protected-no-admission","crash.process-reconciliation","failure.no-fabricated-end","owned.exact-death-sentinel"],provenance:{runtime:"synthetic-ACP",terminal:"actual-tmux-scripted",authenticated_cursor:false,human_terminal:false},facts:{runs:map(.facts)}}' "$receipts"
rm -f "$receipts"
```
