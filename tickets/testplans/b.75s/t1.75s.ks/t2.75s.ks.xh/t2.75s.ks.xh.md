# kill-4: a second kill finds the session gone and succeeds with nothing sent

Per SRD §5 + Epic 5 t2.31 ticket, revised by SRD SR-20.9 and SR-6.1
(Epic `t1.h98.aq`, the honest kill). `kill` does NOT change the row's
state (`find-missing` reconciles that out-of-band, Epic 8), so the row
is still `waiting` after the first kill and a second call on the same
id reaches tmux again. The first kill finds the row's labelled session,
kills its pane and session and returns 0 with `kill_sent` true. The
second kill's lookup finds no session carrying the row's label (Gone)
and the row's recorded pane process is gone, so it returns 0 with
`kill_sent` false: nothing was sent, and nothing failed.

The seeding is kill-1's: a hand-made `cd-k4` session with
`-e AGENT_DIRECTOR_INSTANCE_ID`, labelled
`ad1 <row's launch token> <$N> id-k4 <this store's id>`, its pane
labelled `@ad_pane` `<token> <%N>`. An unlabelled bystander session
`cd-by-k4` (no prefix neighbour of `cd-k4`, so the name check
`has-session -t cd-k4` cannot match it) keeps the tmux server running
between the two kills, so the second lookup reads the same server with
no labelled session rather than a server that is still shutting down.

## Setup

Per-case DB-reset. An EXIT trap removes both sessions by their session
ids if the case fails part-way.

## Steps

1. Read this store's id with `sqlite3` from `store_meta` (`key =
   'store_id'`).
2. `tmux new-session -d -s cd-by-k4 -- cat` (the bystander), then
   `tmux new-session -d -s cd-k4 -e AGENT_DIRECTOR_INSTANCE_ID=id-k4 --
   cat`, capturing `cd-k4`'s session id `$N`, pane id `%N` and pane pid.
3. Seed a `spawns` row `id-k4` at state `waiting`, session name `cd-k4`,
   with a 16-lowercase-hex `launch_token`; read the token back with
   `sqlite3`.
4. Set `@ad_owner` `ad1 <token> <$N> id-k4 <store id>` on `'<$N>'` and
   `@ad_pane` `<token> <%N>` on `'<%N>'`; read the label back.
5. First `kill` → exit 0, `kill_sent` true; the session (by `$N`) is
   gone.
6. Second `kill` against the same id → exit 0, `kill_sent` false.

## Pass criteria

- The label read back has five fields and equals the one set.
- Both kills exit 0; the first has `kill_sent == true`, the second
  `kill_sent == false`.
- `tmux has-session -t '<$N>'` and `tmux has-session -t cd-k4` return
  non-zero after the first kill; the bystander (by its `$N`) still runs.
- The row is still `waiting` after both kills.

## Script

```bash
set -euo pipefail
db="$HOME/.agent-director/state.db"
fail() { echo "FAIL: $*"; exit 1; }
sid=""
by_sid=""
cleanup() {
    [ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true
    [ -z "$by_sid" ] || tmux kill-session -t "$by_sid" 2>/dev/null || true
}
trap cleanup EXIT

store_id="$(/opt/driver/sql.sh "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

by_sid="$(tmux new-session -d -s cd-by-k4 -P -F '#{session_id}' -- cat)"
read -r sid pane cat_pid < <(tmux new-session -d -s cd-k4 -e AGENT_DIRECTOR_INSTANCE_ID=id-k4 \
    -P -F '#{session_id} #{pane_id} #{pane_pid}' -- cat)
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"

seed_token="$(od -An -N8 -tx1 /dev/urandom | tr -d ' 
')"
/opt/driver/sql.sh "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, launch_token)
   VALUES ('id-k4', 'waiting', '/tmp', 'cd-k4', 'off', '$seed_token');"
token="$(/opt/driver/sql.sh "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-k4';")"
[[ "$token" =~ ^[0-9a-f]{16}$ ]] || fail "launch_token is not 16 lowercase hex: [$token]"

label="ad1 $token $sid id-k4 $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
tmux set-option -p -t "$pane" @ad_pane "$token $pane"
got_label="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$got_label" = "$label" ] || fail "label read back [$got_label]; want [$label]"
read -r -a fields <<<"$got_label"
[ "${#fields[@]}" -eq 5 ] || fail "label has ${#fields[@]} fields; want 5: [$got_label]"

out="$(agent-director kill --claude-instance-id id-k4)" || fail "first kill exited non-zero; want 0"
sent="$(jq -r '.kill_sent' <<<"$out")"
[ "$sent" = "true" ] || fail "first kill kill_sent=$sent; want true (stdout: $out)"
if tmux has-session -t "$sid" 2>/dev/null; then
    fail "session $sid (cd-k4) not gone after first kill"
fi
if tmux has-session -t cd-k4 2>/dev/null; then
    echo "FAIL: session not gone after first kill"; exit 1
fi
tmux has-session -t "$by_sid" 2>/dev/null || fail "bystander $by_sid (cd-by-k4) no longer runs"

out="$(agent-director kill --claude-instance-id id-k4)" || fail "second kill exited non-zero; want 0"
sent="$(jq -r '.kill_sent' <<<"$out")"
[ "$sent" = "false" ] || fail "second kill kill_sent=$sent; want false (stdout: $out)"

state="$(/opt/driver/sql.sh "$db" "SELECT state FROM spawns WHERE claude_instance_id = 'id-k4';")"
[ "$state" = "waiting" ] || fail "row state=$state after both kills; want waiting"

echo "kill-4 ok: first kill kill_sent true, session $sid gone; second kill finds it gone, exit 0 with kill_sent false; row still waiting"
```
