# agent-20: the relay's fail-closed timeout on a codex row

Maps to SRD SR-8.4 and SR-14.5 of Epic 13 (`b.ssz`), and to b.146 rule 4 as
`relay-8` pins it for Claude. With `[relay] timeout_seconds` = 5 and no
`decide`, a relayed Codex `PermissionRequest` gives up 3 seconds before its
kill instant (a 2 s reserve to write an answer after its ack, plus 1 s for
the timeout deny's own lock wait): the hook prints a deny envelope after
about 2 seconds, and the request reads `decision` `deny`, `decision_reason`
`timeout`. The window is also the one the launch handed Codex: the
`PermissionRequest` entry of the stand-in's recorded argv carries
`--timeout 5` in its command and `timeout=5` in its entry, so Codex would
end the hook at the same instant (the stand-in does not enforce it).

Agent and hooks (collector "Driver mode"): the pane process is the Codex
stand-in `/opt/driver/stand-in-codex/codex`, named by `[launch] codex_path`;
every hook is typed into its pane with `/opt/driver/pane-hook.sh --agent
codex` (the blocking `PermissionRequest` with `--no-wait` and `--wait`),
with no `--timeout`, so the hook takes its kill instant from the configured
window.

## Setup

Per-case DB-reset. The case writes `~/.config/agent-director/config.toml`
with `[launch]` `codex_path = "/opt/driver/stand-in-codex/codex"` and
`[relay]` `timeout_seconds = 5` (the hook in the pane reads it from the same
HOME), makes a cwd and a temporary Codex folder holding the one rollout file
the payloads name, and removes them, the stand-in's record directory and the
config on exit (an EXIT trap, so later cases see the default even when this
case fails early).

## Steps

1. Write the config; make the cwd and the Codex folder with its rollout.
2. `agent-director spawn --agent codex --cwd <cwd> --instance-id <id>
   --tmux-session-name cd-ag-to --relay-mode on --extra-env
   CODEX_HOME=<folder>`; type a `SessionStart`; the row is `waiting`. Read
   the stand-in's recorded argv.
3. Type a `PermissionRequest` (tool `Bash`) with `pane-hook.sh --agent codex
   --no-wait`; note the time.
4. Do not call `decide`. `pane-hook.sh --wait` the hook (bound 15 s).
5. `get-permission`.

## Pass criteria

- Step 2: in the recorded argv, the `-c` value that starts `hooks.PermissionRequest=`
  holds one `hook --agent codex --timeout 5` command and `timeout=5`.
- Step 4: the hook exits 0, from 2 s to 5 s after it was typed, with a JSON
  envelope on stdout whose `hookSpecificOutput.decision.behavior` is `deny`.
- Step 5: `decision` `deny` and `decision_reason` `timeout`, and the row's
  state is still `check_permission` (nothing moved it).

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN CODEX_HOME

db="$HOME/.config/agent-director/state.db"
config="$HOME/.config/agent-director/config.toml"
standin="/opt/driver/stand-in-codex/codex"
rec_root="/tmp/stand-in-codex"
uuid="$(cat /proc/sys/kernel/random/uuid)"
id="ag-to-$uuid"
sid="$(cat /proc/sys/kernel/random/uuid)"
codex_home=""
cwd=""
rollout=""
fail() { echo "FAIL: $*"; exit 1; }

col() { /opt/driver/sql.sh -readonly "$db" "SELECT $1 FROM spawns WHERE instance_id = '$id';"; }

# Reset config on any exit so later cases see the default.
cleanup() {
    local row sock pane s
    row="$(col "IFNULL(tmux_socket,'') || '|' || IFNULL(pane_id,'')" 2>/dev/null || true)"
    sock="${row%%|*}"
    pane="${row#*|}"
    if [ -n "$pane" ]; then
        s="$(tmux ${sock:+-S "$sock"} display-message -p -t "$pane" '#{session_id}' 2>/dev/null || true)"
        [ -z "$s" ] || tmux ${sock:+-S "$sock"} kill-session -t "$s" 2>/dev/null || true
    fi
    rm -f "$config"
    rm -rf "$rec_root/$id" ${codex_home:+"$codex_home"} ${cwd:+"$cwd"}
    rmdir "$rec_root" 2>/dev/null || true
}
trap cleanup EXIT

# wait_state WANT: the row's state (get) is WANT within 10 s.
wait_state() {
    local want="$1" end got=""
    end=$(( $(date +%s) + 10 ))
    while :; do
        got="$(agent-director get --instance-id "$id" | jq -r '.state')"
        [ "$got" != "$want" ] || return 0
        [ "$(date +%s)" -lt "$end" ] || fail "row $id state is [$got]; want [$want] within 10 s"
        sleep 0.2
    done
}

# fire EVENT [EXTRA_JSON]: type the Codex hook EVENT into the row's pane; the
# hook must exit 0 and print nothing.
fire() {
    local extra='{}' body out
    [ $# -lt 2 ] || extra="$2"
    body="$(jq -cn --arg e "$1" --arg sid "$sid" --arg tp "$rollout" --arg cwd "$cwd" --argjson x "$extra" \
        '{hook_event_name: $e, session_id: $sid, transcript_path: $tp, cwd: $cwd, model: "codex-stand-in", permission_mode: "default"} + $x')"
    out="$(/opt/driver/pane-hook.sh --agent codex "$id" "$body")" || fail "the $1 hook exited non-zero"
    [ -z "$out" ] || fail "the $1 hook printed [$out]; want nothing"
}

# Step 1: the config with the short window, the cwd, and a Codex folder with the rollout.
[ -x "$standin" ] || fail "$standin is not an executable file"
mkdir -p "$HOME/.config/agent-director"
printf '[launch]\ncodex_path = "%s"\n\n[relay]\ntimeout_seconds = 5\n' "$standin" > "$config"
cwd="$(mktemp -d /tmp/ag-to-XXXXXX)"
cwd="$(cd -P "$cwd" && pwd)"
codex_home="$(mktemp -d)"
rollout="$codex_home/sessions/2026/10/12/rollout-2026-10-12T10-00-00-$sid.jsonl"
mkdir -p "$(dirname "$rollout")"
printf '{"type":"session_meta"}\n' > "$rollout"

# Step 2: a waiting codex row with the relay on; the window Codex was given.
out="$(agent-director spawn --agent codex --cwd "$cwd" --instance-id "$id" --tmux-session-name cd-ag-to \
    --relay-mode on --extra-env "CODEX_HOME=$codex_home")" || fail "spawn exited non-zero"
[ "$(jq -r '.instance_id' <<<"$out")" = "$id" ] || fail "spawn echoed [$out]; want id $id"
end=$(( $(date +%s%N) + 10000000000 ))
until [ -s "$rec_root/$id/pid" ]; do
    [ "$(date +%s%N)" -lt "$end" ] || fail "no stand-in record at $rec_root/$id within 10 s"
    sleep 0.1
done
mapfile -d '' -t argv < "$rec_root/$id/argv"
entry=""
hits=0
for ((i = 0; i + 1 < ${#argv[@]}; i++)); do
    if [ "${argv[$i]}" = "-c" ] && [[ "${argv[$((i + 1))]}" == "hooks.PermissionRequest="* ]]; then
        entry="${argv[$((i + 1))]}"
        hits=$((hits + 1))
    fi
done
[ "$hits" -eq 1 ] || fail "$hits -c values start with hooks.PermissionRequest=; want 1"
[ "$(grep -o 'hook --agent codex --timeout 5"' <<<"$entry" | wc -l)" -eq 1 ] || fail "the PermissionRequest entry has no 'hook --agent codex --timeout 5' command: $entry"
[ "$(grep -o 'timeout=5\b' <<<"$entry" | wc -l)" -eq 1 ] || fail "the PermissionRequest entry has no timeout=5: $entry"
fire SessionStart '{"source":"startup"}'
wait_state waiting

# Step 3 and 4: the PermissionRequest nobody decides, timed from its typing to its exit.
req="$(jq -cn --arg sid "$sid" --arg tp "$rollout" --arg cwd "$cwd" \
    '{hook_event_name: "PermissionRequest", session_id: $sid, transcript_path: $tp, cwd: $cwd, model: "codex-stand-in", permission_mode: "default", turn_id: "turn-1", tool_name: "Bash", tool_input: {command: "ls", description: "list"}}')"
hook_out="$(mktemp)"
start=$(date +%s)
job="$(/opt/driver/pane-hook.sh --agent codex --no-wait "$id" "$req")"
# --wait exits with the hook's exit status: the call fails unless it is 0.
/opt/driver/pane-hook.sh --timeout 15 --wait "$job" >"$hook_out" || fail "the relay hook exited non-zero or never ended within 15 s"
elapsed=$(( $(date +%s) - start ))
[ "$elapsed" -ge 2 ] && [ "$elapsed" -le 5 ] || fail "the hook ended after ${elapsed}s; want 2 to 5 s"
behavior="$(jq -r '.hookSpecificOutput.decision.behavior' "$hook_out")"
[ "$behavior" = "deny" ] || fail "behavior=[$behavior]; want deny (fail-closed): $(cat "$hook_out")"
rm -f "$hook_out"

# Step 5: the stored verdict.
token="$(/opt/driver/sql.sh -readonly "$db" "SELECT request_token FROM permission_requests WHERE instance_id = '$id' ORDER BY request_id DESC LIMIT 1;")"
[ -n "$token" ] || fail "no permission request recorded for $id"
perm="$(agent-director get-permission --request-token "$token")"
got="$(jq -r '[.decision, .decision_reason] | join("|")' <<<"$perm")"
[ "$got" = "deny|timeout" ] || fail "request reads [$got]; want deny|timeout: $perm"
[ "$(agent-director get --instance-id "$id" | jq -r '.state')" = "check_permission" ] || fail "state is [$(agent-director get --instance-id "$id" | jq -r '.state')]; want check_permission"

echo "agent-20 ok: undecided Codex PermissionRequest -> deny envelope after ${elapsed}s (window 5 s, also on Codex's entry), decision_reason timeout"
```
