# Test case: Literal terminal turns and independent report authority

Maps to E1 AC2/3/5/7; SR-0.1, SR-4.2, SR-9.1 and Task2 t3.jf1.3e.d6.k2.

## Setup

The Docker driver reset provides a clean baseline. Source the shared Cursor collector helper from the exact revision source mount. It creates a new protected HOME, explicitly routed store, short private tmux namespace, unique id and synthetic Node ACP peer using the existing cursorfix/runtime.js. No Cursor login or real AD store is accessed. Requires Linux, Node, Bun, tmux, jq and procfs.

## Steps

1. Launch to waiting and save the complete current row tuple.
2. Submit a controller hook claiming the exact current connection/session and require no mutation.
3. Send a literal multiline Unicode turn and compare the received ACP prompt and protected transcript.
4. Read the real pane response and pause only after runtime-gone proof.

Each predicate is exact in the executable block. These actions use the shipped CLI, real tmux and a synthetic protocol peer.

## Pass criteria

Every shell/JSON/SQL assertion in the block passes, followed by the one deterministic evidence JSON object with this case id and authenticated_cursor=false. This does not satisfy the separate authenticated operator acceptance. Record the exact source/binary SHA and Node/Bun/tmux/kernel versions in the scheduler receipt.

```bash
set -euo pipefail
source /work/source/test/driver/cursor-owned-launch.sh
spawn_cursor
wait_state waiting
load_identity
snapshot=$(sql "SELECT row_version||'|'||state||'|'||session_id||'|'||jsonl_path FROM spawns WHERE instance_id='$id';")
connection=$(sql "SELECT bound_connection_id FROM cursor_runtimes WHERE bound_instance_id='$id';")
transcript=$(sql "SELECT jsonl_path FROM spawns WHERE instance_id='$id';")
jq -cn --arg sid "$session" --arg conn "$connection" --arg path "$transcript" '{hook_event_name:"UserPromptSubmit",origin:"main",session_id:$sid,cursor_connection:$conn,transcript_path:$path}' > "$case_dir/claim"
AGENT_DIRECTOR_INSTANCE_ID="$id" AGENT_DIRECTOR_AGENT=cursor AGENT_DIRECTOR_CURSOR_STORE_PATH="$STORE" agent-director hook --agent cursor < "$case_dir/claim" >/dev/null
[[ $(sql "SELECT row_version||'|'||state||'|'||session_id||'|'||jsonl_path FROM spawns WHERE instance_id='$id';") == "$snapshot" ]]
prompt=$'literal 多行\nsecond 🦋'
ad send-keys --instance-id "$id" --text "$prompt" >/dev/null
deadline=$((SECONDS+15))
until frames | jq -se --arg p "$prompt" 'any(.[];.method=="session/prompt" and .params.prompt[0].text==$p)' >/dev/null; do (( SECONDS < deadline )); sleep 0.05; done
wait_state waiting
ad read-pane --instance-id "$id" --n-lines 100 | jq -e '.pane|contains("Synthetic reply:")' >/dev/null
jq -se --arg p "$prompt" '[.[]|select(.kind=="user_input")|.data.text]==[$p]' "$transcript" >/dev/null
[[ $(stat -c %a "$transcript") == 600 ]]
ad pause --instance-id "$id" >/dev/null
wait_state ended
wait_gone "$runtime"
jq -se 'any(.[];.kind=="session_end" and .data.runtime_gone==true)' "$transcript" >/dev/null
evidence t2.jf1.cl.02 'literal-turn,read-pane,controller-refused,protected-order,proved-runtime-gone'
```
