# recov-8: expire keeps a finished row whose own session runs, and deletes one with no session

Maps to Epic 8 AC #2, as changed by Epic 15 of plan b.h98 (Task
`t2.h98.fz.5i`; SRD SR-12.2 to SR-12.4, SR-3.4, SR-3.5, SR-5.1, SR-20.9).
`expire` no longer deletes a finished row on age alone. For each selected
`ended`/`missing` row it first checks the row's agent process; a row with no
recorded process identity goes on to one tmux lookup. Only Gone leads to the
delete. A session that carries the row's current label is the row's own
(Ours), so `expire` keeps the row with reason `ours` and lists it in
`kept_ids`, however long ago the row ended. A row whose recorded name no
session holds is Gone and is deleted. The next run, once the row's session
has ended, deletes the formerly kept row.

The label is the session option `@ad_owner` = `ad1 <launch token> <session
id $N> <instance id> <store id>` (SR-3.5). The store id is this store's
`store_meta.store_id` (SR-5.1), 16 lowercase hex characters, created by the
DB-reset fixture's `agent-director list`. A label naming another store's id
would be another store's session, which is Gone for the row, so the case
reads the store id back from this store and never hard-codes it. `expire`
lists no panes, so no `@ad_pane` tag is set.

## Setup

Per-case DB-reset has wiped `~/.agent-director/state.db` (and re-created it,
`store_meta` included) and ended every tmux server. The container
has `agent-director`, `tmux`, `sqlite3` and `jq` on PATH; plain `tmux`
reaches the same default socket agent-director resolves. No agent is
spawned and no `claude` runs. No hook payload is sent.

The instance ids are `rc8k-<uuid>` (K, kept) and `rc8d-<uuid>` (D, deleted),
and the recorded names are `cd-rc8k-<n>` and `cd-rc8d-<n>` for one random
`<n>` per run. The trail is not reset between cases, so records are
selected by these ids. The seed first deletes any `rc8*` rows an earlier run
of this case left, and the script kills the session it made on exit, so the
harness's `bash -x` re-run of a failed case starts from the same state.

## Steps

1. Read this store's id: `SELECT value FROM store_meta WHERE key =
   'store_id'`; it must be 16 lowercase hex characters.
2. Delete any `rc8*` rows an earlier run left. Seed two `ended` rows with
   `sqlite3`, each with an `ended_at` one hour in the past and no `pid`,
   `proc_starttime`, `tmux_socket`, server identity or pane:
   - K: name `cd-rc8k-<n>`, a 16-lowercase-hex `launch_token`;
   - D: name `cd-rc8d-<n>`, no token.
3. Create a session `cd-rc8k-<n>` running `sleep 3600` and read its `$N`.
   Read K's token back with `sqlite3` and label the session by `$N` with
   `ad1 <token> <$N> <K> <store id>`; read the label back (five fields).
   Check no session holds `cd-rc8d-<n>`.
4. `agent-director expire --older-than 0d`.
5. Read the store, the session and the trail.
6. End the case's session by its `$N`, then run `agent-director expire
   --older-than 0d` again.

## Pass criteria

- Step 1: the store id is 16 lowercase hex characters (else the case
  fails in Setup, not as a wrong `expire` result).
- Step 3: the label read back equals the one set and has five fields.
- Step 4: exit 0; `count == 1`; `ids == [D]`; `kept == 1`;
  `kept_ids == [K]` (compact JSON arrays).
- Step 5:
  - D is gone from the store; K is still present with `state = 'ended'`;
  - the session `$N` still runs, still named `cd-rc8k-<n>`;
  - exactly one `ad.expire.kept` record for K, with `reason == "ours"`,
    `source == "ad_expire"` and `tmux_session_name == "cd-rc8k-<n>"`;
    none for D.
- Step 6: exit 0; `count == 1`; `ids == [K]`; `kept == 0`;
  `kept_ids == []`; K is gone from the store; still exactly one
  `ad.expire.kept` record for K. (Ending the only session may stop the
  tmux server; "no server running" still reads Gone for a row with no
  recorded server.)

## Script

```bash
set -euo pipefail

db="$HOME/.agent-director/state.db"
trail="$HOME/.agent-director/ad-trail.jsonl"
k="rc8k-$(cat /proc/sys/kernel/random/uuid)"
d="rc8d-$(cat /proc/sys/kernel/random/uuid)"
n="$(cat /proc/sys/kernel/random/uuid | cut -c1-8)"
name_k="cd-rc8k-$n"
name_d="cd-rc8d-$n"

fail() {
    echo "FAIL: $*" >&2
    exit 1
}

# The session this run makes is killed on exit, pass or fail.
sid=""
cleanup() {
    if [ -n "$sid" ]; then
        tmux kill-session -t "$sid" 2>/dev/null || true
    fi
}
trap cleanup EXIT

# Step 1: this store's id, created by the fixture's agent-director list.
store_id="$(/opt/driver/sql.sh "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] \
    || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

# Step 2: idempotent seed of two ended rows with no process identity, no
# socket and no pane; K carries a launch token, D none.
seed_token="$(od -An -N8 -tx1 /dev/urandom | tr -dc '0-9a-f')"
/opt/driver/sql.sh "$db" "DELETE FROM spawns WHERE claude_instance_id LIKE 'rc8%';"
/opt/driver/sql.sh "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name,
       relay_mode, launch_token, ended_at)
   VALUES ('$k', 'ended', '/tmp', '$name_k', 'off', '$seed_token', datetime('now', '-1 hour')),
          ('$d', 'ended', '/tmp', '$name_d', 'off', NULL,          datetime('now', '-1 hour'));"
token="$(/opt/driver/sql.sh "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = '$k';")"
[[ "$token" =~ ^[0-9a-f]{16}$ ]] || fail "launch_token is not 16 lowercase hex: [$token]"

# Step 3: K's own session, labelled by its $N with the five-field label.
sid="$(tmux new-session -d -s "$name_k" -P -F '#{session_id}' -- sleep 3600)"
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"
label="ad1 $token $sid $k $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
got="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$got" = "$label" ] || fail "label read back [$got]; want [$label]"
read -r -a fields <<<"$got"
[ "${#fields[@]}" -eq 5 ] || fail "label has ${#fields[@]} fields; want 5: [$got]"
if tmux has-session -t "=$name_d" 2>/dev/null; then
    fail "a session already holds $name_d"
fi

# Step 4: first expire run.
res="$(agent-director expire --older-than 0d)" || fail "expire exited non-zero: $res"
got="$(printf '%s' "$res" | jq -c '[.count, .ids, .kept, .kept_ids]')"
want="$(jq -cn --arg k "$k" --arg d "$d" '[1, [$d], 1, [$k]]')"
[ "$got" = "$want" ] \
    || fail "expire [count, ids, kept, kept_ids] = $got; want $want (res=$res)"

# Step 5: store, session and trail.
got="$(/opt/driver/sql.sh "$db" "SELECT COUNT(*) FROM spawns WHERE claude_instance_id = '$d';")"
[ "$got" = "0" ] || fail "session-less row $d survived expire"
got="$(/opt/driver/sql.sh "$db" "SELECT state FROM spawns WHERE claude_instance_id = '$k';")"
[ "$got" = "ended" ] || fail "kept row $k state=[$got]; want [ended]"
tmux has-session -t "$sid" 2>/dev/null || fail "session $sid no longer runs after expire"
got="$(tmux display-message -p -t "$sid" '#{session_name}')"
[ "$got" = "$name_k" ] || fail "session $sid is named [$got]; want [$name_k]"

[ -f "$trail" ] || fail "no trail file at $trail"
# kept_records ID: the ad.expire.kept records for ID, one compact JSON per line.
kept_records() {
    jq -c --arg x "$1" \
        'select(.event == "ad.expire.kept" and .claude_instance_id == $x)' "$trail"
}
recs="$(kept_records "$k")"
cnt="$(printf '%s' "$recs" | grep -c . || true)"
[ "$cnt" -eq 1 ] || fail "want 1 ad.expire.kept for $k, got $cnt: $recs"
got="$(printf '%s' "$recs" | jq -r '[.reason, .source, .tmux_session_name] | join("|")')"
[ "$got" = "ours|ad_expire|$name_k" ] \
    || fail "ad.expire.kept for $k: [$got]; want [ours|ad_expire|$name_k]: $recs"
recs="$(kept_records "$d")"
[ -z "$recs" ] || fail "unexpected ad.expire.kept for $d: $recs"

# Step 6: once K's session has ended, the next run deletes K.
tmux kill-session -t "$sid"
if tmux has-session -t "$sid" 2>/dev/null; then
    fail "session $sid still runs after kill-session"
fi
sid=""
res="$(agent-director expire --older-than 0d)" || fail "second expire exited non-zero: $res"
got="$(printf '%s' "$res" | jq -c '[.count, .ids, .kept, .kept_ids]')"
want="$(jq -cn --arg k "$k" '[1, [$k], 0, []]')"
[ "$got" = "$want" ] \
    || fail "second expire [count, ids, kept, kept_ids] = $got; want $want (res=$res)"
got="$(/opt/driver/sql.sh "$db" "SELECT COUNT(*) FROM spawns WHERE claude_instance_id = '$k';")"
[ "$got" = "0" ] || fail "row $k survived the second expire"
recs="$(kept_records "$k")"
cnt="$(printf '%s' "$recs" | grep -c . || true)"
[ "$cnt" -eq 1 ] || fail "second expire wrote another ad.expire.kept for $k: $recs"

echo "recov-8 ok: expire 0d kept $k (own labelled session up, reason ours) and deleted session-less $d; after the session ended the next run deleted $k"
```
