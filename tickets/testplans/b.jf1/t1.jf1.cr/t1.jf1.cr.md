# E2 — cursor-relay testplan

Ordered shell collector for E2 AC1–8 and SR-4.1/4.2, SR-5.1–5.3, SR-9.1/9.2. Run only through the operator scheduler at the pinned full source SHA, matching shipped binary and source mount: `make test-docker EPIC=cursor-relay DRIVER_MODE=shell`.

All ten cases use the existing shared cursor-owned-launch driver, shared cursorfix runtime and sanitized captures. They require Linux procfs, Node, Bun, tmux, jq and the harness toolchain. Each isolated subscenario gets a unique HOME, explicit override store, config, transcript, cwd, socket, runtime and control sentinel; cleanup addresses that socket and direct owned helpers only. Every SQL read/write/fault/observer uses /opt/driver/sql.sh, including independent first-byte observations. No real AD store or credentials are mounted.

Captured envelope provenance is separate from the synthetic peer. Unobserved approval kinds are explicitly synthetic. Question methods/signatures are installed-source-derived with synthetic values. No authenticated Cursor, live question-denial, loaded-session, group-policy or macOS acceptance is claimed. Runtime cancellation is observed through actual session/cancel and independent process death, never inferred from screen text. Pane text/hash is used only for human-choice and refusal assertions, never AD state classification.

Stable check IDs are separate from variable run facts in each JSON receipt. External acceptance must retain every raw case transcript, exact SHA and CLI build stamp, source/input hashes, image digest, kernel/architecture and Node/Bun/tmux versions. Case authoring and syntax checks are not an execution pass. The separately owned controller/API unit tests retain detailed stale-identity, race, migration, malformed-question, delayed-lock and proof matrices; this shipped-artifact collector is representative, not their Cartesian product.
