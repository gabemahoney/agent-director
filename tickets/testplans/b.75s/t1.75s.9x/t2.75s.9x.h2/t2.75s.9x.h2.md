# interact-5: read-pane default strips ANSI but preserves unicode

Per Epic 4 testplan + `reference/pane-output-research.md`: default
`read-pane` returns ANSI-free pane bytes (SGR colors / cursor moves
gone) while leaving unicode TUI glyphs (`❯`, `⎿`, `🐝`, box-drawing)
intact. The orchestrator reads glyphs as state signal; ASCII-mapping
them would destroy that.

Revised by Epic 11 (`t1.h98.m6`, Task `t2.h98.m6.ki`; SR-3.4, SR-3.6,
SR-7.2, SR-20.9): `read-pane` finds the row's session only by its
`@ad_owner` label (one lookup, one pane listing) and captures the
agent's pane by pane id, never `name:0.0`. The session is seeded like
kill-1 (`t2.75s.ks.3h`): the row has a launch token and records no
socket, server, pid or pane; the session carries the five-field label
`ad1 <token> <$N> id-i5 <store id>`. This case also proves the capture
is by pane id: the session's window 0 pane 0 is a decoy `cat` pane
holding the line `DECOY-i5` and no `@ad_pane`; the agent's pane is a
second pane (split off it) running `bash`, and only that pane carries
`@ad_pane` `<token> <%N>`. `read-pane` finds it through that `@ad_pane`
(the row records no pane), returns its text and not the decoy's, and
writes nothing (`row_version` and `pane_id` unchanged).

## Setup

Per-case DB-reset. Use `printf` in the agent's `bash` pane to emit a
controlled mix of ANSI escapes and unicode glyphs. An EXIT trap removes
the session by its session id if the case fails part-way.

## Steps

1. Read this store's id from `store_meta` with `sqlite3`.
2. `tmux new-session -d -s cd-i5 -e AGENT_DIRECTOR_INSTANCE_ID=id-i5 --
   cat` (the decoy, window 0 pane 0), capturing `$N` and the decoy's
   pane id; type `DECOY-i5` into the decoy by its pane id.
3. `tmux split-window -d -t '<$N>' -- bash`, capturing the agent pane's
   id `%N`.
4. Seed a `spawns` row `id-i5` at state `waiting` with a 16-hex
   `launch_token`; read the token back with `sqlite3`.
5. Set the five-field `@ad_owner` label on `$N` and `@ad_pane`
   `<token> <%N>` on the agent's pane only; read the label back.
6. Type (by the agent pane's id) a printf line that emits SGR + glyph
   to the pane's stdout; wait, bounded, until `tmux capture-pane -p -t
   '<%N>'` shows ` hi`.
7. `read-pane` (default), with `row_version` and `pane_id` read before
   and after.

## Pass criteria

- The store id and token are 16 lowercase hex; the label read back has
  five fields and equals the one set.
- The decoy pane (captured by its pane id) holds `DECOY-i5`.
- read-pane exit 0; the captured pane contains the unicode prompt
  glyph and not `DECOY-i5` (it read the agent's pane, not `name:0.0`).
- Captured pane does not contain `\x1b[`.
- read-pane leaves `row_version` and `pane_id` unchanged.

## Script

```bash
set -euo pipefail
db="$HOME/.agent-director/state.db"
fail() { echo "FAIL: $*"; exit 1; }
sid=""
trap '[ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true' EXIT

store_id="$(sqlite3 "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

read -r sid decoy < <(tmux new-session -d -s cd-i5 -e AGENT_DIRECTOR_INSTANCE_ID=id-i5 \
    -P -F '#{session_id} #{pane_id}' -- cat)
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"
[[ "$decoy" =~ ^%[0-9]+$ ]] || fail "new-session gave pane id [$decoy]"
tmux send-keys -t "$decoy" -l 'DECOY-i5'
tmux send-keys -t "$decoy" Enter
pane="$(tmux split-window -d -t "$sid" -P -F '#{pane_id}' -- bash)"
[[ "$pane" =~ ^%[0-9]+$ ]] || fail "split-window gave pane id [$pane]"
[ "$pane" != "$decoy" ] || fail "agent pane equals decoy pane $pane"

seed_token="$(od -An -N8 -tx1 /dev/urandom | tr -dc '0-9a-f')"
sqlite3 "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, launch_token)
   VALUES ('id-i5', 'waiting', '/tmp', 'cd-i5', 'off', '$seed_token');"
token="$(sqlite3 "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-i5';")"
[[ "$token" =~ ^[0-9a-f]{16}$ ]] || fail "launch_token is not 16 lowercase hex: [$token]"

label="ad1 $token $sid id-i5 $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
tmux set-option -p -t "$pane" @ad_pane "$token $pane"
got_label="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$got_label" = "$label" ] || fail "label read back [$got_label]; want [$label]"
read -r -a fields <<<"$got_label"
[ "${#fields[@]}" -eq 5 ] || fail "label has ${#fields[@]} fields; want 5: [$got_label]"

# Type, by the agent pane's id, a printf that emits a red ❯ glyph and " hi".
tmux send-keys -t "$pane" -l 'printf "\033[31m\xe2\x9d\xaf\033[0m hi"; echo'
tmux send-keys -t "$pane" Enter
for _ in $(seq 1 50); do
    tmux capture-pane -p -t "$pane" | grep -q '❯ hi' && break
    sleep 0.1
done
tmux capture-pane -p -t "$pane" | grep -q '❯ hi' || fail "printf output never reached pane $pane"
tmux capture-pane -p -t "$decoy" | grep -q 'DECOY-i5' || fail "decoy pane $decoy does not hold DECOY-i5"

row_q="SELECT row_version || '|' || COALESCE(pane_id, '') FROM spawns WHERE claude_instance_id = 'id-i5';"
before="$(sqlite3 "$db" "$row_q")"
rp="$(agent-director read-pane --claude-instance-id id-i5 --n-lines 50)" || fail "read-pane exited non-zero"
after="$(sqlite3 "$db" "$row_q")"
[ "$before" = "$after" ] || fail "read-pane changed the row: row_version|pane_id [$before] -> [$after]"

pane_text="$(jq -r '.pane' <<<"$rp")"
# Glyph must survive.
echo "$pane_text" | grep -q "❯" || fail "glyph missing from read-pane output: [$pane_text]"
# It read the agent's pane by id, not window 0 pane 0 (the decoy).
if echo "$pane_text" | grep -q 'DECOY-i5'; then
    fail "read-pane returned the decoy pane $decoy (name:0.0), not the agent's pane $pane"
fi
# Escape codes must be stripped.
if echo "$pane_text" | grep -q $'\x1b\['; then
    fail "ANSI escape leaked into default read-pane output"
fi
echo "interact-5 ok: ANSI stripped, ❯ preserved; agent pane $pane read by id, decoy $decoy not read; row unchanged ($after)"
```
