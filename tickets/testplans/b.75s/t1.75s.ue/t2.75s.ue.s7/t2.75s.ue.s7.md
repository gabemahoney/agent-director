# resume-2: resume from missing works the same as from ended

Maps to Epic 9 AC #2. A row marked `missing` by find-missing (because
the operator killed it externally) resumes via the same verb with
the same outcome. Epic 8 (`t1.h98.xw`, SR-20.9, SR-22.9): a hook moves
the row only when it comes from the row's own pane process, so the
SessionStart is typed into the pane.

## Setup

Per-case DB-reset. Both spawns and the resume run with
`PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the
`agent-director` command, so each pane process is the stand-in claude's
interactive bash (it inherits the session's `AGENT_DIRECTOR_INSTANCE_ID`,
which the environ probe sees). The hook is typed into the row's pane
with `/opt/driver/pane-hook.sh <id> '<payload>'` (see the collector's
"Driver mode").

## Steps

1. Spawn a survivor, then `spawn --cwd /tmp` → id, session name.
2. Type a SessionStart hook into the row's pane → claude_session_id
   populated; state=waiting; the row records its pane process as `pid`.
3. Seed JSONL on disk at the resolved path.
4. Externally kill the tmux session.
5. Wait for the pane process to exit (its env disappears from /proc).
6. `find-missing` → row transitions to `missing`.
7. Verify row state is `missing`.
8. `resume` → exits 0.
9. New tmux session exists under the canonical name.

## Pass criteria

- find-missing transitions the row to missing.
- resume succeeds; new tmux session up.

## Script

```bash
set -euo pipefail
standin_path="/opt/driver/stand-in-claude:$PATH"

# Helper: poll /proc for the env-var marker matching `id`.
proc_has() {
    local id="$1"
    for pid in $(ls /proc 2>/dev/null | grep -E '^[0-9]+$'); do
        if [ -r "/proc/$pid/environ" ] && \
            grep -aqz "AGENT_DIRECTOR_INSTANCE_ID=$id" "/proc/$pid/environ" 2>/dev/null; then
            return 0
        fi
    done
    return 1
}

# Spawn a sentinel survivor too — find-missing's degraded-mode guard
# refuses to write when the probe set is empty, so we need at least
# one live pane process visible during the find-missing call.
survivor=$(PATH="$standin_path" agent-director spawn --cwd /tmp | jq -r '.claude_instance_id')
test -n "$survivor"

id=$(PATH="$standin_path" agent-director spawn --cwd /tmp | jq -r '.claude_instance_id')
test -n "$id"
sess=$(agent-director get --claude-instance-id "$id" | jq -r '.tmux_session_name')

session_id="r2-session-uuid"
# transcript_path is the real on-disk path; the hook persists it as the
# row's jsonl_path, which resume Stats pre-flight (b.93m). Typed into the
# row's pane: SR-22.9 applies a hook only from the recorded pane process.
jsonl_path="$HOME/.claude/projects/-tmp/${session_id}.jsonl"
/opt/driver/pane-hook.sh "$id" \
    "{\"hook_event_name\":\"SessionStart\",\"transcript_path\":\"${jsonl_path}\"}" >/dev/null

mkdir -p "$HOME/.claude/projects/-tmp"
echo '{}' > "$jsonl_path"

# Wait for both env vars visible (survivor must be in /proc for the
# degraded-mode guard to NOT trip).
deadline=$(( $(date +%s) + 10 ))
while [ "$(date +%s)" -lt "$deadline" ]; do
    if proc_has "$survivor" && proc_has "$id"; then
        break
    fi
    sleep 0.2
done

# External kill on the spawn we'll resume.
tmux kill-session -t "$sess"

# Wait until the killed pane process's env disappears from /proc.
deadline=$(( $(date +%s) + 10 ))
while [ "$(date +%s)" -lt "$deadline" ]; do
    if ! proc_has "$id"; then break; fi
    sleep 0.2
done

agent-director find-missing >/dev/null

state=$(agent-director get --claude-instance-id "$id" | jq -r '.state')
if [ "$state" != "missing" ]; then
    echo "FAIL: state=$state; want missing"; exit 1
fi

PATH="$standin_path" agent-director resume --claude-instance-id "$id" >/dev/null

if ! tmux has-session -t "$sess" 2>/dev/null; then
    echo "FAIL: tmux session $sess not up after resume from missing"; exit 1
fi
echo "resume-2 ok: missing → resume → new tmux session up"
```
