# spawn-21: a no-verb run given a hook payload writes `no_exec_form`

Maps to Epic `t1.h98.ve` (Plan `b.h98`, hook questions), Task
`t2.h98.ve.df`, Subtask `t3.h98.ve.df.ym`, and Docker case spawn-21 (SRD
SR-22.9 "A Claude Code that does not run exec-form hooks"; SR-14's
`ad.hook.ignored` reason `no_exec_form`; PRD AC-HOOK-06). A Claude Code
older than the exec-form minimum ignores a hook's `args` and runs the bare
binary, so the hook reaches `agent-director` with no verb and its payload
on standard input. That run prints nothing, exits 0, writes exactly one
`ad.hook.ignored` record with reason `no_exec_form`, writes no
`ad.hook.fired`, and opens no store. A no-verb run whose standard input
is not a hook payload (end of input, or a JSON object without
`hook_event_name`) prints help exactly as `agent-director help` does.

## Setup

Per-case DB-reset has wiped `~/.agent-director/state.db` and then
re-created it with `agent-director list`, so the case removes it again.
The container has `agent-director` and `jq` on PATH. No tmux session,
row or `claude` is involved. `~/.agent-director/ad-trail.jsonl` is not
reset between cases, so every trail check selects records by this case's
own instance id X (`sp21-<uuid>`) or session id S (a fresh uuid), which no
other case uses.

## Steps

1. Run `agent-director help` and keep its stdout, stderr and exit code as
   the reference help.
2. Remove `state.db` and its `-wal` / `-shm` siblings.
3. Pipe a SessionStart payload (`hook_event_name` `SessionStart`,
   `session_id` S, `transcript_path` ending in `S.jsonl`) into
   `agent-director` with no verb, with `AGENT_DIRECTOR_INSTANCE_ID=X` set.
4. Run `agent-director` with no verb again with `</dev/null`, still with
   `AGENT_DIRECTOR_INSTANCE_ID=X`.
5. Pipe a JSON object that is not a hook payload (a `session_id`, a
   `cwd` and the `event_name` alias, but no `hook_event_name`) into
   `agent-director` with no verb, still with `AGENT_DIRECTOR_INSTANCE_ID=X`.
6. Read every trail record that carries X or S.

## Pass criteria

- Step 1: `help` exits 0 with non-empty stdout and empty stderr.
- Step 3: exit 0; stdout and stderr are empty; there is no `state.db`
  afterwards.
- Steps 4 and 5: each exits 0, its stdout is byte-identical to the
  reference help and its stderr is empty.
- Step 6: exactly one record carries X or S (so no `ad.hook.fired` and
  nothing from steps 4 and 5). It has `event == "ad.hook.ignored"`,
  `reason == "no_exec_form"`, `hook_event == "SessionStart"`,
  `claude_instance_id == X`, `hook_session_id == S`, `parent_pid` equal to
  the case shell's pid, `parent_command == "bash"`, `source == "ad_hook"`,
  and `row_session_id` and `row_pane_pid` null.
- After all runs there is still no `state.db`, `-wal` or `-shm`.

## Script

```bash
set -euo pipefail

dir="$HOME/.agent-director"
db="$dir/state.db"
trail="$dir/ad-trail.jsonl"
x="sp21-$(cat /proc/sys/kernel/random/uuid)"
s="$(cat /proc/sys/kernel/random/uuid)"
work="$(mktemp -d)"
trap 'rm -rf "$work"' EXIT

fail() {
    echo "FAIL: $*" >&2
    exit 1
}

no_store() {
    local f
    for f in "$db" "$db-wal" "$db-shm"; do
        if [ -e "$f" ]; then
            fail "$1: $f exists"
        fi
    done
}

# Step 1: the reference help.
set +e
agent-director help >"$work/help.out" 2>"$work/help.err"
code=$?
set -e
[ "$code" -eq 0 ] || fail "help exited $code"
[ -s "$work/help.out" ] || fail "help printed nothing"
[ ! -s "$work/help.err" ] || fail "help wrote stderr: $(cat "$work/help.err")"

# Step 2: no store.
rm -f "$db" "$db-wal" "$db-shm"

# Step 3: a SessionStart payload piped into a no-verb run.
payload="$(jq -cn --arg s "$s" '{session_id: $s,
    transcript_path: ("/home/agent/.claude/projects/-tmp/" + $s + ".jsonl"),
    cwd: "/tmp", hook_event_name: "SessionStart", source: "startup"}')"
set +e
printf '%s' "$payload" \
    | AGENT_DIRECTOR_INSTANCE_ID="$x" agent-director >"$work/p.out" 2>"$work/p.err"
code=$?
set -e
[ "$code" -eq 0 ] || fail "payload run exited $code; stderr: $(cat "$work/p.err")"
[ ! -s "$work/p.out" ] || fail "payload run wrote stdout: $(head -c 300 "$work/p.out")"
[ ! -s "$work/p.err" ] || fail "payload run wrote stderr: $(cat "$work/p.err")"
no_store "after the payload run"

# Step 4: end of input prints help.
set +e
AGENT_DIRECTOR_INSTANCE_ID="$x" agent-director </dev/null >"$work/n.out" 2>"$work/n.err"
code=$?
set -e
[ "$code" -eq 0 ] || fail "</dev/null run exited $code"
cmp -s "$work/help.out" "$work/n.out" || fail "</dev/null run did not print help"
[ ! -s "$work/n.err" ] || fail "</dev/null run wrote stderr: $(cat "$work/n.err")"

# Step 5: a JSON object that is not a hook payload prints help.
other="$(jq -cn --arg s "$s" '{session_id: $s, cwd: "/tmp",
    event_name: "SessionStart"}')"
set +e
printf '%s' "$other" \
    | AGENT_DIRECTOR_INSTANCE_ID="$x" agent-director >"$work/j.out" 2>"$work/j.err"
code=$?
set -e
[ "$code" -eq 0 ] || fail "non-hook JSON run exited $code"
cmp -s "$work/help.out" "$work/j.out" || fail "non-hook JSON run did not print help"
[ ! -s "$work/j.err" ] || fail "non-hook JSON run wrote stderr: $(cat "$work/j.err")"

# Step 6: exactly one record for X or S, the no_exec_form one.
[ -f "$trail" ] || fail "no trail file at $trail"
jq -c --arg x "$x" --arg s "$s" \
    'select(.claude_instance_id == $x or .hook_session_id == $s)' \
    "$trail" >"$work/records"
n="$(wc -l <"$work/records")"
[ "$n" -eq 1 ] || fail "want 1 trail record for $x / $s, got $n: $(cat "$work/records")"
jq -e --arg x "$x" --arg s "$s" --argjson ppid "$$" '
    .event == "ad.hook.ignored" and .reason == "no_exec_form"
    and .hook_event == "SessionStart" and .claude_instance_id == $x
    and .hook_session_id == $s and .parent_pid == $ppid
    and .parent_command == "bash" and .source == "ad_hook"
    and has("row_session_id") and .row_session_id == null
    and has("row_pane_pid") and .row_pane_pid == null' \
    "$work/records" >/dev/null \
    || fail "record does not match (parent pid $$): $(cat "$work/records")"

no_store "after all runs"

echo "spawn-21 ok: no-verb payload run silent, one no_exec_form for $x, no store; end of input and non-hook JSON print help"
```
