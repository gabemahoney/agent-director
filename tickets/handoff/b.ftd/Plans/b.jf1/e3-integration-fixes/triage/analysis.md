Source cause: session.go's unconditional owned-process defer terminates the runtime after fatal returns, but fatal returns never publish a terminal lifecycle state. The :1152 intentional block alone proves death and reports SessionEnd. reporter.reportIdentity hardcodes reason prompt_input_exit for SessionEnd. Reusing that path unchanged for a crash would misstate intent. Get and Status are database/settle reads and do not run process reconciliation. Existing FindMissing already selects the recorded pane/gateway identity, uses exact start-time checks and marks missing when gone. Therefore an explicitly requested sweep would likely already repair this particular row; this run did not exercise it.

Minimal architecture: retain ended for the existing intentional positive-death path. Use missing for unexpected gateway failure, including protocol/persistence failure; this also preserves existing tests that forbid fabricated ended after persistence failures. On catchable fatal exit, stop admission/requests, terminate and join the owned runtime, prove exact runtime death while registered gateway descriptors remain open, then conditionally mark only the examined current launch missing with existing transactional request/subagent close semantics. Preserve the original fatal error. Do not make transcript persistence or the dying hook a prerequisite for independent process reconciliation.

A defer alone cannot handle external SIGKILL. Add narrow Cursor-only reconciliation before public Get/Status reads, using the existing ProcChecker and tmux.JudgeProcess semantics. Avoid a full-store FindMissing sweep on one-row reads. If the gateway is alive or the probe is unknown, do not infer death from stale timestamps, EOF, pane text or transcript termination. Missing can truthfully identify a lost gateway even when a runtime remains alive, but **ended must never be reported while the owned runtime is alive or unknown**. If the implementation chooses to require both identities gone before missing, it still needs a machine-readable lost-gateway result during the interval rather than returning working. An older binding must never retire a newer launch or session publication. Reread after a conditional-write race; do not return the stale working snapshot as a successful death reconciliation.
