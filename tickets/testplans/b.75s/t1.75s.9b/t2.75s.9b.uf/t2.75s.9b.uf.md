# recov-1: find-missing reconciles externally-killed Spawn

Maps to Epic 8 AC #1. Spawn TWO Claudes, externally kill ONE via
`tmux kill-session` (the manual operator path, NOT
`agent-director kill`), then `find-missing` reports count=1 and the
killed row's state flips to `missing` with `ended_at` populated.

The "two Claudes" framing matters: the survivor is the
no-false-positive check — find-missing must mark only the dead row
and keep the live one. It is also the realistic operator scenario
(find-missing exists for fleets, not single-Spawn setups).

### Why find-missing runs in a bounded loop

`find-missing` never judges a `pending` row while it is inside the
pending grace period (`pending_grace_seconds`, 60 s by default),
measured from the row's launch start (`launch_started_at`), not its
`started_at` (SRD t1.fmk.i8 SR-11.2, "the grace period is measured
from the launch start"; PRD AC-FM-12). Inside the grace
period the row is left as it is and is in neither `ids` nor
`unverified_ids`. That is correct behaviour, not a failure.

The image's `claude` never reports in (no hook applies), so both
spawned rows stay `pending` with no SessionStart pid; each records only
the pane process tmux reported when its session was created
(`pane_pid`, `pane_starttime`). A single `find-missing` run seconds
after the spawn would therefore see the killed row still inside its
grace period and correctly leave it alone. The case instead runs
`find-missing` repeatedly, a few seconds apart, for up to 120 s
(longer than the 60 s default grace period plus margin). Once the
killed row's grace period has passed, `find-missing` judges it by its
recorded pane process, which exited with its session, and marks it
`missing`; the survivor's pane process still runs, so it is kept. No
SessionStart is synthesised: the rows' meaning (agents that never
reported in) is exactly what this case exercises.

## Setup

Per-case DB-reset. The harness image has `claude` + `tmux` + `jq` +
`sqlite3` on PATH.

## Steps

1. Spawn two Claudes; capture both ids, the first's tmux session
   name and the first's recorded pane process pid (`pane_pid`, read
   with `sqlite3`).
2. Check that pane process runs (`kill -0 <pid>`).
3. `tmux kill-session -t <name>` — external kill on Claude #1.
4. Poll (up to 10 s) until that pane process has exited.
5. Run `find-missing` in a bounded loop (deadline 120 s, 3 s between
   runs). Every run must exit 0. A run that lists the survivor in
   `ids` or `unverified_ids` fails the case at once. Runs with
   `count=0` mean the killed row is still inside its grace period:
   wait and run again. The first run with `count>=1` must be exactly
   `count=1` with Claude #1's id as the only entry in `.ids`; the loop
   stops there. If the deadline passes with no such run, fail and
   print each row's `state` and `launch_started_at`.
6. `get` on Claude #1 → state is `missing`, `ended_at` populated.
7. `get` on Claude #2 → unchanged.

## Pass criteria

- Every find-missing run exits 0.
- No find-missing run lists the survivor.
- Result envelope of the first run that marks anything:
  `{"count":1,"ids":["<killed-id>"]}`, reached within the 120 s bound.
- Killed row's state transitions to `missing`; `ended_at` is non-null.
- Survivor row is unchanged.

## Script

```bash
set -euo pipefail

# row_report prints a row's state and launch start for a failure message.
row_report() {
    local label="$1" id="$2"
    agent-director get --claude-instance-id "$id" \
        | jq -r --arg l "$label" --arg id "$id" \
            '"\($l) \($id): state=\(.state) launch_started_at=\(.launch_started_at // "absent")"'
}

killed=$(agent-director spawn --cwd /tmp | jq -r '.claude_instance_id')
survivor=$(agent-director spawn --cwd /tmp | jq -r '.claude_instance_id')
test -n "$killed" && test -n "$survivor"

sess=$(agent-director get --claude-instance-id "$killed" | jq -r '.tmux_session_name')
test -n "$sess"

# The pane process the killed row recorded when its session was created.
pane_pid=$(/opt/driver/sql.sh "$HOME/.agent-director/state.db" \
    "SELECT pane_pid FROM spawns WHERE claude_instance_id='$killed';")
if [ -z "$pane_pid" ]; then
    echo "FAIL: killed row records no pane_pid after spawn"; exit 1
fi
if ! kill -0 "$pane_pid" 2>/dev/null; then
    echo "FAIL: killed row's pane process $pane_pid is not running before the kill"; exit 1
fi

# External kill on the first spawn.
tmux kill-session -t "$sess"

# Wait until the killed row's pane process has exited.
deadline=$(( $(date +%s) + 10 ))
while [ "$(date +%s)" -lt "$deadline" ]; do
    if ! kill -0 "$pane_pid" 2>/dev/null; then
        break
    fi
    sleep 0.2
done
if kill -0 "$pane_pid" 2>/dev/null; then
    echo "FAIL: killed row's pane process $pane_pid still runs after kill-session + 10s"; exit 1
fi

# Bounded find-missing loop. A pending row inside its grace period
# (pending_grace_seconds, 60 s by default, measured from launch_started_at)
# is correctly not judged, so early runs return count=0. 120 s exceeds the
# default grace period plus margin.
start=$(date +%s)
deadline=$(( start + 120 ))
runs=0
marked=""
res=""
while [ "$(date +%s)" -lt "$deadline" ]; do
    res=$(agent-director find-missing)
    runs=$(( runs + 1 ))
    count=$(printf '%s' "$res" | jq -r '.count')
    ids=$(printf '%s' "$res" | jq -r '.ids | join(",")')
    if printf '%s' "$res" | jq -e --arg s "$survivor" \
        '((.ids // []) + (.unverified_ids // [])) | index($s) != null' >/dev/null; then
        echo "FAIL: run $runs listed the survivor $survivor (res=$res)"; exit 1
    fi
    if [ "$count" != "0" ]; then
        if [ "$count" != "1" ]; then
            echo "FAIL: count=$count; want 1 (res=$res)"; exit 1
        fi
        if [ "$ids" != "$killed" ]; then
            echo "FAIL: ids=$ids; want $killed"; exit 1
        fi
        marked=yes
        break
    fi
    sleep 3
done
if [ -z "$marked" ]; then
    echo "FAIL: find-missing never marked the killed row within 120s ($runs runs; last res=$res)"
    row_report killed "$killed"
    row_report survivor "$survivor"
    exit 1
fi

killed_state=$(agent-director get --claude-instance-id "$killed" | jq -r '.state')
if [ "$killed_state" != "missing" ]; then
    echo "FAIL: killed state=$killed_state; want missing"; exit 1
fi
ended=$(/opt/driver/sql.sh "$HOME/.agent-director/state.db" \
    "SELECT ended_at FROM spawns WHERE claude_instance_id='$killed';")
if [ -z "$ended" ]; then
    echo "FAIL: ended_at not populated after find-missing"; exit 1
fi

survivor_state=$(agent-director get --claude-instance-id "$survivor" | jq -r '.state')
if [ "$survivor_state" = "missing" ]; then
    echo "FAIL: survivor was wrongly marked missing"; exit 1
fi
echo "recov-1 ok: external kill on 1 of 2 → find-missing marks just the killed row (run $runs, $(( $(date +%s) - start ))s after the kill)"
```
