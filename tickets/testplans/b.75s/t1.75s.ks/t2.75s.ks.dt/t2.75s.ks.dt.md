# kill-8: the finished-row option kills a reported-in leftover at the configured minimums

Maps to SRD SR-20.9 kill-8 (AC-KILL-11, AC-CFG-02, AC-CFG-04; Epic
`t1.h98.9b`, Task `t2.h98.9b.mg`; SR-6.5, SR-6.7, SR-4.1, SR-4.2; the
Epic's demo). X is spawned for real, reports in (SessionStart typed
into its pane), and then finishes (SessionEnd typed into its pane), but
its agent process and its session keep running: a leftover of a row
that reported in. With the starting-session bound and the stopping
window configured at their safe minimums (60 s and 30 s), about a
minute after the SessionEnd the session is past both, so the operator
tool's `agent-director-admin kill-finished` (kill's operator-only
finished-row option, b.vqr) ends it: exit 0, `kill_sent` true, the
session and the recorded process gone. The row is never changed; X
stays `ended`. The harness image keeps agent-director-admin off PATH at
`/opt/bin/agent-director-admin` (install.sh installs it at
`~/.agent-director/admin/agent-director-admin`), so the case runs it by
that full path.

The kill runs while X ended less than the default stopping window
(90 s) ago and its session is younger than the default bound (300 s),
so a kill that ignored the configured values would refuse as "still
stopping" (`ErrTmuxUnresponsive`), and the case would fail.

## Setup

Per-case DB-reset. A per-case `~/.agent-director/config.toml`, written
before the spawn, sets `[tmux] starting_session_seconds = 60` and
`stopping_window_seconds = 30`. The spawn runs with
`PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the
`agent-director` command, so X's pane process is the stand-in claude's
interactive bash, which sends no hook by itself and keeps running
after a SessionEnd. Both hooks are typed into X's recorded pane with
`/opt/driver/pane-hook.sh <id> '<payload>'`, so their parent is the
pane process (SR-22.9). Before any tmux or agent-director call the
script:

1. unsets `ANTHROPIC_API_KEY` and `CLAUDE_CODE_OAUTH_TOKEN`;
2. removes both from the global environment of a tmux server already
   answering on the default socket (`tmux set-environment -g -u`),
   tolerating "no server";
3. right after the spawn, before any state assertion, checks neither
   name appears in `/proc/<recorded pane_pid>/environ`, failing with
   "credentials reached the agent".

X's session is named `cd-k8` (the harness's reserved prefix, which the
DB-reset sweeps). An EXIT trap removes the config file and, if it is
still there, the session by its session id `$N` on the recorded
socket.

## Steps

1. Write the config above.
2. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd
   /tmp --tmux-session-name cd-k8 --claude-instance-id id-k8`.
3. Read X's `tmux_socket`, `pane_id` and `pane_pid` with `sqlite3`; get
   `$N` and `#{session_created}` from the recorded pane on that socket.
   Run the credential check. `status` X is `pending`.
4. Type `{"hook_event_name":"SessionStart","transcript_path":"<path>"}`
   into X's pane (`<path>` ends in `k8-session-uuid.jsonl`). X is
   `waiting`, its `pid` equals `pane_pid` and its `claude_session_id`
   is `k8-session-uuid`.
5. Wait 2 s, then type `{"hook_event_name":"SessionEnd","reason":"logout"}`
   into X's pane. X is `ended` with its `pid` still `pane_pid`, its
   `ended_at` later than the session's creation; the session (by `$N`)
   and the pid still run.
6. Wait 60 s. Check the timing: X ended at least 31 s and at most 85 s
   ago, and the session is at least 61 s and at most 290 s old.
7. `/opt/bin/agent-director-admin kill-finished --claude-instance-id id-k8`.
8. Check the session by `$N`, the pid, X's row, `get`, and the last
   `ad.kill.called` trail line for `id-k8`; print the kill result and
   the row state.

## Pass criteria

- Neither credential variable is in the pane process's environment.
- After the SessionStart: `waiting`, `pid` = `pane_pid`, session id
  `k8-session-uuid`. After the SessionEnd: `ended`, `pid` = `pane_pid`,
  `ended_at` after the session's creation, the session and the pid
  still running.
- The kill runs past the configured window and bound and inside the
  defaults (the timing check of step 6).
- kill-finished exits 0 with `kill_sent` true.
- Afterwards `tmux -S <socket> has-session -t '<$N>'` fails and the
  recorded pid is gone (absent or a zombie).
- X's row (`state`, `pid`, `pane_id`, `pane_pid`, `row_version`,
  `launch_token`, `ended_at`) is exactly as before the kill, and `get`
  shows `ended`.
- The last `ad.kill.called` line for `id-k8` has `include_finished`
  true, outcome `ok`, `kill_sent` true, `pane_killed` true,
  `lookup_outcome` `ours` and `caller_process` `agent-director-admin`.

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN
tmux set-environment -g -u ANTHROPIC_API_KEY 2>/dev/null || true
tmux set-environment -g -u CLAUDE_CODE_OAUTH_TOKEN 2>/dev/null || true

db="$HOME/.agent-director/state.db"
trail="$HOME/.agent-director/ad-trail.jsonl"
cfg="$HOME/.agent-director/config.toml"
standin_path="/opt/driver/stand-in-claude:$PATH"
admin=/opt/bin/agent-director-admin
id="id-k8"
fail() { echo "FAIL: $*"; exit 1; }
sock=""
sid=""
trap 'rm -f "$cfg"; [ -z "$sid" ] || tmux -S "$sock" kill-session -t "$sid" 2>/dev/null || true' EXIT

# row_snapshot: every column the kill must leave alone.
row_snapshot() {
    /opt/driver/sql.sh -readonly -separator '|' "$db" \
        "SELECT state, IFNULL(pid,''), IFNULL(pane_id,''), IFNULL(pane_pid,''),
                row_version, IFNULL(launch_token,''), IFNULL(ended_at,'')
         FROM spawns WHERE claude_instance_id = '$id';"
}

# running <pid>: the process exists and is not a zombie.
running() {
    local st
    [ -e "/proc/$1" ] || return 1
    st="$(sed -E 's/^.*\) //' "/proc/$1/stat" 2>/dev/null | cut -d' ' -f1 || true)"
    [ -n "$st" ] && [ "$st" != "Z" ]
}

# The bound and the window at their safe minimums, before the spawn.
mkdir -p "$HOME/.agent-director"
cat >"$cfg" <<'EOF'
[tmux]
starting_session_seconds = 60
stopping_window_seconds = 30
EOF

# The spawn's stderr (a "pre-trust failed" note: no ~/.claude.json here) is
# shown only if the spawn fails, so the case's last line stays the summary.
spawn_err="$(mktemp)"
spawn_out="$(PATH="$standin_path" agent-director spawn --cwd /tmp --tmux-session-name cd-k8 \
    --claude-instance-id "$id" 2>"$spawn_err")" \
    || fail "spawn exited non-zero: $(cat "$spawn_err")"
got_id="$(jq -r '.claude_instance_id' <<<"$spawn_out")"
[ "$got_id" = "$id" ] || fail "spawn returned claude_instance_id [$got_id]; want $id: $spawn_out"

IFS='|' read -r sock pane pane_pid < <(/opt/driver/sql.sh -readonly "$db" \
    "SELECT IFNULL(tmux_socket,'') || '|' || IFNULL(pane_id,'') || '|' || IFNULL(pane_pid,'') FROM spawns WHERE claude_instance_id = '$id';")
[ -n "$sock" ] && [ -n "$pane" ] && [[ "$pane_pid" =~ ^[0-9]+$ ]] \
    || fail "recorded tmux_socket|pane_id|pane_pid=[$sock|$pane|$pane_pid]; want all set"
read -r sid created < <(tmux -S "$sock" display-message -p -t "$pane" '#{session_id} #{session_created}')
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "pane $pane gave session id [$sid]"
[[ "$created" =~ ^[0-9]+$ ]] || fail "pane $pane gave session creation time [$created]"

for v in ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN; do
    if grep -qz "^$v=" "/proc/$pane_pid/environ"; then
        fail "credentials reached the agent: $v is in /proc/$pane_pid/environ"
    fi
done

state="$(agent-director status --claude-instance-id "$id" | jq -r '.state')"
[ "$state" = "pending" ] || fail "after spawn state=$state; want pending (the agent reported in on its own?)"

# Step 4: X reports in through its own pane process.
jsonl_path="$HOME/.claude/projects/-tmp/k8-session-uuid.jsonl"
/opt/driver/pane-hook.sh "$id" \
    "{\"hook_event_name\":\"SessionStart\",\"transcript_path\":\"${jsonl_path}\"}" >/dev/null \
    || fail "SessionStart typed into $pane failed"
IFS='|' read -r state pid csid < <(/opt/driver/sql.sh -readonly "$db" \
    "SELECT state || '|' || IFNULL(pid,'') || '|' || IFNULL(claude_session_id,'') FROM spawns WHERE claude_instance_id = '$id';")
[ "$state" = "waiting" ] || fail "after SessionStart state=$state; want waiting"
[ "$pid" = "$pane_pid" ] || fail "after SessionStart pid=[$pid]; want the recorded pane_pid $pane_pid"
[ "$csid" = "k8-session-uuid" ] || fail "after SessionStart claude_session_id=[$csid]; want k8-session-uuid"

# Step 5: X finishes; its agent and its session keep running.
sleep 2
/opt/driver/pane-hook.sh "$id" '{"hook_event_name":"SessionEnd","reason":"logout"}' >/dev/null \
    || fail "SessionEnd typed into $pane failed"
IFS='|' read -r state pid ended_epoch < <(/opt/driver/sql.sh -readonly "$db" \
    "SELECT state || '|' || IFNULL(pid,'') || '|' || IFNULL(strftime('%s', ended_at),'') FROM spawns WHERE claude_instance_id = '$id';")
[ "$state" = "ended" ] || fail "after SessionEnd state=$state; want ended"
[ "$pid" = "$pane_pid" ] || fail "after SessionEnd pid=[$pid]; want the recorded pane_pid $pane_pid"
[[ "$ended_epoch" =~ ^[0-9]+$ ]] || fail "after SessionEnd ended_at did not parse: [$ended_epoch]"
[ "$created" -lt "$ended_epoch" ] || fail "session created at $created, not before ended_at $ended_epoch"
tmux -S "$sock" has-session -t "$sid" 2>/dev/null || fail "session $sid is gone after the SessionEnd"
running "$pane_pid" || fail "pid $pane_pid stopped after the SessionEnd"

# Step 6: past the configured window (30 s) and bound (60 s), inside the
# defaults (90 s, 300 s).
sleep 60
now="$(date +%s)"
since_end=$(( now - ended_epoch ))
age=$(( now - created ))
[ "$since_end" -ge 31 ] && [ "$since_end" -le 85 ] \
    || fail "X ended ${since_end}s ago; want 31-85 s (past the configured window, inside the default)"
[ "$age" -ge 61 ] && [ "$age" -le 290 ] \
    || fail "session is ${age}s old; want 61-290 s (past the configured bound, inside the default)"

before="$(row_snapshot)"

# Step 7: the operator tool's kill-finished ends the reported-in leftover.
kill_err="$(mktemp)"
set +e
out="$("$admin" kill-finished --claude-instance-id "$id" 2>"$kill_err")"
code=$?
set -e
[ "$code" -eq 0 ] || fail "kill-finished exited $code; want 0 (stderr: $(cat "$kill_err"))"
sent="$(jq -r '.kill_sent' <<<"$out")"
[ "$sent" = "true" ] || fail "kill_sent=$sent; want true (stdout: $out)"

if tmux -S "$sock" has-session -t "$sid" 2>/dev/null; then
    fail "session $sid (cd-k8) still exists after the kill"
fi
if running "$pane_pid"; then
    fail "pid $pane_pid still runs after the kill"
fi
after="$(row_snapshot)"
[ "$after" = "$before" ] || fail "X's row changed on the kill: [$before] -> [$after]"
state="$(agent-director get --claude-instance-id "$id" | jq -r '.state')"
[ "$state" = "ended" ] || fail "get shows state=$state after the kill; want ended"

line="$(jq -cR 'fromjson? | select(.event == "ad.kill.called" and .claude_instance_id == "id-k8")' "$trail" | tail -n 1)"
[ -n "$line" ] || fail "no ad.kill.called line for $id in $trail"
tr="$(jq -r '[.include_finished, .outcome, .kill_sent, .pane_killed, .lookup_outcome, .caller_process] | map(tostring) | join(" ")' <<<"$line")"
[ "$tr" = "true ok true true ours agent-director-admin" ] \
    || fail "ad.kill.called include_finished/outcome/kill_sent/pane_killed/lookup_outcome/caller_process=[$tr]; want [true ok true true ours agent-director-admin]: $line"

echo "kill-8 ok: reported-in leftover $sid (cd-k8) of ended X ($id), ended ${since_end}s ago, ${age}s old, at the configured 30 s window and 60 s bound: kill-finished result $out; session and pid $pane_pid gone; row state $state, unchanged"
```
