# resume-6: id-less stale tmux session under the canonical name triggers ErrTmuxSessionConflict

Per SRD SR-8.1 (step 3) and SR-8.2: before its move to `pending`,
`resume` looks the row up on its recorded socket (a row that records no
socket uses the caller's default socket, SR-3.3). Here the row's name is
held by a session that carries no valid agent-director label, so the
lookup finds no session of this row and one holder of the name with no
valid instance id. `resume` refuses with `ErrTmuxSessionConflict`
("no valid instance id") and writes nothing: the row stays `ended` with
no launch start and its parent id as it was, and no `ad.resume.*` event
is written (an `ad.provenance.disagree` record may be). The holder
session is never touched.

## Setup

Per-case DB-reset. No agent is launched on the pass path; as a guard
against a regression that launches one, the script unsets
`ANTHROPIC_API_KEY` and `CLAUDE_CODE_OAUTH_TOKEN` first, and it unsets
`AGENT_DIRECTOR_INSTANCE_ID` so a resume could only derive a NULL parent
(resume-7). An EXIT trap kills the holder session by its session id.

## Steps

1. Seed two rows directly via sqlite3: a parent `id-r6-parent` (ended)
   and `id-r6`, `ended`, with a populated `claude_session_id`, its
   transcript on disk, `tmux_session_name` = `cd-r6` and `parent_id` =
   `id-r6-parent`. Neither records a socket, pid, pane or launch token.
2. Snapshot `id-r6`'s whole row.
3. Start an unlabelled stale session under `cd-r6` (running `cat`),
   capturing its session id `$N`.
4. `resume --claude-instance-id id-r6` → non-zero; `err_name` is
   `ErrTmuxSessionConflict`; `err_description` contains "no valid
   instance id" and "nothing was done".
5. The row is unchanged: still `ended`, no `launch_started_at`,
   `parent_id` still `id-r6-parent`, and the whole row equals the
   snapshot.
6. The trail holds no `ad.resume.*` event for `id-r6`.
7. The stale session (by `$N`) is still alive and still has no label.

## Pass criteria

- `resume` exits non-zero with `ErrTmuxSessionConflict`, and its
  description names the holder class ("no valid instance id").
- The refusal wrote nothing: the row (state, launch start, parent id,
  every column) is as seeded and no `ad.resume.*` event exists for it.
- The pre-existing stale tmux session is not killed or labelled.
- Each failed check prints a `FAIL:` line naming what was expected and
  what was seen; the final line summarises what was checked.

## Script

```bash
set -euo pipefail
# No agent launches on the pass path; no credentials as a guard anyway.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN AGENT_DIRECTOR_INSTANCE_ID
db="$HOME/.agent-director/state.db"
trail="$HOME/.agent-director/ad-trail.jsonl"
fail() { echo "FAIL: $*"; exit 1; }
sid=""
cleanup() { [ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true; }
trap cleanup EXIT

session_id="r6-session-uuid"
mkdir -p "$HOME/.claude/projects/-tmp"
echo '{}' > "$HOME/.claude/projects/-tmp/${session_id}.jsonl"

sqlite3 "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, ended_at)
   VALUES ('id-r6-parent', 'ended', '/tmp', 'cd-r6-parent', 'off', CURRENT_TIMESTAMP);
   INSERT INTO spawns (claude_instance_id, parent_id, state, cwd, tmux_session_name, relay_mode, claude_session_id, ended_at)
   VALUES ('id-r6', 'id-r6-parent', 'ended', '/tmp', 'cd-r6', 'off', '${session_id}', CURRENT_TIMESTAMP);"
row_before="$(sqlite3 -readonly "$db" "SELECT * FROM spawns WHERE claude_instance_id = 'id-r6';")"
[ -n "$row_before" ] || fail "seeded row id-r6 not found"

# The id-less holder: an unlabelled session under the row's name.
sid="$(tmux new-session -d -s cd-r6 -P -F '#{session_id}' -- cat)"
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"

stderr_file="$(mktemp)"
if agent-director resume --claude-instance-id id-r6 2>"$stderr_file" >/dev/null; then
    fail "resume with an id-less session holding the name exited 0; want ErrTmuxSessionConflict"
fi
err_name="$(jq -r '.err_name' "$stderr_file")"
[ "$err_name" = "ErrTmuxSessionConflict" ] || fail "err_name=$err_name; want ErrTmuxSessionConflict ($(cat "$stderr_file"))"
desc="$(jq -r '.err_description' "$stderr_file")"
for want in "no valid instance id" "nothing was done"; do
    case "$desc" in
        *"$want"*) ;;
        *) fail "err_description lacks \"$want\": $desc" ;;
    esac
done

# The refusal wrote nothing to the row.
got="$(sqlite3 -readonly "$db" "SELECT state || '|' || IFNULL(launch_started_at,'NULL') || '|' || IFNULL(parent_id,'NULL') FROM spawns WHERE claude_instance_id = 'id-r6';")"
[ "$got" = "ended|NULL|id-r6-parent" ] || fail "row state|launch_started_at|parent_id=$got; want ended|NULL|id-r6-parent"
row_after="$(sqlite3 -readonly "$db" "SELECT * FROM spawns WHERE claude_instance_id = 'id-r6';")"
[ "$row_after" = "$row_before" ] || fail "row changed by the refused resume: [$row_after]; want [$row_before]"
if [ -f "$trail" ]; then
    ev="$(jq -cR 'fromjson? | select(.claude_instance_id == "id-r6" and (.event | tostring | startswith("ad.resume.")))' "$trail")"
    [ -z "$ev" ] || fail "refused resume wrote an ad.resume event: $ev"
fi

# The holder is untouched: alive, still unlabelled.
tmux has-session -t "$sid" 2>/dev/null || fail "resume ended the holder session $sid (cd-r6); want it left alone"
label="$(tmux show-options -t "$sid" -v @ad_owner 2>/dev/null || true)"
[ -z "$label" ] || fail "holder session $sid gained label [$label]; want none"

echo "resume-6 ok: id-less holder $sid of cd-r6 -> ErrTmuxSessionConflict (no valid instance id, nothing was done); row unchanged (ended, no launch start, parent kept), no ad.resume event; holder alive and unlabelled"
```
