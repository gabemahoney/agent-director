# kill-5: a session without a label that holds the row's name is left alone

Maps to SRD SR-20.9 kill-5 (Epic `t1.h98.aq`, the honest kill; SR-6.1,
SR-1.4, SR-3.4). `kill` finds a row's session only by its `@ad_owner`
label, never by name. Here the row's name `cd-k5` is held by a session
nobody labelled (made in the container with no instance id): the
lookup finds no session carrying the row's label, so the row's own
session is Gone; the row records no agent process, so there is nothing
to wait for. `kill` returns 0 with `kill_sent` false and the holder is
not touched.

The row carries a `launch_token`, so it could be Ours if a session
carried its label: the case does not pass merely because a row with no
token is never Ours.

## Setup

Per-case DB-reset. An EXIT trap removes the holder by its session id.

## Steps

1. `tmux new-session -d -s cd-k5 -- cat` (no `-e`, no label), capturing
   its session id `$N`.
2. Seed a `spawns` row `id-k5` at state `waiting`, session name `cd-k5`,
   with a 16-lowercase-hex `launch_token` and no pid or pane; read the
   token back with `sqlite3`.
3. `agent-director kill --claude-instance-id id-k5`.
4. Check the holder by its `$N`.

## Pass criteria

- The token is 16 lowercase hex; the holder has no `@ad_owner` before
  the kill.
- kill exits 0 and its stdout JSON has `kill_sent == false`.
- `tmux has-session -t '<$N>'` succeeds after the kill and the holder
  still has no `@ad_owner`.
- The row is still `waiting`.

## Script

```bash
set -euo pipefail
db="$HOME/.agent-director/state.db"
fail() { echo "FAIL: $*"; exit 1; }
sid=""
trap '[ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true' EXIT

sid="$(tmux new-session -d -s cd-k5 -P -F '#{session_id}' -- cat)"
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"

seed_token="$(od -An -N8 -tx1 /dev/urandom | tr -d ' 
')"
/opt/driver/sql.sh "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, launch_token)
   VALUES ('id-k5', 'waiting', '/tmp', 'cd-k5', 'off', '$seed_token');"
token="$(/opt/driver/sql.sh "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-k5';")"
[[ "$token" =~ ^[0-9a-f]{16}$ ]] || fail "launch_token is not 16 lowercase hex: [$token]"
held="$(/opt/driver/sql.sh "$db" "SELECT IFNULL(pid,'NULL') || '|' || IFNULL(pane_id,'NULL') FROM spawns WHERE claude_instance_id = 'id-k5';")"
[ "$held" = "NULL|NULL" ] || fail "seeded row pid|pane_id=$held; want NULL|NULL"

owner="$(tmux show-options -t "$sid" -v @ad_owner 2>/dev/null || true)"
[ -z "$owner" ] || fail "holder $sid carries @ad_owner [$owner] before the kill; want none"

out="$(agent-director kill --claude-instance-id id-k5)" || fail "kill exited non-zero; want 0"
sent="$(jq -r '.kill_sent' <<<"$out")"
[ "$sent" = "false" ] || fail "kill_sent=$sent; want false (stdout: $out)"

tmux has-session -t "$sid" 2>/dev/null || fail "holder $sid (cd-k5) no longer runs after kill"
owner="$(tmux show-options -t "$sid" -v @ad_owner 2>/dev/null || true)"
[ -z "$owner" ] || fail "holder $sid carries @ad_owner [$owner] after the kill; want none"
state="$(/opt/driver/sql.sh "$db" "SELECT state FROM spawns WHERE claude_instance_id = 'id-k5';")"
[ "$state" = "waiting" ] || fail "row state=$state after kill; want waiting"

echo "kill-5 ok: unlabelled holder $sid of cd-k5 → kill exit 0 with kill_sent false; holder still runs; row still waiting"
```
