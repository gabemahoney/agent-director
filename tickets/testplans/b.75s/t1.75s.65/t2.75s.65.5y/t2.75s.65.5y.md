# relay-1: allow decision round-trip

Maps to Epic 10 AC #2. The full happy-path: spawn with relay_mode=on,
PermissionRequest hook starts polling, orchestrator calls `decide
--decision=allow --reason ok`, hook's stdout carries the allow envelope.

## Setup

Per-case DB-reset. Epic 8 (`t1.h98.xw`, SR-20.9, SR-22.9): a hook moves a
row only when it comes from the row's own pane process, so the row is a
real spawn and every hook is typed into its pane. The spawn runs with
`--relay-mode on` (which puts `AGENT_DIRECTOR_RELAY_MODE=on` in the
session's environment, so the pane's shell and the hook it forks inherit
it) and with `PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the
`agent-director` command, so the pane process is the stand-in claude's
interactive bash. `/opt/driver/pane-hook.sh` types each hook into that
pane; the blocking PermissionRequest uses `--no-wait` (prints the job
dir) and `--wait <job dir>` (prints the hook's stdout, exits with the
hook's exit status). No hook is piped from the case's own shell, so the
driver shell backgrounds nothing. The session is named `cd-<case>` so
the DB-reset fixture's `cd-*` sweep removes it.

## Steps

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd /tmp
   --relay-mode on --tmux-session-name cd-r1` → capture
   `claude_instance_id`.
2. Type a SessionStart hook into the pane → state `waiting` (the
   state the pre-Epic-8 seed wrote).
3. Type the synthesized PermissionRequest payload into the pane with
   `pane-hook.sh --no-wait` → capture the job dir. The hook polls.
4. Poll the store (read-only) for the open request's token.
5. `decide --claude-instance-id <id> --request-token <token> --decision
   allow --reason "ok"`.
6. `pane-hook.sh --wait <job dir>` → the hook's stdout; its exit status
   is the hook's.
7. Parse its stdout: behavior=allow, no message.

## Pass criteria

- Hook exits 0.
- decide exits 0.
- Hook stdout is a JSON envelope with behavior=allow and no message
  (decide stores an empty reason for allow).

## Script

```bash
set -euo pipefail
id="$(PATH="/opt/driver/stand-in-claude:$PATH" agent-director spawn --cwd /tmp --relay-mode on --tmux-session-name cd-r1 | jq -r '.claude_instance_id')"
test -n "$id"
# SR-22.9: the hooks are typed into the row's pane, so they apply.
/opt/driver/pane-hook.sh "$id" '{"hook_event_name":"SessionStart","transcript_path":"/x/r1.jsonl"}'
state="$(agent-director status --claude-instance-id "$id" | jq -r '.state')"
test "$state" = "waiting"

job="$(/opt/driver/pane-hook.sh --no-wait "$id" '{"hook_event_name":"PermissionRequest","tool_name":"Bash","tool_input":{"cmd":"echo"}}')"

# decide REQUIRES --request-token. The hook in the pane mints a UUIDv4
# token and inserts the open permission_requests row; poll the DB for that
# token (decision IS NULL) before deciding.
token=""
for _ in $(seq 1 50); do
    token=$(sqlite3 -readonly "$HOME/.agent-director/state.db" \
      "SELECT request_token FROM permission_requests
       WHERE claude_instance_id='$id' AND decision IS NULL
       ORDER BY request_id DESC LIMIT 1;")
    [ -n "$token" ] && break
    sleep 0.1
done
if [ -z "$token" ]; then
    echo "FAIL: no open permission_requests row for $id (hook never upserted)"; exit 1
fi

agent-director decide --claude-instance-id "$id" --request-token "$token" --decision allow --reason "ok" >/dev/null

# --wait exits with the hook's exit status: set -e fails the case unless 0.
hook_out=$(mktemp)
/opt/driver/pane-hook.sh --wait "$job" >"$hook_out"
behavior=$(jq -r '.hookSpecificOutput.decision.behavior' "$hook_out")
message=$(jq -r '.hookSpecificOutput.decision.message' "$hook_out")

# The envelope's message mirrors the DB decision_reason (internal/hook/
# polling.go → EncodeDecision). decide() discards --reason and writes
# an EMPTY decision_reason for allow (pkg/api/decide.go), so an allow
# envelope carries NO message field — jq surfaces that as "null".
if [ "$behavior" != "allow" ] || [ "$message" != "null" ]; then
    echo "FAIL: envelope behavior=$behavior message=$message; want allow/null (allow carries no message)"
    cat "$hook_out"; exit 1
fi
echo "relay-1 ok: allow round-trip → allow envelope (no message)"
```
