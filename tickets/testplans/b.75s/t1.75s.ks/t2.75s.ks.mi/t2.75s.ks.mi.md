# kill-7: the finished-row option refuses a finished row's own session that never reported in

Maps to SRD SR-20.9 kill-7 (AC-KILL-14, AC-CFG-04; Epic `t1.h98.9b`,
Task `t2.h98.9b.mg`; SR-6.5, SR-6.7, SR-4.1, SR-4.2, SR-1.4). X is an
`ended` row whose own session (the one carrying X's current label) is
still running, but no agent of X's latest launch ever reported in from
it: X records no pid, and the session was created after X's `ended_at`.
With the starting-session bound configured at its safe minimum (60 s)
and the session older than that:

- `resume` refuses with the own-id conflict (`ErrTmuxSessionConflict`,
  "this row's own id", the pointer to "Operator actions");
- `kill` without the option is the finished row's no-op (exit 0,
  `kill_sent` false);
- `kill` with the operator-only finished-row option refuses with
  `ErrTmuxSessionConflict` "never reported in" and sends nothing.

No description names a way to end a session. Afterwards the session and
its pane process still run and X's row is unchanged, still `ended`.

The configured bound is what lets either verb reach its conflict: at
the default bound (300 s) the one-minute-old session is "still
starting" (`ErrTmuxUnresponsive`), so the case fails if the configured
value is ignored. It also fails if the option kills a session that
never reported in (exit 0, the session gone).

## Setup

Per-case DB-reset (fresh store, no `cd-*` sessions); the store exists
after the reset, so its id can be read from `store_meta`. X's session
is made by hand like kill-1 (`t2.75s.ks.3h`): `cd-k7` (the harness's
reserved prefix) with `-e AGENT_DIRECTOR_INSTANCE_ID=id-k7`, running
`cat`; the row carries a launch token and records no socket, server,
pid or pane; the session carries the five-field label
`ad1 <token> <$N> id-k7 <store id>` and its pane `@ad_pane`
`<token> <%N>`, as agent-director's own create sets them. X's
transcript is seeded where resume looks (the resume-1 pattern,
`t2.75s.ue.go`), so resume's pre-flight passes and it reaches its
lookup. A per-case `~/.agent-director/config.toml` sets
`[tmux] starting_session_seconds = 60`.

Credential isolation, before any tmux or agent-director call: unset
`ANTHROPIC_API_KEY` and `CLAUDE_CODE_OAUTH_TOKEN`, and remove both from
the global environment of a tmux server already answering on the
default socket (`tmux set-environment -g -u`), tolerating "no server".
The resume runs with `PATH=/opt/driver/stand-in-claude:$PATH`
prefixed, so even a wrongly allowed launch would start only the
stand-in.

An EXIT trap removes the session by its session id `$N`, the config
file and the seeded transcript.

## Steps

1. Read this store's id with `sqlite3`.
2. `tmux new-session -d -s cd-k7 -e AGENT_DIRECTOR_INSTANCE_ID=id-k7 --
   cat`, capturing `$N`, the pane id `%N`, the pane pid and
   `#{session_created}`.
3. Seed the transcript `$HOME/.claude/projects/-tmp/k7-session-uuid.jsonl`.
   Insert X with `sqlite3`: `id-k7`, state `ended`, cwd `/tmp`, session
   name `cd-k7`, `claude_session_id` `k7-session-uuid`, `jsonl_path` the
   seeded transcript, a 16-hex `launch_token`; no pid, pane or socket.
4. Label the session by `$N` (`@ad_owner`, read back) and its pane
   (`@ad_pane`).
5. Now that the session exists, set X's `ended_at` to
   `datetime('now', '-120 seconds')` (the store's `CURRENT_TIMESTAMP`
   layout); it is earlier than the session's creation.
6. Write `[tmux] starting_session_seconds = 60` to
   `~/.agent-director/config.toml`; wait until the session is 62 s old.
7. `PATH=/opt/driver/stand-in-claude:$PATH agent-director resume
   --claude-instance-id id-k7`.
8. `agent-director kill --claude-instance-id id-k7`.
9. `agent-director kill --include-finished --claude-instance-id id-k7`.
10. Check the session by `$N`, the `cat` pid, X's row, `get`, and the
    `ad.kill.called` trail lines for `id-k7`.

## Pass criteria

- The store id and the token are 16 lowercase hex; the label read back
  has five fields and equals the one set; X records no pid and its
  `ended_at` is earlier than the session's creation.
- resume exits 1; the last JSON line on stderr has `err_name`
  `ErrTmuxSessionConflict`, and its `err_description` contains
  `"cd-k7"` (quoted), "this row's own id", "bound of 60 s" and
  "Operator actions".
- kill without the option exits 0 with `kill_sent` false.
- kill with the option exits 1; the last JSON line on stderr has
  `err_name` `ErrTmuxSessionConflict`, and its `err_description`
  contains `"cd-k7"` (quoted), "never reported in", "this row's own
  id", "bound of 60 s" and "Operator actions".
- Neither refusal's description contains `tmux `, `kill-session`,
  `kill-pane`, `kill-server`, `agent-director kill` or
  `--include-finished`.
- After each of the three calls: `tmux has-session -t '<$N>'`
  succeeds, the `cat` pid still runs (present, not a zombie), X's row
  (`state`, `pid`, `pane_id`, `pane_pid`, `row_version`,
  `launch_token`, `ended_at`, `claude_session_id`, `jsonl_path`) is
  exactly as before the resume, and `get` shows `ended`.
- The trail has exactly two `ad.kill.called` lines for `id-k7`: the
  plain kill (`include_finished` false, outcome `ok`, `kill_sent`
  false, `lookup_outcome` `not_run`), then the opt-in kill
  (`include_finished` true, outcome `ErrTmuxSessionConflict`,
  `kill_sent` false, `lookup_outcome` `ours`).

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN
tmux set-environment -g -u ANTHROPIC_API_KEY 2>/dev/null || true
tmux set-environment -g -u CLAUDE_CODE_OAUTH_TOKEN 2>/dev/null || true

db="$HOME/.agent-director/state.db"
trail="$HOME/.agent-director/ad-trail.jsonl"
cfg="$HOME/.agent-director/config.toml"
standin_path="/opt/driver/stand-in-claude:$PATH"
id="id-k7"
name="cd-k7"
session_id="k7-session-uuid"
jsonl_dir="$HOME/.claude/projects/-tmp"
jsonl_path="$jsonl_dir/${session_id}.jsonl"
fail() { echo "FAIL: $*"; exit 1; }
last_json() { awk '/^\{/{ln=$0} END{print ln}' <<<"$1"; }
sid=""
trap 'rm -f "$cfg" "$jsonl_path"; [ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true' EXIT

# row_snapshot: every column no call of this case may change.
row_snapshot() {
    /opt/driver/sql.sh -readonly -separator '|' "$db" \
        "SELECT state, IFNULL(pid,''), IFNULL(pane_id,''), IFNULL(pane_pid,''),
                row_version, IFNULL(launch_token,''), IFNULL(ended_at,''),
                IFNULL(claude_session_id,''), IFNULL(jsonl_path,'')
         FROM spawns WHERE claude_instance_id = '$id';"
}

# refusal <what> <stderr> <want err_name> <want text>...: the last stderr JSON
# line names the error, its description holds every wanted text and names no
# session-ending command.
refusal() {
    local what="$1" err="$2" want_name="$3" envelope got desc w bad
    shift 3
    envelope="$(last_json "$err")"
    got="$(jq -r '.err_name' <<<"$envelope")"
    [ "$got" = "$want_name" ] || fail "$what: err_name=$got; want $want_name (stderr: $err)"
    desc="$(jq -r '.err_description' <<<"$envelope")"
    for w in "$@"; do
        case "$desc" in *"$w"*) ;; *) fail "$what: description lacks [$w]: $desc" ;; esac
    done
    for bad in "tmux " kill-session kill-pane kill-server "agent-director kill" --include-finished; do
        case "$desc" in *"$bad"*) fail "$what: description names [$bad]: $desc" ;; esac
    done
}

# untouched <what>: X's session and its pane process still run, X's row is
# exactly as before the resume, and get shows ended.
untouched() {
    local what="$1" st after state
    tmux has-session -t "$sid" 2>/dev/null || fail "session $sid ($name) is gone after $what"
    [ -e "/proc/$cat_pid" ] || fail "pane process $cat_pid is gone after $what"
    st="$(sed -E 's/^.*\) //' "/proc/$cat_pid/stat" | cut -d' ' -f1)"
    [ "$st" != "Z" ] || fail "pane process $cat_pid is a zombie after $what"
    after="$(row_snapshot)"
    [ "$after" = "$before" ] || fail "X's row changed on $what: [$before] -> [$after]"
    state="$(agent-director get --claude-instance-id "$id" | jq -r '.state')"
    [ "$state" = "ended" ] || fail "get shows state=$state after $what; want ended"
}

store_id="$(/opt/driver/sql.sh "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

read -r sid pane cat_pid created < <(tmux new-session -d -s "$name" -e AGENT_DIRECTOR_INSTANCE_ID="$id" \
    -P -F '#{session_id} #{pane_id} #{pane_pid} #{session_created}' -- cat)
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"
[[ "$pane" =~ ^%[0-9]+$ ]] || fail "new-session gave pane id [$pane]"
[[ "$cat_pid" =~ ^[0-9]+$ ]] && [[ "$created" =~ ^[0-9]+$ ]] \
    || fail "new-session gave pane pid [$cat_pid] and creation time [$created]"

# The transcript where resume looks, so its pre-flight passes.
mkdir -p "$jsonl_dir"
echo '{}' >"$jsonl_path"

seed_token="$(od -An -N8 -tx1 /dev/urandom | tr -dc '0-9a-f')"
/opt/driver/sql.sh "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, launch_token,
                       claude_session_id, jsonl_path)
   VALUES ('$id', 'ended', '/tmp', '$name', 'off', '$seed_token', '$session_id', '$jsonl_path');"
token="$(/opt/driver/sql.sh "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = '$id';")"
[[ "$token" =~ ^[0-9a-f]{16}$ ]] || fail "launch_token is not 16 lowercase hex: [$token]"

label="ad1 $token $sid $id $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
tmux set-option -p -t "$pane" @ad_pane "$token $pane"
got_label="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$got_label" = "$label" ] || fail "label read back [$got_label]; want [$label]"
read -r -a fields <<<"$got_label"
[ "${#fields[@]}" -eq 5 ] || fail "label has ${#fields[@]} fields; want 5: [$got_label]"

# ended_at 120 s back, set after the session exists, in the store's layout.
/opt/driver/sql.sh "$db" "UPDATE spawns SET ended_at = datetime('now', '-120 seconds') WHERE claude_instance_id = '$id';"
IFS='|' read -r pid ended_epoch < <(/opt/driver/sql.sh -readonly "$db" \
    "SELECT IFNULL(pid,'') || '|' || IFNULL(strftime('%s', ended_at),'') FROM spawns WHERE claude_instance_id = '$id';")
[ -z "$pid" ] || fail "X records pid [$pid]; want none (its agent never reported in)"
[[ "$ended_epoch" =~ ^[0-9]+$ ]] || fail "X's ended_at did not parse: [$ended_epoch]"
[ "$ended_epoch" -lt "$created" ] || fail "X's ended_at ($ended_epoch) is not before the session's creation ($created)"

# The starting-session bound at its safe minimum; the default (300 s) would
# keep the session "still starting".
mkdir -p "$HOME/.agent-director"
cat >"$cfg" <<'EOF'
[tmux]
starting_session_seconds = 60
EOF
while [ $(( $(date +%s) - created )) -lt 62 ]; do sleep 1; done

before="$(row_snapshot)"

# Step 7: resume answers the own-id conflict and launches nothing.
set +e
err="$(PATH="$standin_path" agent-director resume --claude-instance-id "$id" 2>&1 >/dev/null)"
code=$?
set -e
[ "$code" -eq 1 ] || fail "resume exited $code; want 1 (stderr: $err)"
refusal "resume" "$err" ErrTmuxSessionConflict "\"$name\"" "this row's own id" "bound of 60 s" "Operator actions"
untouched "the resume"

# Step 8: kill without the option is the finished row's no-op.
out="$(agent-director kill --claude-instance-id "$id")" || fail "kill without the option exited non-zero; want 0"
sent="$(jq -r '.kill_sent' <<<"$out")"
[ "$sent" = "false" ] || fail "kill without the option: kill_sent=$sent; want false (stdout: $out)"
untouched "the kill without the option"

# Step 9: the option refuses the session that never reported in.
set +e
err="$(agent-director kill --include-finished --claude-instance-id "$id" 2>&1 >/dev/null)"
code=$?
set -e
[ "$code" -eq 1 ] || fail "opt-in kill exited $code; want 1 (stderr: $err)"
refusal "opt-in kill" "$err" ErrTmuxSessionConflict "\"$name\"" "never reported in" "this row's own id" "bound of 60 s" "Operator actions"
untouched "the opt-in kill"

# The trail: the plain kill made no lookup; the opt-in kill found Ours and sent nothing.
lines="$(jq -rR 'fromjson? | select(.event == "ad.kill.called" and .claude_instance_id == "id-k7")
    | [.include_finished, .outcome, .kill_sent, .lookup_outcome] | map(tostring) | join(" ")' "$trail")"
n="$(grep -c . <<<"$lines" || true)"
[ "$n" -eq 2 ] || fail "want 2 ad.kill.called lines for $id; got $n: [$lines]"
first="$(head -n 1 <<<"$lines")"
second="$(tail -n 1 <<<"$lines")"
[ "$first" = "false ok false not_run" ] || fail "plain kill trail [$first]; want [false ok false not_run]"
[ "$second" = "true ErrTmuxSessionConflict false ours" ] \
    || fail "opt-in kill trail [$second]; want [true ErrTmuxSessionConflict false ours]"

echo "kill-7 ok: never-reported-in own session $sid ($name) at the configured 60 s bound: resume ErrTmuxSessionConflict (own id), plain kill kill_sent false, opt-in kill ErrTmuxSessionConflict (never reported in); session and cat $cat_pid still run; X still ended, row unchanged"
```
