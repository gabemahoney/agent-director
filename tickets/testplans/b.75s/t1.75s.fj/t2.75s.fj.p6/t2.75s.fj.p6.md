# discover-11: a Stop snapshot creates an unseen background subagent, closes it when it drops out, and a real stop overrides it

Maps to Epic `t1.f5h.59` AC 2 (case (d)) (SRD `t1.xjn.du` SR-15.7 (d),
SR-7.4 to SR-7.6, SR-6.3, SR-5.1, SR-5.2, N3, N4, N13). X is spawned for
real and reports in (a SessionStart `startup` typed into its pane), then its
own pane process delivers main-agent Stop hooks whose `background_tasks`
list the running background subagents, and one SubagentStop.
`list-subagents` reads the record after each step. A hook applies only from
the row's own pane process (SR-22.9), so each is typed with
`/opt/driver/pane-hook.sh`.

- A main-agent Stop that lists a subagent id agent-director has never seen
  creates its record: `running`, `run_mode` `background`, `subagent_type`
  the listing's `agent_type`, and `description`, `first_started_at` and
  `started_at` null (a missed launch has no start event and no launch result
  yet).
- A Stop more than 2 s later whose `background_tasks` is `[]` turns it
  `lost` with `close_reason` `absent_from_snapshot` and `lost_at` set. The
  record was opened by the first Stop at its receipt, and the grace is
  measured from receipt times (the real hook start), so the case sleeps 3 s
  between the two Stops.
- That id's SubagentStop makes it `stopped` with `close_reason`
  `stop_event`, `stopped_at` set and `lost_at` null: a real stop overrides
  an inferred `lost`.
- A later Stop listing the id again leaves it `stopped`, with `stopped_at`
  unchanged: a snapshot never reopens a record.

## Setup

Per-case DB-reset. The spawn runs with
`PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the `agent-director`
command, so X's pane process is the stand-in claude's interactive bash,
which sends no hook by itself. The payloads are minimal: `hook_event_name`
and the SR-5.1 fields of each step (`session_id` for the Stop, `agent_id`
for the SubagentStop, and the `background_tasks` array), and no content: a
listed entry carries only `type`, `status`, `id` and `agent_type`. The store
is read only through `list-subagents` (at the path the build uses, never a
hard-coded one); the case runs no SQL and names no schema version. The case
starts a real tmux session; the DB-reset fixture ends it.

## Steps

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --agent claude --cwd /tmp`
   → X. Type a SessionStart (`source` `startup`) into X's pane. X is
   `waiting`; `list-subagents` reads `{"tracked":true,"subagents":[]}`.
2. Type a main-agent Stop (`session_id` `d11-sess`) with `background_tasks`
   `[{"type":"subagent","status":"running","id":"d11-sub-x","agent_type":"Explore"}]`.
   `list-subagents` shows exactly one record, `d11-sub-x`, with the fields
   above.
3. Sleep 3 s, then type a Stop with `"background_tasks":[]`. The record is
   `lost` with `close_reason` `absent_from_snapshot` and `lost_at` set;
   `stopped_at` is null; `run_mode` is still `background`.
4. Type a SubagentStop for `d11-sub-x`. The record is `stopped`,
   `close_reason` `stop_event`, `stopped_at` set, `lost_at` null.
5. Type a Stop listing `d11-sub-x` again as running. The record is
   `stopped` still; its `close_reason`, `stopped_at`, `lost_at` and
   `started_at` equal those after step 4; still one record.

## Pass criteria

- Every hook exits 0 with empty stdout.
- After step 1: `tracked` true, no record.
- After step 2: `tracked` true and one record: `subagent_id` `d11-sub-x`,
  `instance_id` X, `state` `running`, `run_mode` `background`,
  `subagent_type` `Explore`, `session_id` `d11-sess`, `description`,
  `first_started_at`, `started_at`, `model`, `parent_type`, `parent_id`,
  `tool_use_id`, `close_reason`, `stopped_at` and `lost_at` null.
- After step 3: `state` `lost`, `close_reason` `absent_from_snapshot`,
  `lost_at` a time, `stopped_at` null, `run_mode` `background`,
  `description`, `first_started_at` and `started_at` still null.
- After step 4: `state` `stopped`, `close_reason` `stop_event`,
  `stopped_at` a time, `lost_at` null.
- After step 5: `state` `stopped`, `close_reason` `stop_event`,
  `stopped_at` equal to its value after step 4, `lost_at` null, one record.

## Script

```bash
set -euo pipefail
fail() { echo "FAIL: $*"; exit 1; }
id="$(PATH="/opt/driver/stand-in-claude:$PATH" agent-director spawn --agent claude --cwd /tmp | jq -r '.instance_id')"
test -n "$id" || fail "spawn returned no instance_id"

# hook <label> <payload>: type it into X's own pane; exit 0 and empty stdout.
hook() {
    local out
    out="$(/opt/driver/pane-hook.sh "$id" "$2")" || fail "[$1] hook exited non-zero"
    test -z "$out" || fail "[$1] hook stdout = $out; want empty"
}
subs() { agent-director list-subagents --instance-id "$id"; }
# check <label> <field summary> <jq filter>: the filter must be true of list-subagents' output.
check() {
    local got
    got="$(subs)"
    jq -e "$3" <<<"$got" >/dev/null || fail "[$1] list-subagents = $got; want $2"
}
# field <jq path under the one record>: its value as compact JSON.
field() { subs | jq -c ".subagents[0]$1"; }
null_launch_fields='[.description, .model, .parent_type, .parent_id, .tool_use_id] | all(. == null)'
listing_x='{"type":"subagent","status":"running","id":"d11-sub-x","agent_type":"Explore"}'

# 1. X reports in; nothing is recorded.
hook session-start '{"hook_event_name":"SessionStart","source":"startup","transcript_path":"/x/d11-session.jsonl"}'
state="$(agent-director status --instance-id "$id" | jq -r '.state')"
test "$state" = "waiting" || fail "after SessionStart state=$state; want waiting"
check after-session-start 'tracked true and no record' '.tracked == true and .subagents == []'

# 2. A Stop lists a subagent never seen: a running background record, no times, no description.
hook stop-lists-x '{"hook_event_name":"Stop","session_id":"d11-sess","background_tasks":['"$listing_x"']}'
check after-stop-lists-x "one record d11-sub-x: running, run_mode background, subagent_type Explore, session_id d11-sess, description/first_started_at/started_at/model/parent/tool_use_id/close_reason/stopped_at/lost_at null" \
    ".tracked == true and (.subagents | length) == 1 and (.subagents[0]
    | .subagent_id == \"d11-sub-x\" and .instance_id == \"$id\" and .state == \"running\"
      and .run_mode == \"background\" and .subagent_type == \"Explore\" and .session_id == \"d11-sess\"
      and .first_started_at == null and .started_at == null
      and .close_reason == null and .stopped_at == null and .lost_at == null
      and ($null_launch_fields))"

# 3. More than 2 s later a Stop omits it: lost, absent_from_snapshot, lost_at set.
sleep 3
hook stop-empty '{"hook_event_name":"Stop","session_id":"d11-sess","background_tasks":[]}'
check after-stop-empty "one record: lost, close_reason absent_from_snapshot, lost_at a time, stopped_at null, run_mode background, first_started_at/started_at/description null" \
    ".tracked == true and (.subagents | length) == 1 and (.subagents[0]
    | .subagent_id == \"d11-sub-x\" and .state == \"lost\" and .close_reason == \"absent_from_snapshot\"
      and (.lost_at | type) == \"string\" and .stopped_at == null and .run_mode == \"background\"
      and .first_started_at == null and .started_at == null and .description == null)"

# 4. Its SubagentStop is the real stop: stopped, stop_event, stopped_at set, lost_at cleared.
hook subagent-stop-x '{"hook_event_name":"SubagentStop","agent_id":"d11-sub-x"}'
check after-subagent-stop-x "one record: stopped, close_reason stop_event, stopped_at a time, lost_at null" \
    ".tracked == true and (.subagents | length) == 1 and (.subagents[0]
    | .subagent_id == \"d11-sub-x\" and .state == \"stopped\" and .close_reason == \"stop_event\"
      and (.stopped_at | type) == \"string\" and .lost_at == null)"
before="$(field ' | [.state, .close_reason, .stopped_at, .lost_at, .started_at]')"

# 5. A later Stop lists it again: it stays stopped and no field moves.
hook stop-lists-x-again '{"hook_event_name":"Stop","session_id":"d11-sess","background_tasks":['"$listing_x"']}'
check after-stop-lists-x-again "one record, stopped" '.tracked == true and (.subagents | length) == 1 and .subagents[0].state == "stopped"'
after="$(field ' | [.state, .close_reason, .stopped_at, .lost_at, .started_at]')"
test "$after" = "$before" || fail "[stop-lists-x-again] [state, close_reason, stopped_at, lost_at, started_at] changed: $before -> $after; want unchanged"

echo "discover-11 ok: id=$id; a Stop listing unseen d11-sub-x created it running/background/Explore with no description or start times; a Stop 3 s later with background_tasks [] made it lost (absent_from_snapshot, lost_at set); its SubagentStop made it stopped (stop_event, lost_at null); a later Stop listing it left it stopped with stopped_at $(jq -r '.[2]' <<<"$after") unchanged"
```
