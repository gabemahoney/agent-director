# interact-8: send-keys with relay_mode=on + check_permission → ErrSendKeysWhileRelayed

Per SRD §4.3: when a Spawn is sitting on a relayed permission prompt
(`relay_mode=on` AND `state=check_permission`), the permission relay
(Epic 10) owns the modal answer. A pane-side send-keys would race the
decide() write. Epic 4 stubs this guard so the precondition is correct
from day one — the actual relay path activates in Epic 10.

Revised by Epic 11 (`t1.h98.m6`, Task `t2.h98.m6.bh`; SR-3.4, SR-3.6,
SR-20.9): `send-keys` finds the row's session only by its `@ad_owner`
label (one lookup, one pane listing) and sends to the agent's pane by
pane id, never `name:0.0` or an unlabelled session. The negative
control's session is made by hand, so it is seeded like interact-1
(`t2.75s.9x.if`) and kill-1 (`t2.75s.ks.3h`): the row has a launch
token and records no socket, server, pid or pane; the session carries
the five-field label `ad1 <token> <$N> id-i8 <store id>` and the
agent's pane carries `@ad_pane` `<token> <%N>`. Window 0 pane 0 is an
unlabelled decoy `cat` holding `DECOY-i8`; the agent's `cat` pane is
split off it and is the only one with `@ad_pane`, so a send to
`cd-i8:0.0` would land in the decoy.

## Setup

Per-case DB-reset has wiped `~/.agent-director/state.db` and killed
`cd-*` sessions; the store exists after the reset, so its id can be
read from `store_meta`. The container has `agent-director`, `tmux`,
`sqlite3`, and `jq` on PATH. An EXIT trap removes the session by its
session id if the case fails part-way.

## Steps

1. Seed `spawns` row `id-i8` at state `check_permission` with
   `relay_mode=on`, `tmux_session_name=cd-i8` and a `launch_token` of
   16 lowercase hex characters (read back with `sqlite3`). Make session
   `cd-i8` (`-e AGENT_DIRECTOR_INSTANCE_ID=id-i8`) whose window 0 pane 0
   is the decoy `cat` holding `DECOY-i8`, split the agent's `cat` pane
   off it, then label the session (`@ad_owner` `ad1 <token> <$N> id-i8
   <store id>`, read back) and the agent's pane (`@ad_pane`
   `<token> <%N>`).
2. `agent-director send-keys --claude-instance-id id-i8 --text "1"` →
   non-zero exit; `err_name=ErrSendKeysWhileRelayed`.
3. (Negative control) Update the row to `relay_mode=off`. Re-run
   send-keys (`--text "i8-relay-off"`) against the labelled session —
   succeeds and delivers into the agent's pane by pane id.

## Pass criteria

- The store id and the token are 16 lowercase hex; the label read back
  has five fields and equals the one set.
- Step 2 non-zero exit with the relay guard envelope.
- Step 3 exit 0; empty `{}` on stdout; `i8-relay-off` appears in the
  agent's pane `<%N>` and not in the decoy pane; the row now records
  the agent's pane (`pane_id` = `<%N>`, found through `@ad_pane`).
- Step 3 proves the guard is conditional on relay_mode, not on the
  state alone.

## Script

```bash
set -euo pipefail
db="$HOME/.agent-director/state.db"
fail() { echo "FAIL: $*"; exit 1; }
sid=""
stderr_file="$(mktemp)"
trap 'rm -f "$stderr_file"; [ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true' EXIT

store_id="$(sqlite3 "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

seed_token="$(od -An -N8 -tx1 /dev/urandom | tr -dc '0-9a-f')"
sqlite3 "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, launch_token)
   VALUES ('id-i8', 'check_permission', '/tmp', 'cd-i8', 'on', '$seed_token');"
token="$(sqlite3 "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-i8';")"
[[ "$token" =~ ^[0-9a-f]{16}$ ]] || fail "launch_token is not 16 lowercase hex: [$token]"

read -r sid decoy < <(tmux new-session -d -s cd-i8 -e AGENT_DIRECTOR_INSTANCE_ID=id-i8 \
    -P -F '#{session_id} #{pane_id}' -- cat)
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"
[[ "$decoy" =~ ^%[0-9]+$ ]] || fail "new-session gave pane id [$decoy]"
tmux send-keys -t "$decoy" -l 'DECOY-i8'
tmux send-keys -t "$decoy" Enter
pane="$(tmux split-window -d -t "$sid" -P -F '#{pane_id}' -- cat)"
[[ "$pane" =~ ^%[0-9]+$ ]] || fail "split-window gave pane id [$pane]"
[ "$pane" != "$decoy" ] || fail "agent pane equals decoy pane $pane"

label="ad1 $token $sid id-i8 $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
tmux set-option -p -t "$pane" @ad_pane "$token $pane"
got_label="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$got_label" = "$label" ] || fail "label read back [$got_label]; want [$label]"
read -r -a fields <<<"$got_label"
[ "${#fields[@]}" -eq 5 ] || fail "label has ${#fields[@]} fields; want 5: [$got_label]"

# Step 2: relay guard refuses under relay_mode=on + check_permission.
if agent-director send-keys --claude-instance-id id-i8 --text "1" 2>"$stderr_file"; then
    fail "send-keys unexpectedly succeeded with relay_mode=on"
fi
err_name="$(jq -r '.err_name' <"$stderr_file")"
[ "$err_name" = "ErrSendKeysWhileRelayed" ] || fail "relay_mode=on err_name [$err_name]; want ErrSendKeysWhileRelayed"

# Step 3 (negative control): relay_mode=off with the same state delivers by pane id.
sqlite3 "$db" "UPDATE spawns SET relay_mode='off' WHERE claude_instance_id='id-i8';"
out="$(agent-director send-keys --claude-instance-id id-i8 --text 'i8-relay-off')" || fail "send-keys exited non-zero with relay_mode=off"
[ "$(echo "$out" | jq -c '.')" = "{}" ] || fail "send-keys stdout [$out]; want {}"
for _ in $(seq 1 50); do
    tmux capture-pane -p -t "$pane" | grep -q 'i8-relay-off' && break
    sleep 0.1
done
tmux capture-pane -p -t "$pane" | grep -q 'i8-relay-off' || fail "i8-relay-off never reached agent pane $pane"
if tmux capture-pane -p -t "$decoy" | grep -q 'i8-relay-off'; then
    fail "send-keys typed into the decoy pane $decoy (name:0.0), not the agent's pane $pane"
fi
row_pane="$(sqlite3 "$db" "SELECT COALESCE(pane_id, '') FROM spawns WHERE claude_instance_id = 'id-i8';")"
[ "$row_pane" = "$pane" ] || fail "row pane_id [$row_pane]; want the agent pane $pane"
echo "interact-8 ok: relay guard fires under on; clears under off; delivered to agent pane $pane by id (decoy $decoy untouched); row records $row_pane"
```
