# spawn-13: a `\` in an explicit session name is rejected

Maps to Epic `t1.h98.cu` (Plan `b.h98`), scope "Names" and Docker case
spawn-13 (SRD SR-9.2; AC-SPN-01). tmux cannot match such a name exactly,
because a backslash goes through tmux's escaping. `spawn` must refuse
such a name with `ErrTmuxSessionNameInvalid` before it creates a row or
a session.

## Setup

Per-case DB-reset has wiped `~/.agent-director/state.db` and ended every
tmux server. The container has `agent-director`, `tmux`, `sqlite3` and
`jq` on PATH. The name used here does not start with `cd-`. The script
records the live session ids first and, on exit, kills any session
that was not there before (by its `$N` id, never by name), so a stray
session does not wait for the next reset.

## Steps

1. Record the live tmux session ids.
2. `agent-director spawn --cwd /tmp --tmux-session-name 'sp13-a\b'`
   (single-quoted, so the shell passes `\` literally).
3. Read the last JSON line on stderr.
4. `agent-director list`, and count rows in the `spawns` table.
5. Read the live tmux sessions again.

## Pass criteria

- Step 2 exits non-zero.
- Step 3: `err_name == "ErrTmuxSessionNameInvalid"`.
- Step 4: `list` gives `.spawns | length == 0`, and
  `SELECT COUNT(*) FROM spawns` is `0`.
- Step 5: no session is named `sp13-a\b`, and the session ids equal
  the step 1 ids.

## Script

```bash
set -euo pipefail

name='sp13-a\b'

session_ids() {
    tmux ls -F '#{session_id}' 2>/dev/null || true
}
session_names() {
    tmux ls -F '#{session_name}' 2>/dev/null || true
}
before="$(session_ids)"
cleanup() {
    local sid
    for sid in $(session_ids); do
        case " $(printf '%s ' $before)" in
            *" $sid "*) ;;
            *) tmux kill-session -t "$sid" 2>/dev/null || true ;;
        esac
    done
}
trap cleanup EXIT

set +e
err="$(agent-director spawn --cwd /tmp --tmux-session-name "$name" 2>&1 >/dev/null)"
code=$?
set -e
if [ "$code" -eq 0 ]; then
    echo "FAIL: spawn accepted the name $name" >&2
    exit 1
fi

envelope="$(printf '%s
' "$err" | awk '/^\{/{ln=$0} END{print ln}')"
got="$(printf '%s' "$envelope" | jq -r '.err_name')"
if [ "$got" != "ErrTmuxSessionNameInvalid" ]; then
    echo "FAIL: err_name=$got; stderr: $err" >&2
    exit 1
fi

n_list="$(agent-director list | jq '.spawns | length')"
test "$n_list" = "0"
n_db="$(/opt/driver/sql.sh "$HOME/.agent-director/state.db" 'SELECT COUNT(*) FROM spawns;')"
test "$n_db" = "0"

# ENVIRON, not awk -v: -v would turn a backslash into an escape.
if session_names | N="$name" awk '$0 == ENVIRON["N"] {f = 1} END {exit !f}'; then
    echo "FAIL: a tmux session named $name exists" >&2
    exit 1
fi
after="$(session_ids)"
if [ "$after" != "$before" ]; then
    echo "FAIL: tmux sessions changed; before=[$before] after=[$after]" >&2
    exit 1
fi

echo "spawn-13 ok: name $name -> ErrTmuxSessionNameInvalid; no row; no session"
```
