# resume-10: history by life holds when the reuse moves --cwd or CLAUDE_CONFIG_DIR

Maps to SRD SR-20.9 resume-10 (history by life, FR S1; PRD AC-REUSE-22),
SR-8.7 and SR-10.3 (Epic 17 `t1.h98.i4`, Task `t2.h98.i4.tm`, Subtask
`t3.h98.i4.tm.pm`; spec `t3.h98.i4.y9.2k`). The same as resume-9, but the
reuse moves the place `resume` looks for transcripts: variant A passes a
different `--cwd`, variant B a fresh `CLAUDE_CONFIG_DIR` through
`--extra-env`. S1's transcript is on disk both where the first life wrote
it and where the moved cwd or config dir would put it (named for S1 only,
so S2 stays never written). `resume` reads only the current life's
history, so it returns `ErrJsonlNeverWritten` and creates no session: no
create, and no `--resume` of S1.

Agent and hooks (SR-20.9, SR-22.9; collector "Driver mode"): every spawn,
reuse and `resume` runs with `PATH=/opt/driver/stand-in-claude:$PATH`
prefixed, so each pane process is the stand-in's interactive bash, which
sends no hook by itself. Every hook is typed into the launch's recorded
pane with `/opt/driver/pane-hook.sh <id> '<payload>'`; none is piped from
the case's own shell. The reuse's `pending` row takes S2's SessionStart
from its own pane (AC-HOOK-02, reuse half).

Credential isolation (Epic 10's kill-10 pattern), before any tmux or
agent-director call: `ANTHROPIC_API_KEY` and `CLAUDE_CODE_OAUTH_TOKEN` are
unset and removed from the tmux server's global environment (tolerating no
server); after every launch, neither appears in
`/proc/<recorded pane_pid>/environ` ("credentials reached the agent").

Pre-trust: variant B's reuse resolves `.claude.json` under its fresh
`CLAUDE_CONFIG_DIR`, where none exists, so it reports `pre_trust`
`failed` and prints a soft-warning line on stderr; the launch proceeds.
The case does not assert `pre_trust`.

## Setup

Per-case DB-reset. Each variant has its own id (`r10a-<uuid>`,
`r10b-<uuid>`; the trail is not reset between cases, so records are
selected by id) and its own session name (`cd-r10a`, `cd-r10b`), swept by
the reset. An EXIT trap ends any session the case made by its session id
and removes every transcript and directory it created (the moved cwd under
`/tmp`, the fresh config dir under `/tmp`, and the S1 copy under
`$HOME/.claude/projects/<slug of the moved cwd>/`). Session ids carry a
per-run tag: `r10a-s1-<tag>` and so on.

Credential isolation as above, once, before anything else.

## Steps (each variant)

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd /tmp
   --tmux-session-name <name> --claude-instance-id X` → exit 0; check the
   pane environ.
2. Seed S1's transcript `$HOME/.claude/projects/-tmp/<S1>.jsonl`; type a
   SessionStart with that path into X's pane (`waiting`, S1, `pid` =
   `pane_pid`, `jsonl_path` S1's file), then a SessionEnd (`ended`).
3. End X's session by its `$N` and wait (bounded, 5 s) for its recorded
   `pid`, `pane_pid` and, when it was the server's last session,
   `tmux_server_pid` to exit (resume-1's wait).
4. Spawn again with the same id, opting in to reuse (`--reuse-finished`):
   - A: `--cwd <new dir>` (a fresh directory under `/tmp`); S1's second
     copy goes to `$HOME/.claude/projects/<slug of the new dir's canonical
     path>/<S1>.jsonl` (every character outside `[A-Za-z0-9-]` becomes
     `-`), and S2's path is `<that dir>/<S2>.jsonl`.
   - B: `--cwd /tmp --extra-env CLAUDE_CONFIG_DIR=<fresh dir>`; S1's second
     copy goes to `<fresh dir>/projects/-tmp/<S1>.jsonl`, and S2's path is
     `<fresh dir>/projects/-tmp/<S2>.jsonl`.
   → exit 0, echoes X; check the new pane environ. `get` shows `pending`
   and `prior_sessions` `[]`; A's `cwd` is the new dir's canonical path;
   B's `extra_env` (`sqlite3`) has `CLAUDE_CONFIG_DIR` = the fresh dir.
5. Type a SessionStart with S2's path (never written) into the new pane
   (`waiting`, S2, `pid` = the new `pane_pid`, `jsonl_path` NULL), then a
   SessionEnd (`ended`).
6. End the reused launch's session by its `$N` and wait as in step 3.
   Capture the session ids on X's socket.
7. `PATH=/opt/driver/stand-in-claude:$PATH agent-director resume
   --claude-instance-id X` → exit 1, `err_name` `ErrJsonlNeverWritten`.
8. Check S1's two copies, the sessions on X's socket, every process's
   command line, the trail and `get` X.

## Pass criteria

- Steps 1-6 hold as stated for both variants, with no credentials in any
  launch's pane environ.
- Step 7: exit 1 and `ErrJsonlNeverWritten` in both variants.
- Step 8: both copies of S1's transcript are on disk; no session on X's
  socket carries X's name and the session id set equals the capture (no
  session created); no process's command line has `--resume` with S1; the
  trail holds no `ad.resume.*` record for X; `get` shows `ended`,
  `transcript_status` `never_written` and `prior_sessions` `[]`.

Each failed check prints a `FAIL:` line naming the variant, what was
expected and what was seen; the final line summarises what was checked.

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN
tmux set-environment -g -u ANTHROPIC_API_KEY 2>/dev/null || true
tmux set-environment -g -u CLAUDE_CODE_OAUTH_TOKEN 2>/dev/null || true

db="$HOME/.agent-director/state.db"
trail="$HOME/.agent-director/ad-trail.jsonl"
standin_path="/opt/driver/stand-in-claude:$PATH"
projects="$HOME/.claude/projects"
jsonl_dir="$projects/-tmp"
uuid="$(cat /proc/sys/kernel/random/uuid)"
tag="${uuid:0:8}"
err_file="$(mktemp)"
sock=""
sid=""
v=""
rm_files=()
rm_dirs=()
fail() { echo "FAIL: ${v:+[$v] }$*"; exit 1; }
cleanup() {
    [ -z "$sid" ] || tmux ${sock:+-S "$sock"} kill-session -t "$sid" 2>/dev/null || true
    rm -f "$err_file" ${rm_files[@]+"${rm_files[@]}"}
    rm -rf ${rm_dirs[@]+"${rm_dirs[@]}"}
}
trap cleanup EXIT

# end_and_wait <id> <tmux target>: ends the row's tmux session, then waits
# (bounded, 5 s) until the processes the row records have exited (no /proc
# entry): its pid and pane_pid, and its tmux_server_pid when the session was
# the server's last. A server that holds other sessions must still run after.
end_and_wait() {
    local id="$1" target="$2" rec rpid rpane rserver rsock n left p end
    rec="$(/opt/driver/sql.sh -readonly "$db" "SELECT IFNULL(pid,'') || '|' || IFNULL(pane_pid,'') || '|' || IFNULL(tmux_server_pid,'') || '|' || IFNULL(tmux_socket,'') FROM spawns WHERE claude_instance_id = '$id';")"
    IFS='|' read -r rpid rpane rserver rsock <<<"$rec"
    [[ "$rpid|$rpane|$rserver" =~ ^[0-9]+\|[0-9]+\|[0-9]+$ ]] || fail "$id records pid|pane_pid|tmux_server_pid [$rpid|$rpane|$rserver]; want all set"
    n="$(tmux ${rsock:+-S "$rsock"} list-sessions 2>/dev/null | wc -l)"
    tmux ${rsock:+-S "$rsock"} kill-session -t "$target" || fail "kill-session -t $target of $id failed"
    set -- "$rpid" "$rpane"
    [ "$n" -gt 1 ] || set -- "$@" "$rserver"
    end=$(( $(date +%s%N) + 5000000000 ))
    while :; do
        left=""
        for p in "$@"; do [ ! -e "/proc/$p" ] || left+=" $p"; done
        [ -n "$left" ] || break
        [ "$(date +%s%N)" -lt "$end" ] || fail "$id's recorded process(es)$left still running 5 s after its session $target ended"
        sleep 0.1
    done
    [ "$n" -le 1 ] || [ -e "/proc/$rserver" ] || fail "tmux server $rserver of $id ended although it held $((n - 1)) other session(s)"
}
row_field() { /opt/driver/sql.sh -readonly "$db" "SELECT IFNULL($2,'') FROM spawns WHERE claude_instance_id = '$1';"; }
no_creds() {
    local e
    for e in ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN; do
        if grep -qz "^$e=" "/proc/$1/environ"; then
            fail "credentials reached the agent: $e is in /proc/$1/environ ($2)"
        fi
    done
}
hook() { /opt/driver/pane-hook.sh "$1" "$2" >/dev/null || fail "hook $2 for $1 exited non-zero"; }
session_start() { printf '{"hook_event_name":"SessionStart","source":"startup","transcript_path":"%s"}' "$1"; }
session_end='{"hook_event_name":"SessionEnd","reason":"logout"}'
last_json() { printf '%s' "$1" | awk '/^\{/{ln=$0} END{print ln}'; }
session_set() { { tmux ${sock:+-S "$sock"} list-sessions -F '#{session_id}' 2>/dev/null || true; } | sort; }
session_names() { tmux ${sock:+-S "$sock"} list-sessions -F '#{session_name}' 2>/dev/null || true; }
slug() { printf '%s' "$1" | sed 's/[^A-Za-z0-9-]/-/g'; }
# spawn_x <args...>: a stand-in spawn of X; stdout in $out, stderr in $err_file, exit status in $rc.
spawn_x() {
    set +e
    out="$(PATH="$standin_path" agent-director spawn --claude-instance-id "$x" "$@" 2>"$err_file")"
    rc=$?
    set -e
}
# launched <what>: reads X's socket, pane, pane_pid and the pane's session id
# into sock, pane, pane_pid and sid, and checks the pane environment.
launched() {
    sock="$(row_field "$x" tmux_socket)"
    pane="$(row_field "$x" pane_id)"
    pane_pid="$(row_field "$x" pane_pid)"
    [ -n "$pane" ] && [[ "$pane_pid" =~ ^[0-9]+$ ]] || fail "X after $1 records pane_id|pane_pid [$pane|$pane_pid]; want both set"
    sid="$(tmux ${sock:+-S "$sock"} display-message -p -t "$pane" '#{session_id}')"
    [[ "$sid" =~ ^\$[0-9]+$ ]] || fail "X's pane $pane after $1 gave session id [$sid]"
    no_creds "$pane_pid" "X after $1"
}
# start_end <session> <transcript> <want jsonl_path>: SessionStart then SessionEnd typed into X's pane.
start_end() {
    local got
    hook "$x" "$(session_start "$2")"
    got="$(/opt/driver/sql.sh -readonly "$db" "SELECT state || '|' || IFNULL(claude_session_id,'') || '|' || IFNULL(pid,'') || '|' || IFNULL(jsonl_path,'NULL') FROM spawns WHERE claude_instance_id = '$x';")"
    [ "$got" = "waiting|$1|$pane_pid|$3" ] || fail "X after SessionStart [state|session|pid|jsonl_path]=[$got]; want [waiting|$1|$pane_pid|$3]"
    hook "$x" "$session_end"
    got="$(row_field "$x" state)"
    [ "$got" = "ended" ] || fail "X after SessionEnd state=$got; want ended"
}
# no_resume_of <session>: no process's command line has --resume with the session.
no_resume_of() {
    local f c
    for f in /proc/[0-9]*/cmdline; do
        c="$( { tr '\0' ' ' < "$f"; } 2>/dev/null )" || continue
        case "$c" in
            *--resume*"$1"*) fail "a process was started with --resume naming $1: [$c] ($f)" ;;
        esac
    done
}

# variant <A|B>: the whole resume-9 flow with the reuse moving the cwd (A) or
# the config dir (B).
variant() {
    v="$1"
    local lc name s1 s2 s1_home s1_moved s2_file new_dir canon moved_dir got set_before set_after n life0 life1
    lc="$(printf '%s' "$v" | tr 'A-Z' 'a-z')"
    x="r10$lc-$(cat /proc/sys/kernel/random/uuid)"
    name="cd-r10$lc"
    s1="r10$lc-s1-$tag"
    s2="r10$lc-s2-$tag"
    s1_home="$jsonl_dir/$s1.jsonl"
    rm_files+=("$s1_home")

    # Steps 1-2: first life, S1 on disk where it writes it.
    spawn_x --cwd /tmp --tmux-session-name "$name"
    [ "$rc" -eq 0 ] || fail "spawn of X exited $rc; want 0: $(cat "$err_file")"
    [ "$(jq -r '.claude_instance_id' <<<"$out")" = "$x" ] || fail "spawn of X echoed [$out]; want id $x"
    launched spawn
    echo '{}' > "$s1_home"
    start_end "$s1" "$s1_home" "$s1_home"

    # Step 3: end the first launch's session by its $N; wait for its processes.
    end_and_wait "$x" "$sid"
    sid=""
    life0="$(row_field "$x" life_number)"
    [[ "$life0" =~ ^[0-9]+$ ]] || fail "X's life_number [$life0]; want a number"

    # Step 4: spawn again with the same id, opting in to reuse, moving the cwd or the config dir.
    new_dir="$(mktemp -d "/tmp/r10$lc-dir.XXXXXX")"
    rm_dirs+=("$new_dir")
    if [ "$v" = A ]; then
        canon="$(cd "$new_dir" && pwd -P)"
        moved_dir="$projects/$(slug "$canon")"
        rm_dirs+=("$moved_dir")
        spawn_x --cwd "$new_dir" --tmux-session-name "$name" --reuse-finished
    else
        canon="$(cd /tmp && pwd -P)"
        moved_dir="$new_dir/projects/-tmp"
        spawn_x --cwd /tmp --tmux-session-name "$name" --reuse-finished --extra-env "CLAUDE_CONFIG_DIR=$new_dir"
    fi
    [ "$rc" -eq 0 ] || fail "spawn --reuse-finished of ended X exited $rc; want 0: $(cat "$err_file")"
    [ "$(jq -r '.claude_instance_id' <<<"$out")" = "$x" ] || fail "spawn --reuse-finished echoed [$out]; want id $x"
    launched reuse
    s1_moved="$moved_dir/$s1.jsonl"
    s2_file="$moved_dir/$s2.jsonl"
    mkdir -p "$moved_dir"
    echo '{}' > "$s1_moved"
    got="$(agent-director get --claude-instance-id "$x" | jq -r '[.state, .cwd, (.prior_sessions | tojson)] | join("|")')"
    [ "$got" = "pending|$canon|[]" ] || fail "get after reuse [state|cwd|prior_sessions]=[$got]; want [pending|$canon|[]]"
    life1="$(row_field "$x" life_number)"
    [ "$life1" -eq $((life0 + 1)) ] || fail "life_number after reuse=$life1; want $((life0 + 1))"
    if [ "$v" = B ]; then
        got="$(row_field "$x" extra_env | jq -r '.CLAUDE_CONFIG_DIR // "absent"')"
        [ "$got" = "$new_dir" ] || fail "reused X's extra_env CLAUDE_CONFIG_DIR=[$got]; want [$new_dir]"
    fi

    # Step 5: S2 (never written) reported from the reused pane, then SessionEnd.
    [ ! -e "$s2_file" ] || fail "S2's transcript $s2_file exists before its SessionStart"
    start_end "$s2" "$s2_file" NULL

    # Step 6: end the reused launch's session by its $N; wait for its processes.
    end_and_wait "$x" "$sid"
    sid=""
    set_before="$(session_set)"

    # Step 7: resume finds no transcript in the current life.
    set +e
    PATH="$standin_path" agent-director resume --claude-instance-id "$x" >/dev/null 2>"$err_file"
    rc=$?
    set -e
    [ "$rc" -eq 1 ] || fail "resume of X exited $rc; want 1: $(cat "$err_file")"
    got="$(last_json "$(cat "$err_file")" | jq -r '.err_name')"
    [ "$got" = "ErrJsonlNeverWritten" ] || fail "resume err_name=[$got]; want ErrJsonlNeverWritten: $(cat "$err_file")"

    # Step 8: S1 is on disk at both places, yet nothing was launched.
    [ -f "$s1_home" ] || fail "S1's transcript $s1_home is gone; want it on disk"
    [ -f "$s1_moved" ] || fail "S1's copy $s1_moved is gone; want it on disk"
    [ ! -e "$s2_file" ] || fail "S2's transcript $s2_file exists; want it never written"
    if session_names | grep -qxF "$name"; then
        fail "a session named $name runs on X's socket after the refused resume"
    fi
    set_after="$(session_set)"
    [ "$set_after" = "$set_before" ] || fail "tmux session set changed on the refused resume: [$set_after]; was [$set_before]"
    no_resume_of "$s1"
    if [ -f "$trail" ]; then
        n="$(jq -c --arg x "$x" 'select(.claude_instance_id == $x and (.event | startswith("ad.resume.")))' "$trail" | grep -c . || true)"
        [ "$n" -eq 0 ] || fail "$n ad.resume.* record(s) for X; want none"
    fi
    got="$(agent-director get --claude-instance-id "$x" | jq -r '[.state, .transcript_status, (.prior_sessions | tojson)] | join("|")')"
    [ "$got" = "ended|never_written|[]" ] || fail "get after the refused resume [state|transcript_status|prior_sessions]=[$got]; want [ended|never_written|[]]"
    echo "variant $v ok: $x life $life0->$life1, S1 at $s1_home and $s1_moved; resume -> ErrJsonlNeverWritten, no session, no --resume, never_written|[]"
    v=""
}

mkdir -p "$jsonl_dir"
variant A
variant B
echo "resume-10 ok: reuse with a moved --cwd (A) and a moved CLAUDE_CONFIG_DIR (B): resume never reaches the earlier life's S1 (ErrJsonlNeverWritten, no session created)"
```
