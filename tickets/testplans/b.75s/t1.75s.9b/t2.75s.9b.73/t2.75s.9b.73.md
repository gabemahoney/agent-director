# recov-2: live rows with no process identity are judged by one tmux lookup

Maps to Epic 8 AC #4, as changed by Epic 14 of plan b.h98 (Task
`t2.h98.gq.km`; SRD SR-11.3, SR-13.5, SR-14; PRD AC-FM-02, AC-FM-17,
AC-FM-18). `find-missing` judges a live row by its agent process when the
row records one. A row that records no process identity cannot be checked
that way, so one tmux lookup on the row's socket decides it. These rows are
seeded with `sqlite3` and record no launch token and no `tmux_socket`, so
their lookup runs on the socket the caller resolves (the one plain `tmux`
uses) and can never answer "ours":

- a row whose recorded name no session holds is marked `missing` with tick
  reason `tmux_absent`;
- a row whose recorded name is held by a session made by hand (no
  `@ad_owner` label) is marked `missing` with tick reason `tmux_name_held`,
  and exactly one `ad.launch.name_held` record is written for it (source
  `ad_find_missing`, `launch` and `outcome` null, `row_result`
  `marked_missing`). The holding session is never touched: it still runs,
  still unlabelled.

A `pending` row is judged only once its grace period
(`pending_grace_seconds`, 60 s by default) has passed since its launch
start, so the `pending` row here records a launch start ten minutes ago.

## Setup

Per-case DB-reset has wiped `~/.agent-director/state.db` and ended every
tmux server. The container has `agent-director`, `tmux`,
`sqlite3` and `jq` on PATH; plain `tmux` reaches the same default socket
agent-director resolves from `TMUX` / `TMUX_TMPDIR`. No `claude` runs.

The instance ids are `rc2a-<uuid>` (A), `rc2b-<uuid>` (B) and
`rc2h-<uuid>` (H), and the recorded names are `cd-rc2a-<n>`,
`cd-rc2b-<n>` and `cd-rc2h-<n>` for one random `<n>` per run, so no
earlier case's session or trail record can carry them. The trail is not
reset between cases, so records are selected by these ids. The seed is
idempotent: it first deletes any row an earlier run of this case left
(ids starting `rc2`), and the script kills the session it made on exit, so
a second run of the script (the harness re-runs a failed case under
`bash -x`) starts from the same state as the first.

## Steps

1. Delete any `rc2*` rows an earlier run of this case left.
2. Create a session named `cd-rc2h-<n>` running `sleep 3600` with no
   `@ad_owner` label, and read its tmux id `$N`.
3. Seed three live rows with `sqlite3`, none with `pid`,
   `proc_starttime`, `launch_token`, `tmux_socket` or a pane:
   - A: state `waiting`, name `cd-rc2a-<n>` (no session holds it);
   - B: state `pending`, name `cd-rc2b-<n>` (no session holds it),
     `launch_started_at` ten minutes ago in milliseconds;
   - H: state `working`, name `cd-rc2h-<n>` (the session from step 2).
4. `agent-director find-missing`.
5. `agent-director get` on A, B and H.
6. Check the session `$N` still runs, still under `cd-rc2h-<n>`, still
   with no `@ad_owner` label.
7. Read the trail file `~/.agent-director/ad-trail.jsonl` and select the
   `ad.find_missing.tick` and `ad.launch.name_held` records whose
   `claude_instance_id` is A, B or H.

## Pass criteria

- Step 4: exit 0; `count == 3`; `ids`, sorted, is `[A, B, H]` sorted;
  `unverified_ids` is empty.
- Step 5: each row's `state` is `missing` and `ended_at` is set.
- Step 6: `tmux has-session -t <$N>` succeeds, its `#{session_name}` is
  `cd-rc2h-<n>`, and it has no `@ad_owner`.
- Step 7:
  - exactly one `ad.find_missing.tick` per row, with `new_state ==
    "missing"`, `source == "ad_find_missing"` and `lookup_outcome ==
    "gone"`; A's has `prior_state == "waiting"` and
    `reconciliation_reason == "tmux_absent"`; B's has `prior_state ==
    "pending"` and `reconciliation_reason == "tmux_absent"`; H's has
    `prior_state == "working"`, `reconciliation_reason ==
    "tmux_name_held"` and `tmux_session_name == "cd-rc2h-<n>"`;
  - exactly one `ad.launch.name_held` for H, with `source ==
    "ad_find_missing"`, `launch == null`, `outcome == null`, `row_result
    == "marked_missing"`, `tmux_session_name == "cd-rc2h-<n>"`,
    `tmux_session_id == "$N"` and `carries_this_id == false`;
  - no `ad.launch.name_held` for A or B.

## Script

```bash
set -euo pipefail

db="$HOME/.agent-director/state.db"
trail="$HOME/.agent-director/ad-trail.jsonl"
a="rc2a-$(cat /proc/sys/kernel/random/uuid)"
b="rc2b-$(cat /proc/sys/kernel/random/uuid)"
h="rc2h-$(cat /proc/sys/kernel/random/uuid)"
n="$(cat /proc/sys/kernel/random/uuid | cut -c1-8)"
name_a="cd-rc2a-$n"
name_b="cd-rc2b-$n"
name_h="cd-rc2h-$n"

fail() {
    echo "FAIL: $*" >&2
    exit 1
}

# The session this run makes is killed on exit, pass or fail.
sid_h=""
cleanup() {
    if [ -n "$sid_h" ]; then
        tmux kill-session -t "$sid_h" 2>/dev/null || true
    fi
}
trap cleanup EXIT

# Step 1: idempotent seed. Rows an earlier run of this case left go first.
/opt/driver/sql.sh "$db" "DELETE FROM spawns WHERE claude_instance_id LIKE 'rc2%';"

# Step 2: an unlabelled session holds H's name.
sid_h="$(tmux new-session -d -s "$name_h" -P -F '#{session_id}' sleep 3600)"
[ -n "$sid_h" ] || fail "could not create session $name_h"
[ -z "$(tmux show-options -t "$sid_h" -v @ad_owner 2>/dev/null || true)" ] \
    || fail "new session $sid_h already has a label"
for name in "$name_a" "$name_b"; do
    if tmux has-session -t "=$name" 2>/dev/null; then
        fail "a session already holds $name"
    fi
done

# Step 3: three live rows with no process identity, no token, no socket and
# no pane. B is pending with a launch start far past the grace period.
old_ms=$(( $(date +%s%3N) - 600000 ))
/opt/driver/sql.sh "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name,
       relay_mode, launch_started_at)
   VALUES ('$a', 'waiting', '/tmp', '$name_a', 'off', NULL),
          ('$b', 'pending', '/tmp', '$name_b', 'off', $old_ms),
          ('$h', 'working', '/tmp', '$name_h', 'off', NULL);"

# Step 4: one find-missing run.
res="$(agent-director find-missing)"
got="$(printf '%s' "$res" | jq -c '[.count, (.ids | sort), (.unverified_ids // [])]')"
want="$(jq -cn --arg a "$a" --arg b "$b" --arg h "$h" '[3, ([$a, $b, $h] | sort), []]')"
[ "$got" = "$want" ] \
    || fail "find-missing [count, ids, unverified_ids] = $got; want $want (res=$res)"

# Step 5: every row is missing with ended_at set.
for id in "$a" "$b" "$h"; do
    got="$(agent-director get --claude-instance-id "$id" \
        | jq -r '[.state, (if .ended_at then "ended_at" else "no ended_at" end)] | join("|")')"
    [ "$got" = "missing|ended_at" ] \
        || fail "get of $id: [$got]; want [missing|ended_at]"
done

# Step 6: the holder still runs, under the same name, still unlabelled.
tmux has-session -t "$sid_h" 2>/dev/null \
    || fail "holder $sid_h no longer runs after find-missing"
got="$(tmux display-message -p -t "$sid_h" '#{session_name}')"
[ "$got" = "$name_h" ] || fail "holder $sid_h is named [$got]; want [$name_h]"
got="$(tmux show-options -t "$sid_h" -v @ad_owner 2>/dev/null || true)"
[ -z "$got" ] || fail "holder $sid_h was labelled: [$got]"

# Step 7: the trail.
[ -f "$trail" ] || fail "no trail file at $trail"

# records EVENT ID: the EVENT records for ID, one compact JSON per line.
records() {
    jq -c --arg e "$1" --arg x "$2" \
        'select(.event == $e and .claude_instance_id == $x)' "$trail"
}

# tick_is ID PRIOR REASON: exactly one mark tick for ID, from PRIOR, with
# REASON and lookup_outcome gone; the tick is printed on stdout.
tick_is() {
    local id="$1" prior="$2" reason="$3" recs cnt got
    recs="$(records ad.find_missing.tick "$id")"
    cnt="$(printf '%s' "$recs" | grep -c . || true)"
    [ "$cnt" -eq 1 ] || fail "want 1 ad.find_missing.tick for $id, got $cnt: $recs"
    got="$(printf '%s' "$recs" | jq -r \
        '[.prior_state, .new_state, .reconciliation_reason, .lookup_outcome, .source] | join("|")')"
    [ "$got" = "$prior|missing|$reason|gone|ad_find_missing" ] \
        || fail "tick for $id: [$got]; want [$prior|missing|$reason|gone|ad_find_missing]: $recs"
    printf '%s' "$recs"
}

tick_is "$a" waiting tmux_absent >/dev/null
tick_is "$b" pending tmux_absent >/dev/null
tick_h="$(tick_is "$h" working tmux_name_held)"
got="$(printf '%s' "$tick_h" | jq -r '.tmux_session_name')"
[ "$got" = "$name_h" ] || fail "H's tick tmux_session_name=[$got]; want [$name_h]"

for id in "$a" "$b"; do
    recs="$(records ad.launch.name_held "$id")"
    [ -z "$recs" ] || fail "unexpected ad.launch.name_held for $id: $recs"
done
recs="$(records ad.launch.name_held "$h")"
cnt="$(printf '%s' "$recs" | grep -c . || true)"
[ "$cnt" -eq 1 ] || fail "want 1 ad.launch.name_held for $h, got $cnt: $recs"
got="$(printf '%s' "$recs" | jq -r \
    '[.source, (.launch | tostring), (.outcome | tostring), .row_result, .tmux_session_name, .tmux_session_id, (.carries_this_id | tostring)] | join("|")')"
want="ad_find_missing|null|null|marked_missing|$name_h|$sid_h|false"
[ "$got" = "$want" ] || fail "name_held for $h: [$got]; want [$want]: $recs"

echo "recov-2 ok: count=3; waiting + pending (past grace) rows marked tmux_absent; held row marked tmux_name_held with 1 ad.launch.name_held; unlabelled holder $sid_h still runs"
```
