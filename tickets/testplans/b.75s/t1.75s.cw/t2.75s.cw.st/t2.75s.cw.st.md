# busy-send-claude-wait-turn-6: Steer Turn at consecutive parent tool boundaries

Maps to Epic `t1.xis.wm` acceptance criteria 3, 4 and 5 (Task `t2.xis.wm.hg`,
Subtask `t3.xis.wm.hg.k1`; SRD `t1.kii.kn` SR-2.2, SR-2.5, SR-3.3, SR-3.3a,
SR-3.4, SR-3.5, SR-3.9, SR-8.4; the Managing Intelligence's reading (a) of
"back to back" mid-turn; E4 Main Agent decisions 1 and 2). Three Steer Turn
Messages, each over half a 9,600-byte prompt, so no two share one, are Held
during a turn. Each parent `PostToolBatch` carries one prompt as its stdout
`additionalContext`, at consecutive parent boundaries, and an earlier steer
still awaiting its take evidence does not hold the next one. Callbacks of a
subagent and of a background agent, which carry `agent_id`, take nothing. The
parent `Stop` records the steers' take evidence and only then re-signals, and
the ordinary wake hands the remainder over at turn end.

The case types the callbacks where Claude Code would fire them. It makes no
claim about Claude Code's own hook order or timing, or when the model reads the
context, which the Main Agent's live check on the AD test VM owns (Task
`t2.xis.wm.hg`). Each hook is a separate process the case runs to its end
before the next, so each steer's completion is recorded before the `Stop`
that follows it starts; the case adds no sleeps.

## Setup

Per-case DB-reset; `/opt/driver/busy-send-claude.sh cw6` (the collector's
"Driver mode"). The case spawns the stand-in Claude in its own directory. No
coverage, route or wake endpoint is seeded.

## Steps

1. Spawn. Read the newest Launch's recorded facts; type `SessionStart`; type
   `UserPromptSubmit` (a user turn).
2. Send three Steer Turn Messages of 5,017 bytes each, in order: `a`
   (confirmed), `b` (unconfirmed) and `c` (confirmed).
3. Type a subagent's `PostToolBatch` and a background agent's, each with its
   own `agent_id` and `agent_type`.
4. Type a parent `PostToolBatch`. Type `FileChanged`.
5. Type a parent `PostToolBatch`.
6. Type `Stop`.
7. Type `FileChanged`, then `FileChanged` and a parent `PostToolBatch` again.
   Type the wake's sighting.
8. Read the tmux call log, the input journal and the pane.

Before each step that should touch the endpoint, the case sets its
modification time back to a fixed past second; a changed time is the touch.

## Pass criteria

- Step 1: the Launch is a covered `spawn` Launch with route `claude_hooks`
  (as case 1 checks); the turn starts.
- Step 2: `a` is Held waiting `turn_running`, `b` and `c` `earlier_message`;
  `b` returns no `caller_uuid` or `request_id`.
- Step 3: each child callback exits 0 and writes nothing; `a` is still Held.
- Step 4: the parent `PostToolBatch` exits 0, nothing on stderr, and one line
  on stdout: exactly the one JSON object
  `{"hookSpecificOutput":{"hookEventName":"PostToolBatch","additionalContext":"[agent-director: message 1 of 1]\n<a>"}}`.
  `a` is Final `sent_unconfirmed` `handed_over_not_proven`; `b` and `c` are
  Held; `awaiting_turn_start` is 1. The wake during the turn exits 0 and
  writes nothing.
- Step 5: the next parent `PostToolBatch` writes exactly
  `[agent-director: message 1 of 1]\n<b>` the same way, though `a` still
  awaits its take evidence; `b` is Final `sent_unconfirmed`
  `confirmation_off`; `c` is Held; `awaiting_turn_start` is 2.
- Step 6: `Stop` exits 0, writes nothing, records both steers' take evidence
  (`awaiting_turn_start` 0) and only then touches the endpoint, and leaves
  the row `waiting`.
- Step 7: the wake exits 2 with nothing on stdout and exactly
  `[agent-director: message 1 of 1]\n<c>` on stderr; `c` is Final
  `sent_unconfirmed` `wait_turn_raced` (the ordinary wake keeps its
  exposure); the second wake and the `PostToolBatch` exit 0 and write
  nothing; nothing is Held; the sighting leaves `awaiting_turn_start` 0.
- Step 8: no tmux call of agent-director's sent keys or a paste buffer, the
  input journal is empty, and the pane shows none of the Messages' texts.

```bash
set -euo pipefail
. /opt/driver/busy-send-claude.sh cw6

a="steer-a-$tag-$(head -c 5000 /dev/zero | tr '\0' 'a')"
b="steer-b-$tag-$(head -c 5000 /dev/zero | tr '\0' 'b')"
c="steer-c-$tag-$(head -c 5000 /dev/zero | tr '\0' 'c')"

# Step 1: a production spawn, its SessionStart and a user turn.
agent-director spawn --agent claude --cwd "$work" --instance-id "$id" --tmux-session-name "cd-cw6-$tag" >/dev/null \
    || fail "spawn exited non-zero"
launched spawn startup
quiet UserPromptSubmit "$(jq -cn --arg p "user turn $tag" '{prompt: $p}')"

# Step 2: three Steer Turn Messages, no two of which fit one prompt, are Held during the turn.
rewind
send a "$a" turn_running steer_turn
out="$(agent-director send-keys --instance-id "$id" --text "$b" --send-mode steer_turn)" \
    || fail "the unconfirmed Steer Turn send exited non-zero"
[ "$(jq -c '[.class, .wait.reason, has("caller_uuid"), has("request_id")]' <<<"$out")" = '["held","earlier_message",false,false]' ] \
    || fail "the unconfirmed Steer Turn send returned [$out]; want Held earlier_message with no ID"
send c "$c" earlier_message steer_turn
touched || fail "the sends did not touch the wake endpoint"

# Step 3: a subagent's and a background agent's tool batches take nothing.
quiet PostToolBatch '{"agent_id": "a4d8e2c61b9f0357", "agent_type": "general-purpose"}'
quiet PostToolBatch '{"agent_id": "a6c3f9e0d2b71548", "agent_type": "general-purpose"}'
[[ "$(result a)" == '["held",false,'* ]] || fail "a is [$(result a)] after the child callbacks; want Held"

# Step 4: the first parent boundary takes the first prompt alone; the wake during the turn takes nothing.
steers "$(printf '[agent-director: message 1 of 1]\n%s' "$a")"
[ "$(result a)" = "$steered" ] || fail "a is [$(result a)]; want $steered"
[[ "$(result c)" == '["held",false,'* ]] || fail "c is [$(result c)] after the first boundary; want Held"
[ "$(delivery .awaiting_turn_start)" = "[1]" ] || fail "awaiting_turn_start is $(delivery .awaiting_turn_start) after the first steer; want 1"
quiet FileChanged "$changed"

# Step 5: the next parent boundary takes the next prompt, though the first still awaits its take evidence.
steers "$(printf '[agent-director: message 1 of 1]\n%s' "$b")"
[ "$(unconfirmed)" = "sent_unconfirmed|1|confirmation_off" ] || fail "b's Result is [$(unconfirmed)]; want sent_unconfirmed|1|confirmation_off"
[[ "$(result c)" == '["held",false,'* ]] || fail "c is [$(result c)] after the second boundary; want Held"
[ "$(delivery .awaiting_turn_start)" = "[2]" ] || fail "awaiting_turn_start is $(delivery .awaiting_turn_start) after the second steer; want 2"

# Step 6: the parent Stop records both steers' take evidence, then re-signals the remainder.
rewind
quiet Stop "$stop"
[ "$(delivery .awaiting_turn_start)" = "[0]" ] || fail "awaiting_turn_start is $(delivery .awaiting_turn_start) after Stop; want 0"
touched || fail "Stop with c Held did not touch the wake endpoint"
[ "$(state)" = waiting ] || fail "row is [$(state)] after Stop; want waiting"

# Step 7: the ordinary wake hands the remainder over at turn end, once.
wakes "$(printf '[agent-director: message 1 of 1]\n%s' "$c")"
[ "$(result c)" = "$raced" ] || fail "c is [$(result c)]; want $raced"
quiet FileChanged "$changed"
quiet PostToolBatch
[ "$(delivery .held_count)" = "[0]" ] || fail "a Message is still Held: $(delivery .held_count)"
sighting
[ "$(delivery .awaiting_turn_start)" = "[0]" ] || fail "awaiting_turn_start is $(delivery .awaiting_turn_start) after c's sighting; want 0"

# Step 8: agent-director typed nothing.
no_product_input "steer-a-$tag" "steer-b-$tag" "steer-c-$tag"

echo "busy-send-claude-wait-turn-6 ok: child callbacks take nothing; one Steer Turn prompt per consecutive parent boundary, in order, handed_over_not_proven and confirmation_off; an awaiting steer does not hold the next; Stop's take evidence before its re-signal; the remainder at turn end, raced; nothing repeated or typed"
```
