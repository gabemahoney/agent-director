# kill-11: kill ends the agent's pane even while a grouped viewer shows its window

Maps to SRD SR-20.9 kill-11 (amendment 5; AC-KILL-01, AC-KILL-03; the
Epic's user demo; Epic `t1.h98.aq`, the honest kill, SR-6.1, SR-3.7). A
human who watches an agent through a grouped session (`tmux
new-session -t <X's session>`) shares X's windows. Killing only X's
session would leave its window, and the agent in it, alive in the
viewer. `kill` instead kills the agent's pane by pane id, then X's
labelled session by session id, and returns only once the agent's pane
process is gone: exit 0 with `kill_sent` true, the pane process
recorded for X is gone, and the viewer no longer shows X's window.

## Setup

Per-case DB-reset. X is spawned with
`PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the
`agent-director` command, so its pane process is the stand-in claude's
interactive bash (it sends no hook and exits on the pane kill's SIGHUP);
no hook is synthesised, since kill-11 needs no reported-in row. As a
second guard, before any tmux or agent-director call the script unsets
`ANTHROPIC_API_KEY` and `CLAUDE_CODE_OAUTH_TOKEN`, removes both from the
global environment of a tmux server already answering on the default
socket (`tmux set-environment -g -u`, tolerating "no server"), and right
after the spawn checks neither appears in `/proc/<recorded
pane_pid>/environ` ("credentials reached the agent").

X's session is named `cd-k11` (swept by the DB-reset). The viewer is
named `viewer`, outside the `cd-` prefix, so the case removes it itself:
an EXIT trap kills it (and X's session, if left) by session id on the
recorded socket.

## Steps

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd
   /tmp --tmux-session-name cd-k11` → X's id.
2. Read X's `tmux_socket`, `pane_id` and `pane_pid` with `sqlite3`; get
   X's session id `$N` from tmux (the recorded pane's `#{session_id}`)
   and X's window ids (`list-windows -t '<$N>'`). Run the credential
   check.
3. `tmux -u -S <socket> new-session -d -t '<$N>' -s viewer`, capturing
   the viewer's session id; the viewer lists X's window ids.
4. `agent-director kill --claude-instance-id X`.
5. Check the recorded pane pid, the viewer's windows, and X's session.

## Pass criteria

- Neither credential variable is in the pane process's environment.
- Before the kill the viewer shows every one of X's window ids.
- kill exits 0 and its stdout JSON has `kill_sent == true`.
- The recorded pane pid is gone (absent or a zombie).
- The viewer no longer exists, or lists none of X's window ids.
- X's session (by `$N`) is gone.

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN
tmux set-environment -g -u ANTHROPIC_API_KEY 2>/dev/null || true
tmux set-environment -g -u CLAUDE_CODE_OAUTH_TOKEN 2>/dev/null || true

db="$HOME/.agent-director/state.db"
standin_path="/opt/driver/stand-in-claude:$PATH"
fail() { echo "FAIL: $*"; exit 1; }
sock=""
sid=""
viewer_sid=""
cleanup() {
    [ -z "$viewer_sid" ] || tmux -S "$sock" kill-session -t "$viewer_sid" 2>/dev/null || true
    [ -z "$sid" ] || tmux -S "$sock" kill-session -t "$sid" 2>/dev/null || true
}
trap cleanup EXIT

# The spawn's stderr (a "pre-trust failed" note: no ~/.claude.json here) is
# shown only if the spawn fails, so the case's last line stays the summary.
spawn_err="$(mktemp)"
spawn_out="$(PATH="$standin_path" agent-director spawn --cwd /tmp --tmux-session-name cd-k11 2>"$spawn_err")" \
    || fail "spawn exited non-zero: $(cat "$spawn_err")"
id="$(jq -r '.claude_instance_id' <<<"$spawn_out")"
[ -n "$id" ] && [ "$id" != "null" ] || fail "spawn returned no claude_instance_id: $spawn_out"

IFS='|' read -r sock pane pane_pid < <(sqlite3 -readonly "$db" \
    "SELECT IFNULL(tmux_socket,'') || '|' || IFNULL(pane_id,'') || '|' || IFNULL(pane_pid,'') FROM spawns WHERE claude_instance_id = '$id';")
[ -n "$sock" ] && [ -n "$pane" ] && [[ "$pane_pid" =~ ^[0-9]+$ ]] \
    || fail "recorded tmux_socket|pane_id|pane_pid=[$sock|$pane|$pane_pid]; want all set"
sid="$(tmux -S "$sock" display-message -p -t "$pane" '#{session_id}')"
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "pane $pane gave session id [$sid]"
x_windows="$(tmux -S "$sock" list-windows -t "$sid" -F '#{window_id}')"
[ -n "$x_windows" ] || fail "X's session $sid lists no windows"

for v in ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN; do
    if grep -qz "^$v=" "/proc/$pane_pid/environ"; then
        fail "credentials reached the agent: $v is in /proc/$pane_pid/environ"
    fi
done

viewer_sid="$(tmux -u -S "$sock" new-session -d -t "$sid" -s viewer -P -F '#{session_id}')"
[[ "$viewer_sid" =~ ^\$[0-9]+$ ]] || fail "viewer new-session gave session id [$viewer_sid]"
v_windows="$(tmux -S "$sock" list-windows -t "$viewer_sid" -F '#{window_id}')"
for w in $x_windows; do
    grep -qxF -- "$w" <<<"$v_windows" || fail "viewer $viewer_sid does not show X's window $w before the kill"
done

out="$(agent-director kill --claude-instance-id "$id")" || fail "kill exited non-zero; want 0"
sent="$(jq -r '.kill_sent' <<<"$out")"
[ "$sent" = "true" ] || fail "kill_sent=$sent; want true (stdout: $out)"

if [ -e "/proc/$pane_pid" ]; then
    st="$(sed -E 's/^.*\) //' "/proc/$pane_pid/stat" 2>/dev/null | cut -d' ' -f1 || true)"
    [ -z "$st" ] || [ "$st" = "Z" ] || fail "recorded pane process $pane_pid still running (state $st) after kill"
fi
if tmux -S "$sock" has-session -t "$viewer_sid" 2>/dev/null; then
    v_windows="$(tmux -S "$sock" list-windows -t "$viewer_sid" -F '#{window_id}' 2>/dev/null || true)"
    for w in $x_windows; do
        if grep -qxF -- "$w" <<<"$v_windows"; then
            fail "viewer $viewer_sid still shows X's window $w after kill"
        fi
    done
    viewer_note="viewer $viewer_sid still runs without X's window"
else
    viewer_note="viewer $viewer_sid gone with X's window"
fi
if tmux -S "$sock" has-session -t "$sid" 2>/dev/null; then
    fail "X's session $sid still exists after kill"
fi

echo "kill-11 ok: X ($id) with grouped viewer → kill exit 0 with kill_sent true; pane process $pane_pid gone; $viewer_note; session $sid gone"
```
