# Busy send E1 (b.kii) — `busy-send-uncovered` testplan

t1 collector for an agent busy send does not cover (Idea `b.kii`, Plan
`b.xis`, Task `t2.xis.pu.ar`, Subtask `t3.xis.pu.ar.ka`; SRD `t1.kii.kn`
SR-9.2 and SR-9.4). Its one case runs under
`make test-docker EPIC=busy-send-uncovered` with `DRIVER_MODE=shell`, against
the real CLI, store and tmux.

## Driver mode

The agent is the Codex stand-in `/opt/driver/stand-in-codex/codex`, named by
`[launch] codex_path`: an interactive bash, so what is typed at its pane runs
as a shell command. Codex stays uncovered until its own busy-send release.
Its first report is a `SessionStart` typed with
`/opt/driver/pane-hook.sh --agent codex`. The Go API owns the refusal matrix
over every agent and option; this case checks one option end to end.
