# resume-9: after a reuse, resume never reaches the earlier life's transcript

Maps to SRD SR-20.9 resume-9 (history by life; PRD AC-REUSE-20, 21 and 26
end to end), SR-8.7 and SR-10.3 (Epic 17 `t1.h98.i4`, Task
`t2.h98.i4.tm`, Subtask `t3.h98.i4.tm.pm`; spec `t3.h98.i4.y9.cj`). X's
first life records session S1, whose transcript is on disk. X is then
spawned again with the same id, opting in to reuse (`--reuse-finished`),
in the same directory: the reuse archives S1 under the first life and
starts a new life, so `get` shows an empty `prior_sessions`. The new life
reports a session S2 whose transcript is never written, and ends. `resume`
of X reads only the current life's history, so it returns
`ErrJsonlNeverWritten`, although S1's transcript is still on disk, and
creates no session.

Agent and hooks (SR-20.9, SR-22.9; collector "Driver mode"): the spawn,
the reuse and the `resume` run with `PATH=/opt/driver/stand-in-claude:$PATH`
prefixed, so each pane process is the stand-in's interactive bash, which
sends no hook by itself. SR-20.9's "synthesise" steps are hooks typed into
the launch's recorded pane with `/opt/driver/pane-hook.sh <id>
'<payload>'`; none is piped from the case's own shell. The reuse's
`pending` row takes S2's SessionStart from its own pane (AC-HOOK-02, reuse
half).

Credential isolation (Epic 10's kill-10 pattern), before any tmux or
agent-director call: `ANTHROPIC_API_KEY` and `CLAUDE_CODE_OAUTH_TOKEN` are
unset and removed from the tmux server's global environment (tolerating no
server); after the spawn and after the reuse, neither appears in
`/proc/<recorded pane_pid>/environ` ("credentials reached the agent").

## Setup

Per-case DB-reset. X's id is `r9-<uuid>` (the trail is not reset between
cases, so records are selected by this id) and both launches are named
`cd-r9`, swept by the reset; an EXIT trap also ends any session the case
made by its session id and removes S1's transcript. The session ids carry
a per-run tag: S1 = `r9-s1-<tag>`, S2 = `r9-s2-<tag>`.

1. Credential isolation as above.
2. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd /tmp
   --tmux-session-name cd-r9 --claude-instance-id X` → exit 0. Read the
   socket, pane, `pane_pid` and `$N`; check the pane environ.
3. Seed S1's transcript `$HOME/.claude/projects/-tmp/<S1>.jsonl`, then type
   a SessionStart with that `transcript_path` into X's pane → `waiting`,
   S1, `pid` = `pane_pid`, `jsonl_path` S1's file. Type a SessionEnd →
   `ended`.
4. End X's session by its `$N` and wait (bounded, 5 s) until X's recorded
   `pid`, `pane_pid` and, when it was the server's last session,
   `tmux_server_pid` have exited (resume-1's wait). Record X's
   `life_number`.

## Steps

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd /tmp
   --tmux-session-name cd-r9 --claude-instance-id X --reuse-finished` →
   exit 0, echoes X. Read the new pane, `pane_pid` and `$N`; check the pane
   environ.
2. `get` X → `pending`, `prior_sessions` `[]`; `sqlite3`: `life_number`
   one more than recorded.
3. Type a SessionStart with S2's `transcript_path`
   (`$HOME/.claude/projects/-tmp/<S2>.jsonl`, never written) into the new
   pane → `waiting`, S2, `pid` = the new `pane_pid`, `jsonl_path` NULL.
   Type a SessionEnd → `ended`.
4. End the reused launch's session by its `$N` and wait for its recorded
   processes as in setup step 4. Capture the session ids on X's socket.
5. `PATH=/opt/driver/stand-in-claude:$PATH agent-director resume
   --claude-instance-id X` → exit 1, `err_name` `ErrJsonlNeverWritten`
   (last JSON line on stderr).
6. Check S1's transcript, the sessions on X's socket, every process's
   command line, the trail and `get` X.

## Pass criteria

- Setup and steps 1-4: every launch exits 0 with no credentials in its
  pane environ; the hook results are as stated; after the reuse `get`
  shows `pending` and `[]`, and the life is one more.
- Step 5: exit 1 and `ErrJsonlNeverWritten`.
- Step 6: S1's transcript is still on disk; no session on X's socket is
  named `cd-r9` and the session id set equals the capture (no session was
  created); no process's command line has `--resume` with S1; the trail
  holds no `ad.resume.*` record for X; `get` shows `ended`,
  `transcript_status` `never_written` and `prior_sessions` `[]`.

Each failed check prints a `FAIL:` line naming what was expected and what
was seen; the final line summarises what was checked.

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN
tmux set-environment -g -u ANTHROPIC_API_KEY 2>/dev/null || true
tmux set-environment -g -u CLAUDE_CODE_OAUTH_TOKEN 2>/dev/null || true

db="$HOME/.agent-director/state.db"
trail="$HOME/.agent-director/ad-trail.jsonl"
standin_path="/opt/driver/stand-in-claude:$PATH"
jsonl_dir="$HOME/.claude/projects/-tmp"
uuid="$(cat /proc/sys/kernel/random/uuid)"
tag="${uuid:0:8}"
x="r9-$uuid"
name=cd-r9
s1="r9-s1-$tag"
s2="r9-s2-$tag"
s1_file="$jsonl_dir/$s1.jsonl"
s2_file="$jsonl_dir/$s2.jsonl"
err_file="$(mktemp)"
sock=""
sid=""
fail() { echo "FAIL: $*"; exit 1; }
cleanup() {
    [ -z "$sid" ] || tmux ${sock:+-S "$sock"} kill-session -t "$sid" 2>/dev/null || true
    rm -f "$err_file" "$s1_file" "$s2_file"
}
trap cleanup EXIT

# end_and_wait <id> <tmux target>: ends the row's tmux session, then waits
# (bounded, 5 s) until the processes the row records have exited (no /proc
# entry): its pid and pane_pid, and its tmux_server_pid when the session was
# the server's last. A server that holds other sessions must still run after.
end_and_wait() {
    local id="$1" target="$2" rec rpid rpane rserver rsock n left p end
    rec="$(/opt/driver/sql.sh -readonly "$db" "SELECT IFNULL(pid,'') || '|' || IFNULL(pane_pid,'') || '|' || IFNULL(tmux_server_pid,'') || '|' || IFNULL(tmux_socket,'') FROM spawns WHERE claude_instance_id = '$id';")"
    IFS='|' read -r rpid rpane rserver rsock <<<"$rec"
    [[ "$rpid|$rpane|$rserver" =~ ^[0-9]+\|[0-9]+\|[0-9]+$ ]] || fail "$id records pid|pane_pid|tmux_server_pid [$rpid|$rpane|$rserver]; want all set"
    n="$(tmux ${rsock:+-S "$rsock"} list-sessions 2>/dev/null | wc -l)"
    tmux ${rsock:+-S "$rsock"} kill-session -t "$target" || fail "kill-session -t $target of $id failed"
    set -- "$rpid" "$rpane"
    [ "$n" -gt 1 ] || set -- "$@" "$rserver"
    end=$(( $(date +%s%N) + 5000000000 ))
    while :; do
        left=""
        for p in "$@"; do [ ! -e "/proc/$p" ] || left+=" $p"; done
        [ -n "$left" ] || break
        [ "$(date +%s%N)" -lt "$end" ] || fail "$id's recorded process(es)$left still running 5 s after its session $target ended"
        sleep 0.1
    done
    [ "$n" -le 1 ] || [ -e "/proc/$rserver" ] || fail "tmux server $rserver of $id ended although it held $((n - 1)) other session(s)"
}
row_field() { /opt/driver/sql.sh -readonly "$db" "SELECT IFNULL($2,'') FROM spawns WHERE claude_instance_id = '$1';"; }
no_creds() {
    local v
    for v in ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN; do
        if grep -qz "^$v=" "/proc/$1/environ"; then
            fail "credentials reached the agent: $v is in /proc/$1/environ ($2)"
        fi
    done
}
hook() { /opt/driver/pane-hook.sh "$1" "$2" >/dev/null || fail "hook $2 for $1 exited non-zero"; }
session_start() { printf '{"hook_event_name":"SessionStart","source":"startup","transcript_path":"%s"}' "$1"; }
session_end='{"hook_event_name":"SessionEnd","reason":"logout"}'
last_json() { printf '%s' "$1" | awk '/^\{/{ln=$0} END{print ln}'; }
session_set() { { tmux ${sock:+-S "$sock"} list-sessions -F '#{session_id}' 2>/dev/null || true; } | sort; }
session_names() { tmux ${sock:+-S "$sock"} list-sessions -F '#{session_name}' 2>/dev/null || true; }
# spawn_x <args...>: a stand-in spawn of X; stdout in $out, stderr in $err_file, exit status in $rc.
spawn_x() {
    set +e
    out="$(PATH="$standin_path" agent-director spawn --claude-instance-id "$x" "$@" 2>"$err_file")"
    rc=$?
    set -e
}
# launched <what>: reads X's socket, pane, pane_pid and the pane's session id
# into sock, pane, pane_pid and sid, and checks the pane environment.
launched() {
    sock="$(row_field "$x" tmux_socket)"
    pane="$(row_field "$x" pane_id)"
    pane_pid="$(row_field "$x" pane_pid)"
    [ -n "$pane" ] && [[ "$pane_pid" =~ ^[0-9]+$ ]] || fail "X after $1 records pane_id|pane_pid [$pane|$pane_pid]; want both set"
    sid="$(tmux ${sock:+-S "$sock"} display-message -p -t "$pane" '#{session_id}')"
    [[ "$sid" =~ ^\$[0-9]+$ ]] || fail "X's pane $pane after $1 gave session id [$sid]"
    no_creds "$pane_pid" "X after $1"
}
# start_end <session> <transcript> <want jsonl_path>: SessionStart then SessionEnd typed into X's pane.
start_end() {
    local got
    hook "$x" "$(session_start "$2")"
    got="$(/opt/driver/sql.sh -readonly "$db" "SELECT state || '|' || IFNULL(claude_session_id,'') || '|' || IFNULL(pid,'') || '|' || IFNULL(jsonl_path,'NULL') FROM spawns WHERE claude_instance_id = '$x';")"
    [ "$got" = "waiting|$1|$pane_pid|$3" ] || fail "X after SessionStart [state|session|pid|jsonl_path]=[$got]; want [waiting|$1|$pane_pid|$3]"
    hook "$x" "$session_end"
    got="$(row_field "$x" state)"
    [ "$got" = "ended" ] || fail "X after SessionEnd state=$got; want ended"
}
# no_resume_of <session>: no process's command line has --resume with the session.
no_resume_of() {
    local f c
    for f in /proc/[0-9]*/cmdline; do
        c="$( { tr '\0' ' ' < "$f"; } 2>/dev/null )" || continue
        case "$c" in
            *--resume*"$1"*) fail "a process was started with --resume naming $1: [$c] ($f)" ;;
        esac
    done
}

mkdir -p "$jsonl_dir"
rm -f "$s2_file"

# Setup 2: spawn X with the stand-in.
spawn_x --cwd /tmp --tmux-session-name "$name"
[ "$rc" -eq 0 ] || fail "spawn of X exited $rc; want 0: $(cat "$err_file")"
[ "$(jq -r '.claude_instance_id' <<<"$out")" = "$x" ] || fail "spawn of X echoed [$out]; want id $x"
launched spawn

# Setup 3: S1's transcript on disk, then S1's SessionStart and SessionEnd.
echo '{}' > "$s1_file"
start_end "$s1" "$s1_file" "$s1_file"

# Setup 4: end the first launch's session by its $N; wait for its processes.
end_and_wait "$x" "$sid"
sid=""
life0="$(row_field "$x" life_number)"
[[ "$life0" =~ ^[0-9]+$ ]] || fail "X's life_number [$life0]; want a number"

# Step 1: spawn again with the same id, opting in to reuse, in the same directory.
spawn_x --cwd /tmp --tmux-session-name "$name" --reuse-finished
[ "$rc" -eq 0 ] || fail "spawn --reuse-finished of ended X exited $rc; want 0: $(cat "$err_file")"
[ "$(jq -r '.claude_instance_id' <<<"$out")" = "$x" ] || fail "spawn --reuse-finished echoed [$out]; want id $x"
launched reuse

# Step 2: a new life with no prior sessions.
got="$(agent-director get --claude-instance-id "$x" | jq -r '[.state, (.prior_sessions | tojson)] | join("|")')"
[ "$got" = "pending|[]" ] || fail "get after reuse [state|prior_sessions]=[$got]; want [pending|[]]"
life1="$(row_field "$x" life_number)"
[ "$life1" -eq $((life0 + 1)) ] || fail "life_number after reuse=$life1; want $((life0 + 1))"

# Step 3: S2 (never written) reported from the reused pane, then SessionEnd.
start_end "$s2" "$s2_file" NULL

# Step 4: end the reused launch's session by its $N; wait for its processes.
end_and_wait "$x" "$sid"
sid=""
set_before="$(session_set)"

# Step 5: resume finds no transcript in the current life.
set +e
PATH="$standin_path" agent-director resume --claude-instance-id "$x" >/dev/null 2>"$err_file"
rc=$?
set -e
[ "$rc" -eq 1 ] || fail "resume of X exited $rc; want 1: $(cat "$err_file")"
err_name="$(last_json "$(cat "$err_file")" | jq -r '.err_name')"
[ "$err_name" = "ErrJsonlNeverWritten" ] || fail "resume err_name=[$err_name]; want ErrJsonlNeverWritten: $(cat "$err_file")"

# Step 6: S1's transcript is there, yet nothing was launched.
[ -f "$s1_file" ] || fail "S1's transcript $s1_file is gone; want it on disk"
if session_names | grep -qxF "$name"; then
    fail "a session named $name runs on X's socket after the refused resume"
fi
set_after="$(session_set)"
[ "$set_after" = "$set_before" ] || fail "tmux session set changed on the refused resume: [$set_after]; was [$set_before]"
no_resume_of "$s1"
if [ -f "$trail" ]; then
    n="$(jq -c --arg x "$x" 'select(.claude_instance_id == $x and (.event | startswith("ad.resume.")))' "$trail" | grep -c . || true)"
    [ "$n" -eq 0 ] || fail "$n ad.resume.* record(s) for X; want none"
fi
got="$(agent-director get --claude-instance-id "$x" | jq -r '[.state, .transcript_status, (.prior_sessions | tojson)] | join("|")')"
[ "$got" = "ended|never_written|[]" ] || fail "get after the refused resume [state|transcript_status|prior_sessions]=[$got]; want [ended|never_written|[]]"

echo "resume-9 ok: X ($x) life $life0 S1 on disk, reused in /tmp -> life $life1 pending with []; S2 never written; resume -> ErrJsonlNeverWritten, no session, no --resume of $s1, no ad.resume.*; get ended|never_written|[]"
```
