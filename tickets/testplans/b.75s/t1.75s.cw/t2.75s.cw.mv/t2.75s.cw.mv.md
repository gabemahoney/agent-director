# MixedVersionComposition: captured issuers across publication and death

Maps to Subtask t3.xis.jo.b2.y1, M3 T4 and representative T1. The complete
semantic matrices run only in test/mixed-version. This one trace uses its
same stamped generation builder and production-operation drivers, plus real
owned Claude hooks and stream bytes. Publication and rollback are causal
perturbations, not another installation matrix. Stand-in hooks do not claim
to qualify Claude Code's live intake.

## Setup

The ordinary per-case reset and busy-send-claude.sh fixture. Build the two
retained runtimes once from the image's immutable final source/module inputs;
apply vb's build-only hook observer to both. All files and endpoints are
owned by this case. No coverage or custody is seeded by SQL.

## Steps

1. Start the old generation with a startup prompt. Park its real admission
   COMMIT return; the new generation reads it. Lose the reply and repeat the
   pair through the new CLI without a second admission. Startup runs first.
2. Park the old owned hook after its native issue COMMIT as a direct
   background child. Publish the new generation, append later work, and run
   a real new-generation hook while the old return remains pending. The new
   attempt exits without bytes or another issue and leaves the owner's
   authority unchanged. Confirm the old issue, let
   the actual issuer exit with its bytes still unread in a kernel FIFO, and
   end its Launch. Resume through the new runtime with creation held at a
   FIFO barrier; admit new work against the pending candidate.
3. Roll back the selection, finish the candidate's SessionStart, and only
   then consume the old issuer's buffered bytes. The new owned hook emits
   only the later Messages in order. Park its exact UserPromptSubmit admission COMMIT
   return: the old runtime observes the cleared awaiting obligation and
   unchanged Message Result. Lose that reply; neither hook replays output.
4. Start a real force call with two frozen prompts. Park the new hook's
   intent return, append later work through the old generation, and let the
   call end at its original deadline. Lose the intent reply. Neither runtime
   emits or reissues that uncertain prompt or extends the frozen membership.
5. End the old target, delete it, expire its Results and recreate the same
   instance ID. Captured old evidence and both old pairs remain fenced;
   bytes and Results are never restored, and the replacement emits nothing.

## Pass criteria

Both executed version/commit stamps are distinct and the final core is
identical. Native-COMMIT events name the real recorded pane parent, hook PID
and store. Exact old/new bytes arrive once and in accepted order; actual
process exit is established with pidfd readiness before the old FIFO is
read. Pending/lost replies preserve uncertainty, force members/cursor and
original deadlines. Replays add no Message, startup and pending candidates
cannot skip ordering, expired pairs cannot be stolen, stale evidence cannot
change the replacement, and no product tmux input or journal attempt exists.

def line(fd, timeout=30):
    out = b''
    end = time.monotonic() + timeout
    while not out.endswith(b'\n'):
        assert select.select([fd], [], [], max(0, end-time.monotonic()))[0], ('IPC timeout', out)
        chunk = os.read(fd, 1)
        assert chunk, ('IPC EOF', out)
        out += chunk
    return out

def fifo(path, *, read_only=False):
    os.mkfifo(path, 0o600)
    fd = os.open(path, (os.O_RDONLY if read_only else os.O_RDWR) | os.O_NONBLOCK)
    descriptors.append(fd)

class ParkedHook:
    def __init__(self, g, hook_event, *, target='intent', background=False, **extra):
        self.root = work / ('hook-' + str(uuid.uuid4()))
        self.root.mkdir()
        (self.root/'plan.json').write_text(json.dumps({'target':target,'occurrence':1}))
        self.release = fifo(self.root/'release')
        self.events = fifo(self.root/'events')
        self.stream = fifo(self.root/'stream', read_only=True)
        self.job = Path(run(['/opt/driver/pane-hook.sh', '--executable', runtimes[g], '--observe-commit', self.root,
            '--stderr-pipe', '--stream-fifo', self.root/'stream', '--no-wait', *(['--background'] if background else []), instance,
            json.dumps(payload(hook_event, **extra))]).stdout.decode().strip())
        self.event = json.loads(line(self.events))
        assert {k:self.event[k] for k in ('barrier','target','occurrence','store_path')} == {
            'barrier':'after_commit','target':target,'occurrence':1,'store_path':db}, self.event
        assert self.event['parent_pid'] == current()['pane_pid'], self.event
        self.pidfd = os.pidfd_open(self.event['pid'])
        descriptors.append(self.pidfd)
    def finish(self, *, lose=False, code=2):
        os.write(self.release, json.dumps({'release':True,'lose_reply':lose}).encode()+b'\n')
        assert select.select([self.pidfd], [], [], 35)[0], 'actual hook did not exit'
        p = run(['/opt/driver/pane-hook.sh', '--wait', self.job], code=code)
        assert not p.stdout and not p.stderr, (p.stdout,p.stderr)
    def consume(self):
        out = b''
        while True:
            chunk = os.read(self.stream, 65536)
            if not chunk: return out
            out += chunk
