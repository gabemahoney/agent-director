# A fallen-back permission request keeps check_permission and live command authority

Maps to the report-only guarantee: what `send-keys`, `decide` and `pause` may
do follows the raw state, a refusal writes no trail record (PRD t1.ob8.s4,
SRD t1.ob8.gw SR-5.2, acceptance criterion 11 of Epic t1.sp6.6s), and the
request, fallen back since 2020, keeps its row `check_permission` throughout
(b.zpv).

## Setup

As for the public case, but per agent a relay-on spawn `guard-<agent>` with
one request (token `aaaaaaaa-aaaa-4aaa-aaaa-aaaaaaaaaaaa`, tool `Bash`) whose
fallback clock is already stored: `fallback_at` 2020-01-01, basis
`deadline`. Each is first read once with `status`.

## Steps

1. For each of `claude`, `codex` and `cursor`, run
   `agent-director send-keys --instance-id guard-<agent> --text next`.
2. Run `agent-director decide --instance-id guard-<agent> --request-token aaaaaaaa-aaaa-4aaa-aaaa-aaaaaaaaaaaa --decision allow --max-wait-ms 0`.
   A zero wait cannot wait for a store lock, so under load it may refuse
   `ErrStoreBusy`, recording nothing: rerun it, every 100 ms for at most
   10 s, only while that is its refusal. Any other outcome ends the retry.
3. Run `agent-director pause --instance-id guard-<agent>`.
4. Read the request's `decision`, `proven_gone_at` and `pane_answer` with
   `sql.sh`, then run `status` again and read the trail records whose
   `instance_id` is `guard-<agent>`.

## Pass criteria

- The first and the second `status` each have state `check_permission`,
  `idle_screen_availability` `available` for Claude and Codex and
  `unavailable` for Cursor, and exactly the keys `context`, `family_state`,
  `idle_screen_availability` and `state`.
- Steps 1 and 2 each exit non-zero with a stderr JSON envelope whose
  `err_name` is `ErrRelayFallenBack`; step 3 exits non-zero with `err_name`
  `ErrSpawnNotPausable`, for all 3 agents. A step 2 success, any other
  refusal, or `ErrStoreBusy` still answered after the 10 s retry fails the
  case.
- The request row is `decision` empty, `proven_gone_at` empty, `pane_answer`
  `none` (read as `||none`), and the raw `spawns.state` is still
  `check_permission`.
- Per id the trail holds no `ad.spawn.displayed_state_transition` record, no
  `ad.spawn.stuck_transition` record, and no `ad.spawn.state_transition`
  record naming `needs_intelligence` or `idle_screen`.
- The evidence line shows each verb's observed `err_name`, the request
  facts, the state shown and the record count.

set -euo pipefail
node /work/source/test/driver/needs-intelligence.cjs guards
