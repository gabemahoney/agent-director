# agent-18: the relay allow round trip on a codex row, and the hold that follows

Maps to SRD SR-8.1 to SR-8.4 and SR-14.5 of Epic 13 (`b.ssz`), and to the
demo's step 3: with `relay_mode` on, a Codex `PermissionRequest` for the
shell tool moves the row to `check_permission` and records an open request
holding Codex's `tool_name` and `tool_input` (and no `tool_use_id`, no
`agent_id`). `get-permission` shows them. `decide --decision allow` is
delivered: the allow envelope is on the relay hook's stdout. Nothing on a
Codex row proves the request's dialog gone except the main agent's turn end,
so a plain `send-keys` is refused with `ErrDialogMaybeOpen` even after the
hook has acked, until a Codex `Interrupt` (no `agent_id`) is typed; then the
request reads proven gone (`turn_end`) and a plain `send-keys` types.

Agent and hooks (collector "Driver mode"): the pane process is the Codex
stand-in `/opt/driver/stand-in-codex/codex`, named by `[launch] codex_path`.
The case types each hook into its pane with `/opt/driver/pane-hook.sh --agent
codex` (the blocking `PermissionRequest` with `--no-wait` and `--wait`); the
pane's environment carries `AGENT_DIRECTOR_RELAY_MODE=on` from the spawn's
`--relay-mode on`.

## Setup

Per-case DB-reset. The case writes `~/.config/agent-director/config.toml`
with `[launch]` `codex_path = "/opt/driver/stand-in-codex/codex"`, makes a
cwd and a temporary Codex folder holding the one rollout file the payloads
name, and removes them, the config and the stand-in's record directory on
exit.

## Steps

1. Write the config; make the cwd and the Codex folder with its rollout.
2. `agent-director spawn --agent codex --cwd <cwd> --instance-id <id>
   --tmux-session-name cd-ag-al --relay-mode on --extra-env
   CODEX_HOME=<folder>`; type a `SessionStart`; the row is `waiting`.
3. Type a `PermissionRequest` (tool `Bash`, input a `command`) with
   `pane-hook.sh --agent codex --no-wait`; wait for the open request.
4. `get-permission` and `get` on the request; read its store columns.
5. `decide --decision allow`; `pane-hook.sh --wait` the hook.
6. Plain `send-keys --text <marker>`.
7. Type a Codex `Interrupt` (no `agent_id`); `get-permission` again.
8. Plain `send-keys --text <marker>` again; `read-pane`.

## Pass criteria

- Step 2: spawn exits 0; the row is `waiting` with agent `codex` and
  `relay_mode` `on`.
- Step 3: the hook is still running (no exit status yet); the row is
  `check_permission`; one open request exists.
- Step 4: `get-permission` shows `tool_name` `Bash`, a `tool_input` that is a
  JSON string whose `command` is the payload's, `decision` null, `tool_use_id`
  null, `proven_gone_at` null; the store's `agent_id` and `tool_use_id` are
  NULL; `get` lists the request in `permission_requests` with the same token.
- Step 5: decide exits 0 with `delivery` `delivered`; the hook exits 0 and
  its stdout is a JSON envelope whose `hookSpecificOutput.decision.behavior`
  is `allow` (and no message); `get-permission` shows `decision` `allow`,
  `delivery` `delivered`, and still no `proven_gone_at`.
- Step 6: exit 1 with `err_name` `ErrDialogMaybeOpen`; the marker never
  reaches the pane.
- Step 7: the hook exits 0 and prints nothing; the row is `waiting`;
  `get-permission` shows `proven_gone_how` `turn_end` and a `proven_gone_at`.
- Step 8: send-keys exits 0 with `{}`; the marker is on the pane within
  10 s.

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN CODEX_HOME

db="$HOME/.config/agent-director/state.db"
config="$HOME/.config/agent-director/config.toml"
standin="/opt/driver/stand-in-codex/codex"
rec_root="/tmp/stand-in-codex"
uuid="$(cat /proc/sys/kernel/random/uuid)"
id="ag-al-$uuid"
sid="$(cat /proc/sys/kernel/random/uuid)"
marker="ag-al-marker-$RANDOM$RANDOM"
codex_home=""
cwd=""
rollout=""
errfile="$(mktemp)"
fail() { echo "FAIL: $*"; exit 1; }

col() { /opt/driver/sql.sh -readonly "$db" "SELECT $1 FROM spawns WHERE instance_id = '$id';"; }

cleanup() {
    local row sock pane s
    row="$(col "IFNULL(tmux_socket,'') || '|' || IFNULL(pane_id,'')" 2>/dev/null || true)"
    sock="${row%%|*}"
    pane="${row#*|}"
    if [ -n "$pane" ]; then
        s="$(tmux ${sock:+-S "$sock"} display-message -p -t "$pane" '#{session_id}' 2>/dev/null || true)"
        [ -z "$s" ] || tmux ${sock:+-S "$sock"} kill-session -t "$s" 2>/dev/null || true
    fi
    rm -f "$config" "$errfile"
    rm -rf "$rec_root/$id" ${codex_home:+"$codex_home"} ${cwd:+"$cwd"}
    rmdir "$rec_root" 2>/dev/null || true
}
trap cleanup EXIT

# wait_state WANT: the row's state (get) is WANT within 10 s.
wait_state() {
    local want="$1" end got=""
    end=$(( $(date +%s) + 10 ))
    while :; do
        got="$(agent-director get --instance-id "$id" | jq -r '.state')"
        [ "$got" != "$want" ] || return 0
        [ "$(date +%s)" -lt "$end" ] || fail "row $id state is [$got]; want [$want] within 10 s"
        sleep 0.2
    done
}

# fire EVENT [EXTRA_JSON]: type the Codex hook EVENT into the row's pane; the
# hook must exit 0 and print nothing.
fire() {
    local extra='{}' body out
    [ $# -lt 2 ] || extra="$2"
    body="$(jq -cn --arg e "$1" --arg sid "$sid" --arg tp "$rollout" --arg cwd "$cwd" --argjson x "$extra" \
        '{hook_event_name: $e, session_id: $sid, transcript_path: $tp, cwd: $cwd, model: "codex-stand-in", permission_mode: "default"} + $x')"
    out="$(/opt/driver/pane-hook.sh --agent codex "$id" "$body")" || fail "the $1 hook exited non-zero"
    [ -z "$out" ] || fail "the $1 hook printed [$out]; want nothing"
}

# pane_has TEXT: the row's pane shows TEXT now.
pane_has() {
    local pane_text
    pane_text="$(agent-director read-pane --instance-id "$id" --n-lines 40 | jq -r '.pane')"
    [[ "$pane_text" == *"$1"* ]]
}

# Step 1: the config, the cwd, and a Codex folder with the rollout the payloads name.
[ -x "$standin" ] || fail "$standin is not an executable file"
mkdir -p "$HOME/.config/agent-director"
printf '[launch]\ncodex_path = "%s"\n' "$standin" > "$config"
cwd="$(mktemp -d /tmp/ag-al-XXXXXX)"
cwd="$(cd -P "$cwd" && pwd)"
codex_home="$(mktemp -d)"
rollout="$codex_home/sessions/2026/10/12/rollout-2026-10-12T10-00-00-$sid.jsonl"
mkdir -p "$(dirname "$rollout")"
printf '{"type":"session_meta"}\n' > "$rollout"

# Step 2: a waiting codex row with the relay on.
out="$(agent-director spawn --agent codex --cwd "$cwd" --instance-id "$id" --tmux-session-name cd-ag-al \
    --relay-mode on --extra-env "CODEX_HOME=$codex_home")" || fail "spawn exited non-zero"
[ "$(jq -r '.instance_id' <<<"$out")" = "$id" ] || fail "spawn echoed [$out]; want id $id"
end=$(( $(date +%s%N) + 10000000000 ))
until [ -s "$rec_root/$id/pid" ]; do
    [ "$(date +%s%N)" -lt "$end" ] || fail "no stand-in record at $rec_root/$id within 10 s"
    sleep 0.1
done
fire SessionStart '{"source":"startup"}'
wait_state waiting
[ "$(col "agent || '|' || relay_mode")" = "codex|on" ] || fail "row agent|relay_mode is [$(col "agent || '|' || relay_mode")]; want codex|on"

# Step 3: the PermissionRequest, typed as a hook that blocks on the relay.
command="touch $cwd/shell.txt"
req="$(jq -cn --arg sid "$sid" --arg tp "$rollout" --arg cwd "$cwd" --arg cmd "$command" \
    '{hook_event_name: "PermissionRequest", session_id: $sid, transcript_path: $tp, cwd: $cwd, model: "codex-stand-in", permission_mode: "default", turn_id: "turn-1", tool_name: "Bash", tool_input: {command: $cmd, description: "write a file"}}')"
job="$(/opt/driver/pane-hook.sh --agent codex --no-wait "$id" "$req")"
token=""
for _ in $(seq 1 100); do
    token="$(/opt/driver/sql.sh -readonly "$db" "SELECT request_token FROM permission_requests WHERE instance_id = '$id' AND decision IS NULL ORDER BY request_id DESC LIMIT 1;")"
    [ -z "$token" ] || break
    sleep 0.1
done
[ -n "$token" ] || fail "no open permission request for $id: the relay hook never recorded one"
[ ! -s "$job/rc" ] || fail "the relay hook has already exited ($(cat "$job/rc")) with no decision"
wait_state check_permission

# Step 4: what the request holds.
perm="$(agent-director get-permission --request-token "$token")"
[ "$(jq -r '.tool_name' <<<"$perm")" = "Bash" ] || fail "tool_name is [$(jq -r '.tool_name' <<<"$perm")]; want Bash: $perm"
[ "$(jq -r '.tool_input | fromjson | .command' <<<"$perm")" = "$command" ] || fail "tool_input is [$(jq -r '.tool_input' <<<"$perm")]; want command [$command]"
[ "$(jq -r '[.decision, .tool_use_id, .proven_gone_at] | map(. == null) | all' <<<"$perm")" = "true" ] || fail "decision, tool_use_id and proven_gone_at must all be null: $perm"
[ "$(/opt/driver/sql.sh -readonly "$db" "SELECT IFNULL(agent_id, 'NULL') || '|' || IFNULL(tool_use_id, 'NULL') FROM permission_requests WHERE request_token = '$token';")" = "NULL|NULL" ] \
    || fail "the stored request has an agent_id or a tool_use_id"
[ "$(agent-director get --instance-id "$id" | jq -r --arg t "$token" '[.permission_requests[] | select(.request_token == $t)] | length')" = "1" ] \
    || fail "get does not list request $token in permission_requests"

# Step 5: decide allow reaches the hook's stdout.
dec="$(agent-director decide --instance-id "$id" --request-token "$token" --decision allow --reason ok)" || fail "decide exited non-zero"
[ "$(jq -r '.delivery' <<<"$dec")" = "delivered" ] || fail "decide delivery is [$(jq -r '.delivery' <<<"$dec")]; want delivered: $dec"
hook_out="$(/opt/driver/pane-hook.sh --timeout 10 --wait "$job")" || fail "the relay hook exited non-zero"
[ "$(jq -r '.hookSpecificOutput.decision.behavior' <<<"$hook_out")" = "allow" ] || fail "the hook's stdout is [$hook_out]; want an allow envelope"
[ "$(jq -r '.hookSpecificOutput.decision.message' <<<"$hook_out")" = "null" ] || fail "the allow envelope carries a message: $hook_out"
perm="$(agent-director get-permission --request-token "$token")"
[ "$(jq -r '[.decision, .delivery] | join("|")' <<<"$perm")" = "allow|delivered" ] || fail "request reads [$(jq -r '[.decision, .delivery] | join("|")' <<<"$perm")]; want allow|delivered"
[ "$(jq -r '.proven_gone_at' <<<"$perm")" = "null" ] || fail "request proven gone before any Interrupt: $perm"

# Step 6: delivered proves nothing, so a plain send-keys is held.
set +e
agent-director send-keys --instance-id "$id" --text "echo $marker" >/dev/null 2>"$errfile"
rc=$?
set -e
[ "$rc" -eq 1 ] || fail "plain send-keys exited $rc; want 1: $(cat "$errfile")"
envelope="$(awk '/^\{/{ln=$0} END{print ln}' "$errfile")"
[ "$(jq -r '.err_name' <<<"$envelope")" = "ErrDialogMaybeOpen" ] || fail "err_name is [$(jq -r '.err_name' <<<"$envelope")]; want ErrDialogMaybeOpen: $(cat "$errfile")"
sleep 1
if pane_has "$marker"; then fail "the held send-keys typed its marker into the pane"; fi

# Step 7: a Codex Interrupt of the main agent proves it gone.
fire Interrupt '{"turn_id":"turn-1"}'
wait_state waiting
perm="$(agent-director get-permission --request-token "$token")"
[ "$(jq -r '.proven_gone_how' <<<"$perm")" = "turn_end" ] || fail "proven_gone_how is [$(jq -r '.proven_gone_how' <<<"$perm")]; want turn_end: $perm"
[ "$(jq -r '.proven_gone_at' <<<"$perm")" != "null" ] || fail "proven_gone_at is null after the Interrupt: $perm"

# Step 8: now a plain send-keys types.
out="$(agent-director send-keys --instance-id "$id" --text "echo $marker")" || fail "plain send-keys exited non-zero after the Interrupt"
[ "$(jq -c . <<<"$out")" = "{}" ] || fail "send-keys printed [$out]; want {}"
end=$(( $(date +%s) + 10 ))
until pane_has "$marker"; do
    [ "$(date +%s)" -lt "$end" ] || fail "the marker never reached the pane within 10 s"
    sleep 0.2
done

echo "agent-18 ok: Codex PermissionRequest -> check_permission (Bash, command kept, no tool_use_id/agent_id); decide allow -> allow envelope; send-keys held (ErrDialogMaybeOpen) until the Interrupt (turn_end), then typed"
```
