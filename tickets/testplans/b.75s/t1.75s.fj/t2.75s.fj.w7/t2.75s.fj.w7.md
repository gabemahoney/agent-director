# discover-12: kill leaves a subagent record running; the mark that makes the row missing turns it lost with agent_gone

Maps to Epic `t1.f5h.mg` AC 2 (case (c)) (SRD `t1.xjn.du` SR-15.7 (c),
SR-8.1, SR-8.4, SR-3.5, SR-20.9, N9). X is spawned for real and reports in
(a SessionStart `startup` typed into its pane), then its own pane process
delivers a launch request and a SubagentStart that make one `running`
record. A hook applies only from the row's own pane process (SR-22.9), so
each is typed with `/opt/driver/pane-hook.sh`. `list-subagents` reads the
record after each step.

- A launch request (PreToolUse of the `Agent` tool) opens a claimable
  launch; the SubagentStart of its type claims it: one `running` record.
- `kill` ends X's session and pane process, exits 0 with `kill_sent` true
  and changes no state: X reads the state it read before the kill (`working`,
  from the tool hook) and is not `missing`, and the record still reads
  `running` with `close_reason` and `lost_at` null (N9: a killed agent's
  records turn `lost` only once its row is marked).
- Once the recorded pane process has exited, `find-missing` lists X's id and
  X reads `missing`. The mark closes the record in its own transaction:
  `list-subagents` shows it `lost` with `close_reason` `agent_gone`,
  `lost_at` set, `stopped_at` null.

## Setup

Per-case DB-reset. The spawn runs with
`PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the `agent-director`
command, so X's pane process is the stand-in claude's interactive bash,
which sends no hook by itself and exits on the pane kill's SIGHUP. The
payloads are minimal: `hook_event_name` and the SR-5.1 fields of each step
(`tool_name` for the launch request, `agent_id`, `agent_type` and
`session_id` for the start), and no content. The store is read through
`list-subagents`, `get`, `/opt/driver/sql.sh` (for the recorded pane
process only, at the path the build uses, never a hard-coded one) and
`find-missing`'s own output. The case starts a real tmux session; the
DB-reset fixture ends it.

## Steps

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --agent claude --cwd /tmp`
   → X. Type a SessionStart (`source` `startup`) into X's pane. X is
   `waiting`; `list-subagents` reads `{"tracked":true,"subagents":[]}`; the
   row records its pane process as `pid`.
2. Type a PreToolUse (`tool_name` `Agent`, `tool_use_id` `d12-toolu`,
   `tool_input.subagent_type` `general-purpose`), then a SubagentStart for
   `d12-sub` (`agent_type` `general-purpose`, `session_id` `d12-sess`).
   `list-subagents` shows exactly one record, `d12-sub`, `running`.
3. Read X's state (`working`, from the PreToolUse), then
   `kill --instance-id X` → exit 0, `kill_sent` true. X reads the same
   state (not `missing`); the record is still `running`, `close_reason`,
   `stopped_at` and `lost_at` null.
4. Wait for the recorded pane process to exit. `find-missing` → its `ids`
   contains X. X reads `missing`.
5. `list-subagents` shows the one record `lost`, `close_reason`
   `agent_gone`, `lost_at` a time, `stopped_at` null.

## Pass criteria

- Every typed hook exits 0 with empty stdout; `kill` and `find-missing`
  exit 0.
- After step 1: X `waiting`; `tracked` true, no record; a pane `pid`
  recorded.
- After step 2: `tracked` true and one record: `subagent_id` `d12-sub`,
  `instance_id` X, `state` `running`, `subagent_type` `general-purpose`,
  `close_reason`, `stopped_at` and `lost_at` null.
- After step 3: `kill_sent` true; X's state equals its state before the
  kill and is neither `missing` nor `ended`; the one record is
  still `running` with `close_reason`, `stopped_at` and `lost_at` null.
- After step 4: `find-missing`'s `ids` contains X; X's state is `missing`.
- After step 5: one record, `subagent_id` `d12-sub`, `state` `lost`,
  `close_reason` `agent_gone`, `lost_at` a time, `stopped_at` null,
  `first_started_at` and `started_at` equal to their values after step 3.

## Script

```bash
set -euo pipefail
db="$HOME/.config/agent-director/state.db"
fail() { echo "FAIL: $*"; exit 1; }
id="$(PATH="/opt/driver/stand-in-claude:$PATH" agent-director spawn --agent claude --cwd /tmp | jq -r '.instance_id')"
test -n "$id" || fail "spawn returned no instance_id"

# hook <label> <payload>: type it into X's own pane; exit 0 and empty stdout.
hook() {
    local out
    out="$(/opt/driver/pane-hook.sh "$id" "$2")" || fail "[$1] hook exited non-zero"
    test -z "$out" || fail "[$1] hook stdout = $out; want empty"
}
subs() { agent-director list-subagents --instance-id "$id"; }
# check <label> <field summary> <jq filter>: the filter must be true of list-subagents' output.
check() {
    local got
    got="$(subs)"
    jq -e "$3" <<<"$got" >/dev/null || fail "[$1] list-subagents = $got; want $2"
}
rowstate() { agent-director get --instance-id "$id" | jq -r '.state'; }

# 1. X reports in; nothing is recorded; the row records its pane process.
hook session-start '{"hook_event_name":"SessionStart","source":"startup","transcript_path":"/x/d12-session.jsonl"}'
state="$(rowstate)"
test "$state" = "waiting" || fail "after SessionStart state=$state; want waiting"
check after-session-start 'tracked true and no record' '.tracked == true and .subagents == []'
pid="$(/opt/driver/sql.sh -readonly "$db" "SELECT pid FROM spawns WHERE instance_id = '$id';")"
test -n "$pid" || fail "row records no pid after SessionStart"

# 2. A launch request, then the SubagentStart of its type: one running record.
hook request '{"hook_event_name":"PreToolUse","tool_name":"Agent","tool_use_id":"d12-toolu","tool_input":{"subagent_type":"general-purpose"}}'
hook start '{"hook_event_name":"SubagentStart","agent_id":"d12-sub","agent_type":"general-purpose","session_id":"d12-sess"}'
check after-start "one record d12-sub: running, subagent_type general-purpose, close_reason/stopped_at/lost_at null" \
    ".tracked == true and (.subagents | length) == 1 and (.subagents[0]
    | .subagent_id == \"d12-sub\" and .instance_id == \"$id\" and .state == \"running\"
      and .subagent_type == \"general-purpose\"
      and .close_reason == null and .stopped_at == null and .lost_at == null)"
times_running="$(subs | jq -c '.subagents[0] | [.first_started_at, .started_at]')"

# 3. kill ends the agent but changes no state: the row is not missing and the record still runs.
before_kill="$(rowstate)"
case "$before_kill" in missing|ended) fail "before kill state=$before_kill; want a live state" ;; esac
out="$(agent-director kill --instance-id "$id")" || fail "kill exited non-zero; want 0"
sent="$(jq -r '.kill_sent' <<<"$out")"
test "$sent" = "true" || fail "kill kill_sent=$sent; want true (stdout: $out)"
state="$(rowstate)"
test "$state" = "$before_kill" || fail "after kill state=$state; want $before_kill (kill never changes the state)"
check after-kill "one record still running, close_reason/stopped_at/lost_at null" \
    '.tracked == true and (.subagents | length) == 1 and (.subagents[0]
    | .state == "running" and .close_reason == null and .stopped_at == null and .lost_at == null)'

# 4. Once the recorded pane process has exited, find-missing marks the row missing.
deadline=$(( $(date +%s) + 10 ))
while [ "$(date +%s)" -lt "$deadline" ]; do
    if ! kill -0 "$pid" 2>/dev/null; then break; fi
    sleep 0.2
done
if kill -0 "$pid" 2>/dev/null; then fail "recorded pane process $pid still runs 10 s after kill"; fi
res="$(agent-director find-missing)" || fail "find-missing exited non-zero; want 0"
jq -e --arg id "$id" '.ids | index($id) != null' <<<"$res" >/dev/null || fail "find-missing = $res; want ids to contain $id"
state="$(rowstate)"
test "$state" = "missing" || fail "after find-missing state=$state; want missing"

# 5. The mark closed the record: lost, agent_gone, lost_at set, no stop time, start times unchanged.
check after-find-missing "one record d12-sub: lost, close_reason agent_gone, lost_at a time, stopped_at null" \
    ".tracked == true and (.subagents | length) == 1 and (.subagents[0]
    | .subagent_id == \"d12-sub\" and .state == \"lost\" and .close_reason == \"agent_gone\"
      and (.lost_at | type) == \"string\" and .stopped_at == null)"
times_lost="$(subs | jq -c '.subagents[0] | [.first_started_at, .started_at]')"
test "$times_lost" = "$times_running" || fail "[find-missing] start times changed: $times_running -> $times_lost"

echo "discover-12 ok: id=$id; d12-sub ran from its claimed launch; kill left X $before_kill and the record running; after pid $pid exited find-missing marked X missing and the record read lost (agent_gone, lost_at $(subs | jq -r '.subagents[0].lost_at'), stopped_at null)"
```
