# recov-4: expire --older-than 0d reaps all terminal rows

Maps to Epic 8 AC #2. With a zero-duration window, every
ended/missing row is removed; live rows are untouched.

## Setup

Per-case DB-reset. Seed three rows: one ended, one missing, one live.
Set ended_at explicitly for both terminal rows: the factory's missing
transition does not timestamp it. The live row has no ended_at.

## Steps

1. Seed three complete rows through `apitest.SeedSpawn`, including their
   published conversations/current Launches.
2. Set ended_at for both terminal rows to CURRENT_TIMESTAMP.
3. `expire --older-than 0d`.
4. Verify the two terminal rows are gone; the live row remains.

## Pass criteria

- expire exits 0.
- `count=2`; `.ids` contains both terminal row IDs.
- Live row is untouched.

## Script

```bash
set -euo pipefail
for shape in end:ended miss:missing live:waiting; do
    /opt/driver/seed-spawn.sh "$HOME/.config/agent-director/state.db" \
      "$(jq -cn --arg suffix "${shape%:*}" --arg state "${shape#*:}" \
        '{ID:("id-ex-"+$suffix),State:$state,Name:("cd-ex-"+$suffix)}')" >/dev/null
done
/opt/driver/sql.sh "$HOME/.config/agent-director/state.db" \
  "UPDATE spawns SET ended_at = CURRENT_TIMESTAMP WHERE instance_id IN ('id-ex-end', 'id-ex-miss');"

res=$(agent-director expire --older-than 0d)
count=$(printf '%s' "$res" | jq -r '.count')
if [ "$count" != "2" ]; then
    echo "FAIL: count=$count; want 2 (res=$res)"; exit 1
fi
ids=$(printf '%s' "$res" | jq -r '.ids | sort | join(",")')
if [ "$ids" != "id-ex-end,id-ex-miss" ]; then
    echo "FAIL: ids=$ids; want id-ex-end,id-ex-miss"; exit 1
fi

# Live row remains.
n=$(/opt/driver/sql.sh "$HOME/.config/agent-director/state.db" \
    "SELECT COUNT(*) FROM spawns WHERE instance_id='id-ex-live';")
if [ "$n" != "1" ]; then
    echo "FAIL: live row gone"; exit 1
fi

# Terminal rows are gone.
n=$(/opt/driver/sql.sh "$HOME/.config/agent-director/state.db" \
    "SELECT COUNT(*) FROM spawns WHERE instance_id IN ('id-ex-end','id-ex-miss');")
if [ "$n" != "0" ]; then
    echo "FAIL: terminal rows survived expire 0d"; exit 1
fi
echo "recov-4 ok: --older-than 0d reaped 2 terminal rows; live row untouched"
```
