# spawn-3: PreToolUse(AskUserQuestion) drives state to ask_user

Maps to Epic 3 AC #3 (AskUserQuestion → state = ask_user). Verifies the
SRD §5.2 tool-name carve-out: PreToolUse with `tool_name=AskUserQuestion`
maps to `ask_user`, any other tool maps to `working`. Epic 8
(`t1.h98.xw`, SR-20.9, SR-22.9): a hook moves the row only when it comes
from the row's own pane process, so each hook is typed into the pane.

## Setup

Per-case DB-reset has wiped the DB. The spawn runs with
`PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the `agent-director`
command (tmux finds `claude` on the launching process's PATH), so the pane
process is the stand-in claude's interactive bash, and
`/opt/driver/pane-hook.sh <id> '<payload>'` types each hook into that
pane with `tmux send-keys` (exiting with the hook's exit status). No hook
is piped from the case's own shell.

## Steps

1. spawn (with the stand-in) → SessionStart hook typed into the pane →
   state should be `waiting`.
2. PreToolUse(AskUserQuestion) hook typed into the pane → state should
   be `ask_user`.
3. PreToolUse(Bash) hook typed into the pane → state should be
   `working` (non-AUQ branch).

## Pass criteria

- All three states observed in order.

## Script

```bash
set -euo pipefail
id="$(PATH="/opt/driver/stand-in-claude:$PATH" agent-director spawn --cwd /tmp | jq -r '.claude_instance_id')"
/opt/driver/pane-hook.sh "$id" '{"hook_event_name":"SessionStart"}'
state="$(agent-director status --claude-instance-id "$id" | jq -r '.state')"
test "$state" = "waiting"
/opt/driver/pane-hook.sh "$id" '{"hook_event_name":"PreToolUse","tool_name":"AskUserQuestion"}'
state="$(agent-director status --claude-instance-id "$id" | jq -r '.state')"
test "$state" = "ask_user"
/opt/driver/pane-hook.sh "$id" '{"hook_event_name":"PreToolUse","tool_name":"Bash"}'
state="$(agent-director status --claude-instance-id "$id" | jq -r '.state')"
test "$state" = "working"
echo "spawn-3 ok: SessionStart -> waiting, AUQ -> ask_user, Bash -> working"
```
