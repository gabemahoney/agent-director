# busy-send-claude-wait-turn-2: Dialog authority and the raw-key advice

Maps to Epic `t1.xis.oo` acceptance criteria 3 and 4 (Subtask
`t3.xis.oo.2o.gv`; SRD `t1.kii.kn` SR-1.2, SR-3.3, SR-3.9; PRD "Agents busy
send doesn't cover keep raw keys"). On a covered Claude Launch, a send that
names a raw-key or pane-answer parameter is refused with `ErrInvalidFlags`
and this advice, from `pkg/api/busy_send_admission.go`: "send the text alone,
and use tmux with record-pane-answer for keys on the pane". The case follows
it as a caller would, with the relay's own fallen-back request open: the text
alone is Held while the Dialog is up, a key is sent to the pane with tmux
directly, and `record-pane-answer` records that outside answer. That answer
is a claim, not proof: the Held Message still waits on the Dialog, and only
the agent's own turn end proves it gone and lets the wake hand it over. The
request's answer is never altered by delivery.

## Setup

Per-case DB-reset; `/opt/driver/busy-send-claude.sh cw2`. A relay-on
spawn of the stand-in Claude.

## Steps

1. Spawn with `--relay-mode on`; type `SessionStart`, then
   `UserPromptSubmit` (a user turn).
2. With `[relay] timeout_seconds = 2` configured (no time left to poll or
   answer, b.146 rule 4), type a `PermissionRequest` (tool `Bash`): the
   relay hook records its request and exits with no answer, so the request
   falls back. `pane-hook.sh`'s wait for the hook's exit is the barrier.
   Read the open request's token once; `get-permission`.
3. The old pane answer: `read-pane`, then `send-keys --request-token <t> --as
   deny --key Escape --expect-pane-sha256 <hash>`. `get-permission`.
4. Follow the advice: send the text alone as `d1` (confirmed); type
   `FileChanged`. Send `Escape` to the agent's pane with tmux directly (then
   `C-c`, which only empties the stand-in shell's line for the next typed
   hook). `read-pane` and `record-pane-answer --request-token <t> --as deny
   --expect-pane-sha256 <hash>`, following its own refusals: after
   `ErrClaimTooSoon` it waits until `err_details.not_before`, after
   `ErrPaneChanged` it reads the pane again (at most five tries).
5. `get-permission`; type `FileChanged`.
6. Type `Stop` (the main agent's turn end), then `FileChanged`.
   `get-permission`.
7. Read the tmux call log, the input journal and the pane.

## Pass criteria

- Steps 1-2: the relay hook exits 0 with nothing on stdout; the row is
  `check_permission`; the request reads `delivery` `fallen_back`,
  `hook_alive` false, `decision` null.
- Step 3: exit 1, `ErrInvalidFlags`, `err_description` containing word for
  word "send the text alone, and use tmux with record-pane-answer for keys on
  the pane" and "nothing was stored, sent or typed"; the request still reads
  `pane_answer` `none` and `decision` null; nothing is Held.
- Step 4: `d1` is Held waiting `dialog`; the wake exits 0 and writes nothing
  and the request is unchanged; `record-pane-answer` returns `pane_answer`
  `outside`, `pane_as` `deny`, `decision` `deny`, `decision_reason`
  `pane_outside`.
- Step 5: the request still reads `proven_gone_at` null and `delivery`
  `fallen_back`; the wake exits 0 and writes nothing; `d1` is still Held
  waiting `dialog`: the outside answer grants no delivery authority.
- Step 6: `Stop` exits 0, writes nothing, proves the request gone
  (`proven_gone_at` set), leaves the row `waiting` and touches the wake
  endpoint; the wake exits 2 with exactly `[agent-director: message 1 of 1]\n<d1>`;
  `d1` is Final `sent_unconfirmed` `wait_turn_raced`; the request still reads
  `pane_answer` `outside`, `decision` `deny`, `decision_reason`
  `pane_outside`.
- Step 7: no tmux call of agent-director's sent keys or a paste buffer (the
  case's own `Escape` and `C-c` are logged as the case shell's), the input
  journal is empty, and the pane does not show `d1`'s text.

```bash
set -euo pipefail
. /opt/driver/busy-send-claude.sh cw2

d1="dialog-$tag: the text alone"
perm() { agent-director get-permission --request-token "$token" | jq -c "[$1]"; }

# Step 1: a relay-on production spawn, mid-turn.
agent-director spawn --agent claude --cwd "$work" --instance-id "$id" --tmux-session-name "cd-cw2-$tag" \
    --relay-mode on >/dev/null || fail "spawn exited non-zero"
launched spawn startup
quiet UserPromptSubmit "$(jq -cn --arg p "user turn $tag" '{prompt: $p}')"

# Step 2: a relayed PermissionRequest with no time left to poll: it records its
# request and exits with no answer, so the request falls back. pane-hook.sh's
# own wait for the hook's exit is the barrier; the request is recorded by then.
write_config $'[relay]\ntimeout_seconds = 2'
hook PermissionRequest '{"permission_mode":"default","tool_name":"Bash","tool_input":{"command":"touch x","description":"write a file"}}'
[ "$rc" -eq 0 ] && [ ! -s "$work/out" ] || fail "the relay hook exited $rc, stdout [$(cat "$work/out")]; want 0 and no answer"
token="$(/opt/driver/sql.sh -readonly "$db" "SELECT request_token FROM permission_requests WHERE instance_id = '$id' AND decision IS NULL;")"
[[ "$token" =~ ^[0-9a-f-]{36}$ ]] || fail "the relay hook recorded no open request: [$token]"
[ "$(state)" = check_permission ] || fail "row is [$(state)] with the request open; want check_permission"
[ "$(perm '.delivery, .hook_alive, .decision')" = '["fallen_back",false,null]' ] \
    || fail "the request reads $(perm '.delivery, .hook_alive, .decision'); want fallen_back, hook gone, undecided"

# Step 3: the pane answer through send-keys is refused with the advice; nothing changes.
hash="$(agent-director read-pane --instance-id "$id" | jq -r '.pane_sha256')"
set +e
agent-director send-keys --instance-id "$id" --request-token "$token" --as deny --key Escape \
    --expect-pane-sha256 "$hash" >"$work/out" 2>"$work/err"
rc=$?
set -e
desc="$(jq -r '.err_description' "$work/err")"
[ "$rc" -eq 1 ] && [ "$(jq -r '.err_name' "$work/err")" = ErrInvalidFlags ] \
    && [[ "$desc" == *"send the text alone, and use tmux with record-pane-answer for keys on the pane"* ]] \
    && [[ "$desc" == *"nothing was stored, sent or typed"* ]] \
    || fail "the covered pane answer exited $rc: [$(cat "$work/err")]; want ErrInvalidFlags with the tmux and record-pane-answer advice"
[ "$(perm '.pane_answer, .decision')" = '["none",null]' ] || fail "the refused answer changed the request: $(perm '.pane_answer, .decision')"
[ "$(delivery .held_count)" = "[0]" ] || fail "the refused send left a Message Held"

# Step 4a: "send the text alone": Held while the Dialog is up; the wake answers nothing.
send d1 "$d1" dialog
quiet FileChanged "$changed"
[ "$(perm '.pane_answer, .decision')" = '["none",null]' ] || fail "the wake changed the request: $(perm '.pane_answer, .decision')"

# Step 4b: "use tmux ... for keys on the pane": the caller's own direct tmux.
row="$(/opt/driver/sql.sh -readonly "$db" "SELECT IFNULL(tmux_socket,'') || '|' || pane_id FROM spawns WHERE instance_id = '$id';")"
sock="${row%%|*}"
tmux ${sock:+-S "$sock"} send-keys -t "${row#*|}" Escape
tmux ${sock:+-S "$sock"} send-keys -t "${row#*|}" C-c

# Step 4c: "with record-pane-answer", following its own refusals.
answered=""
for _ in 1 2 3 4 5; do
    hash="$(agent-director read-pane --instance-id "$id" | jq -r '.pane_sha256')"
    set +e
    agent-director record-pane-answer --request-token "$token" --as deny --expect-pane-sha256 "$hash" >"$work/out" 2>"$work/err"
    rc=$?
    set -e
    if [ "$rc" -eq 0 ]; then answered=1; break; fi
    case "$(jq -r '.err_name' "$work/err")" in
        ErrClaimTooSoon)
            nb="$(jq -r '.err_details.not_before // empty' "$work/err")"
            [ -n "$nb" ] || fail "ErrClaimTooSoon names no not_before: $(cat "$work/err")"
            ns=$(( $(date -d "$nb" +%s%N) - $(date +%s%N) ))
            [ "$ns" -le 0 ] || sleep "$(printf '%d.%09d' $((ns / 1000000000)) $((ns % 1000000000)))" ;;
        ErrPaneChanged) ;;
        *) fail "record-pane-answer: $(cat "$work/err")" ;;
    esac
done
[ -n "$answered" ] || fail "record-pane-answer never succeeded: $(cat "$work/err")"
jq -e '.pane_answer == "outside" and .pane_as == "deny" and .decision == "deny" and .decision_reason == "pane_outside"' "$work/out" >/dev/null \
    || fail "record-pane-answer returned [$(cat "$work/out")]"

# Step 5: the outside answer is a claim, not proof: no delivery authority.
[ "$(perm '.proven_gone_at, .delivery')" = '[null,"fallen_back"]' ] || fail "the outside answer reads $(perm '.proven_gone_at, .delivery')"
quiet FileChanged "$changed"
[ "$(result d1)" = '["held",false,"dialog"]' ] || fail "d1 is [$(result d1)] after the outside answer; want Held dialog"

# Step 6: the agent's own turn end proves the Dialog gone; then the wake hands d1 over.
rewind
quiet Stop "$stop"
touched || fail "Stop did not re-signal the Held d1"
[ "$(state)" = waiting ] || fail "row is [$(state)] after Stop; want waiting"
[ "$(perm '.proven_gone_at != null')" = "[true]" ] || fail "Stop did not prove the request gone"
wakes "$(printf '[agent-director: message 1 of 1]\n%s' "$d1")"
[ "$(result d1)" = "$raced" ] || fail "d1 is [$(result d1)]; want $raced"
[ "$(perm '.pane_answer, .decision, .decision_reason')" = '["outside","deny","pane_outside"]' ] \
    || fail "delivery changed the request: $(perm '.pane_answer, .decision, .decision_reason')"

# Step 7: agent-director typed nothing; the case's own keys are its shell's.
awk -F'\t' '$1 != "agent-director" && $2 ~ /(^| )send-keys -t [^ ]+ Escape $/' "$TMUX_CALL_LOG" | grep -q . \
    || fail "the case's direct Escape is not in the tmux call log"
no_product_input "dialog-$tag"

echo "busy-send-claude-wait-turn-2 ok: covered pane answer refused with the tmux and record-pane-answer advice; text alone Held dialog; direct tmux key and record-pane-answer recorded outside; no proof, still Held; the agent's Stop proved the Dialog gone and the wake handed d1 over once; request unchanged; nothing typed by agent-director"
```
