# Test case: Actual Bun default launch deadline and caller recreation

Maps to E1 AC5/8; SR-0.2, SR-4.1, SR-6.1 and Task2 t3.jf1.3e.d6.k2.

## Setup

The Docker driver reset provides a clean baseline. Source the shared Cursor collector helper from the exact revision source mount. It creates a new protected HOME, explicitly routed store, short private tmux namespace, unique id and synthetic Node ACP peer using the existing cursorfix/runtime.js. No Cursor login or real AD store is accessed. Requires Linux, Node, Bun, tmux, jq and procfs.

## Steps

1. Use the actual Bun Client with callTimeoutMs omitted to spawn a HOLD initial prompt.
2. Require measured launch <30000ms, close/recreate the Client and observe working.
3. Recreate independent CLI calls and compare launch/runtime/session identity while generation remains unfinished.
4. Release the fixture, observe waiting and confirm pause/runtime death.

Each predicate is exact in the executable block. These actions use the shipped CLI, real tmux and a synthetic protocol peer.

## Pass criteria

Every shell/JSON/SQL assertion in the block passes, followed by the one deterministic evidence JSON object with this case id and authenticated_cursor=false. This does not satisfy the separate authenticated operator acceptance. Record the exact source/binary SHA and Node/Bun/tmux/kernel versions in the scheduler receipt.

```bash
set -euo pipefail
source /work/source/test/driver/cursor-owned-launch.sh
export CO_STORE="$STORE" CO_ID="$id" CO_CWD="$case_dir/cwd"
cat > "$case_dir/default-client.ts" <<'TS'
import {Client} from "/work/source/pkg/ts-bun-client/src/client.ts";
const options={home:process.env.HOME,storePath:process.env.CO_STORE,_cliPath:"/usr/local/bin/agent-director"};
const c=await Client.create(options);
const start=performance.now();
const result=await c.spawn({agent:"cursor",instance_id:process.env.CO_ID,cwd:process.env.CO_CWD!,no_pre_trust:true,agent_args:["HOLD"]});
const elapsed=performance.now()-start;
if(!(elapsed<30000))throw Error("default timeout exceeded");
c.close();
const replacement=await Client.create(options);
const row=await replacement.get({instance_id:result.instance_id});
if(row.agent!=="cursor")throw Error("not a genuine shipped Cursor row");
replacement.close();
console.log(JSON.stringify({default_timeout:true,launch_under_30000ms:true}));
TS
bun "$case_dir/default-client.ts" | jq -e '.default_timeout==true and .launch_under_30000ms==true' >/dev/null
wait_state working
load_identity
snapshot=$(sql "SELECT launch_token||'|'||pane_pid||'|'||pane_starttime||'|'||session_id FROM spawns WHERE instance_id='$id';")
for caller in 1 2; do ad get --instance-id "$id" | jq -e '.state=="working"' >/dev/null; done
[[ $(sql "SELECT launch_token||'|'||pane_pid||'|'||pane_starttime||'|'||session_id FROM spawns WHERE instance_id='$id';") == "$snapshot" ]]
! proc_gone "$runtime"
! proc_gone "$gateway"
touch "$case_dir/release"
wait_state waiting
ad pause --instance-id "$id" >/dev/null
wait_state ended
wait_gone "$runtime"
evidence t2.jf1.cl.05 'actual-Bun-default,launch-under-30000ms,unfinished-generation,caller-recreation,same-identity'
```
