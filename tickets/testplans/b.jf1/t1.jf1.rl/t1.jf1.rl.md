# Cursor latest resume and lifecycle collector

Task2 owns latest resume, refusal, replay, saved versus transient input, and actual
installed default TypeScript caller timing. Task3 extends this collector for reuse
and agent switches after its separate gate. Existing cursor-relay cases stay unchanged.

All cases use independent temp HOME, store and tmux namespaces through the existing
Cursor launch helper. Native SQLite and protobuf are the same source-derived synthetic
factory used by cursorfix.NewNativeHistory; SQL executes through /opt/driver/sql.sh.
No authenticated recall, native lifecycle capture, human terminal, group/account or
other-platform claim. Go public API parity lives in TestCursorResumePublicLaunchPendingParity;
this collector owns shipped CLI/MCP and the baked public Bun tarball.

Authoring/static validation is separate from exact-commit scheduler execution.
The image builds the stdlib-only native encoder offline with GOPROXY=off; the
existing baked Bun consumer is copied with no package-manager or network execution.
The default 30000 ms client remains unchanged. Each timing receipt measures the
entire public process invocation, including Client.create/resume/close.
