# kill-3: kill on unknown id returns ErrSpawnNotFound

Per SRD §13.1, revised by SR-1.7 and SR-6.1 (Epic `t1.h98.aq`, the
honest kill): `ErrSpawnNotFound` is `kill`'s error for an unknown id,
returned when no row matches the supplied claude_instance_id; no tmux
call is made. It is one of `kill`'s five catalogued errors:
`ErrSpawnNotFound`, `ErrTmuxNotAvailable`, `ErrTmuxKillFailed`,
`ErrTmuxUnresponsive` and `ErrTmuxSessionConflict`. The four tmux errors
are reported to the caller, never swallowed; this case pins only the
unknown-id one.

`kill` must run as the same user and in the same tmux environment as the
agents it acts on, so that it reaches their tmux server; a call from
another user or another tmux server cannot act on an agent's session
(a permission-denied socket, or a different server, is
`ErrTmuxNotAvailable`).

## Setup

Per-case DB-reset. Empty spawns table.

## Steps

1. `agent-director kill --claude-instance-id absent` (no row exists).
2. Inspect stderr for the typed error envelope.

## Pass criteria

- kill exits non-zero.
- stderr JSON envelope's `err_name` is `ErrSpawnNotFound`.

## Script

```bash
set -euo pipefail
stderr_file=$(mktemp)
if agent-director kill --claude-instance-id absent 2>"$stderr_file" >/dev/null; then
    echo "FAIL: kill on absent id exited 0"; exit 1
fi
err_name=$(jq -r '.err_name' "$stderr_file")
if [ "$err_name" != "ErrSpawnNotFound" ]; then
    echo "FAIL: err_name=$err_name; want ErrSpawnNotFound"; exit 1
fi
echo "kill-3 ok: unknown id → ErrSpawnNotFound"
```
