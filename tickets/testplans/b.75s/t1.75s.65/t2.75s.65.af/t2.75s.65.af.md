# relay-8: polling timeout → fail-closed deny envelope

Maps to Epic 10 AC #4 (timeout half). With `relay.timeout_seconds=2`
configured and no decide arriving, the polling loop must give up
and emit a deny envelope after ~2 seconds — SRD §6.4 fail-closed
boundary.

## Setup

Per-case DB-reset. Epic 8 (`t1.h98.xw`, SR-20.9, SR-22.9): a hook moves a
row only when it comes from the row's own pane process, so the row is a
real spawn and every hook is typed into its pane. The spawn runs with
`--relay-mode on` (which puts `AGENT_DIRECTOR_RELAY_MODE=on` in the
session's environment, so the pane's shell and the hook it forks inherit
it) and with `PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the
`agent-director` command, so the pane process is the stand-in claude's
interactive bash. `/opt/driver/pane-hook.sh` types each hook into that
pane; the blocking PermissionRequest uses `--no-wait` (prints the job
dir) and `--wait <job dir>` (prints the hook's stdout, exits with the
hook's exit status). No hook is piped from the case's own shell, so the
driver shell backgrounds nothing. The session is named `cd-<case>`; the
DB-reset fixture, which ends every tmux server (b.8yq), removes it.
Before the spawn, write a per-case
`~/.agent-director/config.toml` pinning `relay.timeout_seconds = 2`; the
hook in the pane reads it (same HOME). An EXIT trap removes it so later
cases see the default even when this case fails early.

## Steps

1. Write config.toml with the short timeout.
2. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd /tmp
   --relay-mode on --tmux-session-name cd-r8` → capture
   `claude_instance_id`.
3. Type a SessionStart hook into the pane → state `waiting`.
4. Type the PermissionRequest into the pane (`--no-wait`); it polls with
   the 2s timeout.
5. Do NOT call decide.
6. `pane-hook.sh --wait <job dir>` until the hook exits (~2s).
7. Inspect stdout: deny envelope.
8. Verify elapsed time (from typing the hook to its exit status) is
   between 2 and 5 seconds.

## Pass criteria

- Hook exits 0 in [2s, 5s].
- Stdout is a deny envelope.

## Script

```bash
set -euo pipefail
# Reset config on any exit so later cases see the default.
trap 'rm -f "$HOME/.agent-director/config.toml"' EXIT
mkdir -p "$HOME/.agent-director"
printf '[relay]
timeout_seconds = 2
' > "$HOME/.agent-director/config.toml"

id="$(PATH="/opt/driver/stand-in-claude:$PATH" agent-director spawn --cwd /tmp --relay-mode on --tmux-session-name cd-r8 | jq -r '.claude_instance_id')"
test -n "$id"
# SR-22.9: the hooks are typed into the row's pane, so they apply.
/opt/driver/pane-hook.sh "$id" '{"hook_event_name":"SessionStart","transcript_path":"/x/r8.jsonl"}'
state="$(agent-director status --claude-instance-id "$id" | jq -r '.state')"
test "$state" = "waiting"

hook_out=$(mktemp)
start=$(date +%s)
job="$(/opt/driver/pane-hook.sh --no-wait "$id" '{"hook_event_name":"PermissionRequest","tool_name":"Bash"}')"
# --wait exits with the hook's exit status: set -e fails the case unless 0.
/opt/driver/pane-hook.sh --timeout 10 --wait "$job" >"$hook_out"
elapsed=$(( $(date +%s) - start ))

if [ "$elapsed" -lt 2 ] || [ "$elapsed" -gt 5 ]; then
    echo "FAIL: elapsed=${elapsed}s; want 2-5s"; exit 1
fi
behavior=$(jq -r '.hookSpecificOutput.decision.behavior' "$hook_out")
if [ "$behavior" != "deny" ]; then
    echo "FAIL: behavior=$behavior; want deny (fail-closed)"
    cat "$hook_out"; exit 1
fi
echo "relay-8 ok: polling timeout → deny envelope after ${elapsed}s"
```
