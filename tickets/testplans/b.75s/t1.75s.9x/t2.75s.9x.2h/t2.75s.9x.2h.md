# interact-6: read-pane --ansi returns raw bytes

Per Epic 4 testplan: `read-pane --ansi` (the opt-in raw mode) returns
the pane bytes verbatim, including ANSI escape sequences. The opposite
of interact-5: where the default strips escapes, `--ansi` preserves
them so a future TUI viewer can re-render the color layout.

Revised by Epic 11 (`t1.h98.m6`, Task `t2.h98.m6.ki`; SR-3.4, SR-3.6,
SR-7.2, SR-20.9): `read-pane` finds the row's session only by its
`@ad_owner` label and captures the agent's pane by pane id. The session
is seeded like kill-1 (`t2.75s.ks.3h`): the row has a launch token and
records no socket, server, pid or pane; the session carries the
five-field label `ad1 <token> <$N> id-i6 <store id>` and its pane
`@ad_pane` `<token> <%N>`, so `read-pane --ansi` finds the agent's pane
through that `@ad_pane` and writes nothing (`row_version` and `pane_id`
unchanged).

## Setup

Per-case DB-reset. Use the same printf-into-bash trick as interact-5
to produce a deterministic ANSI corpus. An EXIT trap removes the session
by its session id if the case fails part-way.

## Steps

1. Read this store's id from `store_meta` with `sqlite3`.
2. `tmux new-session -d -s cd-i6 -e AGENT_DIRECTOR_INSTANCE_ID=id-i6 --
   bash`, capturing `$N` and `%N`.
3. Seed a `spawns` row `id-i6` at state `waiting` with a 16-hex
   `launch_token`; read the token back with `sqlite3`.
4. Set the five-field `@ad_owner` label on `$N` and `@ad_pane`
   `<token> <%N>` on the pane; read the label back.
5. Type (by pane id) a printf that emits SGR red + text; wait, bounded,
   until `tmux capture-pane -p -t '<%N>'` shows `RED END`.
6. `agent-director read-pane --claude-instance-id id-i6 --ansi` (with
   `row_version` and `pane_id` read before and after) → confirm an ESC
   byte (0x1B) survives in the JSON `.pane` value.

## Pass criteria

- The store id and token are 16 lowercase hex; the label read back has
  five fields and equals the one set.
- read-pane exit 0; its output contains the ESC byte (in JSON form,
  that's `\u001b`) followed by `[`.
- read-pane leaves `row_version` and `pane_id` unchanged.

## Script

```bash
set -euo pipefail
db="$HOME/.agent-director/state.db"
fail() { echo "FAIL: $*"; exit 1; }
sid=""
trap '[ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true' EXIT

store_id="$(/opt/driver/sql.sh "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

read -r sid pane < <(tmux new-session -d -s cd-i6 -e AGENT_DIRECTOR_INSTANCE_ID=id-i6 \
    -P -F '#{session_id} #{pane_id}' -- bash)
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"
[[ "$pane" =~ ^%[0-9]+$ ]] || fail "new-session gave pane id [$pane]"

seed_token="$(od -An -N8 -tx1 /dev/urandom | tr -dc '0-9a-f')"
/opt/driver/sql.sh "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, launch_token)
   VALUES ('id-i6', 'waiting', '/tmp', 'cd-i6', 'off', '$seed_token');"
token="$(/opt/driver/sql.sh "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-i6';")"
[[ "$token" =~ ^[0-9a-f]{16}$ ]] || fail "launch_token is not 16 lowercase hex: [$token]"

label="ad1 $token $sid id-i6 $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
tmux set-option -p -t "$pane" @ad_pane "$token $pane"
got_label="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$got_label" = "$label" ] || fail "label read back [$got_label]; want [$label]"
read -r -a fields <<<"$got_label"
[ "${#fields[@]}" -eq 5 ] || fail "label has ${#fields[@]} fields; want 5: [$got_label]"

tmux send-keys -t "$pane" -l 'printf "\033[31mRED\033[0m END"; echo'
tmux send-keys -t "$pane" Enter
for _ in $(seq 1 50); do
    tmux capture-pane -p -t "$pane" | grep -q '^RED END' && break
    sleep 0.1
done
tmux capture-pane -p -t "$pane" | grep -q '^RED END' || fail "printf output never reached pane $pane"

row_q="SELECT row_version || '|' || COALESCE(pane_id, '') FROM spawns WHERE claude_instance_id = 'id-i6';"
before="$(/opt/driver/sql.sh "$db" "$row_q")"
raw_json="$(agent-director read-pane --claude-instance-id id-i6 --ansi --n-lines 50)" || fail "read-pane exited non-zero"
after="$(/opt/driver/sql.sh "$db" "$row_q")"
[ "$before" = "$after" ] || fail "read-pane changed the row: row_version|pane_id [$before] -> [$after]"

# The JSON string field carries the escape byte as \u001b.
if ! echo "$raw_json" | grep -q '\\u001b\['; then
    fail "--ansi did not preserve escape codes: $raw_json"
fi
echo "interact-6 ok: raw bytes preserved under --ansi; pane $pane read by id; row unchanged ($after)"
```
