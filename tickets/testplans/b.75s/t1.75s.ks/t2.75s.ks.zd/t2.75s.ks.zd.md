# pause-3: pause on waiting → row flips to ended → verb returns 0

Per SRD §9 + Epic 5 AC #1: pause on a `waiting` Spawn sends `/exit`,
polls the row's state, and returns 0 when the state becomes `ended`.

Revised by Epic 11 (`t1.h98.m6`, Task `t2.h98.m6.yn`; SR-7.2, SR-3.4,
SR-3.6, SR-20.9): `pause` finds the row's session only by its
`@ad_owner` label (one lookup, one pane listing) and types `/exit` and
Enter into the agent's pane by pane id, never `name:0.0` or an
unlabelled session. The session is made by hand, so it is seeded like
kill-1 (`t2.75s.ks.3h`) and interact-8 (`t2.75s.9x.tf`): the row has a
launch token and records no socket, server, pid or pane; the session
carries the five-field label `ad1 <token> <$N> id-p3 <store id>` and
the agent's pane carries `@ad_pane` `<token> <%N>`. Window 0 pane 0 is
an unlabelled decoy `cat` holding `DECOY-p3`; the agent's `cat` pane is
split off it and is the only one with `@ad_pane`, so a send to
`cd-p3:0.0` would land in the decoy.

In production the SessionEnd hook flips the row to `ended` after
Claude actually exits. In the harness a background process stands in
for that hook: it waits until `/exit` shows in the agent's pane, then
writes `state='ended'` directly via `sqlite3`.

## Setup

Per-case DB-reset has wiped `~/.agent-director/state.db` and killed
`cd-*` sessions; the store exists after the reset, so its id can be
read from `store_meta`. An EXIT trap stops the background flip and
removes the session by its session id if the case fails part-way.

## Steps

1. Read this store's id with `sqlite3` (`SELECT value FROM store_meta
   WHERE key = 'store_id'`).
2. Seed `spawns` row `id-p3` at state `waiting`, session name `cd-p3`,
   with a `launch_token` of 16 lowercase hex characters and no recorded
   socket, pid or pane; read the token back with `sqlite3`.
3. Make session `cd-p3` (`-e AGENT_DIRECTOR_INSTANCE_ID=id-p3`) whose
   window 0 pane 0 is the decoy `cat` holding `DECOY-p3`, split the
   agent's `cat` pane off it, then label the session (`@ad_owner`
   `ad1 <token> <$N> id-p3 <store id>`, read back) and the agent's pane
   (`@ad_pane` `<token> <%N>`).
4. Start the background flip: poll the agent's pane (bounded, 10s) until
   `/exit` shows, then write `state='ended'` for `id-p3`. If `/exit`
   never shows it flips anyway (so pause returns) and exits non-zero.
5. `agent-director pause --claude-instance-id id-p3` (default 30s
   timeout; the flip lands well within it).

## Pass criteria

- The store id and the token are 16 lowercase hex; the label read back
  has five fields and equals the one set.
- pause exits 0 with `{}` on stdout.
- The background flip saw `/exit` in the agent's pane `<%N>` (pause
  typed it there by pane id) before flipping; `/exit` is not in the
  decoy pane.
- Final row state is `ended`; the row now records the agent's pane
  (`pane_id` = `<%N>`, found through `@ad_pane`).
- The trail has no `ad.send_keys.called` line and no `ad.pause.*` line
  for `id-p3` (pause writes no call event).

## Script

```bash
set -euo pipefail
db="$HOME/.agent-director/state.db"
trail="$HOME/.agent-director/ad-trail.jsonl"
fail() { echo "FAIL: $*"; exit 1; }
sid=""
flipper=""
trap '[ -z "$flipper" ] || kill "$flipper" 2>/dev/null || true; [ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true' EXIT

store_id="$(sqlite3 "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

seed_token="$(od -An -N8 -tx1 /dev/urandom | tr -dc '0-9a-f')"
sqlite3 "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, launch_token)
   VALUES ('id-p3', 'waiting', '/tmp', 'cd-p3', 'off', '$seed_token');"
token="$(sqlite3 "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-p3';")"
[[ "$token" =~ ^[0-9a-f]{16}$ ]] || fail "launch_token is not 16 lowercase hex: [$token]"

read -r sid decoy < <(tmux new-session -d -s cd-p3 -e AGENT_DIRECTOR_INSTANCE_ID=id-p3 \
    -P -F '#{session_id} #{pane_id}' -- cat)
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"
[[ "$decoy" =~ ^%[0-9]+$ ]] || fail "new-session gave pane id [$decoy]"
tmux send-keys -t "$decoy" -l 'DECOY-p3'
tmux send-keys -t "$decoy" Enter
pane="$(tmux split-window -d -t "$sid" -P -F '#{pane_id}' -- cat)"
[[ "$pane" =~ ^%[0-9]+$ ]] || fail "split-window gave pane id [$pane]"
[ "$pane" != "$decoy" ] || fail "agent pane equals decoy pane $pane"

label="ad1 $token $sid id-p3 $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
tmux set-option -p -t "$pane" @ad_pane "$token $pane"
got_label="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$got_label" = "$label" ] || fail "label read back [$got_label]; want [$label]"
read -r -a fields <<<"$got_label"
[ "${#fields[@]}" -eq 5 ] || fail "label has ${#fields[@]} fields; want 5: [$got_label]"

# Background flip: stands in for the SessionEnd hook once /exit reached the agent's pane.
(
    seen=1
    for _ in $(seq 1 100); do
        if tmux capture-pane -p -t "$pane" | grep -qF '/exit'; then seen=0; break; fi
        sleep 0.1
    done
    sqlite3 "$db" "UPDATE spawns SET state='ended' WHERE claude_instance_id='id-p3';"
    exit "$seen"
) &
flipper=$!

out="$(agent-director pause --claude-instance-id id-p3)" || fail "pause exited non-zero; want 0"
[ "$(echo "$out" | jq -c '.')" = "{}" ] || fail "pause stdout [$out]; want {}"
saw=0
wait "$flipper" || saw=$?
flipper=""
[ "$saw" -eq 0 ] || fail "/exit never reached the agent pane $pane"
if tmux capture-pane -p -t "$decoy" | grep -qF '/exit'; then
    fail "pause typed /exit into the decoy pane $decoy (name:0.0), not the agent's pane $pane"
fi

final="$(sqlite3 "$db" "SELECT state FROM spawns WHERE claude_instance_id='id-p3';")"
[ "$final" = "ended" ] || fail "final state=$final; want ended"
row_pane="$(sqlite3 "$db" "SELECT COALESCE(pane_id, '') FROM spawns WHERE claude_instance_id = 'id-p3';")"
[ "$row_pane" = "$pane" ] || fail "row pane_id [$row_pane]; want the agent pane $pane"

if [ -f "$trail" ]; then
    calls="$(jq -cR 'fromjson? | select(.claude_instance_id == "id-p3" and ((.event == "ad.send_keys.called") or (.event | tostring | startswith("ad.pause"))))' "$trail")"
    [ -z "$calls" ] || fail "pause wrote a call event: $calls"
fi
echo "pause-3 ok: waiting → /exit by pane id to agent pane $pane (decoy $decoy untouched) → flipped → ended; row records $row_pane"
```
