# relay-3: deny with empty reason defaults to "Denied by orchestrator"

Per SRD §6.3: on `deny` with empty reason, the envelope's message
field defaults to "Denied by orchestrator" so the TUI always shows
something actionable. The default lives at the envelope encoder
(not the DB).

## Setup

Per-case DB-reset.

## Steps

1. Seed row, background hook.
2. `decide --decision=deny` (no --reason).
3. Envelope's message is the literal "Denied by orchestrator".

## Pass criteria

- behavior=deny, message="Denied by orchestrator".

## Script

```bash
set -euo pipefail
trap 'if [ -n "${hook_pid:-}" ]; then kill "$hook_pid" 2>/dev/null || true; fi' EXIT
sqlite3 "$HOME/.agent-director/state.db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode)
   VALUES ('id-r3', 'waiting', '/tmp', 'cd-r3', 'on');"

hook_out=$(mktemp)
( printf '%s' '{"hook_event_name":"PermissionRequest","tool_name":"Bash"}' \
  | AGENT_DIRECTOR_RELAY_MODE=on \
    AGENT_DIRECTOR_INSTANCE_ID=id-r3 \
    agent-director hook >"$hook_out" 2>/dev/null ) &
hook_pid=$!

# decide now REQUIRES --request-token: read the token the backgrounded
# hook minted for the open permission_requests row.
token=""
for _ in $(seq 1 50); do
    token=$(sqlite3 "$HOME/.agent-director/state.db" \
      "SELECT request_token FROM permission_requests
       WHERE claude_instance_id='id-r3' AND decision IS NULL
       ORDER BY request_id DESC LIMIT 1;")
    [ -n "$token" ] && break
    sleep 0.1
done
if [ -z "$token" ]; then
    echo "FAIL: no open permission_requests row for id-r3 (hook never upserted)"; exit 1
fi

agent-director decide --claude-instance-id id-r3 --request-token "$token" --decision deny >/dev/null

wait "$hook_pid"
behavior=$(jq -r '.hookSpecificOutput.decision.behavior' "$hook_out")
message=$(jq -r '.hookSpecificOutput.decision.message' "$hook_out")

# The envelope's message mirrors the DB decision_reason (internal/hook/
# polling.go:144 → EncodeDecision). Even with an EMPTY --reason, decide()
# persists the canonical store.DecisionReasonOperator ("operator") for a
# deny (pkg/api/decide.go). Because that reason is non-empty, EncodeDecision
# passes it straight through — the envelope message is "operator", NOT the
# empty-reason "Denied by orchestrator" fallback (which only the hook's own
# fail-closed/timeout deny path with a truly empty reason produces; see
# relay-8).
if [ "$behavior" != "deny" ] || [ "$message" != "operator" ]; then
    echo "FAIL: envelope behavior=$behavior message=$message; want deny/'operator'"
    cat "$hook_out"; exit 1
fi
echo "relay-3 ok: empty --reason deny still persists canonical 'operator'"
```
