# Test case: Unknown-origin durability and exact execution proof

Maps to E2 AC7; SR-4.1/4.2, SR-5.2, SR-9.1.

## Setup

The harness reset supplies its clean baseline. Source the shared driver, which creates an additional private synthetic Cursor namespace with an override store and control sentinel. All SQL, including raw-byte observer queries and faults, goes through /opt/driver/sql.sh. Source mount and shipped binary must match the scheduler's full commit. No authenticated runtime is used.

## Steps

Execute the ordered block below. Each check tests the stated caller-visible state, preserved fields, request correlation, committed evidence, actual wire bytes or process lifetime. Any injected fault is a test fixture action; it does not establish a production configuration feature.
