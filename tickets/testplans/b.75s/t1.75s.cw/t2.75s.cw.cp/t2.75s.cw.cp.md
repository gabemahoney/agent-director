# busy-send-claude-wait-turn-7: conditional pause, refused then eligible

Maps to Epic `t1.xis.8a` (Task `t2.xis.8a.sv`, Subtask `t3.xis.8a.sv.ga`;
SRD `t1.kii.kn` SR-6.4, SR-6.5, SR-8.4; Model Doc `t1.kii.ta` P-C4.1,
P-C4.5, P-C4.6, P-C4.7). `pause --only-if-waiting` on a Covered Agent reads
the row's raw state and the Launch's turn facts in its claim's transaction:
a working agent is refused `not_waiting` with that raw state, and an agent
that is raw waiting while issued input awaits its turn start is refused
`turn_pending`. Each refusal claims, signals and changes nothing. Once the
agent's own exact sighting and a later parent `Stop` clear those, with
Messages Held, the same call claims the Launch, persists its signal intent,
ends the agent with an identity-checked SIGTERM and verifies its exit,
typing nothing. The Launch End ends the claim, nothing more is handed to the
old Launch, and the Held Messages go to `resume`'s new Launch in order, once.

Case 3 keeps the plain `pause`'s unresolved-input custody; this case is the
conditional call's. Refusal snapshots and claim facts are read through
`/opt/driver/sql.sh` only, which writes nothing; every fact is written by the
binary's own hooks and verbs.

## Setup

Per-case DB-reset; `/opt/driver/busy-send-claude.sh cw7`.

## Steps

1. Spawn; type `SessionStart`, then `UserPromptSubmit` (a user turn). Send
   `m1`.
2. `pause --only-if-waiting`.
3. Type `Stop`, then `FileChanged`; withhold `m1`'s sighting.
4. `pause --only-if-waiting`.
5. Type `m1`'s exact sighting. Send `h1` then `h2`. Type `Stop`; run no
   `FileChanged`.
6. `pause --only-if-waiting`.
7. `resume`; type the resumed Launch's `SessionStart` (`source` `resume`).
8. Type the idle-prompt `Notification`, then `FileChanged`.
9. Read the tmux call log, the input journal and the resumed pane.

## Pass criteria

- Step 1: the raw state is `working`; `m1` is Held waiting `turn_running`.
- Step 2: `pause` exits non-zero with `ErrSpawnNotPausable` and err_details
  exactly `{"cause":"not_waiting","observed_state":"working"}`; every store
  row of the instance (row, conversation, Launches, Messages, hand-overs,
  prompts, pause claims) and the input journal read the same before and
  after, with no pause claim; the agent process still runs.
- Step 3: `Stop` touches the wake endpoint; the wake exits 2 with exactly
  `[agent-director: message 1 of 1]\n<m1>`; `m1` is Final `sent_unconfirmed`
  `wait_turn_raced`; the raw state is `waiting` and `awaiting_turn_start` 1.
- Step 4: as step 2, with err_details exactly `{"cause":"turn_pending"}`.
- Step 5: the sighting clears `awaiting_turn_start`; `h1` is Held waiting
  `turn_running`, `h2` `earlier_message`; `Stop` touches the endpoint; the
  raw state is `waiting`, `awaiting_turn_start` 0 and `held_count` 2.
- Step 6: `pause` exits 0 and prints `{}`; the agent's recorded process is
  gone (or a zombie not yet reaped); the row is `ended` with its session id
  kept; the Launch's End is `process_exited`; its one pause claim is
  `ended` by `launch_end` with its signal intent recorded and outcome
  `paused` or none; `h1` and `h2` are still Held with the same ids, order,
  bytes and options; `m1`'s Result is unchanged; the old Launch has no
  hand-over or prompt but `m1`'s.
- Step 7: the resumed Launch is a covered `resume` Launch with route
  `claude_hooks` and a new wake endpoint, which its `SessionStart` returns;
  `h1` and `h2` are still Held, unchanged.
- Step 8: the Notification exits 0, writes nothing and touches the new
  endpoint; the wake exits 2 with exactly
  `[agent-director: message 1 of 2]\n<h1>\n\n[agent-director: message 2 of 2]\n<h2>`
  (no `m1`); `h1` and `h2` are Final `sent_unconfirmed` `wait_turn_raced`;
  `m1`'s Result and the old Launch's hand-overs are unchanged.
- Step 9: no tmux call of agent-director's, the three `pause` calls and
  `resume` included, sent keys or a paste buffer; the input journal is
  empty; the resumed pane shows neither `h1`'s nor `h2`'s text.

```bash
set -euo pipefail
. /opt/driver/busy-send-claude.sh cw7

m1="handed-over-$tag"
h1="held-one-$tag"
h2="$(printf 'held-two-%s\nsecond line ü' "$tag")"

# raw: the row's raw lifecycle state, which the pause claim judges.
raw() { /opt/driver/sql.sh -readonly "$db" "SELECT state FROM spawns WHERE instance_id = '$id';"; }

# snap: every store row of the instance and the input journal's size.
snap() {
    /opt/driver/sql.sh -readonly "$db" "
        SELECT * FROM spawns WHERE instance_id = '$id';
        SELECT * FROM busy_conversations WHERE instance_id = '$id' ORDER BY generation;
        SELECT * FROM busy_send_launches WHERE instance_id = '$id' ORDER BY recorded_at_ms, launch_id;
        SELECT * FROM busy_send_messages WHERE instance_id = '$id' ORDER BY accepted_seq;
        SELECT * FROM busy_send_handovers WHERE instance_id = '$id' ORDER BY handover_seq;
        SELECT p.* FROM busy_send_prompts p JOIN busy_send_handovers h ON h.handover_id = p.handover_id
            WHERE h.instance_id = '$id' ORDER BY h.handover_seq, p.prompt_index;
        SELECT * FROM busy_send_pause_claims WHERE instance_id = '$id';
        SELECT COUNT(*) FROM input_attempts;"
}

# alive: the row's recorded agent process runs (it exists and is no zombie).
alive() {
    local st
    st="$(sed 's/^.*) //' "/proc/$pid/stat" 2>/dev/null | cut -d' ' -f1 || true)"
    [ -n "$st" ] && [ "$st" != Z ]
}

# refused DETAILS: pause --only-if-waiting exits non-zero with ErrSpawnNotPausable
# carrying exactly DETAILS; the store and the agent are as before, with no claim.
refused() {
    local before out status=0
    before="$(snap)"
    out="$(agent-director pause --instance-id "$id" --only-if-waiting 2>&1 >/dev/null)" || status=$?
    [ "$status" -ne 0 ] && jq -e --argjson d "$1" '.err_name == "ErrSpawnNotPausable" and .err_details == $d' <<<"$out" >/dev/null \
        || fail "pause --only-if-waiting exited $status with [$out]; want ErrSpawnNotPausable with err_details $1"
    [ "$(snap)" = "$before" ] || fail "the refused pause changed the store: $(diff <(printf '%s\n' "$before") <(snap) || true)"
    [ -z "$(/opt/driver/sql.sh -readonly "$db" "SELECT claim_id FROM busy_send_pause_claims WHERE instance_id = '$id';")" ] \
        || fail "a refused pause left a pause claim"
    alive || fail "the agent process $pid is not running after a refused pause"
}

# held: the Held Messages' ids, order, bytes and options, in accepted order.
held() {
    /opt/driver/sql.sh -readonly -separator '|' "$db" "SELECT message_id, accepted_seq, hex(text), send_mode, confirmed
        FROM busy_send_messages WHERE instance_id = '$id' AND place = 'held' ORDER BY accepted_seq;"
}

# issued: the paused Launch's hand-overs and their prompts.
issued() {
    /opt/driver/sql.sh -readonly -separator '|' "$db" "SELECT h.handover_id, p.prompt_index, p.message_count, p.rendered_bytes
        FROM busy_send_handovers h JOIN busy_send_prompts p ON p.handover_id = h.handover_id
        WHERE h.launch_id = '$old_launch' ORDER BY h.handover_seq, p.prompt_index;"
}

# Step 1: a production spawn, mid-turn, with m1 Held.
agent-director spawn --agent claude --cwd "$work" --instance-id "$id" --tmux-session-name "cd-cw7-$tag" >/dev/null \
    || fail "spawn exited non-zero"
launched spawn startup
pid="$(/opt/driver/sql.sh -readonly "$db" "SELECT pid FROM spawns WHERE instance_id = '$id';")"
[[ "$pid" =~ ^[1-9][0-9]*$ ]] || fail "the row records pid [$pid]"
quiet UserPromptSubmit "$(jq -cn --arg p "user turn $tag" '{prompt: $p}')"
send m1 "$m1" turn_running
[ "$(raw)" = working ] || fail "the raw state is [$(raw)] during the user turn; want working"

# Step 2: a working agent is refused with its raw state; nothing changes.
refused '{"cause":"not_waiting","observed_state":"working"}'

# Step 3: the turn ends and the idle wake hands m1 over; its sighting is withheld.
rewind
quiet Stop "$stop"
touched || fail "Stop did not touch the wake endpoint"
wakes "$(printf '[agent-director: message 1 of 1]\n%s' "$m1")"
[ "$(result m1)" = "$raced" ] || fail "m1 is [$(result m1)]; want $raced"
[ "$(raw)" = waiting ] || fail "the raw state is [$(raw)] after the hand-over; want waiting"
[ "$(delivery .awaiting_turn_start)" = "[1]" ] || fail "awaiting_turn_start is $(delivery .awaiting_turn_start); want 1"

# Step 4: raw waiting with a turn pending is refused turn_pending; nothing changes.
refused '{"cause":"turn_pending"}'

# Step 5: m1's exact sighting starts its turn; h1 and h2 arrive and stay Held;
# its Stop records readiness and touches the endpoint, and no FileChanged runs.
sighting
[ "$(delivery .awaiting_turn_start)" = "[0]" ] || fail "m1's exact sighting left awaiting_turn_start $(delivery .awaiting_turn_start)"
send h1 "$h1" turn_running
send h2 "$h2" earlier_message
rewind
quiet Stop "$stop"
touched || fail "Stop did not touch the wake endpoint with h1 and h2 Held"
[ "$(raw)" = waiting ] || fail "the raw state is [$(raw)] after Stop; want waiting"
[ "$(delivery '.awaiting_turn_start, .held_count')" = "[0,2]" ] \
    || fail "before the eligible pause the delivery block reads $(delivery '.awaiting_turn_start, .held_count'); want awaiting 0, 2 Held"

# Step 6: the eligible conditional pause claims the Launch and ends the agent keylessly.
old_wake="$wake"
old_launch="$(/opt/driver/sql.sh -readonly "$db" "SELECT launch_id FROM busy_send_launches WHERE wake_path = '$old_wake';")"
held_before="$(held)"
issued_before="$(issued)"
m1_before="$(result m1)"
[ "$(wc -l <<<"$held_before")" -eq 2 ] && [ "$(wc -l <<<"$issued_before")" -eq 1 ] \
    || fail "before the pause: Held [$held_before], old Launch hand-overs [$issued_before]; want h1, h2 and m1's one prompt"
out="$(agent-director pause --instance-id "$id" --only-if-waiting)" || fail "pause --only-if-waiting exited non-zero on a waiting agent"
[ "$out" = "{}" ] || fail "pause --only-if-waiting printed [$out]; want {}"
# pause succeeds only once it verified the agent's exit: no wait of the case's own.
st="$(sed 's/^.*) //' "/proc/$pid/stat" 2>/dev/null | cut -d' ' -f1 || true)"
[ -z "$st" ] || [ "$st" = Z ] || fail "the agent process $pid is still running (state $st) after pause succeeded"
got="$(/opt/driver/sql.sh -readonly -separator '|' "$db" "SELECT state, IFNULL(session_id, '') FROM spawns WHERE instance_id = '$id';")"
[ "$got" = "ended|$sid" ] || fail "the row reads [$got] after pause; want ended|$sid"
got="$(/opt/driver/sql.sh -readonly "$db" "SELECT IFNULL(end_cause, '') FROM busy_send_launches WHERE launch_id = '$old_launch';")"
[ "$got" = process_exited ] || fail "the paused Launch's end_cause is [$got]; want process_exited"
got="$(/opt/driver/sql.sh -readonly -separator '|' "$db" "SELECT launch_id, state, IFNULL(closed_by, ''),
    signal_intent_at_ms IS NOT NULL, IFNULL(call_outcome, '') FROM busy_send_pause_claims WHERE instance_id = '$id';")"
case "$got" in
    "$old_launch|ended|launch_end|1|paused" | "$old_launch|ended|launch_end|1|") ;;
    *) fail "the pause claims read [$got]; want one on $old_launch, ended by launch_end, with its signal intent" ;;
esac
[ "$(held)" = "$held_before" ] || fail "pause changed the Held Messages: [$(held)]; want [$held_before]"
[ "$(result m1)" = "$m1_before" ] || fail "m1 is [$(result m1)] after pause; want [$m1_before]"
[ "$(issued)" = "$issued_before" ] || fail "the paused Launch has hand-overs [$(issued)]; want only m1's [$issued_before]"

# Step 7: resume publishes a new covered Launch; h1 and h2 stay Held, unchanged.
agent-director resume --instance-id "$id" >/dev/null || fail "resume exited non-zero"
launched resume resume
[ "$wake" != "$old_wake" ] || fail "the resumed Launch reuses the paused Launch's wake endpoint"
[ "$(held)" = "$held_before" ] || fail "resume changed the Held Messages: [$(held)]; want [$held_before]"

# Step 8: the idle agent's wake hands h1 and h2 over in order, once; m1 is not replayed.
rewind
quiet Notification '{"notification_type":"idle_prompt","message":"Claude is waiting for your input"}'
touched || fail "the idle-prompt Notification did not touch the resumed Launch's wake endpoint"
wakes "$(printf '[agent-director: message 1 of 2]\n%s\n\n[agent-director: message 2 of 2]\n%s' "$h1" "$h2")"
for m in h1 h2; do
    [ "$(result "$m")" = "$raced" ] || fail "$m is [$(result "$m")]; want $raced"
done
[ "$(result m1)" = "$m1_before" ] || fail "m1 is [$(result m1)] after resume; want [$m1_before]"
[ "$(issued)" = "$issued_before" ] || fail "the paused Launch has hand-overs [$(issued)] after resume; want only m1's"

# Step 9: agent-director typed nothing, the three pauses and resume included.
no_product_input "held-one-$tag" "held-two-$tag"

echo "busy-send-claude-wait-turn-7 ok: working refused not_waiting/working and raw waiting with a turn pending refused turn_pending, each unchanged with no claim; after the exact sighting and a later Stop the conditional pause claimed, ended the agent keylessly (process_exited, claim ended by launch_end with its intent) and kept h1, h2 Held; resume's idle wake handed them over in order once; m1 not replayed; nothing typed"
```
