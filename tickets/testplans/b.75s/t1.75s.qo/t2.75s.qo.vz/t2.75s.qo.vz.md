# spawn-1: spawn returns pending with a launch start; SessionStart hook flips to waiting

Maps to Epic 3 AC #1 (`spawn --cwd /tmp` returns id; `status` shows
pending immediately; SessionStart hook bumps to waiting) and Epic 7
(`t1.h98.hy`, AC-CAT-04 launch-start half, SR-22.2): `status` of a
`pending` row carries `launch_started_at` (RFC3339 UTC, millisecond
precision); on any other row the key is omitted. Epic 8 (`t1.h98.xw`,
SR-20.9, SR-22.9): a hook moves the row only when it comes from the
row's own pane process, so the SessionStart is typed into the pane.

## Setup

Per-case DB-reset has already wiped `~/.agent-director/state.db`. The
container has `agent-director`, `tmux`, `sqlite3`, `jq` on PATH, the
stand-in claude under `/opt/driver/stand-in-claude/` and the helper
`/opt/driver/pane-hook.sh`.

The spawn runs with `PATH=/opt/driver/stand-in-claude:$PATH` prefixed to
the `agent-director` command (tmux finds `claude` on the launching
process's PATH), so the session's command is the stand-in `claude`, which `exec`s an
interactive bash: that shell is the pane process agent-director records.
`pane-hook.sh` types `agent-director hook < <payload file> > <out>;
echo $? > <rc>` into the row's pane with `tmux send-keys` and prints the
hook's stdout, exiting with the hook's exit status. No hook is piped
from the case's own shell (it would be ignored as `pid_mismatch`).

## Steps

1. Record the wall clock (whole seconds), run
   `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd /tmp`
   → capture `claude_instance_id`, record the wall clock again.
2. `agent-director status --claude-instance-id <id>` → assert state =
   `pending` and `launch_started_at` is present: an RFC3339 UTC
   timestamp ending in `Z`, with at most three fraction digits, that
   falls within the spawn's wall-clock window (one second of slack
   either side).
3. Type a SessionStart hook payload into the row's pane with
   `/opt/driver/pane-hook.sh <id> '<payload>'`. Exit 0 with empty
   stdout.
4. `agent-director status --claude-instance-id <id>` → assert state =
   `waiting` and the `launch_started_at` key is absent (not `null`).
   `get` shows the session id taken from the transcript path, and a
   read-only `sqlite3` read shows the row's `pid` equal to its
   `pane_pid` (the applied SessionStart records the hook's parent, the
   pane process).

## Pass criteria

- Step 1 exit 0; result JSON has non-empty `claude_instance_id`.
- Step 2 returns `state` = `pending` and a `launch_started_at` matching
  `^YYYY-MM-DDTHH:MM:SS(.f{1,3})?Z$` inside the spawn's window, e.g.
  `{"state":"pending","launch_started_at":"2026-09-29T12:00:00.123Z"}`.
- Step 3 exits 0 with empty stdout (state-tracking fail-open).
- Step 4 returns `state` = `waiting` with no `launch_started_at` key,
  e.g. `{"state":"waiting"}`; `get` shows
  `claude_session_id` = `abc-uuid`; `pid` = `pane_pid`, both set.

## Script

```bash
set -euo pipefail
before="$(date -u +%s)"
spawn_out="$(PATH="/opt/driver/stand-in-claude:$PATH" agent-director spawn --cwd /tmp)"
after="$(date -u +%s)"
id="$(printf '%s' "$spawn_out" | jq -r '.claude_instance_id')"
test -n "$id"
status_out="$(agent-director status --claude-instance-id "$id")"
state="$(printf '%s' "$status_out" | jq -r '.state')"
test "$state" = "pending"
test "$(printf '%s' "$status_out" | jq -r 'has("launch_started_at")')" = "true"
started="$(printf '%s' "$status_out" | jq -r '.launch_started_at')"
[[ "$started" =~ ^[0-9]{4}-[0-9]{2}-[0-9]{2}T[0-9]{2}:[0-9]{2}:[0-9]{2}(\.[0-9]{1,3})?Z$ ]]
started_s="$(date -u -d "$started" +%s)"
test "$started_s" -ge "$((before - 1))"
test "$started_s" -le "$((after + 1))"
hook_out="$(/opt/driver/pane-hook.sh "$id" '{"hook_event_name":"SessionStart","transcript_path":"/x/abc-uuid.jsonl"}')"
test -z "$hook_out"
status_out="$(agent-director status --claude-instance-id "$id")"
state="$(printf '%s' "$status_out" | jq -r '.state')"
test "$state" = "waiting"
test "$(printf '%s' "$status_out" | jq -r 'has("launch_started_at")')" = "false"
session_id="$(agent-director get --claude-instance-id "$id" | jq -r '.claude_session_id')"
test "$session_id" = "abc-uuid"
pids="$(/opt/driver/sql.sh -readonly "$HOME/.agent-director/state.db" "SELECT COALESCE(pid, 'NULL') || '|' || COALESCE(pane_pid, 'NULL') FROM spawns WHERE claude_instance_id = '$id';")"
[[ "$pids" =~ ^([0-9]+)\|([0-9]+)$ ]] || { echo "FAIL: pid|pane_pid = $pids; want both set"; exit 1; }
test "${BASH_REMATCH[1]}" = "${BASH_REMATCH[2]}" || { echo "FAIL: pid|pane_pid = $pids; want pid = pane_pid"; exit 1; }
echo "spawn-1 ok: id=$id launch_started_at=$started state=waiting (launch start omitted) session_id=$session_id pid=pane_pid=${BASH_REMATCH[1]}"
```
