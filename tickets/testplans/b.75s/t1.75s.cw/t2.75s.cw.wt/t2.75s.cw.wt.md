# busy-send-claude-wait-turn-1: Wait Turn delivery through the owned hooks

Maps to Subtask `t3.xis.oo.u8.sm` (Task `t2.xis.oo.u8`; SRD `t1.kii.kn`
SR-3.1, SR-3.3 to SR-3.5, SR-5.6; Main Agent decision 10). A covered Claude
Launch's Held Messages reach the agent only as the stderr of its owned
`FileChanged` hook, which exits 2; `Stop` only re-signals the wake endpoint,
and AD's own `UserPromptSubmit` sighting of the exact wake text is the
evidence the agent took it. Every hook is typed into the row's pane, so its
parent is the recorded pane process, and gets a pipe for its stderr, as
Claude Code gives it (`pane-hook.sh --stderr-pipe`); one callback runs from
the case's own shell and must be refused.

## Setup

Per-case DB-reset. The case makes a cwd holding the transcript its hooks
name, spawns the stand-in Claude there, and records the row covered with
route A through `ts-helper seed-busy-send-claude-route`, which prints the
Launch's wake endpoint (not yet created). It kills the row's session and
removes the cwd on exit.

## Steps

1. Spawn; seed the route; type `SessionStart` (`source` `startup`).
2. Type `UserPromptSubmit` (a user turn). Send `m1` then `m2`, confirmed,
   with the case's Caller UUID. Type `FileChanged` for the endpoint.
3. Type `Stop`. Run `FileChanged` from the case's own shell.
4. Type `FileChanged`, then type it again.
5. Type `UserPromptSubmit` whose prompt is step 4's stderr in Claude Code's
   measured wake wrapping.
6. Send `m3` and run no `FileChanged` for its hint. Type `Stop`, then
   `FileChanged`.
7. `read-pane`; count the store's input attempts.

Before each step that should touch the endpoint, the case sets its
modification time back to a fixed past second; a changed time is the touch.

## Pass criteria

- Step 1: `SessionStart` exits 0 with exactly
  `{"hookSpecificOutput":{"hookEventName":"SessionStart","watchPaths":["<wake>"]}}`
  on stdout; the endpoint is then an empty regular file, mode 600, of the
  case's user; the row is `waiting`.
- Step 2: `m1` is Held waiting `turn_running` and `m2` behind it
  (`earlier_message`); the sends touch the endpoint; the hint during the turn
  exits 0 and writes nothing.
- Step 3: `Stop` exits 0, writes nothing, touches the endpoint and leaves the
  row `waiting`; the outside-pane `FileChanged` exits 0 and writes nothing;
  `m1` is still Held.
- Step 4: the first `FileChanged` exits 2 with nothing on stdout and exactly
  `[agent-director: message 1 of 2]\none-<tag>\n\n[agent-director: message 2 of 2]\ntwo-<tag>`
  on stderr; the second exits 0 and writes nothing. `m1` and `m2` are Final
  `sent_unconfirmed` `wait_turn_raced`; `get` shows `awaiting_turn_start` 1.
- Step 5: exits 0, writes nothing; `awaiting_turn_start` is 0.
- Step 6: `m3` is Held after its send touched the endpoint; `Stop` touches it
  again; `FileChanged` exits 2 with exactly
  `[agent-director: message 1 of 1]\nthree-<tag>`; `m3` is Final
  `sent_unconfirmed` `wait_turn_raced`.
- Step 7: the pane shows none of the three Messages' texts (it shows only
  the hook command lines the driver typed) and the store records no input
  attempt.

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN

db="$HOME/.config/agent-director/state.db"
uuid="$(cat /proc/sys/kernel/random/uuid)"
tag="${uuid:0:8}"
id="cw-$uuid"
sid="$(cat /proc/sys/kernel/random/uuid)"
caller="$(cat /proc/sys/kernel/random/uuid)"
work="$(mktemp -d /tmp/cw-XXXXXX)"
work="$(cd -P "$work" && pwd)"
transcript="$work/$sid.jsonl"
: > "$transcript"
old=1000000000
wake=""
rc=0
fail() { echo "FAIL: $*"; exit 1; }

cleanup() {
    local row sock pane s
    row="$(/opt/driver/sql.sh -readonly "$db" \
        "SELECT IFNULL(tmux_socket,'') || '|' || IFNULL(pane_id,'') FROM spawns WHERE instance_id = '$id';" 2>/dev/null || true)"
    sock="${row%%|*}"
    pane="${row#*|}"
    if [ -n "$pane" ]; then
        s="$(tmux ${sock:+-S "$sock"} display-message -p -t "$pane" '#{session_id}' 2>/dev/null || true)"
        [ -z "$s" ] || tmux ${sock:+-S "$sock"} kill-session -t "$s" 2>/dev/null || true
    fi
    rm -rf "$work"
}
trap cleanup EXIT

# payload EVENT [EXTRA_JSON]: a Claude hook payload of the main agent's session.
payload() {
    local extra='{}'
    [ $# -lt 2 ] || extra="$2"
    jq -cn --arg e "$1" --arg sid "$sid" --arg tp "$transcript" --arg cwd "$work" --argjson x "$extra" \
        '{hook_event_name: $e, session_id: $sid, transcript_path: $tp, cwd: $cwd} + $x'
}

# hook EVENT [EXTRA_JSON]: type the hook into the row's pane (its parent is the
# pane process) with a pipe for its stderr, as Claude Code gives it; its stdout
# lands in $work/out, its stderr in $work/err and its exit status in rc.
hook() {
    local body
    body="$(payload "$@")"
    set +e
    /opt/driver/pane-hook.sh --stderr-pipe "$id" "$body" >"$work/out" 2>"$work/err"
    rc=$?
    set -e
}

# quiet EVENT [EXTRA_JSON]: the typed hook exits 0 and writes nothing.
quiet() {
    hook "$@"
    [ "$rc" -eq 0 ] && [ ! -s "$work/out" ] && [ ! -s "$work/err" ] \
        || fail "$1 exited $rc, stdout [$(cat "$work/out")], stderr [$(cat "$work/err")]; want 0 and nothing"
}

# wakes WANT: the typed FileChanged for the endpoint exits 2 with nothing on
# stdout and exactly WANT on stderr, which it keeps in $work/prompt.
wakes() {
    hook FileChanged "$changed"
    [ "$rc" -eq 2 ] && [ ! -s "$work/out" ] || fail "FileChanged exited $rc, stdout [$(cat "$work/out")]; want 2 and nothing"
    printf '%s' "$1" | cmp -s - "$work/err" || fail "FileChanged wrote [$(cat -A "$work/err")]; want [$1]"
    cp "$work/err" "$work/prompt"
}

# send NAME TEXT WAIT: a confirmed send of TEXT as Message NAME, Held waiting WAIT.
send() {
    local out
    out="$(agent-director send-keys --instance-id "$id" --text "$2" --confirmed-delivery \
        --caller-uuid "$caller" --delivery-request-id "$1")" || fail "send-keys $1 exited non-zero"
    [ "$(jq -c '[.class, .wait.reason]' <<<"$out")" = "[\"held\",\"$3\"]" ] || fail "send $1 returned [$out]; want Held $3"
}

# result NAME: Message NAME's class, finality and reason.
result() {
    agent-director get-delivery --caller-uuid "$caller" --delivery-request-id "$1" | jq -c '.result | [.class, .final, .reason]'
}
state() { agent-director get --instance-id "$id" | jq -r '.state'; }
awaiting() { agent-director get --instance-id "$id" | jq -r '.delivery.awaiting_turn_start'; }
rewind() { touch -m -d "@$old" "$wake"; }
touched() { [ "$(stat -c %Y "$wake")" != "$old" ]; }
stop='{"stop_hook_active":false,"last_assistant_message":"done"}'
raced='["sent_unconfirmed",true,"wait_turn_raced"]'

# Step 1: a stand-in Claude row recorded covered; SessionStart creates the endpoint and returns it to watch.
PATH="/opt/driver/stand-in-claude:$PATH" agent-director spawn --agent claude --cwd "$work" --instance-id "$id" \
    --tmux-session-name "cd-cw-$tag" >/dev/null || fail "spawn exited non-zero"
wake="$(/work/source/bin/ts-helper seed-busy-send-claude-route --store "$db" --id "$id" | jq -r '.wake_path')"
[ -n "$wake" ] && [ ! -e "$wake" ] || fail "wake endpoint [$wake] is unnamed or exists before SessionStart"
changed="$(jq -cn --arg p "$wake" '{file_path: $p, event: "change"}')"
hook SessionStart '{"source":"startup","model":"claude-stand-in"}'
want="$(jq -cn --arg p "$wake" '{hookSpecificOutput: {hookEventName: "SessionStart", watchPaths: [$p]}}')"
[ "$rc" -eq 0 ] && [ "$(cat "$work/out")" = "$want" ] && [ ! -s "$work/err" ] \
    || fail "SessionStart exited $rc, stdout [$(cat "$work/out")], stderr [$(cat "$work/err")]; want 0 and [$want]"
[ "$(stat -c '%F %a %U' "$wake")" = "regular empty file 600 $(whoami)" ] || fail "wake endpoint is [$(stat -c '%F %a %U' "$wake")]"
[ "$(state)" = waiting ] || fail "row is [$(state)] after SessionStart; want waiting"

# Step 2: a burst sent during a turn stays Held; a hint during the turn writes nothing.
quiet UserPromptSubmit "$(jq -cn --arg p "user turn $tag" '{prompt: $p}')"
rewind
send m1 "one-$tag" turn_running
send m2 "two-$tag" earlier_message
touched || fail "the sends did not touch the wake endpoint"
quiet FileChanged "$changed"

# Step 3: Stop only re-signals; a callback from outside the pane gets nothing.
rewind
quiet Stop "$stop"
touched || fail "Stop with Messages Held did not touch the wake endpoint"
[ "$(state)" = waiting ] || fail "row is [$(state)] after Stop; want waiting"
set +e
payload FileChanged "$changed" | AGENT_DIRECTOR_INSTANCE_ID="$id" agent-director hook 2>&1 >"$work/out" | cat >"$work/err"
rc=${PIPESTATUS[1]}
set -e
[ "$rc" -eq 0 ] && [ ! -s "$work/out" ] && [ ! -s "$work/err" ] \
    || fail "an outside-pane FileChanged exited $rc, stdout [$(cat "$work/out")], stderr [$(cat "$work/err")]; want 0 and nothing"
[[ "$(result m1)" == '["held",false,'* ]] || fail "m1 is [$(result m1)] after the outside-pane wake; want Held"

# Step 4: the wake writes the whole ordered batch on stderr, once.
wakes "$(printf '[agent-director: message 1 of 2]\none-%s\n\n[agent-director: message 2 of 2]\ntwo-%s' "$tag" "$tag")"
quiet FileChanged "$changed"
for m in m1 m2; do
    [ "$(result "$m")" = "$raced" ] || fail "$m is [$(result "$m")]; want $raced"
done
[ "$(awaiting)" = 1 ] || fail "awaiting_turn_start is [$(awaiting)] after the wake; want 1"

# Step 5: AD's own sighting of the exact wake text is the evidence the agent took it.
prefix=$'<task-notification>\n<summary>Stop hook feedback</summary>\n</task-notification>\n<system-reminder>\nStop hook blocking error from command "FileChanged": '
suffix=$'\n</system-reminder>'
quiet UserPromptSubmit "$(jq -cn --rawfile b "$work/prompt" --arg pre "$prefix" --arg suf "$suffix" '{prompt: ($pre + $b + $suf)}')"
[ "$(awaiting)" = 0 ] || fail "awaiting_turn_start is [$(awaiting)] after the sighting; want 0"

# Step 6: a lost hint leaves the Message Held until the next eligible event.
rewind
send m3 "three-$tag" turn_running
touched || fail "the send did not touch the wake endpoint"
[[ "$(result m3)" == '["held",false,'* ]] || fail "m3 is [$(result m3)] with its hint lost; want Held"
rewind
quiet Stop "$stop"
touched || fail "Stop did not re-signal the lost hint"
wakes "$(printf '[agent-director: message 1 of 1]\nthree-%s' "$tag")"
[ "$(result m3)" = "$raced" ] || fail "m3 is [$(result m3)]; want $raced"

# Step 7: AD typed nothing. The pane holds only the hook lines the driver typed.
pane="$(agent-director read-pane --instance-id "$id" --n-lines 200 | jq -r '.pane')"
for text in "one-$tag" "two-$tag" "three-$tag"; do
    [[ "$pane" != *"$text"* ]] || fail "[$text] reached the pane: $pane"
done
[ "$(/opt/driver/sql.sh -readonly "$db" 'SELECT COUNT(*) FROM input_attempts;')" = 0 ] || fail "the store records an input attempt"

echo "busy-send-claude-wait-turn-1 ok: SessionStart watch path; Held during the turn; Stop re-signal; outside-pane wake refused; ordered batch on stderr once; sighting cleared awaiting; lost hint delivered at the next Stop; nothing typed"
```
