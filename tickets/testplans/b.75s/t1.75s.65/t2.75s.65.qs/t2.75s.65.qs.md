# relay-2: deny decision with explicit reason

Maps to Epic 10 AC #3. `decide --decision=deny --reason "not now"`
emits an envelope whose message field carries "not now" verbatim.

## Setup

Per-case DB-reset. Same shape as relay-1.

## Steps

1. Seed Spawn row, background hook.
2. `decide --decision=deny --reason "not now"`.
3. Parse envelope: behavior=deny, message="not now".

## Pass criteria

- Hook stdout's envelope has behavior=deny and the exact reason text.

## Script

```bash
set -euo pipefail
trap 'if [ -n "${hook_pid:-}" ]; then kill "$hook_pid" 2>/dev/null || true; fi' EXIT
sqlite3 "$HOME/.agent-director/state.db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode)
   VALUES ('id-r2', 'waiting', '/tmp', 'cd-r2', 'on');"

hook_out=$(mktemp)
( printf '%s' '{"hook_event_name":"PermissionRequest","tool_name":"Bash"}' \
  | AGENT_DIRECTOR_RELAY_MODE=on \
    AGENT_DIRECTOR_INSTANCE_ID=id-r2 \
    agent-director hook >"$hook_out" 2>/dev/null ) &
hook_pid=$!

# decide now REQUIRES --request-token: read the token the backgrounded
# hook minted for the open permission_requests row.
token=""
for _ in $(seq 1 50); do
    token=$(sqlite3 "$HOME/.agent-director/state.db" \
      "SELECT request_token FROM permission_requests
       WHERE claude_instance_id='id-r2' AND decision IS NULL
       ORDER BY request_id DESC LIMIT 1;")
    [ -n "$token" ] && break
    sleep 0.1
done
if [ -z "$token" ]; then
    echo "FAIL: no open permission_requests row for id-r2 (hook never upserted)"; exit 1
fi

agent-director decide --claude-instance-id id-r2 --request-token "$token" --decision deny --reason "not now" >/dev/null

wait "$hook_pid"
behavior=$(jq -r '.hookSpecificOutput.decision.behavior' "$hook_out")
message=$(jq -r '.hookSpecificOutput.decision.message' "$hook_out")

# The envelope's message mirrors the DB decision_reason (internal/hook/
# polling.go:144 → EncodeDecision). decide() DISCARDS --reason and always
# persists the canonical store.DecisionReasonOperator ("operator") for a
# deny (pkg/api/decide.go), so the envelope message is "operator" — NOT the
# verbatim --reason flag.
if [ "$behavior" != "deny" ] || [ "$message" != "operator" ]; then
    echo "FAIL: envelope behavior=$behavior message=$message; want deny/'operator'"
    cat "$hook_out"; exit 1
fi
echo "relay-2 ok: deny envelope carries canonical 'operator' reason"
```
