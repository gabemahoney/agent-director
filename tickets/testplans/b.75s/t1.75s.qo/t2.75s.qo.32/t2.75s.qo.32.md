# spawn-16: reuse of an ended row with no session starts a new life

Maps to SRD SR-20.9 spawn-16 (history by life, PRD OQ9), SR-10.2,
SR-10.3 and SR-10.6 (Epic 17 `t1.h98.i4`, Task `t2.h98.i4.tm`, Subtask
`t3.h98.i4.tm.pm`; spec `t3.h98.i4.y9.fb`): spawning again with the same
id, opting in to reuse (`--reuse-finished`), over an `ended` row whose
session is gone succeeds. The row is reset to `pending` in life + 1 with
a new launch token and this call's request fields; `get` shows an empty
`prior_sessions` and `transcript_status` `no_session`; the old session
S1 stays in the store's `session_history` exactly once, under the earlier
life; the new session carries the five-field label for the new launch;
and exactly one `ad.spawn.reused` record names S1 as archived.

Agent and hooks (SR-20.9, SR-22.9; collector "Driver mode"): the spawn
and the reuse both run with `PATH=/opt/driver/stand-in-claude:$PATH`
prefixed, so each pane process is the stand-in's interactive bash, which
sends no hook by itself. The first launch's hooks are typed into its pane
with `/opt/driver/pane-hook.sh <id> '<payload>'`; the reused launch's
stand-in is never sent a hook, so the row stays `pending`. No hook is
piped from the case's own shell.

Credential isolation (Epic 10's kill-10 pattern), before any tmux or
agent-director call: `ANTHROPIC_API_KEY` and `CLAUDE_CODE_OAUTH_TOKEN` are
unset and removed from the tmux server's global environment (tolerating no
server); after the spawn and after the reuse, neither appears in
`/proc/<recorded pane_pid>/environ` ("credentials reached the agent").

## Setup

Per-case DB-reset. X's id is `sp16-<uuid>` (the trail is not reset
between cases, so records are selected by this id). The first launch is
named `cd-sp16` and the reuse asks for `cd-sp16r`, both swept by the
reset; an EXIT trap also ends any session the case made by its session id
and removes the transcript and the new cwd the case creates.

1. Credential isolation as above. Read this store's id from `store_meta`
   (`key = 'store_id'`) with `sqlite3`: 16 lowercase hex characters.
2. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd /tmp
   --tmux-session-name cd-sp16 --claude-instance-id X` → exit 0. Read the
   socket, pane, `pane_pid` and the pane's `$N`; check the pane environ.
3. Seed S1's transcript `$HOME/.claude/projects/-tmp/sp16-s1-<tag>.jsonl`,
   then type a SessionStart with that `transcript_path` into X's pane →
   `waiting`, S1, `pid` = `pane_pid`. Type a SessionEnd → `ended`.
4. End X's session by its `$N` and wait (bounded, 5 s) until X's recorded
   `pid`, `pane_pid` and, when it was the server's last session,
   `tmux_server_pid` have exited (resume-1's wait).
5. Record X's `life_number`, `launch_token`, `row_version` and
   `no_pre_trust` with `sqlite3`.

## Steps

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd
   <new dir> --tmux-session-name cd-sp16r --claude-instance-id X
   --reuse-finished --no-pre-trust`, where `<new dir>` is a fresh
   directory under `/tmp` → exit 0, echoes X. Read the new socket, pane,
   `pane_pid` and `$N`; check the pane environ.
2. `get` X.
3. `sqlite3`: X's `life_number`, `launch_token`, `no_pre_trust`; S1's
   `session_history` entries for X.
4. The new session by `$N`: it runs, and its `@ad_owner` label.
5. The trail's `ad.spawn.reused` records for X.
6. `status` X once more, after every check.

## Pass criteria

- Setup preconditions hold (spawn exit 0, `waiting|S1|<pane_pid>`, then
  `ended`, recorded processes gone within 5 s, no credentials in the pane
  environ).
- Step 1: exit 0 with X's id; no credentials in the new pane's environ.
- Step 2: `state` `pending`; `cwd` the new directory's canonical path
  (`pwd -P`); `tmux_session_name` `cd-sp16r`; a `launch_started_at`;
  `prior_sessions` `[]`; `transcript_status` `no_session`; an empty
  `claude_session_id`.
- Step 3: `life_number` is the recorded one + 1; `launch_token` is 16
  lowercase hex and differs from the recorded one; `no_pre_trust` is 1
  (it was 0: the call's own choice); S1 has exactly one `session_history`
  entry for X, with the recorded (earlier) `life_number`.
- Step 4: `tmux has-session -t <$N>` succeeds on the row's socket, and the
  label is `ad1 <new token> <$N> X <store id>` (five fields).
- Step 5: exactly one `ad.spawn.reused` record for X, with
  `archived_session_id` S1, `prior_state` `ended`, `lookup_outcome`
  `gone` and `source` `ad_spawn`.
- Step 6: X is still `pending`. If it turns `waiting` although the reused
  launch's stand-in was never sent a hook, report it rather than loosening
  the case.

Each failed check prints a `FAIL:` line naming what was expected and what
was seen; the final line summarises what was checked.

## Script

```bash
set -euo pipefail
# Credential isolation, before any tmux or agent-director call.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN
tmux set-environment -g -u ANTHROPIC_API_KEY 2>/dev/null || true
tmux set-environment -g -u CLAUDE_CODE_OAUTH_TOKEN 2>/dev/null || true

db="$HOME/.agent-director/state.db"
trail="$HOME/.agent-director/ad-trail.jsonl"
standin_path="/opt/driver/stand-in-claude:$PATH"
jsonl_dir="$HOME/.claude/projects/-tmp"
uuid="$(cat /proc/sys/kernel/random/uuid)"
tag="${uuid:0:8}"
x="sp16-$uuid"
name1=cd-sp16
name2=cd-sp16r
s1="sp16-s1-$tag"
err_file="$(mktemp)"
new_cwd="$(mktemp -d /tmp/sp16-cwd.XXXXXX)"
sock=""
x_sid=""
r_sid=""
fail() { echo "FAIL: $*"; exit 1; }
cleanup() {
    [ -z "$x_sid" ] || tmux ${sock:+-S "$sock"} kill-session -t "$x_sid" 2>/dev/null || true
    [ -z "$r_sid" ] || tmux ${sock:+-S "$sock"} kill-session -t "$r_sid" 2>/dev/null || true
    rm -f "$err_file" "$jsonl_dir/$s1.jsonl"
    rm -rf "$new_cwd"
}
trap cleanup EXIT

# end_and_wait <id> <tmux target>: ends the row's tmux session, then waits
# (bounded, 5 s) until the processes the row records have exited (no /proc
# entry): its pid and pane_pid, and its tmux_server_pid when the session was
# the server's last. A server that holds other sessions must still run after.
end_and_wait() {
    local id="$1" target="$2" rec rpid rpane rserver rsock n left p end
    rec="$(/opt/driver/sql.sh -readonly "$db" "SELECT IFNULL(pid,'') || '|' || IFNULL(pane_pid,'') || '|' || IFNULL(tmux_server_pid,'') || '|' || IFNULL(tmux_socket,'') FROM spawns WHERE claude_instance_id = '$id';")"
    IFS='|' read -r rpid rpane rserver rsock <<<"$rec"
    [[ "$rpid|$rpane|$rserver" =~ ^[0-9]+\|[0-9]+\|[0-9]+$ ]] || fail "$id records pid|pane_pid|tmux_server_pid [$rpid|$rpane|$rserver]; want all set"
    n="$(tmux ${rsock:+-S "$rsock"} list-sessions 2>/dev/null | wc -l)"
    tmux ${rsock:+-S "$rsock"} kill-session -t "$target" || fail "kill-session -t $target of $id failed"
    set -- "$rpid" "$rpane"
    [ "$n" -gt 1 ] || set -- "$@" "$rserver"
    end=$(( $(date +%s%N) + 5000000000 ))
    while :; do
        left=""
        for p in "$@"; do [ ! -e "/proc/$p" ] || left+=" $p"; done
        [ -n "$left" ] || break
        [ "$(date +%s%N)" -lt "$end" ] || fail "$id's recorded process(es)$left still running 5 s after its session $target ended"
        sleep 0.1
    done
    [ "$n" -le 1 ] || [ -e "/proc/$rserver" ] || fail "tmux server $rserver of $id ended although it held $((n - 1)) other session(s)"
}
row_field() { /opt/driver/sql.sh -readonly "$db" "SELECT IFNULL($2,'') FROM spawns WHERE claude_instance_id = '$1';"; }
no_creds() {
    local v
    for v in ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN; do
        if grep -qz "^$v=" "/proc/$1/environ"; then
            fail "credentials reached the agent: $v is in /proc/$1/environ ($2)"
        fi
    done
}
hook() { /opt/driver/pane-hook.sh "$1" "$2" >/dev/null || fail "hook $2 for $1 exited non-zero"; }
session_start() { printf '{"hook_event_name":"SessionStart","source":"startup","transcript_path":"%s"}' "$1"; }
session_end='{"hook_event_name":"SessionEnd","reason":"logout"}'
# spawn_x <args...>: a stand-in spawn of X; stdout in $out, stderr in $err_file, exit status in $rc.
spawn_x() {
    set +e
    out="$(PATH="$standin_path" agent-director spawn --claude-instance-id "$x" "$@" 2>"$err_file")"
    rc=$?
    set -e
}
# launched <what>: reads X's socket, pane, pane_pid and the pane's session id
# into sock, pane, pane_pid and sid, and checks the pane environment.
launched() {
    sock="$(row_field "$x" tmux_socket)"
    pane="$(row_field "$x" pane_id)"
    pane_pid="$(row_field "$x" pane_pid)"
    [ -n "$pane" ] && [[ "$pane_pid" =~ ^[0-9]+$ ]] || fail "X after $1 records pane_id|pane_pid [$pane|$pane_pid]; want both set"
    sid="$(tmux ${sock:+-S "$sock"} display-message -p -t "$pane" '#{session_id}')"
    [[ "$sid" =~ ^\$[0-9]+$ ]] || fail "X's pane $pane after $1 gave session id [$sid]"
    no_creds "$pane_pid" "X after $1"
}

# Setup 1: this store's id.
store_id="$(/opt/driver/sql.sh -readonly "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"
mkdir -p "$jsonl_dir"

# Setup 2: spawn X with the stand-in.
spawn_x --cwd /tmp --tmux-session-name "$name1"
[ "$rc" -eq 0 ] || fail "spawn of X exited $rc; want 0: $(cat "$err_file")"
[ "$(jq -r '.claude_instance_id' <<<"$out")" = "$x" ] || fail "spawn of X echoed [$out]; want id $x"
launched spawn
x_sid="$sid"
sock1="$sock"
pane1_pid="$pane_pid"

# Setup 3: S1's transcript, then SessionStart and SessionEnd typed into X's pane.
echo '{}' > "$jsonl_dir/$s1.jsonl"
hook "$x" "$(session_start "$jsonl_dir/$s1.jsonl")"
got="$(/opt/driver/sql.sh -readonly "$db" "SELECT state || '|' || IFNULL(claude_session_id,'') || '|' || IFNULL(pid,'') FROM spawns WHERE claude_instance_id = '$x';")"
[ "$got" = "waiting|$s1|$pane1_pid" ] || fail "X after SessionStart state|session|pid [$got]; want waiting|$s1|$pane1_pid"
hook "$x" "$session_end"
st="$(row_field "$x" state)"
[ "$st" = "ended" ] || fail "X after SessionEnd state=$st; want ended"

# Setup 4: end X's session by its $N and wait for its recorded processes.
end_and_wait "$x" "$x_sid"
x_sid=""

# Setup 5: what the reuse must change.
life0="$(row_field "$x" life_number)"
token0="$(row_field "$x" launch_token)"
ver0="$(row_field "$x" row_version)"
npt0="$(row_field "$x" no_pre_trust)"
[[ "$life0" =~ ^[0-9]+$ ]] || fail "X's life_number [$life0]; want a number"
[[ "$token0" =~ ^[0-9a-f]{16}$ ]] || fail "X's launch_token [$token0]; want 16 lowercase hex"
[ "$npt0" = "0" ] || fail "X's no_pre_trust [$npt0] after a spawn without --no-pre-trust; want 0"

# Step 1: spawn again with the same id, opting in to reuse, with other request fields.
canon="$(cd "$new_cwd" && pwd -P)"
spawn_x --cwd "$new_cwd" --tmux-session-name "$name2" --reuse-finished --no-pre-trust
[ "$rc" -eq 0 ] || fail "spawn --reuse-finished of ended X exited $rc; want 0: $(cat "$err_file")"
[ "$(jq -r '.claude_instance_id' <<<"$out")" = "$x" ] || fail "spawn --reuse-finished echoed [$out]; want id $x"
launched reuse
r_sid="$sid"
[ "$sock" = "$sock1" ] || fail "reused X records socket [$sock]; want the first launch's [$sock1]"
[ "$pane_pid" != "$pane1_pid" ] || fail "reused X's pane_pid $pane_pid equals the first launch's"

# Step 2: get shows a fresh pending life with the new request's fields.
g="$(agent-director get --claude-instance-id "$x")"
got="$(jq -r '[.state, .cwd, .tmux_session_name, (.prior_sessions | tojson), .transcript_status, (.claude_session_id // "")] | join("|")' <<<"$g")"
[ "$got" = "pending|$canon|$name2|[]|no_session|" ] || fail "get after reuse [state|cwd|name|prior_sessions|transcript_status|session]=[$got]; want [pending|$canon|$name2|[]|no_session|]"
[ -n "$(jq -r '.launch_started_at // empty' <<<"$g")" ] || fail "get after reuse has no launch_started_at: $g"

# Step 3: life + 1, a new token, the call's pre-trust choice, S1 kept under the earlier life.
life1="$(row_field "$x" life_number)"
token1="$(row_field "$x" launch_token)"
npt1="$(row_field "$x" no_pre_trust)"
[ "$life1" -eq $((life0 + 1)) ] || fail "life_number after reuse=$life1; want $((life0 + 1))"
[[ "$token1" =~ ^[0-9a-f]{16}$ ]] || fail "launch_token after reuse [$token1]; want 16 lowercase hex"
[ "$token1" != "$token0" ] || fail "launch_token after reuse is the old one [$token0]"
[ "$npt1" = "1" ] || fail "no_pre_trust after reuse with --no-pre-trust=[$npt1]; want 1"
hist="$(/opt/driver/sql.sh -readonly "$db" "SELECT COUNT(*) || '|' || IFNULL(MIN(life_number),'') || '|' || IFNULL(MAX(life_number),'') FROM session_history WHERE claude_instance_id = '$x' AND claude_session_id = '$s1';")"
[ "$hist" = "1|$life0|$life0" ] || fail "S1's session_history [count|min life|max life]=[$hist]; want [1|$life0|$life0]"

# Step 4: the new session runs by $N with the new launch's five-field label.
tmux ${sock:+-S "$sock"} has-session -t "$r_sid" 2>/dev/null || fail "reused X's session $r_sid is not running"
label="$(tmux ${sock:+-S "$sock"} show-options -t "$r_sid" -v @ad_owner 2>/dev/null || true)"
[ "$label" = "ad1 $token1 $r_sid $x $store_id" ] || fail "reused session $r_sid label [$label]; want [ad1 $token1 $r_sid $x $store_id]"

# Step 5: exactly one ad.spawn.reused, naming S1 as archived.
[ -f "$trail" ] || fail "no trail file at $trail"
recs="$(jq -c --arg x "$x" 'select(.event == "ad.spawn.reused" and .claude_instance_id == $x)' "$trail")"
n="$(printf '%s' "$recs" | grep -c . || true)"
[ "$n" -eq 1 ] || fail "want 1 ad.spawn.reused for X, got $n: $recs"
got="$(jq -r '[(.archived_session_id // "null"), .prior_state, .lookup_outcome, .source] | join("|")' <<<"$recs")"
[ "$got" = "$s1|ended|gone|ad_spawn" ] || fail "ad.spawn.reused [archived_session_id|prior_state|lookup_outcome|source]=[$got]; want [$s1|ended|gone|ad_spawn]: $recs"

# Step 6: the reused launch's stand-in was never sent a hook, so X is still pending.
st="$(agent-director status --claude-instance-id "$x" | jq -r '.state')"
[ "$st" = "pending" ] || fail "X at the end state=$st; want pending (the reused stand-in reported in on its own?)"

ver1="$(row_field "$x" row_version)"
echo "spawn-16 ok: ended X ($x) reused -> pending, cwd $canon, name $name2, prior_sessions [], no_session; life $life0->$life1, row_version $ver0->$ver1, new token, no_pre_trust 1; $s1 kept once under life $life0; $r_sid labelled for the new launch; one ad.spawn.reused ($s1|ended|gone)"
```
