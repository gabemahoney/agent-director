# mcp-8: tools/list inputSchema is well-formed JSON Schema

Per SRD §4.1: each tool advertises a JSON Schema describing its
arguments. This case pins that the spawn tool's schema has the
expected shape: type=object, properties.cwd.type=string, and spawn's
non-scalar params declare the JSON shapes MCP decodes (b.pti, b.zkp):
`extra_env` an object with string values, `label` and `claude_args`
arrays of strings. A param whose manifest type the schema builder does
not map is listed with no `type`, the regression b.pti fixed; this case
catches it in the built binary. mcp-9 sends spawn these shapes.

## Setup

Per-case DB-reset.

## Steps

1. tools/list.
2. Pick the spawn entry.
3. Assert inputSchema.type = "object" and properties.cwd.type = "string".
4. For each of `extra_env`, `label` and `claude_args`, read the
   property's `type` and its element schema's `type`
   (`additionalProperties` for `extra_env`, `items` for the two arrays).

## Pass criteria

- spawn entry exists.
- inputSchema.type = "object".
- properties.cwd.type = "string".
- properties.cwd has a non-empty description.
- properties.extra_env.type = "object" and
  properties.extra_env.additionalProperties.type = "string".
- properties.label.type = "array" and
  properties.label.items.type = "string".
- properties.claude_args.type = "array" and
  properties.claude_args.items.type = "string".

A failed step-4 check prints a `FAIL:` line naming the property, the
`type` pair wanted and the pair seen (`none` where a `type` is missing),
then the property as listed.

## Script

```bash
set -euo pipefail
out=$(printf '%s
%s
' \
    '{"jsonrpc":"2.0","id":1,"method":"initialize"}' \
    '{"jsonrpc":"2.0","id":2,"method":"tools/list"}' \
    | agent-director serve --stdio 2>/dev/null)

spawn_tool=$(printf '%s' "$out" | sed -n '2p' | jq -c '.result.tools[] | select(.name=="spawn")')
if [ -z "$spawn_tool" ]; then
    echo "FAIL: no spawn tool in tools/list"; exit 1
fi
schema_type=$(printf '%s' "$spawn_tool" | jq -r '.inputSchema.type')
cwd_type=$(printf '%s' "$spawn_tool" | jq -r '.inputSchema.properties.cwd.type')
cwd_desc=$(printf '%s' "$spawn_tool" | jq -r '.inputSchema.properties.cwd.description // ""')

if [ "$schema_type" != "object" ] || [ "$cwd_type" != "string" ] || [ -z "$cwd_desc" ]; then
    echo "FAIL: schema_type=$schema_type cwd_type=$cwd_type cwd_desc='$cwd_desc'"
    printf '%s' "$spawn_tool"; exit 1
fi

# Spawn's non-scalar params (b.pti): "<name> <type> <element schema key>".
for spec in 'extra_env object additionalProperties' 'label array items' 'claude_args array items'; do
    read -r name want sub <<<"$spec"
    got=$(printf '%s' "$spawn_tool" | jq -r --arg n "$name" --arg s "$sub" \
        '.inputSchema.properties[$n] | "\(.type // "none") \(.[$s].type // "none")"')
    if [ "$got" != "$want string" ]; then
        echo "FAIL: spawn properties.$name [type $sub.type]=[$got]; want [$want string]"
        printf '%s' "$spawn_tool" | jq -c --arg n "$name" '.inputSchema.properties[$n]'; exit 1
    fi
done
echo "mcp-8 ok: spawn inputSchema is well-formed (object, cwd:string, extra_env:object of string, label and claude_args:array of string)"
```
