# interact-1: single-line send-keys + read-pane roundtrip

Maps to Epic 4 AC #1 (`send-keys --text "what is 2+2?"` lands; `read-pane`
shows the answer). The harness exercises the verb surface end-to-end via
real `tmux` inside the Docker image — no Claude required (a `cat`
process holds the pane open, providing a deterministic pane buffer the
test can drive and read back).

Revised by Epic 11 (`t1.h98.m6`, Task `t2.h98.m6.ki`; SR-3.4, SR-3.6,
SR-7.2, SR-20.9): `read-pane` finds the row's session only by its
`@ad_owner` label (one lookup, one pane listing) and captures the
agent's pane by pane id, never `name:0.0` or an unlabelled session. The
session is made by hand, so it is seeded like kill-1 (`t2.75s.ks.3h`):
the row has a launch token and records no socket, server, pid or pane;
the session carries the five-field label
`ad1 <token> <$N> id-i1 <store id>` and its pane carries `@ad_pane`
`<token> <%N>`, as agent-director's own create sets them. `read-pane`
finds the agent's pane through that `@ad_pane` (the row records no pane)
and writes nothing: the row's `row_version` and `pane_id` are the same
before and after it.

## Setup

Per-case DB-reset has wiped `~/.agent-director/state.db` and killed
`cd-*` sessions; the store exists after the reset, so its id can be
read from `store_meta`. The container has `agent-director`, `tmux`,
`sqlite3`, and `jq` on PATH. An EXIT trap removes the session by its
session id if the case fails part-way.

## Steps

1. Read this store's id with `sqlite3` (`SELECT value FROM store_meta
   WHERE key = 'store_id'`).
2. `tmux new-session -d -s cd-i1 -e AGENT_DIRECTOR_INSTANCE_ID=id-i1 --
   cat`, capturing the session id `$N`, the pane id `%N` and the pane
   pid; the pane stays alive and echoes whatever is typed into it.
3. Seed a `spawns` row `id-i1` at state `waiting` with
   `tmux_session_name=cd-i1` and a `launch_token` of 16 lowercase hex
   characters; read the token back with `sqlite3`.
4. Label the session (`tmux set-option -t '<$N>' @ad_owner 'ad1 <token>
   <$N> id-i1 <store id>'`) and its pane (`tmux set-option -p -t '<%N>'
   @ad_pane '<token> <%N>'`); read the label back.
5. `agent-director send-keys --claude-instance-id id-i1 --text "hello"`.
6. Allow a short settle (cat echoes back).
7. Read the row's `row_version` and `pane_id`, then
   `agent-director read-pane --claude-instance-id id-i1 | jq -r '.pane'`,
   then read them again.

## Pass criteria

- The store id and the token are 16 lowercase hex; the label read back
  has five fields and equals the one set.
- Step 5 exit 0; empty `{}` on stdout.
- Step 7 exit 0 and captures the line containing `hello` from the pane
  labelled `<token> <%N>`.
- Default `read-pane` returns ANSI-free text (cat echoes are plain
  ASCII, but the assertion is symmetric: no `\x1b[` escapes).
- `read-pane` changes nothing: `row_version` and `pane_id` (still
  empty) are the same before and after it.

## Script

```bash
set -euo pipefail
db="$HOME/.agent-director/state.db"
fail() { echo "FAIL: $*"; exit 1; }
sid=""
trap '[ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true' EXIT

store_id="$(/opt/driver/sql.sh "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

read -r sid pane pane_pid < <(tmux new-session -d -s cd-i1 -e AGENT_DIRECTOR_INSTANCE_ID=id-i1 \
    -P -F '#{session_id} #{pane_id} #{pane_pid}' -- cat)
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"
[[ "$pane" =~ ^%[0-9]+$ ]] || fail "new-session gave pane id [$pane]"

seed_token="$(od -An -N8 -tx1 /dev/urandom | tr -dc '0-9a-f')"
/opt/driver/sql.sh "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, launch_token)
   VALUES ('id-i1', 'waiting', '/tmp', 'cd-i1', 'off', '$seed_token');"
token="$(/opt/driver/sql.sh "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-i1';")"
[[ "$token" =~ ^[0-9a-f]{16}$ ]] || fail "launch_token is not 16 lowercase hex: [$token]"

label="ad1 $token $sid id-i1 $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
tmux set-option -p -t "$pane" @ad_pane "$token $pane"
got_label="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$got_label" = "$label" ] || fail "label read back [$got_label]; want [$label]"
read -r -a fields <<<"$got_label"
[ "${#fields[@]}" -eq 5 ] || fail "label has ${#fields[@]} fields; want 5: [$got_label]"

out="$(agent-director send-keys --claude-instance-id id-i1 --text 'hello')" || fail "send-keys exited non-zero"
test "$(echo "$out" | jq -c '.')" = "{}" || fail "send-keys stdout [$out]; want {}"
sleep 0.2

row_q="SELECT row_version || '|' || COALESCE(pane_id, '') FROM spawns WHERE claude_instance_id = 'id-i1';"
before="$(/opt/driver/sql.sh "$db" "$row_q")"
rp="$(agent-director read-pane --claude-instance-id id-i1)" || fail "read-pane exited non-zero"
after="$(/opt/driver/sql.sh "$db" "$row_q")"
[ "$before" = "$after" ] || fail "read-pane changed the row: row_version|pane_id [$before] -> [$after]"

pane_text="$(jq -r '.pane' <<<"$rp")"
echo "$pane_text" | grep -q "hello" || fail "read-pane did not return hello from pane $pane: [$pane_text]"
test -z "$(echo "$pane_text" | grep -F $'\x1b[')" || fail "pane contains escape codes"
echo "interact-1 ok: labelled session $sid, pane $pane read by id; row unchanged ($after); pane=${pane_text}"
```
