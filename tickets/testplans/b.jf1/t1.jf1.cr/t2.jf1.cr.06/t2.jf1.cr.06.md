# Test case: Connected native fallback, pane hash and outside claims

Maps to E2 AC6; SR-4.2, SR-5.2, SR-9.1.

## Setup

The harness reset supplies its clean baseline. Source the shared driver, which creates an additional private synthetic Cursor namespace with an override store and control sentinel. All SQL, including raw-byte observer queries and faults, goes through /opt/driver/sql.sh. Source mount and shipped binary must match the scheduler's full commit. No authenticated runtime is used.

## Steps

Execute the ordered block below. Each check tests the stated caller-visible state, preserved fields, request correlation, committed evidence, actual wire bytes or process lifetime. Any injected fault is a test fixture action; it does not establish a production configuration feature.

## Pass criteria

Every assertion passes and one final JSON object contains this case ID, stable check names, status pass, authenticated_cursor false and separate variable facts. Do not treat an exit code alone as evidence. The collector must be executed externally before claiming a case pass.

```bash
set -euo pipefail
receipts=$(mktemp /tmp/cr-pane-receipts-XXXXXX)
for relay in off on; do
 (
  CURSOR_RELAY_TIMEOUT=1
  source /work/source/test/driver/cursor-owned-launch.sh
  relay_scenario permission
  relay_start "$relay"
  wait_until request_count_is 1
  token=$(sql "SELECT request_token FROM permission_requests WHERE instance_id='$id';")
  if [[ $relay == on ]]; then relay_fault_ack; fi
  relay_guard
  wait_until delivery_is "$token" fallen_back
  # Public claim age is measured from persisted settlement, not a guessed sleep.
  claim_old() { [[ $(sql "SELECT (CAST((julianday('now')-2440587.5)*86400000 AS INTEGER)-settled_at)>=2100 FROM permission_requests WHERE request_token='$token';") == 1 ]]; }
  wait_until claim_old
  ad read-pane --instance-id "$id" --n-lines 100 > "$case_dir/pane.json"
  hash=$(jq -r .pane_sha256 "$case_dir/pane.json")
  if ad send-keys --instance-id "$id" --request-token "$token" --as allow --key 1 --n-lines 100 --expect-pane-sha256 "$(printf '%064d' 0)" >"$case_dir/out" 2>"$case_dir/error"; then exit 1; fi
  jq -e '.err_name=="ErrPaneChanged"' "$case_dir/error" >/dev/null
  ad send-keys --instance-id "$id" --request-token "$token" --as allow --key 1 --n-lines 100 --expect-pane-sha256 "$hash" >/dev/null
  wait_until reply_count_is 1
  [[ $(sql "SELECT pane_answer='sent' AND delivered_at IS NULL AND proven_gone_at IS NULL FROM permission_requests WHERE request_token='$token';") == 1 ]]
  frames | jq -se '[.[]|select(has("method")|not)]|length==1 and .[0].result.outcome.optionId=="allow-once"' >/dev/null
  relay_receipt t2.jf1.cr.06 '["AC6.connected-native-on-off","AC6.stale-hash-refusal","AC6.sent-claim-not-relay-ack","AC6.no-execution-proof"]' >> "$receipts"
 )
done
# Outside claims are separately exercised by the same public API below, without key authority.
(
```
