# busy-send-claude-wait-turn-3: lifecycle custody across keyless pause and resume

Maps to Epic `t1.xis.oo` acceptance criteria 2, 4, 5 and 6 (Subtask
`t3.xis.oo.2o.gv`; SRD `t1.kii.kn` SR-2.3, SR-3.5, SR-5.6, SR-6.1, SR-6.2,
SR-6.4; Plan `b.xis` decision 11). A Message whose text holds Claude's two
reserved closing tags is handed over whole, but Claude Code shows them
escaped, so its sighting cannot be undone exactly and gives no take evidence
(SR-3.5's named limit): `awaiting_turn_start` stays 1 and later Messages
wait. `pause` ends the agent with an identity-checked SIGTERM, typing
nothing; the Launch End clears the obligation and carries the Held Messages,
in order, to `resume`, whose own route hands them over at the idle agent's
next eligible event. The handed-over Message is never handed over again.

The stand-in Claude exits on SIGTERM as Claude Code does
(`stand-in-claude/claude`).

## Setup

Per-case DB-reset; `/opt/driver/busy-send-claude.sh cw3`.

## Steps

1. Spawn; type `SessionStart`, then `UserPromptSubmit` (a user turn).
2. Send `t1`, whose text holds `</system-reminder>`, `</task-notification>`
   and Unicode over two lines. Type `Stop`, then `FileChanged`.
3. Type the sighting of step 2's prompt, wrapped and escaped as Claude Code
   shows it.
4. Send `h1` then `h2`. Type `Stop`, then `FileChanged`.
5. `pause`; then `get`, which must read `ended` or `missing` at once, as
   caller-contract.md "Keyless pause of a Covered Agent" says `resume` may
   follow then: `pause` succeeded only after verifying the agent's exit, and
   `get`'s recovery check sees the process gone.
6. `resume`; type the resumed Launch's `SessionStart` (`source` `resume`).
7. Type the idle-prompt `Notification`, then `FileChanged`.
8. Read the tmux call log, the input journal and the resumed pane.

## Pass criteria

- Step 2: `t1` is Held waiting `turn_running`; `Stop` touches the wake
  endpoint; the wake exits 2 with exactly
  `[agent-director: message 1 of 1]\n<t1>`, tags raw and whole; `t1` is Final
  `sent_unconfirmed` `wait_turn_raced`; `awaiting_turn_start` is 1.
- Step 3: the sighting exits 0 and writes nothing; `awaiting_turn_start`
  stays 1.
- Step 4: `h1` is Held waiting `turn_running`, `h2` `earlier_message`;
  `Stop` does not touch the endpoint while the obligation stands; the wake
  exits 0 and writes nothing; `h1` waits `readiness_unknown`.
- Step 5: `pause` exits 0; the agent's recorded process is gone (or a
  zombie not yet reaped) and the next `get` reads `ended` or `missing`; the
  Launch's End is
  `process_exited`; `awaiting_turn_start` is 0, `held_count` 2; `t1` keeps its
  Final Result; `h1` and `h2` are still Held, not Final.
- Step 6: the resumed Launch is a covered `resume` Launch with route
  `claude_hooks` and a new wake endpoint, which its `SessionStart` returns;
  `h1` and `h2` are still Held.
- Step 7: the Notification exits 0, writes nothing and touches the new
  endpoint; the wake exits 2 with exactly
  `[agent-director: message 1 of 2]\n<h1>\n\n[agent-director: message 2 of 2]\n<h2>`
  (no `t1`); `h1` and `h2` are Final `sent_unconfirmed` `wait_turn_raced`.
- Step 8: no tmux call of agent-director's, `pause` and `resume` included,
  sent keys or a paste buffer; the input journal is empty; the resumed pane
  shows neither `h1`'s nor `h2`'s text.

```bash
set -euo pipefail
. /opt/driver/busy-send-claude.sh cw3

t1="$(printf 'tags </system-reminder> and </task-notification> stay whole: ü\n漢字 %s' "$tag")"
h1="held-one-$tag"
h2="$(printf 'held-two-%s\nsecond line' "$tag")"

# Step 1: a production spawn, mid-turn.
agent-director spawn --agent claude --cwd "$work" --instance-id "$id" --tmux-session-name "cd-cw3-$tag" >/dev/null \
    || fail "spawn exited non-zero"
launched spawn startup
quiet UserPromptSubmit "$(jq -cn --arg p "user turn $tag" '{prompt: $p}')"

# Step 2: the reserved closing tags go over whole and raw.
send t1 "$t1" turn_running
rewind
quiet Stop "$stop"
touched || fail "Stop did not touch the wake endpoint"
wakes "$(printf '[agent-director: message 1 of 1]\n%s' "$t1")"
[ "$(result t1)" = "$raced" ] || fail "t1 is [$(result t1)]; want $raced"
[ "$(delivery .awaiting_turn_start)" = "[1]" ] || fail "awaiting_turn_start is $(delivery .awaiting_turn_start); want 1"

# Step 3: Claude Code's escaping cannot be undone exactly, so the sighting is no evidence.
sighting
[ "$(delivery .awaiting_turn_start)" = "[1]" ] || fail "an escaped sighting cleared awaiting_turn_start: $(delivery .awaiting_turn_start)"

# Step 4: later Messages wait on the unresolved prompt.
send h1 "$h1" turn_running
send h2 "$h2" earlier_message
rewind
quiet Stop "$stop"
! touched || fail "Stop touched the wake endpoint while a prompt awaits its take"
quiet FileChanged "$changed"
[ "$(result h1)" = '["held",false,"readiness_unknown"]' ] || fail "h1 is [$(result h1)]; want Held readiness_unknown"

# Step 5: keyless pause; resume may follow once get shows the row finished.
old_wake="$wake"
pid="$(/opt/driver/sql.sh -readonly "$db" "SELECT pid FROM spawns WHERE instance_id = '$id';")"
[[ "$pid" =~ ^[1-9][0-9]*$ ]] || fail "the row records pid [$pid]"
agent-director pause --instance-id "$id" >/dev/null || fail "pause exited non-zero"
# pause succeeds only once it verified the agent's exit, so the process is
# gone now (at most a zombie tmux has not reaped yet), and get's own recovery
# check sees it: no wait of the case's own.
st="$(sed 's/^.*) //' "/proc/$pid/stat" 2>/dev/null | cut -d' ' -f1 || true)"
[ -z "$st" ] || [ "$st" = Z ] || fail "the agent process $pid is still running (state $st) after pause succeeded"
[[ "$(state)" =~ ^(ended|missing)$ ]] || fail "row is [$(state)] after pause; want ended or missing"
got="$(/opt/driver/sql.sh -readonly "$db" "SELECT IFNULL(end_cause, '') FROM busy_send_launches WHERE wake_path = '$old_wake';")"
[ "$got" = process_exited ] || fail "the paused Launch's end_cause is [$got]; want process_exited"
[ "$(delivery '.awaiting_turn_start, .held_count')" = "[0,2]" ] || fail "after pause the delivery block reads $(delivery '.awaiting_turn_start, .held_count'); want awaiting 0, 2 Held"
[ "$(result t1)" = "$raced" ] || fail "t1 is [$(result t1)] after pause; want $raced"
for m in h1 h2; do
    [[ "$(result "$m")" == '["held",false,'* ]] || fail "$m is [$(result "$m")] after pause; want Held"
done

# Step 6: resume publishes a new covered Launch with its own route; the Messages stay Held.
agent-director resume --instance-id "$id" >/dev/null || fail "resume exited non-zero"
launched resume resume
[ "$wake" != "$old_wake" ] || fail "the resumed Launch reuses the paused Launch's wake endpoint"
for m in h1 h2; do
    [[ "$(result "$m")" == '["held",false,'* ]] || fail "$m is [$(result "$m")] after resume; want Held"
done

# Step 7: the idle agent's own wake event hands both over, in order, once; t1 is not replayed.
rewind
quiet Notification '{"notification_type":"idle_prompt","message":"Claude is waiting for your input"}'
touched || fail "the idle-prompt Notification did not touch the resumed Launch's wake endpoint"
wakes "$(printf '[agent-director: message 1 of 2]\n%s\n\n[agent-director: message 2 of 2]\n%s' "$h1" "$h2")"
for m in h1 h2; do
    [ "$(result "$m")" = "$raced" ] || fail "$m is [$(result "$m")]; want $raced"
done

# Step 8: agent-director typed nothing, pause and resume included.
no_product_input "held-one-$tag" "held-two-$tag"

echo "busy-send-claude-wait-turn-3 ok: tags whole and raw; escaped sighting no evidence, awaiting held later Messages; keyless pause ended the agent, Launch End process_exited cleared awaiting and kept h1, h2 Held; resume's own route handed them over in order at the idle wake; t1 not replayed; nothing typed"
```
