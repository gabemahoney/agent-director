# discover-10: subagent hooks piped from the driver's shell write no entry and one pid_mismatch each

Maps to Epic `t1.f5h.f9` AC 2 (b) (SRD `t1.xjn.du` SR-15.7 (b), SR-3.1,
SR-14 `ad.hook.ignored`): only the row's own agent's hooks write records.
The same five hooks as discover-9 (a SubagentStart for A, a launch
request, a SubagentStart for B, B's SubagentStop and B's `completed`
launch result), carrying X's `AGENT_DIRECTOR_INSTANCE_ID` but piped from
the driver's shell instead of typed into X's pane, are refused by the
gate (the hook's parent is the case's shell, not X's pane process). Each
exits 0 with empty stdout and writes exactly one `ad.hook.ignored` with
`reason` `pid_mismatch` and its own `hook_event`; no entry or claimable
launch is written, and `list-subagents` reads no record.

## Setup

Per-case DB-reset. The trail `~/.config/agent-director/ad-trail.jsonl` is
not wiped, so every trail check filters on X's instance id. The spawn runs
with `PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the
`agent-director` command; the SessionStart typed into X's pane with
`/opt/driver/pane-hook.sh` applies and turns X `waiting`, so X is live and
tracked and only the gate refuses the piped hooks. The payloads are
minimal: `hook_event_name` and the SR-5.1 fields of each step (`tool_name`
for the tool hooks), and no content. The store is read only through
`list-subagents` and `/opt/driver/sql.sh`. The case starts a real tmux
session; the DB-reset fixture ends it.

## Steps

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --agent claude --cwd /tmp`
   → X. Type a SessionStart (`source` `startup`) into X's pane. X is
   `waiting`.
2. From the driver's shell, pipe each of the five hooks into
   `AGENT_DIRECTOR_INSTANCE_ID=X agent-director hook`, stdout to a file
   (so the hook's parent is the case's own shell, `$$`): SubagentStart
   (`d10-sub-a`), PreToolUse (`Agent`, `d10-toolu-b`), SubagentStart
   (`d10-sub-b`), SubagentStop (`d10-sub-b`), PostToolUse (`Agent`,
   `completed`, `agentId` `d10-sub-b`).
3. Each hook exits 0 with empty stdout.
4. `sql.sh` shows no row for X in `subagents` and none in
   `subagent_launches`; `list-subagents` reads
   `{"tracked":true,"subagents":[]}`; X is still `waiting`.
5. The trail has exactly five `ad.hook.ignored` lines for X, in order with
   `hook_event` SubagentStart, PreToolUse, SubagentStart, SubagentStop,
   PostToolUse, each with `reason` `pid_mismatch` and `parent_pid` `$$`.

## Pass criteria

- The SessionStart typed into X's pane exits 0 with empty stdout; X is
  `waiting`.
- All five piped hooks exit 0 with empty stdout.
- `subagents` and `subagent_launches` hold no row for X.
- `list-subagents` prints exactly `{"tracked":true,"subagents":[]}`.
- X's `ad.hook.ignored` lines number exactly five, with the `hook_event`
  sequence above, each `reason` `pid_mismatch`, `parent_pid` the case's
  shell and `source` `ad_hook`; X's state is still `waiting`.

## Script

```bash
set -euo pipefail
db="$HOME/.config/agent-director/state.db"
trail="$HOME/.config/agent-director/ad-trail.jsonl"
fail() { echo "FAIL: $*"; exit 1; }
id="$(PATH="/opt/driver/stand-in-claude:$PATH" agent-director spawn --agent claude --cwd /tmp | jq -r '.instance_id')"
test -n "$id" || fail "spawn returned no instance_id"
sqlv() { /opt/driver/sql.sh -readonly "$db" "$1"; }

# 1. X reports in through its own pane process.
out="$(/opt/driver/pane-hook.sh "$id" '{"hook_event_name":"SessionStart","source":"startup","transcript_path":"/x/d10-session.jsonl"}')" \
    || fail "SessionStart typed into X's pane exited non-zero"
test -z "$out" || fail "SessionStart stdout = $out; want empty"
state="$(agent-director status --instance-id "$id" | jq -r '.state')"
test "$state" = "waiting" || fail "after SessionStart state=$state; want waiting"

# 2. The same hooks from the driver's shell: the hook's parent is this shell ($$),
# since stdout goes to a file, not $(...).
out_file="$(mktemp)"
send() {
    local rc=0
    printf '%s' "$2" | AGENT_DIRECTOR_INSTANCE_ID="$id" agent-director hook >"$out_file" || rc=$?
    test "$rc" -eq 0 || fail "[$1] piped hook exited $rc; want 0"
    test ! -s "$out_file" || fail "[$1] piped hook stdout = $(cat "$out_file"); want empty"
}
send start-a '{"hook_event_name":"SubagentStart","agent_id":"d10-sub-a","agent_type":"general-purpose","session_id":"d10-sess-a"}'
send request-b '{"hook_event_name":"PreToolUse","tool_name":"Agent","tool_use_id":"d10-toolu-b","tool_input":{"subagent_type":"general-purpose"}}'
send start-b '{"hook_event_name":"SubagentStart","agent_id":"d10-sub-b","agent_type":"general-purpose","session_id":"d10-sess-b"}'
send stop-b '{"hook_event_name":"SubagentStop","agent_id":"d10-sub-b"}'
send result-b '{"hook_event_name":"PostToolUse","tool_name":"Agent","tool_use_id":"d10-toolu-b","tool_input":{"subagent_type":"general-purpose","description":"d10 short description"},"tool_response":{"status":"completed","agentId":"d10-sub-b","resolvedModel":"d10-model"}}'
rm -f "$out_file"

# 3. No entry and no claimable launch; nothing listed; the row did not move.
for tbl in subagents subagent_launches; do
    n="$(sqlv "SELECT count(*) FROM $tbl WHERE instance_id = '$id';")"
    test "$n" = "0" || fail "$tbl holds $n rows for $id; want 0"
done
listed="$(agent-director list-subagents --instance-id "$id" | jq -c .)"
test "$listed" = '{"tracked":true,"subagents":[]}' || fail "list-subagents = $listed; want {\"tracked\":true,\"subagents\":[]}"
state="$(agent-director status --instance-id "$id" | jq -r '.state')"
test "$state" = "waiting" || fail "after the piped hooks state=$state; want waiting (all ignored)"

# 4. Exactly one pid_mismatch per hook, in order, for this X.
ignored="$(jq -cR --arg id "$id" 'fromjson? | select(.event == "ad.hook.ignored" and .instance_id == $id)' "$trail")"
events="$(jq -r '.hook_event' <<<"$ignored" | paste -sd' ')"
want="SubagentStart PreToolUse SubagentStart SubagentStop PostToolUse"
test "$events" = "$want" || fail "ad.hook.ignored hook_event sequence for $id = [$events]; want [$want]: $ignored"
bad="$(jq -c --argjson pp "$$" 'select(.reason != "pid_mismatch" or .parent_pid != $pp or .source != "ad_hook")' <<<"$ignored")"
test -z "$bad" || fail "ad.hook.ignored lines with a reason, parent_pid or source other than pid_mismatch/$$/ad_hook: $bad"

echo "discover-10 ok: id=$id; five subagent hooks piped from the driver shell ($$) exited 0 with empty stdout, wrote no subagents or subagent_launches row, list-subagents read {\"tracked\":true,\"subagents\":[]}, and each left one ad.hook.ignored pid_mismatch ($events)"
```
