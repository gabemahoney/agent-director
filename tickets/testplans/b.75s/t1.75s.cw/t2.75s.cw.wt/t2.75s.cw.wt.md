# busy-send-claude-wait-turn-1: a mixed burst through the owned hooks

Maps to Epic `t1.xis.oo` acceptance criteria 1, 2, 4 and 5 (Subtasks
`t3.xis.oo.u8.sm` and `t3.xis.oo.2o.gv`) and Epic `t1.xis.wm` acceptance
criteria 1, 2 and 5 (Subtask `t3.xis.wm.hg.k1`; SRD `t1.kii.kn` SR-1.3,
SR-1.4, SR-2.2, SR-2.3, SR-2.5, SR-3.1, SR-3.3 to SR-3.5, SR-3.3a, SR-3.9,
SR-5.1, SR-5.6, SR-9.1; Plan `b.xis` decisions 10, 11, 12 and 13; E4 Main
Agent decisions 1 and 2). A Claude Launch the shipped binary records covered
keeps every Message Held until the agent's own eligible hook event. The Steer
Turn Messages ahead of the first Wait Turn Message reach a working agent
together, as the stdout `additionalContext` of its owned parent
`PostToolBatch` hook, which exits 0. Everything else reaches the agent only as
the stderr of its owned `FileChanged` hook, which exits 2 with one whole
prompt per wake; `Stop` and the sends only touch the wake endpoint. AD's own
`UserPromptSubmit` sighting of the exact wake text, and for a steer the
parent `Stop` after it, are the evidence the agent took them.

## Setup

Per-case DB-reset; `/opt/driver/busy-send-claude.sh cw1` (the collector's
"Driver mode"). The case spawns the stand-in Claude in its own directory. No
coverage, route or wake endpoint is seeded.

## Steps

1. Spawn. Read the newest Launch's recorded facts; type `SessionStart`.
   `get` the row.
2. Type `UserPromptSubmit` (a user turn). Send, in order: Steer Turn `s1`
   (confirmed, multi-line Unicode with a TAB, quotes, a backslash and markup),
   an unconfirmed Steer Turn Message `su`, `m1` (confirmed, multi-line Unicode
   with a TAB), an unconfirmed Message `u1`, `m2` (confirmed, 6,013 bytes),
   `m3` (confirmed, 4,015 bytes) and Steer Turn `s2` (confirmed). Type
   `FileChanged`.
3. Type a parent `PostToolBatch`, then another.
4. Type `Stop`. Run `FileChanged` from the case's own shell.
5. Type `FileChanged`, then type it again.
6. Type the sighting of step 5's prompt; type `Stop`; type `FileChanged`;
   type its sighting.
7. Send `m1` again with its text, then with other text. Type `FileChanged`.
8. Send `m4` and run no `FileChanged` for its hint. Run `get`, `status`,
   `list`, `sweep` and `read-pane`. Type `Stop`, then `FileChanged`.
9. Read the tmux call log, the input journal and the pane.

Before each step that should touch the endpoint, the case sets its
modification time back to a fixed past second; a changed time is the touch.

## Pass criteria

- Step 1: the Launch is a covered `spawn` Launch with route `claude_hooks`
  and its own wake endpoint, absent until `SessionStart`, which exits 0 with
  exactly
  `{"hookSpecificOutput":{"hookEventName":"SessionStart","watchPaths":["<wake>"]}}`
  and creates it: an empty regular file, mode 600, of the case's user; the
  row is `waiting`. `get` shows `busy_send` `covered`, `agent_defaults`
  `{send_mode: wait_turn, confirmed_delivery: false, confirm_from_transcripts: false}`
  and, in `delivery_capabilities`,
  `{modes: [{send_mode: wait_turn, message_bytes: 8000, prompt_bytes: 9600, text_kind: utf8_tab_lf}, {send_mode: steer_turn, message_bytes: 8000, prompt_bytes: 9600, text_kind: utf8_tab_lf}], held_count: 1000, held_bytes: 8000000}`
  (its E5 `force` and Confirm From Transcripts fields are pinned by
  `busyCapabilitiesJSON` and the `settle_off` CLI goldens; Steer Turn's
  acceptance as a default and per Message by Subtask `t3.xis.wm.o7.ad`'s
  tests).
- Step 2: `s1` is Held waiting `turn_running`, the rest `earlier_message`;
  `su` and `u1` return no `caller_uuid` or `request_id`; the sends touch the
  endpoint; the hint during the turn exits 0 and writes nothing.
- Step 3: the first `PostToolBatch` exits 0 with nothing on stderr and one
  line on stdout, exactly one JSON object
  `{"hookSpecificOutput":{"hookEventName":"PostToolBatch","additionalContext":"[agent-director: message 1 of 2]\n<s1>\n\n[agent-director: message 2 of 2]\n<su>"}}`
  and no other key. `s1` is Final `sent_unconfirmed` `handed_over_not_proven`
  and `su` Final `sent_unconfirmed` `confirmation_off` (a tool-boundary steer
  is not race-exposed: never `wait_turn_raced`); `m1` and `s2` are Held,
  since `m1` is the first Wait Turn Message; the second `PostToolBatch`
  exits 0 and writes nothing; `awaiting_turn_start` is 1.
- Step 4: `Stop` exits 0, writes nothing, records the steer's take evidence
  (`awaiting_turn_start` 0) and only then touches the endpoint, and leaves
  the row `waiting`; the outside-pane `FileChanged` exits 0 and writes
  nothing; `m1` is still Held.
- Step 5: the first `FileChanged` exits 2, nothing on stdout, exactly
  `[agent-director: message 1 of 3]\n<m1>\n\n[agent-director: message 2 of 3]\n<u1>\n\n[agent-director: message 3 of 3]\n<m2>`
  on stderr (the fewest prompts: `m3` does not fit the 9,600-byte prompt with
  them); the second exits 0 and writes nothing. `m1`, `m2` and `u1` are Final
  `sent_unconfirmed` `wait_turn_raced` (never `delivered_confirmed`); `su`
  keeps `confirmation_off`; `m3` and `s2` are Held; `awaiting_turn_start` is
  1.
- Step 6: the sighting clears `awaiting_turn_start`; `Stop` then touches the
  endpoint and the wake writes exactly
  `[agent-director: message 1 of 2]\n<m3>\n\n[agent-director: message 2 of 2]\n<s2>`;
  `m3` and `s2` are Final `sent_unconfirmed` `wait_turn_raced` (the Steer
  Turn Message deferred to the ordinary wake keeps that route's exposure);
  its sighting leaves `awaiting_turn_start` 0.
- Step 7: the repeat exits 0 with the owner's Result (`sent_unconfirmed`,
  Final, `wait_turn_raced`); the changed text exits 1 with `ErrCantSend`,
  reason `id_conflict`, and the owner's Result in `err_details.result`;
  nothing is Held and the wake writes nothing.
- Step 8: `m4` is Held waiting `turn_running` after its send touched the
  endpoint; the reads and `sweep` neither touch it nor change `m4`; `Stop`
  touches it and the wake writes exactly `[agent-director: message 1 of 1]\n<m4>`;
  `m4` is Final `sent_unconfirmed` `wait_turn_raced`.
- Step 9: no tmux call of agent-director's sent keys or a paste buffer, the
  input journal is empty, and the pane shows none of the Messages' texts.

```bash
set -euo pipefail
. /opt/driver/busy-send-claude.sh cw1

s1="$(printf 'steer-one-%s "q" \\ <b>&amp;</b>\tü 🙂\nnext line' "$tag")"
su="steer-two-$tag unconfirmed"
m1="$(printf 'one-%s\nzwei: ü 漢字 🙂\tend' "$tag")"
u1="plain-$tag unconfirmed"
m2="two-$tag-$(head -c 6000 /dev/zero | tr '\0' 'b')"
m3="three-$tag-$(head -c 4000 /dev/zero | tr '\0' 'c')"
s2="steer-three-$tag behind a Wait Turn Message"
m4="four-$tag"

# Step 1: a production spawn is covered with route A; get shows its capabilities.
agent-director spawn --agent claude --cwd "$work" --instance-id "$id" --tmux-session-name "cd-cw1-$tag" >/dev/null \
    || fail "spawn exited non-zero"
launched spawn startup
agent-director get --instance-id "$id" | jq -e '.busy_send == "covered"
    and .agent_defaults == {send_mode: "wait_turn", confirmed_delivery: false, confirm_from_transcripts: false}
    and (.delivery_capabilities | {modes, held_count, held_bytes}) == {modes: [
        {send_mode: "wait_turn", message_bytes: 8000, prompt_bytes: 9600, text_kind: "utf8_tab_lf"},
        {send_mode: "steer_turn", message_bytes: 8000, prompt_bytes: 9600, text_kind: "utf8_tab_lf"}],
        held_count: 1000, held_bytes: 8000000}' >/dev/null \
    || fail "get shows [$(agent-director get --instance-id "$id")]"

# Step 2: a mixed burst during a turn stays Held; a hint during the turn writes nothing.
quiet UserPromptSubmit "$(jq -cn --arg p "user turn $tag" '{prompt: $p}')"
rewind
send s1 "$s1" turn_running steer_turn
out="$(agent-director send-keys --instance-id "$id" --text "$su" --send-mode steer_turn)" \
    || fail "the unconfirmed Steer Turn send exited non-zero"
[ "$(jq -c '[.class, .wait.reason, has("caller_uuid"), has("request_id")]' <<<"$out")" = '["held","earlier_message",false,false]' ] \
    || fail "the unconfirmed Steer Turn send returned [$out]; want Held earlier_message with no ID"
send m1 "$m1" earlier_message
out="$(agent-director send-keys --instance-id "$id" --text "$u1")" || fail "the unconfirmed send exited non-zero"
[ "$(jq -c '[.class, .wait.reason, has("caller_uuid"), has("request_id")]' <<<"$out")" = '["held","earlier_message",false,false]' ] \
    || fail "the unconfirmed send returned [$out]; want Held earlier_message with no ID"
send m2 "$m2" earlier_message
send m3 "$m3" earlier_message
send s2 "$s2" earlier_message steer_turn
touched || fail "the sends did not touch the wake endpoint"
quiet FileChanged "$changed"

# Step 3: the next parent tool boundary takes the Steer Turn prefix, whole, in one envelope.
steers "$(printf '[agent-director: message 1 of 2]\n%s\n\n[agent-director: message 2 of 2]\n%s' "$s1" "$su")"
[ "$(result s1)" = "$steered" ] || fail "s1 is [$(result s1)]; want $steered"
[ "$(unconfirmed | head -n 1)" = "sent_unconfirmed|1|confirmation_off" ] \
    || fail "su's Result is [$(unconfirmed | head -n 1)]; want sent_unconfirmed|1|confirmation_off"
for m in m1 s2; do
    [[ "$(result "$m")" == '["held",false,'* ]] || fail "$m is [$(result "$m")] after the steer; want Held behind the first Wait Turn Message"
done
quiet PostToolBatch
[ "$(delivery .awaiting_turn_start)" = "[1]" ] || fail "awaiting_turn_start is $(delivery .awaiting_turn_start) after the steer; want 1"

# Step 4: Stop records the steer's take evidence, then re-signals; a callback from outside the pane gets nothing.
rewind
quiet Stop "$stop"
[ "$(delivery .awaiting_turn_start)" = "[0]" ] || fail "awaiting_turn_start is $(delivery .awaiting_turn_start) after Stop; want 0"
touched || fail "Stop with Messages Held did not touch the wake endpoint"
[ "$(state)" = waiting ] || fail "row is [$(state)] after Stop; want waiting"
set +e
payload FileChanged "$changed" | AGENT_DIRECTOR_INSTANCE_ID="$id" agent-director hook 2>&1 >"$work/out" | cat >"$work/err"
rc=${PIPESTATUS[1]}
set -e
[ "$rc" -eq 0 ] && [ ! -s "$work/out" ] && [ ! -s "$work/err" ] \
    || fail "an outside-pane FileChanged exited $rc, stdout [$(cat "$work/out")], stderr [$(cat "$work/err")]; want 0 and nothing"
[[ "$(result m1)" == '["held",false,'* ]] || fail "m1 is [$(result m1)] after the outside-pane wake; want Held"

# Step 5: one wake writes the first prompt, the fewest whole Messages in order, once.
wakes "$(printf '[agent-director: message 1 of 3]\n%s\n\n[agent-director: message 2 of 3]\n%s\n\n[agent-director: message 3 of 3]\n%s' "$m1" "$u1" "$m2")"
quiet FileChanged "$changed"
for m in m1 m2; do
    [ "$(result "$m")" = "$raced" ] || fail "$m is [$(result "$m")]; want $raced"
done
got="$(unconfirmed | tr '\n' ' ')"
[ "$got" = "sent_unconfirmed|1|confirmation_off sent_unconfirmed|1|wait_turn_raced " ] \
    || fail "su's and u1's Results are [$got]; want confirmation_off, then wait_turn_raced"
for m in m3 s2; do
    [[ "$(result "$m")" == '["held",false,'* ]] || fail "$m is [$(result "$m")]; want Held for the next prompt"
done
[ "$(delivery .awaiting_turn_start)" = "[1]" ] || fail "awaiting_turn_start is $(delivery .awaiting_turn_start) after the wake; want 1"

# Step 6: the exact sighting is the take evidence; the next turn end takes the next prompt, the deferred steer with it.
sighting
[ "$(delivery .awaiting_turn_start)" = "[0]" ] || fail "awaiting_turn_start is $(delivery .awaiting_turn_start) after the sighting; want 0"
rewind
quiet Stop "$stop"
touched || fail "Stop did not re-signal the Held m3 and s2"
wakes "$(printf '[agent-director: message 1 of 2]\n%s\n\n[agent-director: message 2 of 2]\n%s' "$m3" "$s2")"
for m in m3 s2; do
    [ "$(result "$m")" = "$raced" ] || fail "$m is [$(result "$m")]; want $raced"
done
sighting
[ "$(delivery .awaiting_turn_start)" = "[0]" ] || fail "awaiting_turn_start is $(delivery .awaiting_turn_start) after m3's sighting; want 0"

# Step 7: a repeat pair returns the owner's Result and delivers nothing; other text is id_conflict.
out="$(agent-director send-keys --instance-id "$id" --text "$m1" --confirmed-delivery --caller-uuid "$caller" \
    --delivery-request-id m1)" || fail "the repeat of m1 exited non-zero"
[ "$(jq -c '[.class, .final, .reason]' <<<"$out")" = "$raced" ] || fail "the repeat of m1 returned [$out]; want the owner's $raced"
set +e
agent-director send-keys --instance-id "$id" --text "other-$tag" --confirmed-delivery --caller-uuid "$caller" \
    --delivery-request-id m1 >"$work/out" 2>"$work/err"
rc=$?
set -e
[ "$rc" -eq 1 ] && jq -e '.err_name == "ErrCantSend" and .err_details.reason == "id_conflict"
    and [.err_details.result | .class, .final, .reason] == ["sent_unconfirmed", true, "wait_turn_raced"]' "$work/err" >/dev/null \
    || fail "m1 with other text exited $rc: [$(cat "$work/err")]; want ErrCantSend id_conflict with the owner's Result"
[ "$(delivery .held_count)" = "[0]" ] || fail "the repeat or the conflict left a Message Held"
quiet FileChanged "$changed"

# Step 8: a lost hint leaves the Message Held; reads and sweep deliver nothing; the next Stop does.
rewind
send m4 "$m4" turn_running
touched || fail "the send did not touch the wake endpoint"
rewind
for verb in "get --instance-id $id" "status --instance-id $id" list sweep "read-pane --instance-id $id"; do
    agent-director $verb >/dev/null || fail "agent-director $verb exited non-zero"
done
! touched || fail "a read or sweep touched the wake endpoint"
[ "$(result m4)" = '["held",false,"turn_running"]' ] || fail "m4 is [$(result m4)] after the reads and sweep; want Held turn_running"
quiet Stop "$stop"
touched || fail "Stop did not re-signal the lost hint"
wakes "$(printf '[agent-director: message 1 of 1]\n%s' "$m4")"
[ "$(result m4)" = "$raced" ] || fail "m4 is [$(result m4)]; want $raced"

# Step 9: agent-director typed nothing.
no_product_input "steer-one-$tag" "steer-two-$tag" "steer-three-$tag" "one-$tag" "plain-$tag" "two-$tag" "three-$tag" "four-$tag"

echo "busy-send-claude-wait-turn-1 ok: shipped coverage, route A and capabilities; mixed burst Held; Steer Turn prefix whole at the next parent boundary, handed_over_not_proven and confirmation_off; Stop's take evidence before its re-signal; outside-pane wake refused; fewest whole prompts in order, one per wake, the deferred steer raced; sighting cleared awaiting; repeat pair and id_conflict deliver nothing; lost hint survives reads and sweep, delivered at the next Stop; nothing typed"
```
