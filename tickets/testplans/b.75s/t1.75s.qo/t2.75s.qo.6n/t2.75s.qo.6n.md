# spawn-19: the label scan refuses a leftover of the id before anything is written

Maps to Epic `t1.h98.hy` (Plan `b.h98`), Task `t2.h98.hy.4q`, the label
scan, and Docker case spawn-19 (SRD SR-20.9, "GAP 3, revised for the
label scan", WD 2026-09-29 HOOK; SR-9.3, SR-1.4's scan row; AC-SPN-11).
A plain `spawn` with a caller-supplied instance id that has no row first
looks for a tmux session of this agent-director store still labelled
with that id. Such a session is left over from an earlier life of the
id, so the spawn is refused with `ErrTmuxSessionConflict` before
anything is written: no row, and the session keeps running. Once a
human removes the session, the same spawn succeeds.

## Setup

Per-case DB-reset has wiped `~/.agent-director/state.db` (so there is no
row for any id) and killed any `cd-*` tmux sessions. The container has
`agent-director`, `tmux`, `sqlite3` and `jq` on PATH; plain `tmux`
reaches the same default socket `spawn` resolves from `TMUX` /
`TMUX_TMPDIR`. The script records the live session ids first and, on
exit, kills any session that was not there before (by its `$N` id), so a
regression cannot leak a session into later cases. The instance id X is
`sp19-<uuid>`, so no earlier case's leftover can carry it.

## Steps

1. Read this store's id with `sqlite3` from `store_meta` (`key =
   'store_id'`).
2. In the container, create a session named `sp19-held` (the name X's
   spawn will request) and read its tmux id `$N`. Label it as an earlier
   launch of X with `tmux set-option -t <$N> @ad_owner "ad1 <another
   token> <$N> X <store id>"`, where the other token is 16 lowercase hex
   characters no launch of this run minted. Wait 2 s.
3. `agent-director spawn --cwd /tmp --claude-instance-id X
   --tmux-session-name sp19-held`, and read the last JSON line on
   stderr. Then `agent-director status --claude-instance-id X`, count
   the rows in the `spawns` table, and check the session still runs.
4. Rename the leftover to `sp19-moved` (`tmux rename-session -t <$N>`),
   so the requested name is free, and repeat step 3.
5. Remove the leftover by its session id (`tmux kill-session -t <$N>`)
   and repeat the spawn of X.

## Pass criteria

- Step 1: the store id is 16 lowercase hex characters.
- Steps 3 and 4: the spawn exits non-zero; `err_name ==
  "ErrTmuxSessionConflict"`; the decoded `err_description` contains
  `left over from an earlier life`, the leftover's quoted current name
  and its tmux id (`"sp19-held" ($N)` in step 3, `"sp19-moved" ($N)` in
  step 4), `Operator actions` and `README`; it contains no command
  (neither `kill` nor `attach`) and neither the label's token nor the
  store id. `status` of X exits non-zero with `err_name ==
  "ErrSpawnNotFound"`; `SELECT COUNT(*) FROM spawns` is `0`; `tmux
  has-session -t <$N>` succeeds.
- Step 5: the spawn exits 0 and returns `claude_instance_id == X`; `get`
  of X shows `tmux_session_name == "sp19-held"`.

## Script

```bash
set -euo pipefail

db="$HOME/.agent-director/state.db"
x="sp19-$(cat /proc/sys/kernel/random/uuid)"
held=sp19-held
moved=sp19-moved
# Another launch's token: 16 lowercase hex, never minted by this run.
old_token=0123456789abcdef

session_ids() {
    tmux ls -F '#{session_id}' 2>/dev/null || true
}
before="$(session_ids)"
cleanup() {
    local sid
    for sid in $(session_ids); do
        case " $(printf '%s ' $before)" in
            *" $sid "*) ;;
            *) tmux kill-session -t "$sid" 2>/dev/null || true ;;
        esac
    done
}
trap cleanup EXIT

last_json() {
    printf '%s
' "$1" | awk '/^\{/{ln=$0} END{print ln}'
}

# Step 1: this store's id.
store_id="$(sqlite3 "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
if ! [[ "$store_id" =~ ^[0-9a-f]{16}$ ]]; then
    echo "FAIL: store_meta store_id is not 16 lowercase hex: [$store_id]" >&2
    exit 1
fi

# Step 2: a session labelled as an earlier launch of X holds X's name.
sid="$(tmux new-session -d -s "$held" -P -F '#{session_id}' sleep 3600)"
tmux set-option -t "$sid" @ad_owner "ad1 $old_token $sid $x $store_id"
sleep 2

# expect_refused NAME: a plain spawn of X is refused by the scan, naming
# the leftover as NAME ($N), and nothing is written.
expect_refused() {
    local name="$1" err code envelope got desc forbidden status_err n_db
    set +e
    err="$(agent-director spawn --cwd /tmp --claude-instance-id "$x" \
        --tmux-session-name "$held" 2>&1 >/dev/null)"
    code=$?
    set -e
    if [ "$code" -eq 0 ]; then
        echo "FAIL: spawn of $x succeeded while leftover $sid ($name) runs" >&2
        exit 1
    fi
    envelope="$(last_json "$err")"
    got="$(printf '%s' "$envelope" | jq -r '.err_name')"
    if [ "$got" != "ErrTmuxSessionConflict" ]; then
        echo "FAIL: err_name=$got; stderr: $err" >&2
        exit 1
    fi
    desc="$(printf '%s' "$envelope" | jq -r '.err_description')"
    for want in "left over from an earlier life" "\"$name\" ($sid)" \
        "Operator actions" "README"; do
        case "$desc" in
            *"$want"*) ;;
            *)
                echo "FAIL: description lacks [$want]: $desc" >&2
                exit 1
                ;;
        esac
    done
    for forbidden in kill attach "$old_token" "$store_id"; do
        case "$desc" in
            *"$forbidden"*)
                echo "FAIL: description contains [$forbidden]: $desc" >&2
                exit 1
                ;;
        esac
    done

    set +e
    status_err="$(agent-director status --claude-instance-id "$x" 2>&1 >/dev/null)"
    code=$?
    set -e
    got="$(last_json "$status_err" | jq -r '.err_name')"
    if [ "$code" -eq 0 ] || [ "$got" != "ErrSpawnNotFound" ]; then
        echo "FAIL: status of $x: exit=$code err_name=$got; stderr: $status_err" >&2
        exit 1
    fi
    n_db="$(sqlite3 "$db" 'SELECT COUNT(*) FROM spawns;')"
    if [ "$n_db" != "0" ]; then
        echo "FAIL: the refused spawn wrote $n_db row(s)" >&2
        exit 1
    fi
    if ! tmux has-session -t "$sid" 2>/dev/null; then
        echo "FAIL: leftover session $sid no longer runs" >&2
        exit 1
    fi
}

# Step 3: the leftover holds the requested name.
expect_refused "$held"

# Step 4: the leftover under another name; the requested name is free.
tmux rename-session -t "$sid" "$moved"
expect_refused "$moved"

# Step 5: after the leftover is removed by its session id, X spawns.
tmux kill-session -t "$sid"
out="$(agent-director spawn --cwd /tmp --claude-instance-id "$x" \
    --tmux-session-name "$held")"
got_id="$(printf '%s' "$out" | jq -r '.claude_instance_id')"
if [ "$got_id" != "$x" ]; then
    echo "FAIL: spawn after removal returned id [$got_id]; want $x" >&2
    exit 1
fi
name="$(agent-director get --claude-instance-id "$x" | jq -r '.tmux_session_name')"
if [ "$name" != "$held" ]; then
    echo "FAIL: get shows tmux_session_name=[$name]; want $held" >&2
    exit 1
fi

echo "spawn-19 ok: leftover $sid refused under $held and $moved; no row; spawn of $x after removal ok"
```
