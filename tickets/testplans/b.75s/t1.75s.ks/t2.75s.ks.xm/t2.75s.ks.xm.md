# pause-4: pause on stuck waiting Spawn times out

Per SRD §9: if the row never reaches `ended` within
`pause.timeout_seconds`, the verb returns `ErrPauseTimeout`. The
harness writes a 2-second timeout to config.toml and confirms the
verb both errors out and waits the full deadline (no premature
short-circuit).

Revised by Epic 11 (`t1.h98.m6`, Task `t2.h98.m6.yn`; SR-7.2, SR-3.4,
SR-3.6, SR-20.9): `pause` finds the row's session only by its
`@ad_owner` label and types `/exit` and Enter into the agent's pane by
pane id; the wait starts only once both went through. The session is
made by hand, so it is seeded like kill-1 (`t2.75s.ks.3h`) and pause-3
(`t2.75s.ks.zd`): the row has a launch token and records no socket,
server, pid or pane; the session carries the five-field label
`ad1 <token> <$N> id-p4 <store id>` and the agent's pane carries
`@ad_pane` `<token> <%N>`. Window 0 pane 0 is an unlabelled decoy `cat`
holding `DECOY-p4`; the agent's `cat` pane is split off it, so a send
to `cd-p4:0.0` would land in the decoy. Without the label the session
would be Gone (`ErrTmuxSendKeys`, nothing sent) and the timeout would
never be reached.

## Setup

Per-case DB-reset has wiped `~/.agent-director/state.db` and killed
`cd-*` sessions; the store exists after the reset, so its id can be
read from `store_meta`. A scratch `~/.agent-director/config.toml`
pins `pause.timeout_seconds = 2`. An EXIT trap removes the config file
and the session by its session id.

## Steps

1. Read this store's id with `sqlite3`.
2. Seed `spawns` row `id-p4` at state `waiting`, session name `cd-p4`,
   with a `launch_token` of 16 lowercase hex characters and no recorded
   socket, pid or pane; read the token back.
3. Make session `cd-p4` (`-e AGENT_DIRECTOR_INSTANCE_ID=id-p4`) with
   the decoy `cat` at window 0 pane 0 holding `DECOY-p4` and the
   agent's `cat` pane split off it; label the session (`@ad_owner`,
   read back) and the agent's pane (`@ad_pane` `<token> <%N>`).
4. Write `~/.agent-director/config.toml` with
   `[pause] timeout_seconds = 2`.
5. `agent-director pause --claude-instance-id id-p4` — no state
   flip occurs; the deadline must trip.
6. Inspect stderr for the typed envelope and the panes for `/exit`.

## Pass criteria

- The store id and the token are 16 lowercase hex; the label read back
  has five fields and equals the one set.
- pause exits non-zero.
- stderr JSON envelope's `err_name` is `ErrPauseTimeout`.
- Elapsed wall-clock ≥ 2s and ≤ 5s (proves the verb honored the
  deadline rather than short-circuiting or hanging).
- `/exit` is in the agent's pane `<%N>` and not in the decoy pane (the
  wait ran after `/exit` went to the agent's pane by pane id).
- The row is still `waiting` (pause never writes state) and records
  the agent's pane (`pane_id` = `<%N>`, found through `@ad_pane`).

## Script

```bash
set -euo pipefail
db="$HOME/.agent-director/state.db"
cfg="$HOME/.agent-director/config.toml"
fail() { echo "FAIL: $*"; exit 1; }
sid=""
stderr_file="$(mktemp)"
trap 'rm -f "$stderr_file" "$cfg"; [ -z "$sid" ] || tmux kill-session -t "$sid" 2>/dev/null || true' EXIT

store_id="$(sqlite3 "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

seed_token="$(od -An -N8 -tx1 /dev/urandom | tr -dc '0-9a-f')"
sqlite3 "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode, launch_token)
   VALUES ('id-p4', 'waiting', '/tmp', 'cd-p4', 'off', '$seed_token');"
token="$(sqlite3 "$db" "SELECT launch_token FROM spawns WHERE claude_instance_id = 'id-p4';")"
[[ "$token" =~ ^[0-9a-f]{16}$ ]] || fail "launch_token is not 16 lowercase hex: [$token]"

read -r sid decoy < <(tmux new-session -d -s cd-p4 -e AGENT_DIRECTOR_INSTANCE_ID=id-p4 \
    -P -F '#{session_id} #{pane_id}' -- cat)
[[ "$sid" =~ ^\$[0-9]+$ ]] || fail "new-session gave session id [$sid]"
[[ "$decoy" =~ ^%[0-9]+$ ]] || fail "new-session gave pane id [$decoy]"
tmux send-keys -t "$decoy" -l 'DECOY-p4'
tmux send-keys -t "$decoy" Enter
pane="$(tmux split-window -d -t "$sid" -P -F '#{pane_id}' -- cat)"
[[ "$pane" =~ ^%[0-9]+$ ]] || fail "split-window gave pane id [$pane]"
[ "$pane" != "$decoy" ] || fail "agent pane equals decoy pane $pane"

label="ad1 $token $sid id-p4 $store_id"
tmux set-option -t "$sid" @ad_owner "$label"
tmux set-option -p -t "$pane" @ad_pane "$token $pane"
got_label="$(tmux show-options -t "$sid" -v @ad_owner)"
[ "$got_label" = "$label" ] || fail "label read back [$got_label]; want [$label]"
read -r -a fields <<<"$got_label"
[ "${#fields[@]}" -eq 5 ] || fail "label has ${#fields[@]} fields; want 5: [$got_label]"

mkdir -p "$HOME/.agent-director"
cat >"$cfg" <<'EOF'
[pause]
timeout_seconds = 2
EOF

start=$(date +%s)
if agent-director pause --claude-instance-id id-p4 2>"$stderr_file" >/dev/null; then
    fail "pause on stuck waiting row exited 0"
fi
elapsed=$(( $(date +%s) - start ))
err_name="$(jq -r '.err_name' <"$stderr_file")"
[ "$err_name" = "ErrPauseTimeout" ] || fail "err_name=$err_name; want ErrPauseTimeout ($(cat "$stderr_file"))"
if [ "$elapsed" -lt 2 ] || [ "$elapsed" -gt 5 ]; then
    fail "elapsed=${elapsed}s; want 2-5s"
fi

tmux capture-pane -p -t "$pane" | grep -qF '/exit' || fail "/exit never reached the agent pane $pane"
if tmux capture-pane -p -t "$decoy" | grep -qF '/exit'; then
    fail "pause typed /exit into the decoy pane $decoy (name:0.0), not the agent's pane $pane"
fi
state="$(sqlite3 "$db" "SELECT state FROM spawns WHERE claude_instance_id = 'id-p4';")"
[ "$state" = "waiting" ] || fail "row state=$state after timeout; want waiting (pause never writes state)"
row_pane="$(sqlite3 "$db" "SELECT COALESCE(pane_id, '') FROM spawns WHERE claude_instance_id = 'id-p4';")"
[ "$row_pane" = "$pane" ] || fail "row pane_id [$row_pane]; want the agent pane $pane"
echo "pause-4 ok: /exit by pane id to agent pane $pane (decoy $decoy untouched); stuck waiting → ErrPauseTimeout after ${elapsed}s; row records $row_pane"
```
