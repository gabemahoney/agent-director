# busy-send-claude-wait-turn-4: retirement through the public verbs

Maps to Epic `t1.xis.oo` acceptance criterion 6 (Subtask `t3.xis.oo.2o.gv`;
SRD `t1.kii.kn` SR-5.5, SR-6.3; Plan `b.xis` E2 decision 3). Through the
shipped CLI and the operator tool, with the agent's real processes ended by
`kill` and seen gone: `expire` keeps and reports a finished agent that holds
Messages; a fresh `spawn --reuse-finished` publishes a new conversation at
its first report-in and ends the old one's never-emitted Messages
`not_started` (`conversation_replaced`); `agent-director-admin delete` ends
the row's never-emitted Messages `not_started` (`record_deleted`), and
`get-delivery` still finds them after the row is gone. The refusals and their
advice (`ErrSpawnNotDeletable`, a running or uncheckable owned process) are
Task `t2.xis.oo.sf`'s Go tests.

Also maps to E3 `t1.xis.52`, Subtask `t3.xis.52.e6.zu` (SR-5.4/SR-5.5):
real expiry removes those Final Results after deletion, but their pairs stay
owned and refuse a repeat or changed-text conflict without accepting input.

## Setup

Per-case DB-reset; `/opt/driver/busy-send-claude.sh cw4`.

## Steps

1. Spawn; type `SessionStart`. Send `r1` to the idle agent and run no
   `FileChanged`.
2. `kill`, then `sweep`.
3. `expire --older-than 0d`; read its `ad.expire.kept` trail record.
4. `spawn --reuse-finished` with the same id; type the new Launch's
   `SessionStart` (a new session).
5. Send `r2`. `kill`, `sweep`, then `agent-director-admin delete`.
6. `get`; read the tmux call log and the input journal.
7. `expire --older-than 0d`; look up both pairs, then repeat `r2` with its
   original text and with changed text. Read record counts and input again.

## Pass criteria

- Step 1: `r1` is Held waiting `readiness_unknown`.
- Step 2: `kill` reports `kill_sent` true; after `sweep` the row reads
  `ended` or `missing`; `r1` is still Held.
- Step 3: `expire` deletes nothing and keeps the row (`count` 0, `ids` [],
  `kept` 1, `kept_ids` [id]); its `ad.expire.kept` record's reason is
  `held_messages`.
- Step 4: the reuse is a covered `reuse` Launch with route `claude_hooks`
  and its own wake endpoint; once it reports in, `r1` reads exactly
  `not_started`, Final, `conversation_replaced`, `resend_safe` true,
  `retry_with` `new_id`.
- Step 5: `r2` is Held waiting `readiness_unknown`; `delete` returns
  `{"results": {"<id>": "ok"}}`; `r2` then reads `not_started`, Final,
  `record_deleted`, `resend_safe` true, `retry_with` `new_id`, and `r1`
  keeps its Result.
- Step 6: `get` exits 1 with `ErrSpawnNotFound`; no tmux call of
  agent-director's sent keys or a paste buffer; the input journal is empty.
- Step 7: expiry returns exactly empty row lists and zero counts. Both
  Lookups are `{"lookup":"retention_expired","result":null}`. Both sends
  exit 1 with `ErrCantSend`, class `cant_send`, reason `retention_expired`,
  `resend_safe` false and `retry_with` `none`, with no owner Result. Message,
  pair and input counts are unchanged, and no product input was typed.

```bash
set -euo pipefail
. /opt/driver/busy-send-claude.sh cw4

full() {
    agent-director get-delivery --caller-uuid "$caller" --delivery-request-id "$1" \
        | jq -c '.result | [.class, .final, .reason, .resend_safe, .retry_with]'
}
# finish: kill the agent's session, then sweep; the row reads ended or missing.
finish() {
    local out
    out="$(agent-director kill --instance-id "$id")" || fail "kill exited non-zero"
    [ "$(jq -r '.kill_sent' <<<"$out")" = true ] || fail "kill returned [$out]; want kill_sent true"
    agent-director sweep >/dev/null || fail "sweep exited non-zero"
    [[ "$(state)" =~ ^(ended|missing)$ ]] || fail "row is [$(state)] after kill and sweep; want ended or missing"
}

# Step 1: a Message sent to the idle agent whose wake never runs stays Held.
agent-director spawn --agent claude --cwd "$work" --instance-id "$id" --tmux-session-name "cd-cw4-$tag" >/dev/null \
    || fail "spawn exited non-zero"
launched spawn startup
send r1 "replaced-$tag" readiness_unknown

# Step 2: the agent's processes end.
finish
[[ "$(result r1)" == '["held",false,'* ]] || fail "r1 is [$(result r1)] after kill; want Held"

# Step 3: expire keeps and reports the agent holding r1.
out="$(agent-director expire --older-than 0d)" || fail "expire exited non-zero"
jq -e --arg id "$id" '.count == 0 and .ids == [] and .kept == 1 and .kept_ids == [$id]' <<<"$out" >/dev/null \
    || fail "expire returned [$out]; want the row kept"
got="$(jq -cR --arg id "$id" 'fromjson? | select(.event == "ad.expire.kept" and .instance_id == $id) | .reason' \
    "$HOME/.config/agent-director/ad-trail.jsonl")"
[ "$got" = '"held_messages"' ] || fail "ad.expire.kept reasons for $id are [$got]; want held_messages"

# Step 4: a fresh reuse publishes a new conversation at its first report-in; r1 ends not_started.
sid="$(cat /proc/sys/kernel/random/uuid)"
transcript="$work/$sid.jsonl"
printf '{}\n' >"$transcript"
agent-director spawn --agent claude --cwd "$work" --instance-id "$id" --tmux-session-name "cd-cw4-$tag" \
    --reuse-finished >/dev/null || fail "spawn --reuse-finished exited non-zero"
launched reuse startup
[ "$(full r1)" = '["not_started",true,"conversation_replaced",true,"new_id"]' ] || fail "r1 is [$(full r1)] after the reuse"

# Step 5: deletion ends the new conversation's never-emitted r2; both stay found.
send r2 "deleted-$tag" readiness_unknown
finish
out="$(/opt/bin/agent-director-admin delete --instance-id "$id")" || fail "agent-director-admin delete exited non-zero"
jq -e --arg id "$id" '.results == {($id): "ok"}' <<<"$out" >/dev/null || fail "delete returned [$out]; want ok"
[ "$(full r2)" = '["not_started",true,"record_deleted",true,"new_id"]' ] || fail "r2 is [$(full r2)] after delete"
[ "$(full r1)" = '["not_started",true,"conversation_replaced",true,"new_id"]' ] || fail "r1 is [$(full r1)] after delete"

# Step 6: the row is gone; agent-director typed nothing.
set +e
agent-director get --instance-id "$id" >/dev/null 2>"$work/err"
rc=$?
set -e
[ "$rc" -eq 1 ] && [ "$(jq -r '.err_name' "$work/err")" = ErrSpawnNotFound ] || fail "get after delete exited $rc: [$(cat "$work/err")]"
no_product_input

# Step 7: the CLI runs real retention with no agent row left to delete.
before="$(/opt/driver/sql.sh -readonly "$db" 'SELECT (SELECT count(*) FROM busy_send_messages), (SELECT count(*) FROM busy_send_results), (SELECT count(*) FROM input_attempts);')"
out="$(agent-director expire --older-than 0d)" || fail "retention expire exited non-zero"
[ "$(jq -cS . <<<"$out")" = '{"count":0,"ids":[],"kept":0,"kept_ids":[]}' ] || fail "retention expire returned [$out]"
for request in r1 r2; do
    out="$(agent-director get-delivery --caller-uuid "$caller" --delivery-request-id "$request")" || fail "Lookup $request failed"
    [ "$(jq -cS . <<<"$out")" = '{"lookup":"retention_expired","result":null}' ] || fail "Lookup $request returned [$out]"
done
for text in "deleted-$tag" "changed-$tag"; do
    set +e
    agent-director send-keys --instance-id "$id" --text "$text" --confirmed-delivery \
        --caller-uuid "$caller" --delivery-request-id r2 >"$work/out" 2>"$work/err"
    rc=$?
    set -e
    [ "$rc" -eq 1 ] || fail "expired pair exited $rc; want 1"
    jq -e '.err_name == "ErrCantSend" and .err_details == {class:"cant_send", reason:"retention_expired", resend_safe:false, retry_with:"none"}' \
        "$work/err" >/dev/null || fail "expired pair returned [$(cat "$work/err")]"
    [ ! -s "$work/out" ] || fail "expired pair returned an acceptance [$(cat "$work/out")]"
done
after="$(/opt/driver/sql.sh -readonly "$db" 'SELECT (SELECT count(*) FROM busy_send_messages), (SELECT count(*) FROM busy_send_results), (SELECT count(*) FROM input_attempts);')"
[ "$after" = "$before" ] || fail "retention/refusal counts changed from [$before] to [$after]"
no_product_input

echo "busy-send-claude-wait-turn-4 ok: Held custody survived expire; reuse/delete ended Messages not_started; real expiry removed Results and kept both pairs owned; nothing accepted or typed"
```
