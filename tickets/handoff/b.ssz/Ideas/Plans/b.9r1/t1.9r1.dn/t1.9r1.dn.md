# Epic 5: Codex rows report no subagents; resume continues the last agent's latest session, never across a switch

## Outcome
Codex rows report no subagents, on every surface, by a final rule rather than an interim one.
- `list-subagents` on a Codex row returns `tracked` false and `subagents` `[]`.
- No Codex launch registers SubagentStart or SubagentStop, and no Codex hook writes a subagent record.
- Claude is unchanged.

Gabe's rule (2026-10-12): "Resume always continues the last agent's latest session. Switching agents without resume is fine. The one thing you can't do is resume across a switch." Behind it: only an agent switch starts a new life; a same-agent reuse, `resume` and session changes keep it; a switch gives up everything before it, a switch back included. Session history and subagent records show only the current life. AD-agent children are not tied to a life: `list --parent` lists them across a switch.

Recorded in the PRD amendment (`tickets/Ideas/b.ssz/t1.ssz.qi/prd-amendment-2026-10-12-codex-subagents.md`, Decisions 1 and 3) and applied by SRD t1.ssz.pm's SR-6.8 addendum, this Epic's spec. The rule was checked first with a small TLA+ model (`tickets/Ideas/b.ssz/tla/life/`; the final job is in SR-6.8.9's "Model check").

**History, 2026-10-12:** the lock of an id to its agent (Decision 2, SR-6.8.8) and the earlier "every call shows the current life" and `parent_life_number` designs were withdrawn the same day; none is built.
