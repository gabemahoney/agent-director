# relay-4: second decide returns ErrAlreadyDecided

Per SRD §6.2: the decide UPDATE is guarded by `decision IS NULL`.
First call wins; second call sees a populated decision column and
the UPDATE no-ops; the verb surfaces ErrAlreadyDecided.

## Setup

Per-case DB-reset. Epic 8 (`t1.h98.xw`, SR-20.9, SR-22.9): a hook moves a
row only when it comes from the row's own pane process, so the row is a
real spawn and every hook is typed into its pane. The spawn runs with
`--relay-mode on` (which puts `AGENT_DIRECTOR_RELAY_MODE=on` in the
session's environment, so the pane's shell and the hook it forks inherit
it) and with `PATH=/opt/driver/stand-in-claude:$PATH` prefixed to the
`agent-director` command, so the pane process is the stand-in claude's
interactive bash. `/opt/driver/pane-hook.sh` types each hook into that
pane; the blocking PermissionRequest uses `--no-wait` (prints the job
dir) and `--wait <job dir>` (prints the hook's stdout, exits with the
hook's exit status). No hook is piped from the case's own shell, so the
driver shell backgrounds nothing. The session is named `cd-<case>` so
the DB-reset fixture's `cd-*` sweep removes it.

## Steps

1. `PATH=/opt/driver/stand-in-claude:$PATH agent-director spawn --cwd /tmp
   --relay-mode on --tmux-session-name cd-r4` → capture
   `claude_instance_id`.
2. Type a SessionStart hook into the pane → state `waiting`.
3. Type the PermissionRequest into the pane (`--no-wait`); poll the store
   for the open request's token.
4. First decide --decision allow → exits 0; `pane-hook.sh --wait <job
   dir>` → the hook exits 0.
5. Second decide --decision deny with the same token → non-zero with
   err_name=ErrAlreadyDecided.

## Pass criteria

- First decide exits 0 and the hook exits 0.
- Second decide exits non-zero with the typed error.

## Script

```bash
set -euo pipefail
id="$(PATH="/opt/driver/stand-in-claude:$PATH" agent-director spawn --cwd /tmp --relay-mode on --tmux-session-name cd-r4 | jq -r '.claude_instance_id')"
test -n "$id"
# SR-22.9: the hooks are typed into the row's pane, so they apply.
/opt/driver/pane-hook.sh "$id" '{"hook_event_name":"SessionStart","transcript_path":"/x/r4.jsonl"}'
state="$(agent-director status --claude-instance-id "$id" | jq -r '.state')"
test "$state" = "waiting"

job="$(/opt/driver/pane-hook.sh --no-wait "$id" '{"hook_event_name":"PermissionRequest","tool_name":"Bash"}')"

# decide REQUIRES --request-token: read the token the hook in the pane
# minted for the open permission_requests row. The SAME token must
# be reused on the second decide so it targets the already-decided row.
token=""
for _ in $(seq 1 50); do
    token=$(/opt/driver/sql.sh -readonly "$HOME/.agent-director/state.db" \
      "SELECT request_token FROM permission_requests
       WHERE claude_instance_id='$id' AND decision IS NULL
       ORDER BY request_id DESC LIMIT 1;")
    [ -n "$token" ] && break
    sleep 0.1
done
if [ -z "$token" ]; then
    echo "FAIL: no open permission_requests row for $id (hook never upserted)"; exit 1
fi

agent-director decide --claude-instance-id "$id" --request-token "$token" --decision allow >/dev/null
# --wait exits with the hook's exit status: set -e fails the case unless 0.
/opt/driver/pane-hook.sh --wait "$job" >/dev/null

# Second decide AFTER the hook has exited — reuse the SAME request_token
# so it targets the row the first decide already wrote, tripping the
# IS-NULL guard.
stderr_file=$(mktemp)
if agent-director decide --claude-instance-id "$id" --request-token "$token" --decision deny 2>"$stderr_file" >/dev/null; then
    echo "FAIL: second decide exited 0; want ErrAlreadyDecided"; exit 1
fi
err=$(jq -r '.err_name' "$stderr_file")
if [ "$err" != "ErrAlreadyDecided" ]; then
    echo "FAIL: err_name=$err; want ErrAlreadyDecided"; exit 1
fi
echo "relay-4 ok: second decide → ErrAlreadyDecided"
```
