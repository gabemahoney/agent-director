# spawn-22: a SessionStart that arrives before the identity write waits for it and applies

Maps to Epic `t1.h98.ve` (Plan `b.h98`, hook questions), Task
`t2.h98.ve.7p`, Subtask `t3.h98.ve.7p.su` (SRD SR-22.9 "SessionStart
before the identity write", SR-13.4, SR-14; PRD AC-HOOK-05). The pane's
process starts as soon as tmux creates the pane, but agent-director
records the pane only after it has read the create's reply. A SessionStart
that arrives in that window finds a `pending` row with no pane. It waits,
re-reading the row every 250 ms, for as long as the row stays pending
with no pane and inside its pending grace period (launch start +
`pending_grace_seconds`, default 60 s). Then it makes its ordinary gated
write. So the SessionStart applies once the identity lands, with no
`ad.hook.ignored` `no_pane_recorded`. Without the wait, this case fails
with `no_pane_recorded`, and the row stays `pending`.

## Setup

Per-case DB-reset has already wiped `~/.agent-director/state.db`. The
container has `agent-director`, `tmux`, `sqlite3` and `jq` on PATH, plus
two driver assets:

- `/opt/driver/delay-create-tmux/tmux` (`test/driver/delay-create-tmux/tmux`)
  passes every call through to `/usr/bin/tmux`. For `new-session` it holds
  the reply back for 2 s, which is inside the 5 s create timeout. It then
  appends `<created ns> <released ns> <exit status>` to `DELAY_CREATE_LOG`
  and releases the reply.
- `/opt/driver/early-hook-claude/claude`
  (`test/driver/early-hook-claude/claude`) is the pane process. It
  records its pid and its start time (`started`). It then runs
  `agent-director hook` at once, as its own direct child, with a
  SessionStart payload whose session id is a fresh uuid. It records the
  hook's end time (`ended`) and exit status (`rc`) and then `exec`s an
  interactive bash. Its files go in `$EARLY_HOOK_DIR/<instance id>/`,
  where `EARLY_HOOK_DIR` defaults to `/tmp/early-hook-claude`. The case
  sets it with `--extra-env`, which puts it in the session's environment.

The spawn runs with
`PATH=/opt/driver/delay-create-tmux:/opt/driver/early-hook-claude:$PATH`
prefixed. agent-director runs `tmux` from its PATH, and tmux looks `claude`
up on that same PATH. `DELAY_CREATE_LOG` is set to a file in the case's
own temp dir. The name does not start with `AGENT_DIRECTOR_`, so it
reaches the tmux client. The stand-in `claude` in
`/opt/driver/stand-in-claude/` and `pane-hook.sh` are not used.

`~/.agent-director/ad-trail.jsonl` is not reset between cases, so every
trail check selects records by this spawn's instance id.

## Steps

1. Run the spawn with both prefixes, `DELAY_CREATE_LOG` set and
   `--extra-env EARLY_HOOK_DIR=<case temp dir>/early`, and capture
   `claude_instance_id`. Record the wall clock (`date +%s%N`) as
   soon as the spawn returns.
2. Wait (bounded, 20 s) for the stand-in's `rc` file.
3. Read the create log line, and the stand-in's `pid`, `session_id`,
   `started`, `ended`, `out` and `err`.
4. Read every trail record whose `claude_instance_id` is the id.
5. `agent-director status --claude-instance-id <id>` and `get`. Read the
   row's `pid` and `pane_pid` with a read-only `sqlite3` SELECT.
6. Compare the hook's end time with the release time.

## Pass criteria

- Step 1: exit 0; non-empty `claude_instance_id`.
- Step 2: `rc` arrives, and the hook exited 0 with empty stdout and
  stderr.
- Step 3: the create log has exactly one line, with exit status 0, and
  `released - created >= 1.5 s`. The order is
  `started < released <= spawn returned`: the hook started before the
  create reply was released.
- Step 4: exactly one `ad.hook.fired`, with `event_name` `SessionStart`
  and `upsert_outcome` `updated`, and zero `ad.hook.ignored`. That means
  no `no_pane_recorded`; without the wait, this is the check that fails,
  and its message shows the `no_pane_recorded` record.
- Step 5: `state` = `waiting`. `get` shows `claude_session_id` = the
  stand-in's session id. `pid` = `pane_pid` = the stand-in's pid: the
  hook's parent is the pane process, and the SessionStart recorded it.
- Step 6: `released < ended`: the hook waited for the reply and the
  identity write before it ended.

## Script

```bash
set -euo pipefail

work="$(mktemp -d)"
trap 'rm -rf "$work"' EXIT
log="$work/create.log"
early="$work/early"
trail="$HOME/.agent-director/ad-trail.jsonl"

fail() {
    echo "FAIL: $*" >&2
    exit 1
}

# Step 1: the spawn, with the delayed-create tmux and the early stand-in.
spawn_out="$(PATH="/opt/driver/delay-create-tmux:/opt/driver/early-hook-claude:$PATH" \
    DELAY_CREATE_LOG="$log" \
    agent-director spawn --cwd /tmp --extra-env "EARLY_HOOK_DIR=$early")"
returned="$(date +%s%N)"
id="$(printf '%s' "$spawn_out" | jq -r '.claude_instance_id')"
[ -n "$id" ] && [ "$id" != "null" ] || fail "no claude_instance_id in: $spawn_out"

# Step 2: wait (bounded) for the stand-in's hook to exit.
d="$early/$id"
rc=""
for _ in $(seq 1 200); do
    if [ -s "$d/rc" ]; then
        rc="$(cat "$d/rc")"
        [[ "$rc" =~ ^[0-9]+$ ]] && break
        rc=""
    fi
    sleep 0.1
done
[ -n "$rc" ] || fail "no hook exit status in $d after 20s: $(ls -A "$d" 2>&1 | tr '
' ' ')"
[ "$rc" -eq 0 ] || fail "hook exited $rc; stderr: $(cat "$d/err")"
[ ! -s "$d/out" ] || fail "hook wrote stdout: $(head -c 300 "$d/out")"
[ ! -s "$d/err" ] || fail "hook wrote stderr: $(cat "$d/err")"

# Step 3: the hook started before the create reply was released.
[ -f "$log" ] || fail "no create log at $log (the delayed-create tmux did not run)"
[ "$(wc -l <"$log")" -eq 1 ] || fail "want 1 delayed create, got: $(cat "$log")"
read -r created released create_rc <"$log"
[ "$create_rc" -eq 0 ] || fail "the create exited $create_rc"
started="$(cat "$d/started")"
ended="$(cat "$d/ended")"
standin_pid="$(cat "$d/pid")"
sid="$(cat "$d/session_id")"
[ "$((released - created))" -ge 1500000000 ] || fail "reply held back only $((released - created)) ns"
[ "$started" -lt "$released" ] || fail "hook started at $started, not before the reply was released at $released"
[ "$released" -le "$returned" ] || fail "reply released at $released after the spawn returned at $returned"

# Step 4: one ad.hook.fired and no ad.hook.ignored for the id.
[ -f "$trail" ] || fail "no trail file at $trail"
jq -c --arg x "$id" 'select(.claude_instance_id == $x)' "$trail" >"$work/records"
ignored="$(jq -c 'select(.event == "ad.hook.ignored")' "$work/records")"
[ -z "$ignored" ] \
    || fail "want no ad.hook.ignored for $id, got reason(s): $(printf '%s
' "$ignored" | jq -r '.reason' | tr '
' ' ')"
fired="$(jq -c 'select(.event == "ad.hook.fired")' "$work/records")"
[ "$(printf '%s
' "$fired" | grep -c .)" -eq 1 ] || fail "want 1 ad.hook.fired for $id: $(cat "$work/records")"
printf '%s' "$fired" | jq -e '.event_name == "SessionStart" and .upsert_outcome == "updated"' >/dev/null \
    || fail "ad.hook.fired does not match: $fired"

# Step 5: the row is waiting and records the stand-in as pid and pane_pid.
state="$(agent-director status --claude-instance-id "$id" | jq -r '.state')"
[ "$state" = "waiting" ] || fail "state = $state; want waiting"
got_sid="$(agent-director get --claude-instance-id "$id" | jq -r '.claude_session_id')"
[ "$got_sid" = "$sid" ] || fail "claude_session_id = $got_sid; want $sid"
pids="$(/opt/driver/sql.sh -readonly "$HOME/.agent-director/state.db" \
    "SELECT COALESCE(pid, 'NULL') || '|' || COALESCE(pane_pid, 'NULL') FROM spawns WHERE claude_instance_id = '$id';")"
[ "$pids" = "$standin_pid|$standin_pid" ] || fail "pid|pane_pid = $pids; want $standin_pid|$standin_pid (the stand-in)"

# Step 6: the hook ended only after the reply was released.
[ "$released" -lt "$ended" ] || fail "hook ended at $ended, before the reply was released at $released"

echo "spawn-22 ok: hook started $(( (released - started) / 1000000 )) ms before the create reply was released and ended $(( (ended - released) / 1000000 )) ms after; state=waiting pid=pane_pid=$standin_pid; 1 ad.hook.fired, 0 ad.hook.ignored for $id"
```
