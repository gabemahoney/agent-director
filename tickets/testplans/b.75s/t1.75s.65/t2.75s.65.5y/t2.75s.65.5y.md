# relay-1: allow decision round-trip

Maps to Epic 10 AC #2. The full happy-path: spawn with relay_mode=on,
PermissionRequest hook starts polling, orchestrator calls `decide
--decision=allow --reason ok`, hook's stdout carries the allow envelope.

## Setup

Per-case DB-reset. The hook is invoked manually with a synthesized
PermissionRequest payload on stdin and `AGENT_DIRECTOR_RELAY_MODE=on`
in env.

## Steps

1. Seed a Spawn row with relay_mode=on via sqlite3.
2. Background-launch `agent-director hook` with the synthesized
   payload and the relay env vars. Capture stdout to a tempfile.
3. Sleep briefly to let the hook reach its polling state.
4. `decide --claude-instance-id <id> --decision allow --reason "ok"`.
5. Wait for the hook process to exit.
6. Parse its stdout: behavior=allow, message=ok.

## Pass criteria

- Hook exits 0.
- decide exits 0.
- Hook stdout is a JSON envelope with behavior=allow and message=ok.

## Script

```bash
set -euo pipefail
trap 'if [ -n "${hook_pid:-}" ]; then kill "$hook_pid" 2>/dev/null || true; fi' EXIT
sqlite3 "$HOME/.agent-director/state.db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name, relay_mode)
   VALUES ('id-r1', 'waiting', '/tmp', 'cd-r1', 'on');"

hook_out=$(mktemp)
( printf '%s' '{"hook_event_name":"PermissionRequest","tool_name":"Bash","tool_input":{"cmd":"echo"}}' \
  | AGENT_DIRECTOR_RELAY_MODE=on \
    AGENT_DIRECTOR_INSTANCE_ID=id-r1 \
    agent-director hook >"$hook_out" 2>/dev/null ) &
hook_pid=$!

# decide now REQUIRES --request-token. The backgrounded hook mints a
# UUIDv4 token and UPSERTs the open permission_requests row; poll the DB
# for that token (decision IS NULL) before deciding.
token=""
for _ in $(seq 1 50); do
    token=$(sqlite3 "$HOME/.agent-director/state.db" \
      "SELECT request_token FROM permission_requests
       WHERE claude_instance_id='id-r1' AND decision IS NULL
       ORDER BY request_id DESC LIMIT 1;")
    [ -n "$token" ] && break
    sleep 0.1
done
if [ -z "$token" ]; then
    echo "FAIL: no open permission_requests row for id-r1 (hook never upserted)"; exit 1
fi

agent-director decide --claude-instance-id id-r1 --request-token "$token" --decision allow --reason "ok" >/dev/null

wait "$hook_pid"
behavior=$(jq -r '.hookSpecificOutput.decision.behavior' "$hook_out")
message=$(jq -r '.hookSpecificOutput.decision.message' "$hook_out")

# The envelope's message mirrors the DB decision_reason (internal/hook/
# polling.go:144 → EncodeDecision). decide() discards --reason and writes
# an EMPTY decision_reason for allow (pkg/api/decide.go), so an allow
# envelope carries NO message field — jq surfaces that as "null".
if [ "$behavior" != "allow" ] || [ "$message" != "null" ]; then
    echo "FAIL: envelope behavior=$behavior message=$message; want allow/null (allow carries no message)"
    cat "$hook_out"; exit 1
fi
echo "relay-1 ok: allow round-trip → allow envelope (no message)"
```
