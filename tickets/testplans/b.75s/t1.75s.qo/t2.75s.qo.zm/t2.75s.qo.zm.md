# spawn-11: template agent_args flow through when no per-call args

Maps to bug b.qjk (template agent_args silently wiped when caller passes
nothing per-call after `--`). Regression guard: the CLI-level fix in
`cmd/agent-director/spawn_cmd.go` (only assign `p.AgentArgs` when
`len(fs.Args()) > 0`).

## Setup

Per-case DB-reset has already wiped `~/.agent-director/state.db`. The
container has `agent-director`, `tmux`, `sqlite3`, `jq` on PATH.

## Steps

1. Create a template with `agent_args` baked in:
   `agent-director make-template --name spawn-11-tpl --agent-args "--model" --agent-args "opus"`
2. Spawn using that template with NO trailing `-- ...` args:
   `agent-director spawn --cwd /tmp --template spawn-11-tpl` → capture `instance_id`.
3. `agent-director get --instance-id <id>` → assert `agent_args` is `["--model", "opus"]`.

## Pass criteria

- Step 1 exits 0.
- Step 2 exits 0 with non-empty `instance_id`.
- Step 3: `agent_args` equals `["--model", "opus"]` — NOT empty/null.
  The regression (b.qjk) produced `null` / `[]` here.

```bash
set -euo pipefail
agent-director make-template --name spawn-11-tpl --agent-args "--model" --agent-args "opus"
spawn_out="$(agent-director spawn --cwd /tmp --template spawn-11-tpl)"
id="$(printf '%s' "$spawn_out" | jq -r '.instance_id')"
test -n "$id"
get_out="$(agent-director get --instance-id "$id")"
model_arg="$(printf '%s' "$get_out" | jq -r '.agent_args[0]')"
opus_arg="$(printf '%s' "$get_out" | jq -r '.agent_args[1]')"
test "$model_arg" = "--model"
test "$opus_arg" = "opus"
echo "spawn-11 ok: id=$id agent_args=[--model,opus]"
```
