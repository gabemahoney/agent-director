# spawn-18: a plain spawn whose explicit name is held ends its new row and says who holds the name

Maps to Epic `t1.h98.9h` (Plan `b.h98`, held-name docs and path), Task
`t2.h98.9h.hw`, Subtask `t3.h98.9h.hw.ru`, and Docker case spawn-18 (SRD
SR-20.9, GAP 3, PO 2026-09-27 HELD; SR-9.4; SR-1.4's "after \"duplicate
session\"" row; SR-3.10; SR-14 `ad.launch.name_held`). A plain `spawn`
with an explicit instance id and an explicit session name passes the label
scan (no session carries a label of this store naming its id), inserts its
`pending` row, and tmux's create answers "duplicate session" because
another session already has the name. The spawn ends its new row at once,
looks the name up once, and refuses with `ErrTmuxSessionConflict`, saying
by the holder's label whose session it is. The holder is never killed,
labelled or typed into. Exactly one `ad.launch.name_held` trail record is
written per launch, carrying the by-hand commands (for humans reading the
trail, never in the description).

Part 1: the holder was made in the container with no `@ad_owner` label
("no valid instance id", with the README "Operator actions" pointer).
Part 2: the holder is another row's session, labelled with that row's id
Y and this store's id ("a different instance id", another row's agent
that must not be ended, no pointer, and never Y's id).

## Setup

Per-case DB-reset has wiped `~/.agent-director/state.db` and killed any
`cd-*` tmux sessions. The container has `agent-director`, `tmux`,
`sqlite3` and `jq` on PATH; plain `tmux` reaches the same default socket
agent-director resolves from `TMUX` / `TMUX_TMPDIR`. The holders run
`sleep` under names outside `cd-` (`sp18-held`, `sp18-y`), so the script
records the live session ids first and, on exit, kills any session that
was not there before (by its `$N` id); a regression cannot leak a session
into later cases. The instance ids are `sp18a-<uuid>` (A), `sp18b-<uuid>`
(B) and `sp18y-<uuid>` (Y), so no earlier case's session or trail record
can carry them. The trail is not reset between cases, so records are
selected by A's and B's ids.

No real `claude` runs: neither spawn reaches a launch (its create answers
"duplicate session"), Y's row is seeded with `sqlite3` and Y's session
runs `sleep`. As a guard against a regression that does launch, the script
unsets `ANTHROPIC_API_KEY` and `CLAUDE_CODE_OAUTH_TOKEN` and runs each
spawn with the stand-in `claude` (`/opt/driver/stand-in-claude`) first on
PATH.

## Steps

1. Read this store's id with `sqlite3` from `store_meta` (`key =
   'store_id'`).
2. Part 1: create a session named `sp18-held` running `sleep 3600` with no
   `@ad_owner` label, and read its tmux id `$N` and the server's socket
   path.
3. `agent-director spawn --cwd /tmp --tmux-session-name sp18-held
   --claude-instance-id A`, and read the last JSON line on stderr.
4. `agent-director get --claude-instance-id A`; check the holder still
   runs by `$N` and still has no label.
5. Part 2: create a session named `sp18-y` running `sleep 3600`, read its
   `$N`, and label it as Y's current launch with `tmux set-option -t <$N>
   @ad_owner "ad1 <Y token> <$N> Y <store id>"` (five fields; the token
   16 lowercase hex characters). Seed Y's `pending` row with `sqlite3`
   (spawn-20's pattern): recorded name `sp18-y`, `launch_started_at` now
   in milliseconds, `launch_token` Y's token, `tmux_socket` the server's
   socket path. Save Y's full row.
6. `agent-director spawn --cwd /tmp --tmux-session-name sp18-y
   --claude-instance-id B`, and read the last JSON line on stderr.
7. `agent-director get --claude-instance-id B`; check Y's holder still
   runs by `$N` with its label unchanged, and read Y's full row again.
8. Read the trail file `~/.agent-director/ad-trail.jsonl` and select the
   `ad.launch.name_held` records whose `claude_instance_id` is A, then B.

## Pass criteria

- Step 1: the store id is 16 lowercase hex characters.
- Steps 3 and 6: the spawn exits 1; `err_name ==
  "ErrTmuxSessionConflict"`; the decoded `err_description` contains the
  holder's quoted name and tmux id (`"sp18-held" ($N)`, `"sp18-y" ($N)`)
  and `the new row was ended`. It names no command: none of
  `kill-session`, `kill-server`, `kill-pane`, `attach-session`,
  `show-options`, `tmux -u`, `tmux -S`, `agent-director kill`,
  `--include-finished`, `agent-director-admin`, `kill-finished` (a bare
  `tmux ` is allowed: the prose says "tmux session"). It carries no
  store id.
  - Step 3 also contains `no valid instance id` and `Operator actions`.
  - Step 6 also contains `a different instance id`; it contains no
    `Operator actions`, and neither Y's id nor Y's token.
- Steps 4 and 7: `get` shows `state == "ended"` and no
  `launch_started_at`; `tmux has-session -t <$N>` succeeds for the holder.
  Part 1's holder still has no `@ad_owner`; Y's holder's `@ad_owner` is
  unchanged; Y's row is byte-identical to the one saved in step 5.
- Step 8: exactly one `ad.launch.name_held` record for A and exactly one
  for B. Each has `source == "ad_spawn"`, `launch == "spawn"`,
  `outcome == "ErrTmuxSessionConflict"`, `row_result == "ended"`,
  `carries_this_id == false`, `tmux_session_id` the holder's `$N`, and an
  `attach_command` and `end_command` that each contain `-S '<socket>'` and
  `'<$N>'`. B's record contains neither Y's id nor Y's token.

## Script

```bash
set -euo pipefail

db="$HOME/.agent-director/state.db"
trail="$HOME/.agent-director/ad-trail.jsonl"
a="sp18a-$(cat /proc/sys/kernel/random/uuid)"
b="sp18b-$(cat /proc/sys/kernel/random/uuid)"
y="sp18y-$(cat /proc/sys/kernel/random/uuid)"
name_a=sp18-held
name_y=sp18-y
# Y's launch token: 16 lowercase hex, never minted by this run.
y_token=0123456789abcdef

# Guard: should a spawn ever launch, it gets the stand-in, with no
# credentials to report in with.
unset ANTHROPIC_API_KEY CLAUDE_CODE_OAUTH_TOKEN

fail() {
    echo "FAIL: $*" >&2
    exit 1
}

session_ids() {
    tmux ls -F '#{session_id}' 2>/dev/null || true
}
before="$(session_ids)"
cleanup() {
    local sid
    for sid in $(session_ids); do
        case " $(printf '%s ' $before)" in
            *" $sid "*) ;;
            *) tmux kill-session -t "$sid" 2>/dev/null || true ;;
        esac
    done
}
trap cleanup EXIT

last_json() {
    printf '%s
' "$1" | awk '/^\{/{ln=$0} END{print ln}'
}

label_of() {
    tmux show-options -t "$1" -v @ad_owner 2>/dev/null || true
}

# held_spawn ID NAME: a plain spawn of ID under NAME that must exit 1 with
# ErrTmuxSessionConflict; sets desc to the decoded description.
held_spawn() {
    local id="$1" name="$2" err code envelope got
    set +e
    err="$(PATH="/opt/driver/stand-in-claude:$PATH" agent-director spawn \
        --cwd /tmp --tmux-session-name "$name" --claude-instance-id "$id" \
        2>&1 >/dev/null)"
    code=$?
    set -e
    [ "$code" -eq 1 ] || fail "spawn of $id under $name exited $code; want 1; stderr: $err"
    envelope="$(last_json "$err")"
    got="$(printf '%s' "$envelope" | jq -r '.err_name')"
    [ "$got" = "ErrTmuxSessionConflict" ] \
        || fail "spawn of $id: err_name=$got; want ErrTmuxSessionConflict; stderr: $err"
    desc="$(printf '%s' "$envelope" | jq -r '.err_description')"
}

# has_all TEXT WANT...: TEXT contains every WANT.
has_all() {
    local text="$1" want
    shift
    for want in "$@"; do
        case "$text" in
            *"$want"*) ;;
            *) fail "[$want] missing from: $text" ;;
        esac
    done
}

# has_none TEXT FORBIDDEN...: TEXT contains no FORBIDDEN.
has_none() {
    local text="$1" forbidden
    shift
    for forbidden in "$@"; do
        case "$text" in
            *"$forbidden"*) fail "[$forbidden] found in: $text" ;;
        esac
    done
}

no_command=(kill-session kill-server kill-pane attach-session show-options
    "tmux -u" "tmux -S" "agent-director kill" --include-finished
    agent-director-admin kill-finished)

# row_ended ID: get shows ID ended with no launch start.
row_ended() {
    local got
    got="$(agent-director get --claude-instance-id "$1" \
        | jq -r '[.state, (.launch_started_at // "none")] | join("|")')"
    [ "$got" = "ended|none" ] \
        || fail "get of $1: [state|launch_started_at] = [$got]; want [ended|none]"
}

# name_held_record ID SID: the one ad.launch.name_held record for ID, naming
# holder SID with -S and SID in both by-hand commands; printed on stdout.
name_held_record() {
    local id="$1" sid="$2" recs n rec cmd
    [ -f "$trail" ] || fail "no trail file at $trail"
    recs="$(jq -c --arg x "$id" \
        'select(.event == "ad.launch.name_held" and .claude_instance_id == $x)' \
        "$trail")"
    n="$(printf '%s
' "$recs" | grep -c . || true)"
    [ "$n" -eq 1 ] || fail "want 1 ad.launch.name_held for $id, got $n: $recs"
    rec="$recs"
    got="$(printf '%s' "$rec" | jq -r \
        '[.source, .launch, .outcome, .row_result, (.carries_this_id | tostring), .tmux_session_id] | join("|")')"
    [ "$got" = "ad_spawn|spawn|ErrTmuxSessionConflict|ended|false|$sid" ] \
        || fail "name_held for $id: [$got]; want [ad_spawn|spawn|ErrTmuxSessionConflict|ended|false|$sid]: $rec"
    for cmd in attach_command end_command; do
        got="$(printf '%s' "$rec" | jq -r --arg k "$cmd" '.[$k] // ""')"
        case "$got" in
            *"-S '$socket'"*"'$sid'"*) ;;
            *) fail "name_held $cmd for $id lacks -S '$socket' and '$sid': [$got]" ;;
        esac
    done
    printf '%s' "$rec"
}

# Step 1: this store's id.
store_id="$(/opt/driver/sql.sh "$db" "SELECT value FROM store_meta WHERE key = 'store_id';")"
[[ "$store_id" =~ ^[0-9a-f]{16}$ ]] \
    || fail "store_meta store_id is not 16 lowercase hex: [$store_id]"

# Part 1, step 2: an unlabelled session holds sp18-held.
sid_a="$(tmux new-session -d -s "$name_a" -P -F '#{session_id}' sleep 3600)"
socket="$(tmux display-message -p -t "$sid_a" '#{socket_path}')"
[ -n "$socket" ] || fail "could not read the tmux socket path"
[ -z "$(label_of "$sid_a")" ] || fail "new session $sid_a already has a label"

# Step 3: spawn of A under the held name.
held_spawn "$a" "$name_a"
has_all "$desc" "\"$name_a\" ($sid_a)" "no valid instance id" \
    "the new row was ended" "Operator actions"
has_none "$desc" "${no_command[@]}" "$store_id"

# Step 4: A's row ended; the holder still runs, still unlabelled.
row_ended "$a"
tmux has-session -t "$sid_a" 2>/dev/null \
    || fail "holder $sid_a no longer runs after the spawn of $a"
[ -z "$(label_of "$sid_a")" ] || fail "holder $sid_a was labelled: [$(label_of "$sid_a")]"

# Part 2, step 5: Y's session, labelled as Y's launch, and Y's seeded row.
sid_y="$(tmux new-session -d -s "$name_y" -P -F '#{session_id}' sleep 3600)"
y_label="ad1 $y_token $sid_y $y $store_id"
tmux set-option -t "$sid_y" @ad_owner "$y_label"
started_ms="$(date +%s%3N)"
/opt/driver/sql.sh "$db" \
  "INSERT INTO spawns (claude_instance_id, state, cwd, tmux_session_name,
       relay_mode, launch_started_at, launch_token, tmux_socket)
   VALUES ('$y', 'pending', '/tmp', '$name_y', 'off', $started_ms,
       '$y_token', '$socket');"
y_row() {
    /opt/driver/sql.sh -separator '|' "$db" "SELECT * FROM spawns WHERE claude_instance_id = '$y';"
}
y_before="$(y_row)"
[ -n "$y_before" ] || fail "Y's seeded row is missing"

# Step 6: spawn of B under Y's name.
held_spawn "$b" "$name_y"
has_all "$desc" "\"$name_y\" ($sid_y)" "a different instance id" \
    "the new row was ended"
has_none "$desc" "${no_command[@]}" "$store_id" "Operator actions" \
    "$y" "$y_token"

# Step 7: B's row ended; Y's session and row untouched.
row_ended "$b"
tmux has-session -t "$sid_y" 2>/dev/null \
    || fail "Y's session $sid_y no longer runs after the spawn of $b"
[ "$(label_of "$sid_y")" = "$y_label" ] \
    || fail "Y's label changed: [$(label_of "$sid_y")]; want [$y_label]"
[ "$(y_row)" = "$y_before" ] \
    || fail "Y's row changed: [$(y_row)]; was [$y_before]"

# Step 8: one ad.launch.name_held per launch.
name_held_record "$a" "$sid_a" >/dev/null
rec_b="$(name_held_record "$b" "$sid_y")"
has_none "$rec_b" "$y" "$y_token"

echo "spawn-18 ok: $a held by unlabelled $sid_a, $b held by Y's $sid_y; rows ended; holders run; one name_held each"
```
